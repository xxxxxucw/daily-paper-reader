## 摘要
在过去十年中，千米级干涉引力波探测器已观测到数百例致密双星并合，其中大多数为双黑洞。然而，这些数据以噪声为主，人们使用多种独立的搜索算法（流水线）来提高灵敏度和稳健性。我们没有采用选择最显著流水线输出的标准做法，而是利用基于共形预测的框架整合所有流水线的输出，为候选事件提供统计上严格的置信度估计。虽然整合流水线提高了灵敏度和排序稳健性，但它需要一个有原则的统计框架，在数据特性随观测运行演变时仍保持有效。一个关键挑战是用于训练和校准的模拟数据集与用于测试的真实、无标签观测数据之间存在分布偏移，这可能使覆盖保证失效并使置信度估计产生偏差。在这项工作中，我们通过将似然比重加权纳入我们的共形预测框架来应对这一挑战，以考虑协变量偏移。使用包含模拟信号的模拟数据集，我们证明加权共形预测在协变量偏移下恢复了良好校准的覆盖，并提高了接近探测阈值事件的置信度，从而找回原本会被遗漏的真实信号。

## Abstract
In the last decade, kilometre-scale interferometric gravitational-wave detectors have observed hundreds of compact binary mergers, the majority of which are binary black holes. However, the data are noise-dominated, and multiple independent search algorithms (pipelines) are used to enhance sensitivity and improve robustness. Rather than the standard approach of selecting the most significant pipeline output, we combine the outputs from all pipelines using a conformal prediction-based framework to provide statistically rigorous confidence estimates for candidate events. While combining pipelines improves sensitivity and ranking robustness, it requires a principled statistical framework that remains valid as data properties evolve across observing runs. A key challenge is distribution shifts between simulated datasets used for training and calibration and the real, unlabelled, observations used for testing, which can invalidate coverage guarantees and bias confidence estimates. In this work, we address this challenge by incorporating likelihood-ratio reweighting into our conformal prediction framework to account for covariate shift. Using mock datasets containing simulated signals, we demonstrate that weighted conformal prediction restores well-calibrated coverage under covariate shift and increases the confidence of events near the detection threshold, recovering true signals that would otherwise be missed.

## 1. 核心问题与整体含义

- **研究背景**：千米级干涉引力波探测器（LIGO-Virgo-KAGRA）已累计观测到近 400 例致密双星并合信号，但数据以噪声为主。为提升灵敏度与稳健性，LVK 合作组并行运行多个独立搜索流程（pipeline），包括 GstLAL、MBTA、PyCBC（基于匹配滤波）和 CWB（基于相干性的无模板搜索）。
- **现有做法的局限**：当前标准做法是取所有流程中**最小 FAR（虚警率）** 作为最终显著性判据，只要有一个流程报告 FAR 低于 1/年即视为显著。该策略简单保守，但丢弃了流程间的互补信息，且各流程 FAR 并不独立，无法直接使用 Fisher 法或调和平均等经典 p 值组合方法。
- **前期工作**：Ashton et al. (2026) 提出用机器学习分类器学习流程间相关性，并辅以共形预测（CP）提供统计严格的置信度估计；使用条件置信度（conditional confidence）作为可解释的显著性度量。
- **核心挑战**：训练与校准依赖**模拟 mock 数据**，而测试应用于**真实无标签观测数据**，两者存在分布偏移（尤其是协变量偏移），会破坏 CP 的覆盖保证并偏差置信度估计。作者将这一差异建模为流水线输出的分布偏移问题。
- **整体含义**：本文旨在通过**加权共形预测（Weighted CP）** 校正协变量偏移，使框架在跨观测运行、数据属性演变时仍保持统计有效性，并提升近阈值事件的探测灵敏度。

## 2. 方法论

### 2.1 基础框架（继承自 Ashton et al. 2026）

- **输入特征**：四个流程报告的 IFAR（取对数 log₁₀ IFAR = log₁₀(1/FAR)）与 SNR，缺失值以 0 填充。
- **分类器**：逻辑回归（LR），输出信号概率 p₁(X)，训练用二元交叉熵损失。
- **非一致性度量**：sᵧ(X) = 1 − pᵧ(X)，其中 y ∈ {0,1} 表示噪声/信号。
- **Mondrian（标签条件）CP**：按类别分组计算校准分位数，保证类内条件覆盖：
  - 校正分位数 q̂ᵧ_α = sᵧ 排序后第 ⌈(Nᵧ+1)(1−α)⌉ 个值；
  - 预测集 Γα(X′) = {y : sᵧ(X′) ≤ q̂ᵧ_α}；
  - 有限样本保证：1−α ≤ Pr(Y′∈Γα | Y′=y) ≤ 1−α + 1/(Nᵧ+1)。
- **条件置信度**：conf_{Y=1}(X) = max{α : 1 ∈ Γα(X)}，即在信号标签仍被纳入预测集时的最大误差率；对其设阈值（如 0.5）即可得到可控纯度的候选目录。

### 2.2 协变量偏移下的加权 CP

- **问题设定**：校准与测试分布不满足可交换性，具体为**标签条件协变量偏移**：
  P^test_{X|Y=y} ≠ P^cal_{X|Y=y}，y = 0,1。
- **理想校正**：定义条件似然比 wᵧ(X) = dP̃_{X|Y=y}/dP_{X|Y=y}，对校准点加权即可恢复有效性。
- **实际困难**：条件似然比需要测试标签才能一致估计，而这在真实场景中不可得。
- **权重估计**：训练二分类器（随机森林）区分校准/测试样本，似然比估计为 ŵᵧ(X) = p̂ᵧ,C=1(X) / (1 − p̂ᵧ,C=1(X))。
- **四种近似策略**（本文的方法论贡献）：
  1. **Marginal（边缘）** ：用全部测试样本与全部校准样本估计 dP̃_X/dP_X；
  2. **Semi-conditional（半条件）** ：用全部测试样本 + 仅标签 y 的校准样本；
  3. **Classifier conditional（分类器条件）** ：用信号分类器预测 Ŷ = 1(p₁(X) ≥ 0.5) 作伪标签；
  4. **Maximum-log₁₀ IFAR conditional**：用 max log₁₀ IFAR ≳ 7.5（对应 FAR = 1/年）作代理标签。
- **加权分位数**：
  - 归一化校准权重 p^{w,y}_i(X′) = w_cal(Xᵢ) / (Σⱼ w_cal(Xⱼ) + w_test(X′))；
  - 测试点权重 p^{w,y}_test(X′) = w_test(X′) / (Σⱼ w_cal(Xⱼ) + w_test(X′))；
  - 加权分位数 q̂^{w,y}_α(X′) = Quantile(1−α; Σᵢ p^{w,y}_i δ_{sᵧᵢ} + p^{w,y}_test δ_∞)；
  - 加权预测集 Γ^w_α(X′) = {y : sᵧ(X′) ≤ q̂^{w,y}_α(X′)}。
- **有效样本量**：n̂ᵧ = (Σ w_cal)² / Σ w_cal²，用于衡量加权后等效校准样本数，偏移越强则 n̂ᵧ 越小、覆盖方差越大。
- **理论说明**：若条件似然比已知，加权 CP 可恢复有效覆盖；但近似策略引入的偏差无法在无额外假设下界定，因此本文定位为**实证研究**，将一般分布偏移下的 CP 问题约化为可操作的工程问题。

## 3. 实验设计

### 3.1 数据集

- **MDC（Mock Data Challenge）** ：第四次观测运行前数据集，40 天数据，9948 个候选（5910 个信号），按 80%/10%/10% 划分为训练/校准/测试集。
- **LLPIC（Low-Latency Production Integration Challenge）** ：第四次观测运行期间数据集，7 天数据，1204 个候选（534 个信号），**仅用作测试集**，模拟预训练框架应用于真实数据的场景。

### 3.2 两组实验场景

1. **受控协变量偏移（Controlled Covariate Shift）** ：
   - 对测试集按特征相关权重重采样，仅改变边缘分布 P_X，保持 P_{Y|X} 不变；
   - 针对某一选定流程的 IFAR 与 SNR 同时加权；
   - 两个方向：低值区（第 10–30 百分位）和高值区（第 70–90 百分位）；
   - 偏移强度：2、5、10（1 表示无偏移），共 6 个偏移测试集。
2. **未知偏移（Unknown Shift）** ：MDC 训练校准 → LLPIC 测试。

### 3.3 评估指标与基准

- **基准方法**：标准（未加权）Mondrian CP。
- **量化指标**：经验覆盖率（coverage）、条件置信度差 Δconf_{Y=1}、地球移动距离（EMD）、真阳性率（TPR）、假阳性率（FPR）。
- **偏移强度度量**：EMD（一阶 Wasserstein 距离），按特征逐维计算后取平均；未偏移测试与校准的 EMD 为 0.040。
