## 摘要
解释神经网络的预测是可信人工智能中的一个核心挑战。现有的解释方法，例如基于特征归因或最小充分集的方法，通常将输入特征视为独立的，当输入表现出结构化依赖时，这可能会产生误导性的解释。我们通过将解释形式化为Halpern-Pearl（HP）实际原因来解决这一问题，并使用布尔结构因果模型（SCM）对输入依赖进行建模。我们通过应用边界传播和分支定界技术来计算HP原因，同时提供完备性和最小性的形式保证。我们的实验表明，在可扩展性方面，我们显著优于暴力基线和ILP基线，并且随着图大小的增长优于启发式搜索，在搜索空间高达$2.3\times10^{13}$个候选（原因，偶然性）对的实例上，在SCM最多28个节点的情况下，在每实例180秒的预算内计算所有最小实际原因。在一个案例研究中，我们进一步表明，忽略输入依赖会夸大所报告原因的数量，其中14.9%在我们的SCM下是虚假的。

## Abstract
Explaining the predictions of neural networks is a central challenge in trustworthy AI. Existing explanation methods, such as those based on feature attribution or minimal sufficient sets, typically treat input features as independent, which can yield misleading explanations when inputs exhibit structured dependencies. We address this by formalizing explanations as Halpern-Pearl (HP) actual causes, modeling input dependencies using Boolean Structural Causal Models (SCMs). We compute HP causes by applying bound propagation and branch-and-bound techniques, while providing formal guarantees of completeness and minimality. Our experiments show that we substantially outperform brute-force and ILP baselines in scalability, and outperform heuristic search as graph size grows, computing all minimal actual causes on instances with search spaces of up to $2.3\times10^{13}$ candidate (cause, contingency) pairs, on SCMs with up to 28 nodes, within a 180s per-instance budget. In a case study, we further show that ignoring input dependencies inflates the number of reported causes, 14.9% of which are spurious under our SCM.

# 论文总结：Computing Actual Causes for Neural Network Predictions under Structured Causal Inputs

## 1. 论文的核心问题与整体含义

**研究动机**：现有的神经网络解释方法（如特征归因、最小充分集）通常隐含地假设输入特征之间相互独立，但在实际应用中，输入特征常常存在结构化的因果依赖关系（如医学症状与诊断、收入与现金流等）。忽略这些依赖关系会导致解释产生误导，甚至返回虚假的因果原因。

**核心问题**：如何在不忽略输入特征间结构化依赖的前提下，为神经网络预测计算**完备且最小**的实际原因（Actual Causes），并保证计算结果的形式化正确性。

**整体含义**：论文将神经网络解释形式化为 **Halpern–Pearl（HP）实际因果** 的计算问题，并采用**布尔结构因果模型（Boolean SCM）**建模输入依赖，从而在因果语义下给出可验证的解释。该方法在可扩展性上显著优于暴力搜索、ILP 和启发式搜索基线。

## 2. 论文提出的方法论

**核心思路**：将 HP 实际原因的计算问题转化为对“原因集合 × 偶然性集合”的搜索问题，并利用**区间边界传播（Interval Bound Propagation, IBP）**与**分支定界（Branch-and-Bound, BaB）**技术对搜索空间进行剪枝，从而避免逐个枚举所有候选原因与偶然性组合。

**关键技术细节**：

- **SCM 建模**：使用布尔 SCM 描述输入特征间的依赖，每个内生变量由结构方程决定，且方程可松弛为多线性函数，从而支持区间传播。
- **区域（Region）表示**：对于固定候选原因集合 C，将所有可能的偶然性（contingency）表示为“部分角色分配”区域，变量分为四种角色：**原因**、**偶然性**、**自然**、**未定**。
- **边界传播**：
  - 通过 SCM 将区域边界传播为各内生变量的区间；
  - 对 NOT、OR、AND、XOR 等布尔运算采用连续松弛（如 OR: a+b−ab），并利用单调性或四角评估获得紧密区间；
  - 再将特征区间通过 IBP（含 ReLU 层）传播为网络输出的下界 ℓ 和上界 h。
- **分支定界**：
  - 若输出区间完全落在接受集 S 内（ℓ 和 h 均满足 φ），则剪枝；
  - 若输出区间完全落在 S 之外（h < τ 或与 S 无交集），则确认该区域为原因；
  - 若区间不确定，则选择一个未定变量进行分裂，递归处理。
- **完备性与最小性保证**：
  - **AC1** 由实际输入满足 φ 保证；
  - **AC2** 由确认区域保证存在偶然性使得预测翻转；
  - **AC3** 通过按候选原因大小递增枚举并跳过已有原因的超集实现；
  - 对每个原因返回最小基数的偶然性（对应 Halpern 的“责任度”定义）。
- **最优性剪枝**：若某区域的已提交偶然性大小 ≥ 当前最优偶然性大小，则剪枝。

**算法流程**（文字描述）：
1. 按大小 k = 1, …, |V| 枚举候选原因集合 C；
2. 若 C 是已确认原因的真超集，则跳过（保证 AC3）；
3. 初始化区域 B0(C)（C 为原因，其余变量未定），使用队列进行 BFS；
4. 对每个区域计算 SCM 与 NN 的输出边界，根据边界进行确认、剪枝或分裂；
5. 若找到更小基数的偶然性，则更新当前最优；
6. 最终返回所有最小实际原因及其最小偶然性集合。

**复杂度**：最坏情况下需遍历 O(3^|V|) 个区域，与全枚举同阶，但实际中通过剪枝效率显著提升。

## 7. 优点

- **形式化保证**：同时保证原因的 HP 完备性、原因最小性（AC3）、偶然性最小性（责任度），并给出完整正确性证明。
- **结构感知**：显式建模输入依赖，避免独立假设导致的虚假解释。
- **高效剪枝**：区域化表示 + IBP 边界传播 + BaB 的剪枝策略，将搜索空间从全枚举的指数复杂度大幅压缩。
- **可扩展性**：在 28 节点、10^13 搜索空间内可达实时求解，远超 ILP 和启发式方法。
- **分支策略研究**：比较 7 种分支策略，验证 width_large 策略的显著优势（平均剪枝时解决 51.2% 未定节点，其余策略仅 3.7–16.9%）。
- **真实案例验证**：SNAP 案例展示了方法在真实法规与真实数据上的适用性，并量化了忽略依赖的代价。

## 8. 不足与局限

- **布尔 SCM 限制**：方法仅适用于布尔（二值）SCM，对连续变量无法保证穷举所有最小原因，论文也承认扩展到连续域是重要但困难的工作。
- **边界传播精度**：IBP 边界可能较松弛，虽然尝试了 β-CROWN，但未带来整体加速；数值容差内的小误差无法完全消除（论文已明确说明）。
- **实验对比公平性**：ILP 和 ACI 在不同设置下表现差异较大，部分对比场景（如 SNAP 案例中 BF 的 43.24s 与 CausEx BaB 的 4.60s）差异很大；ACI 在 SNAP 上 10/11 超时与节点实验中 n≤10 下最快形成鲜明对比，暗示其启发式对结构敏感。
- **SNAP 案例规模有限**：仅 11 个真实实例，且 SCM 是对法规的简化（忽略了扣除项、州豁免和特殊家庭情况），14.9% 虚假率是特定设置下的结果而非一般性估计。
