## 摘要
贝叶斯因果发现旨在确定因果理论的后验分布，这些理论被解释为解释观测数据的有向无环图（DAG）。所得的后验允许对这些理论中的认知不确定性进行系统性推理。然而，由于可识别性问题和有限的观测数据，找到这样的图是困难的。此外，在大量潜在DAG的背景下，精确逼近图上的后验具有挑战性。最近的贝叶斯方法已解决了其中一些挑战，但它们仍然有限，因为它们未能编码边之间的依赖关系，并且缺乏在搜索过程中将领域知识作为归纳偏置整合的原则性方法。为了克服这些局限性，我们提出了SVI-DAG，一种使用观测数据和先验信念进行贝叶斯因果发现的结构化变分推断方法，该方法使用归一化流来建模边之间的依赖关系，支持在DAG上进行富有表现力的多模态后验学习。为了减轻证据下界优化中的模式寻求行为并促进模式覆盖，我们使用斯坦变分梯度下降，通过在无环性空间中使用核来更新节点势。我们将SVI-DAG与5种最先进的贝叶斯DAG学习方法进行了评估，并在不确定性量化方面展示了优越的性能，同时在结构准确性方面保持竞争力。

## Abstract
Bayesian causal discovery seeks to determine the posterior distribution of causal theories, which are interpreted as directed acyclic graphs (DAGs) that explain the observed data. The resulting posterior allows systematic reasoning regarding epistemic uncertainty within these theories. Nonetheless, finding such graphs is difficult due to identifiability problems and limited observational data. Furthermore, precisely approximating posterior over graphs is challenging given vast range of potential DAGs. Recent Bayesian approaches have addressed some of these challenges, yet they remain limited as they fail to encode dependencies between edges, and lack principled ways to incorporate domain knowledge as inductive biases during the search process. To overcome these limitations, we propose SVI-DAG, a structured variational inference approach to Bayesian causal discovery using observational data and prior beliefs that uses normalizing flows to model dependencies between edges, supporting expressive and multimodal posterior learning over DAGs. To mitigate mode seeking behaviour in evidence lower bound optimization and promote mode coverage, we use stein variational gradient descent to update the node potentials using a kernel in acyclicity space. We evaluate SVI-DAG against 5 state-of-the-art Bayesian DAG learning methods and demonstrate superior performance in uncertainty quantification while remaining competitive in terms of structural accuracy.

## 论文核心问题与整体含义

贝叶斯因果发现（Bayesian causal discovery）旨在从观测数据中推断出能够解释数据的有向无环图（DAG）的后验分布，从而对因果结构中的认知不确定性（epistemic uncertainty）进行系统性推理。然而该任务面临三重核心挑战：

- **可识别性问题**：在纯观测数据下，真实 DAG 通常只能被识别到其马尔可夫等价类（MEC），存在方向模糊性；
- **组合爆炸**：合法 DAG 的数量随变量数超指数增长，精确后验逼近在计算上不现实；
- **现有方法局限**：主流贝叶斯 DAG 学习方法假设边之间相互独立，忽略了边间丰富的依赖关系；同时缺乏将领域知识作为归纳偏置融入搜索过程的机理性手段。

针对上述问题，本文提出 SVI-DAG——一种结构化变分推断（Structured Variational Inference）贝叶斯因果发现方法。其整体含义是：通过为**边对数几率（edge logits）** 构建条件归一化流来建模边间依赖，从而在 DAG 空间上实现表达性更强的多模态后验学习；同时提出一种自适应先验以注入领域知识，并通过 Stein 变分梯度下降（SVGD）在无环空间中更新节点势，缓解标准 ELBO 优化的模式寻求（mode-seeking）问题，提升模式覆盖与不确定性量化质量。

## 方法论

### 核心思想

SVI-DAG 将 DAG 结构学习转化为一个可微分的结构化变分推断问题。其关键组件包括：

1. **域信息先验（Domain-Informed Prior）**：在每条边的存在概率 πij 上引入 Beta 层次先验，使其能自适应地区分强先验（接近 0 或 1）与弱先验（接近 0.5）的信念；
2. **条件归一化流（Conditional Normalizing Flows）**：以节点势 r 为条件，将基础分布映射为边对数几率 γ 的依赖分布，打破独立假设，支持多模态后验；
3. **SVGD 更新节点势**：将节点势 r 视为非参数粒子，使用在松弛无环掩码空间上定义的核进行 Stein 变分梯度下降，利用排斥力促进模式覆盖；
4. **Gumbel-Softmax 软放松与直通估计**：实现离散边采样的可微化，保证前向传播使用硬 DAG 图，反向传播使用可微的松弛代理。

### 关键技术细节

**（1）先验构造**

对每条自由边 Bij，设定 πij ~ Beta(αij, βij)，其中超参数为：

- αij = νij · pij + 1
- βij = νij(1 − pij) + 1
- νij = νmin + κ|pij − 0.5|η

该设计使浓度参数 νij 对远离 0.5 的先验信念赋予更高集中度。当 νij → ∞ 时，边际 Beta-Bernoulli 先验收敛到 Bernoulli(pij) 先验（命题 B.1）。通过边际化 πij，可得到候选边对数几率 γij 上的 Logistic-Beta 先验密度：

p(γij) = σ(γij)^αij · (1 − σ(γij))^βij / B(αij, βij)

其中 γij = logit(πij)，σ 为 sigmoid 函数。

**（2）无环性构造**

采用 Annadani 等人的排序构造：引入节点势向量 r ∈ R^m，通过硬置换矩阵 P(r) 定义无环掩码 M(r) = P(r) L P(r)^T（L 为严格下三角矩阵），最终邻接矩阵为 A = B ⊙ M(r)。该构造保证任意 (B, r) 生成的图必为 DAG（定理 B.3）。同时利用 Sinkhorn 算子对置换矩阵做松弛，得到软掩码 M_τ,KS(r)，用于反向传播。

**（3）ELBO 目标**

采用条件归一化流 Tφ(z; r) 将基础噪声 z 映射为边对数几率 γ。修正后的 ELBO 为：

ELBO(φ, ψ) = E_r∼qψ(r) E_z∼p0 E_B∼p(·|Tφ(z;r)) [期望对数似然 − DKL(qφ(θ|A) ∥ p(θ|A)) + log det(∂Tφ/∂z) − log p0(z) + log p(Tφ(z;r))] − DKL(qψ(r) ∥ p(r))

**（4）SVGD 粒子更新**

将相对于 r 的条件 ELBO 记作 L(φ; r)，采用下界诱导目标 p̃φ(r|D) ∝ p(r)exp{L(φ;r)} 作为替代目标。定义在松弛无环掩码空间上的拉回核 kr(r, r') = kM(ψ(r), ψ(r'))（其中 ψ(r) = vec(M_τ,KS(r))），SVGD 更新为：

r(k) ← r(k) + ηr · (1/K) Σ_j [kr(r(j), r(k)) ∇r(j) log p̃φ(r|D) + ∇r(j) kr(r(j), r(k))]

其中第二项为斥力项，促进粒子多样性。

**算法流程**：初始化参数 φ 和 K 个粒子 → 对每个粒子计算 Sinkhorn 松弛掩码与硬置换掩码 → 抽取 z 经流得到 γ → 用 Gumbel-Softmax 采样硬/软边 → 经直通估计得到 A_ST → 超网络输出高斯参数、采样 θ → 计算 ELBO 各组件 → 用 SVGD 更新粒子 r → 固定粒子更新流参数 φ。

## 主要结论与发现

1. **两节点图的先验行为符合理论预期**：在线性高斯（不可识别）场景下，先验主导方向的推断：错误先验将 84.7% 后验质量推向错误方向，正确先验将 83.2% 推向正确方向；在非线性（可识别）场景下，先验起到正则化作用：错误先验使模型将 86.4% 质量集中到无边的空图，正确先验将 95.2% 质量集中到正确方向。
2. **线性合成数据**：SVI-DAG 在 Brier score 与 AUROC 上大多优于所有基线，表明不确定性量化与边排序能力更优；E-SHD 与 E-F1 与最优基线持平。
3. **非线性合成数据**：SVI-DAG 同样在 Brier score 与 AUROC 上表现出优势，结构准确性保持竞争力（E-F1 在 25 节点非线性场景中显著优于基线）。
4. **Sachs 真实数据**：在 DAG 指标上 F1 score 最优（28.95），在 CPDAG 指标上 AUROC 最优（70.17）；运行时间与基线相当。
5. **整体结论**：通过流模型编码边依赖 + SVGD 促进模式覆盖 + 域信息先验注入，SVI-DAG 在保持结构准确率竞争力的前提下，实现了显著更优的后验不确定性与校准性。

## 优点

- **建模边依赖**：用条件归一化流为边对数几率构建联合依赖分布，突破了独立边假设的表达瓶颈，支持多模态后验；
- **先验设计的理论巧妙**：Beta-Bernoulli 层次先验在无穷浓度极限下收敛到标准 Bernoulli 先验；通过变分变量替换自然导出 Logistic-Beta 密度，避免了固定 Bernoulli 先验下 KL 发散的问题；
- **方法论创新**：将 SVGD 与核的无环空间定义结合，从理论上给出了下界诱导目标 p̃φ(r|D) 与真实后验 p(r|D) 的关系（当条件引导精确时二者相等），为模式覆盖提供了原理性的改进路径；
- **理论支撑完备**：论文附有多个命题/定理/引理（Beta-Bernoulli 收敛性、KL 的映射不等式、DAG 构造的充分必要性、Sinkhorn 松弛的收敛性等），数学基础扎实；
- **实验视角全面**：涵盖不可识别/可识别、线性/非线性、合成/真实数据多维度对比。

## 不足与局限

- **理论保证有限**：缺乏对真实后验逼近误差的严格界限；流 + SVGD 的组合是一种启发式机制，并不能保证完整恢复 MEC 中的所有 DAG；
- **代理梯度偏差**：直通估计器的反向传播梯度是有偏的代理梯度，非精确梯度；硬阈值在排列超平面上的不连续性使得 r 的精确 score 不可得；
- **ELBO 并非全局紧界**：论文明确承认在 (B, r) 空间而非 A 空间上做推断，ELBO 比直接在 A 空间上的 ELBO 更松（命题 B.2）；
- **基准覆盖局限**：合成数据仅采用 ER 拓扑，未在无标度网络、真实生物/物理降维结构上验证；消融实验缺失，无法分解各组件（流、SVGD、先验）的单独贡献；
- **超参数敏感度不明**：Sinkhorn 温度、SVGD 粒子数、流块数、KL 系数等关键超参数缺乏敏感性分析；
- **可扩展性验证不足**：最大规模为 50 节点，虽计算复杂度与主流方法持平，但未在 100+ 节点场景中验证；
- **应用限制**：方法假设观测变量为连续值、噪声为正态，离散变量与组合干预数据的场景未覆盖。
