## 摘要
从观测数据中进行因果发现（CD）面临两个基本挑战。首先，纯统计方法在低样本量情况下往往缺乏解决结构歧义的能力。其次，尽管LLM辅助的混合方法通过语义推理改善了结构恢复，但该推理对单个边决策的影响在很大程度上仍然是不透明的。因此，现有的混合方法无法满足一个基本要求：解释在学习到的有向无环图（DAG）中为何包含或排除特定边。这在现实世界应用中至关重要，因为不存在 ground-truth DAG，每个结构决策都必须独立地被证明合理。我们将这一要求形式化为决策可追溯性，要求每条推断出的边都得到可审计的统计证据、马尔可夫毯一致性或明确的领域推理的支持。我们提出了GENESIS，一个可解释的混合因果发现框架，将图构建分解为可解释的决策点。GENESIS首先识别并评分三节点结构基序，包括链、分叉和对撞子，以建立透明的结构先验，然后通过将这些先验与观测证据相结合逐步细化图，仅在统计证据不足时才调用领域知识。通过设计，每个边决策都通过可审计的证据来源得以解决。实验表明，GENESIS在所有设置中实现了100%的决策可追溯性，将可解释性确立为因果发现中的首要目标。尽管有这一额外要求，GENESIS在大多数基准数据集上、所有样本量范围内，在结构汉明距离（SHD）方面始终优于纯统计因果发现方法，同时实现了与最先进的LLM辅助方法相当的性能。

## Abstract
Causal Discovery (CD) from observational data faces two fundamental challenges. First, purely statistical methods often lack the power to resolve structural ambiguities in low-sample regimes. Second, although LLM-assisted hybrid approaches improve structure recovery through semantic reasoning, the influence of that reasoning on individual edge decisions remains largely opaque. Consequently, existing hybrid methods fail to satisfy a fundamental requirement: explaining why a particular edge is included or excluded in the learned directed acyclic graph (DAG). This is critical in real-world applications, where no ground-truth DAG exists and every structural decision must be independently justified. We formalize this requirement as decision traceability, requiring every inferred edge to be supported by auditable statistical evidence, Markov Blanket consistency, or explicit domain reasoning. We propose GENESIS, an explainable hybrid CD framework that decomposes graph construction into interpretable decision points. GENESIS first identifies and scores three-node structural motifs, including chains, forks, and colliders, to establish transparent structural priors, then progressively refines the graph by integrating these priors with observational evidence, invoking domain knowledge only when statistical evidence is insufficient. By design, every edge decision is resolved through an auditable source of evidence. Experiments show that GENESIS achieves 100% decision traceability across all settings, establishing explainability as a first-class objective in causal discovery. Despite this additional requirement, GENESIS consistently outperforms purely statistical CD methods on the majority of benchmark datasets across all sample regimes in terms of Structural Hamming Distance (SHD), while achieving performance comparable to state-of-the-art LLM-assisted approaches.

## 2. 方法论

### 核心思想
GENESIS 以 **三节点因果基元（3-node causal motifs）**——链（chain X→Y→Z）、分叉（fork X←Y→Z）、对撞子（collider X→Y←Z）——作为推理单元，替代传统的"孤立边预测"，从而利用 d-分离模式提供的更强结构约束。整个框架是一个**渐进式验证级联**：先语义提议，再统计验证，最后按需裁决。

### 算法流程（三个阶段）

**Step 1：LLM Explorer（基元级假设生成）**
- 利用节点元数据 M，查询 LLM（记为 LLM_mf）提取候选三节点基元，每个基元附带置信度 p(m|LLM_mf) ∈ [0,1]。
- 限制最大基元数量为 5n（n 为节点数），以控制计算复杂度。

**Step 2：Data Explorer（统计验证）**
- **边置信度**：对边集合 E1 中的每条边 e，加权聚合四种统计方法的置信度：
  > p(e|D) = w₁·p(e|D,CI) + w₂·p(e|D,BIC) + w₃·p(e|D,ANM) + w₄·p(e|D,LiNGAM)

  其中 CI 为条件独立性检验，BIC 为评分函数，ANM 为加性噪声模型，LiNGAM 为线性非高斯模型；默认权重为 w=[0.5, 0.2, 0.15, 0.15]。
- **基元置信度**：对每个基元 m，通过验证其在数据上的条件独立约束是否成立，计算 p(m|D)，用于验证局部因果结构的整体一致性。

**Step 3：Edge Resolution（边决策解析）**
- **组合分数**：对每个边-基元对（e, m）计算单一分数：
  > s(e,m) = α·p(m|LLM_mf) + (1−α)·[β₀·p(e|D) + β₁·p(m|D)]

  默认超参数：α=0.25，β₀=0.4，β₁=0.6。
- **初始图构建**：保留 s(e,m) ≥ λ_low（=0.25）的边，偏向召回。
- **不确定边识别**（E2）：若 (i) s(e,m) ∈ [λ_low, λ_high]（λ_high=0.7），或 (ii) LLM 与数据的基元置信度不一致，则进入精化阶段。
- **马尔可夫毯（MB）过滤**：对每个节点 a，计算数据驱动 MB（IAMB 算法）与 LLM 驱动 MB 的**交集**作为共识 MB；若边 a→b 的两个端点互在对方共识 MB 中，则保留该边。
- **反事实 LLM 裁决（Judge LLM）**：仅当 MB 过滤无法解决时才触发。先由 LLM_hyp 生成 5 个竞争性结构假设（直接边、两种中介路径、更长因果链、共同父节点混杂替代），再由 LLM_judge 结合累积统计证据进行反事实推理，输出 KEEP/DISCARD 二元决策及理由。

### 决策可追溯性的三种证据来源（Definition 1）
1. **统计证据**：CI 检验、BIC 评分、ANM/LiNGAM 等数据驱动证据；
2. **马尔可夫毯一致性**：数据与 LLM 推断的 MB 交集确认结构必要性；
3. **领域推理**：Judge LLM 的显式反事实推理，仅在统计证据不足时调用。

## 6. 主要结论与发现

1. **100% 决策可追溯性（全部实验设置）**：GENESIS 中所有保留的边均由至少一种可审计证据源支持，无任何"无源"决策。

3. **与 SOTA LLM 辅助方法相当**：在多数数据集上接近或超过 CausalOrder、LLM-CD、SLLM-CD；在 Asia 和 Cancer 等小图上达到近零 SHD。
4. **各证据源的分布规律**：
   - 大多数边由统计证据 + MB 一致性解决；
   - Judge LLM 仅作**定向兜底**，在简单网络（Earthquake、Cancer）上触发率为 0%，在复杂网络（Child）上约 11–31%；
   - 从表 7–11 可见，MB 一致性和 Judge 决策的准确性普遍高于纯统计边置信度。
5. **框架稳定性**：GENESIS 在样本量从 1,000 增至 5,000 时性能波动小，显示良好的数据效率。

## 7. 方法优点

### 概念层面
- **形式化决策可追溯性**：首次将"边决策解释"从隐性的研究目标变为显式的算法约束，为因果发现的可信部署设定新标准；
- **基元作为推理单元**：3 节点基元（链/叉/对撞子）比孤立边提供更丰富的 d-分离约束信息，兼顾语义可解释性与结构性；
- **渐进式精化设计**：从语义提议→统计验证→MB 共识→反事实裁决，逐级过滤，每级仅在上一级无法解决时才触发，"延迟调用 LLM"策略有效控制了成本与偏见。

### 工程与实现层面
- **多 LLM 异构分工**：GPT-5、Qwen3.5-27B、Gemini 3 Pro 分别担任不同角色，降低单一模型的系统性偏差和"自产自评"污染风险；
- **closed vocabulary 约束**：所有提示词强制限制在给定变量集内，减少 LLM 从记忆基准结构泄露信息的风险；
- **提示词设计细致**：要求从第一性原理推理、明确禁止回忆已知基准结构、以 JSON 结构化输出，强化可控性；
- **文献地位明确**：填补了传统统计 CD 方法（不可解释）与 LLM 方法（不透明）之间的空白。

## 8. 不足与局限

### 实验覆盖方面的局限
- **网络规模有限**：最大基准仅为 20 节点；未验证在真实大规模、高维场景（如基因调控网络、推荐系统变量图）中的表现；
- **缺少真实世界数据实验**：所有实验均基于合成数据（从已知图采样），未在无 ground-truth 的真实数据上展示可追溯性的实际价值；
- **基准类型单一**：未涉及含有隐变量、循环因果、非平稳数据等复杂场景。

### 方法与实现层面的潜在问题

- **未做消融实验**：无法判断各模块（统计加权、MB 交集、Judge LLM）对最终性能贡献的边际大小，难以验证设计选择的必要性；
- **超参数敏感度未知**：α、β₀、β₁、λ_low/λ_high 均为手工设定且跨数据集固定，未分析它们对结果的扰动影响；
- **MB 交集可能过严**：数据 MB 与 LLM MB 取交集可能剔除真实但未被 LLM 识别的边，在小图上表现良好，但大图上可能失去召回；
- **计算成本未透明**：未报告 token 消耗、API 等待时间或失败重试率，影响实际部署的可行性判断。

### 公平性隐患
- **LLM 基准确认偏差**：虽然提示词要求"第一性原理推理"，但 GPT-5/Gemini 3 Pro 等模型很可能已在预训练语料中见过 Asia、Child 等经典基准结构，存在记忆泄漏风险；文中通过 closed vocabulary 和反事实约束进行了缓解，但无法完全排除。

## 总结与定位

GENESIS 的核心价值在于将因果发现从"输出一张图"转变为"输出一张**每一步都能被审计**的图"。其提出的决策可追溯性定义、基元级渐进推理算法、以及异构 LLM 分工架构，为可解释因果发现提供了新的研究范式和工程参考。未来工作可围绕更大规模图验证、更丰富的真实数据测试、消融分析以及成本控制等方面展开。
