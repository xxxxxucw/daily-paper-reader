## 摘要
表格数据因其异构特性，其中数值特征展现出多样的分布、尺度与统计属性，给深度学习带来了独特挑战。尽管近期进展改善了模型从表格数据中学习的方式，但数值数据如何被转换为模型友好的表示仍相对未充分探索。我们引入了拉伸变换框架，将数值特征预处理表述为一个优化问题，使目标函数更平滑从而更易学习。我们的框架有两种变体：(1) 无监督拉伸，通过极小极大优化均匀重分布特征密度；(2) 监督拉伸，从目标函数平滑性的角度，通过最小化变换空间中目标函数的狄利克雷能量来优化目标感知的数值特征变换。我们的理论分析进一步将该框架与几种流行变换联系起来：无监督拉伸通过共享的分段线性几何与分段线性编码密切相关，并随着分箱数量的增加趋近于经验累积分布函数变换；而监督拉伸在细分箱极限下与目标编码密切相关。在TALENT基准的38个数据集上的综合实验表明，监督拉伸一致优于所有基线。这些结果表明，显式优化目标函数平滑性是表格深度学习一个强大且未被充分探索的策略。

## Abstract
Tabular data presents unique challenges for deep learning due to its heterogeneous nature, where numeric features exhibit diverse distributions, scales, and statistical properties. Although recent advances have improved how models learn from tabular data, how numeric data are transformed into model-friendly representations remains comparatively underexplored. We introduce the stretch transformation framework, which formulates numeric feature preprocessing as an optimization problem to make the target function smoother and thus more learnable. Our framework has two variants: (1) unsupervised stretch, which uniformly redistributes feature density via minimax optimization, and (2) supervised stretch, which optimizes target-aware numeric feature transformations from the perspective of target-function smoothness by minimizing the target function's Dirichlet energy in the transformed space. Our theoretical analysis further connects this framework to several popular transformations: unsupervised stretch is closely related to Piecewise Linear Encoding through a shared piecewise-linear geometry and approaches the empirical CDF transformation as the number of bins grows, while supervised stretch becomes closely related to target encoding in the fine-binning limit. Comprehensive experiments on 38 datasets from the TALENT benchmark demonstrate that supervised stretch consistently outperforms all baselines. These results show that explicitly optimizing for target function smoothness is a powerful and underexplored strategy for tabular deep learning.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：表格数据是深度学习中的一大挑战，其核心难点在于数值特征的高度异构性——同一数据集中可能混合了二元标志、计数、百分比、货币值、重尾连续变量等不同尺度与统计性质的数值特征。这种异构性导致神经网络的优化景观变得糟糕，因为神经网络通常假定输入具有良好的条件（well-conditioned）。
- **现有方法的不足**：虽然近期研究在架构、优化和训练协议上不断提升表格深度学习的性能，但数值特征本身如何被转换或预处理的环节却始终被忽视。常用的预处理方法如标准化（z-score）、幂变换（Yeo-Johnson）、分位数变换、分段线性编码（PLE）等，绝大多数都是**无监督的**——它们只利用特征自身的分布统计信息，完全忽略了在训练中通常可获得的**目标变量信息**。
- **核心洞察**：特征变换不应仅仅"归一化分布"，而应使**目标函数在变换空间中更加平滑**。由于神经网络存在**频谱偏置**（spectral bias）——即趋向于优先学习低频函数——而表格数据中样本可以任意接近，产生了难以学习的无界高频成分。若能通过变换使特征-目标映射更加平滑（低频化），则神经网络的学习将显著更高效。
- **整体含义**：本文将数值特征预处理重新定义为一个**优化问题**（宽度分配问题），并首次系统地提出了**目标感知（监督式）数值特征变换**方法，挑战了表格深度学习中"预处理应当无监督"的长期惯例。

### 2. 提出的方法论

**（1）总体框架：拉伸变换（Stretch Transformation）**

- 对每个数值特征，将其范围划分为 T 个区间（默认使用分位数分箱），然后在每个区间内通过分段线性映射将输入 x 映射到 [0, 1] 区间。
- 变换形式为：s(x) = c_{t-1} + (x - b_{t-1}) / (b_t - b_{t-1}) · w_t，其中 w_t > 0 和为 1 的宽度分配控制每个区间的"拉伸"或"压缩"程度。
- 关键设计问题：如何设定宽度向量 {w_t}——本文从最小化目标函数 Dirichlet 能量的原则性优化目标来推导。

**（2）优化目标：Dirichlet 能量最小化**

- 从核平滑视角出发，通过高斯 RBF 核的积分算子、热核展开，在小带宽极限下推导出：最大化核平滑度等价于最小化 Dirichlet 能量 ∫||g'(y)||² dy。
- 离散化后得到有限样本 Dirichlet 能量：E_disc = Σ_i ||Δf_i||² / Δy_i，其中 Δf_i 为目标增量，Δy_i 为变换空间的间距。

**（3）无监督拉伸（Unsupervised Stretch）**

- 在没有目标信息时，采用**极小极大（minimax）原则**：假设所有局部目标变化有界，最小化最坏情况下的 Dirichlet 能量。
- 推导结果导致最优分配为均匀宽度：**w_t = 1/T**，即将每个区间均匀分配宽度。
- **理论联系一**：随着 T → n，无监督拉伸收敛于经验 CDF 变换（将每个样本映射到其归一化秩），为"CDF 变换提高可学习性"这一实证现象提供了理论解释——通过最大化样本间最小间距来平滑目标函数、减少高频成分。
- **理论联系二**：无监督拉伸与 PLE（分段线性编码）在几何结构上等价——PLE 在 R^T 空间中的弧长参数化恰好是 T 倍的无监督拉伸值。但无监督拉伸仅需 **O(1) 每特征内存**，而 PLE 需要 O(T)，且不产生维度扩张。

**（4）监督拉伸（Supervised Stretch）**

- 利用目标信息直接优化离散 Dirichlet 能量，但精确目标数值上不稳定（对原始特征间距 Δx_i 高度敏感），因此转而优化一个**稳健下界**。
- 基于 Cauchy-Schwarz 不等式，每个箱的贡献满足：Σ_i ||Δf_i||² / Δy_i ≥ S_t² / w_t，其中 S_t 为箱内的目标总变差。
- 对宽度分配 w_t 的优化得到闭式解：**w_t\* = S_t / Σ_u S_u**——目标变化越剧烈的区域，分配越多的变换空间宽度（等价于均衡各箱的斜率幅度）。
- **理论联系**：当 T = n 时，监督拉伸在极限下与**目标编码**（target encoding）密切相关——两者都利用目标变化来引导变换，但监督拉伸通过 Dirichlet 能量最小化实现了原理性论证，且箱数 T 提供了天然的正则化。
- **OOF 估计**：为防止信息泄漏，使用 K 折交叉验证配合自适应 Nadaraya-Watson 核回归获得 OOF 的目标函数估计值，再据此计算 bin 宽度。

**（5）扩展与折中**：变换是边际的（对每个特征独立）、保维的（d'=d），满足单调性和有界输出范围两个期望性质。

1. **监督拉伸在所有评估中表现最强**，尤其在回归任务中优势明显——在成对比较中统计性胜过所有备选方法（回归中对 PLE 的胜-负记录为 18-7、对 PLE-T 为 28-9、对标准化为 14-4）；在标签噪声下保持竞争力，在最高噪声水平（0.5）下排名第一。

### 7. 优点

- **理论贡献扎实**：建立了与 PLE（通过弧长参数化）、经验 CDF 变换、目标编码（在细分箱极限下）的严格理论联系，为现有实证观察提供了统一解释框架。
- **方法创新性强**：首次将数值特征变换显式建模为目标函数平滑性优化（Dirichlet 能量最小化），并给出了闭式解，简单而优雅。
- **设计细致**：OOF 估计避免信息泄漏；使用稳健下界替代不稳定的精确目标；bin 数 T 提供天然正则化参数；无监督变体的 O(1) 内存优势使其在大数据场景中尤为实用。
- **实验严谨全面**：38 数据集、5 模型、9 变换的大规模对照；自适应的显著性过滤、严格的成对胜率准则、阈值敏感性分析、噪声鲁棒性测试、边际结构分析等多角度验证，增强了结论的可靠性。

### 8. 不足与局限

- **变换是边际的、不考虑特征交互**：如作者自述，预处理本身不感知交互，下游模型仍需自己学习特征组合关系。
- **目标函数估计依赖平滑回归**：监督拉伸的性能依赖于 OOF 核回归对目标函数的估计质量——在训练数据稀疏或目标函数极端不规则的场景下，估计误差可能影响变换效果。
- **精确边界行为未被完全刻画**：理论使用的精确目标在数值上不稳定（对小型 Δx_i 敏感），作者采用下界替代，但未讨论这种替代可能导致的次优性边界；理论分析基于小带宽（σ→0）的核展开近似，一般 σ 情形下的行为未被刻画。
- **实验局限**：所有实验基于 TALENT 基准（属于中小规模表格数据集），未验证在超大规模数据集或高维稀疏场景下的表现；PLE 在部分组合下因内存问题回退为标准化，可能使其基线分数偏乐观或偏悲观而未被专门讨论。
- **实践成本**：监督拉伸需要 OOF 核回归等额外预处理步骤，实际部署时的流程复杂度和调参成本（如 bin 数）高于简单标准化。
- **与 PLE-T 对比的公平性问题**：PLE-T 是唯一的监督基线，但它只利用目标设定 bin 边界、不优化变换本身，因此监督拉伸的优势部分可能仅来自更充分利用目标信息，而非纯粹来自平滑性优化的效果——虽然作者通过极限等价性给出了理论论证，但两种收益的实证分解未被单独量化。
