## 摘要
密度估计是表格数据上许多无监督任务的基础，如异常检测、分布外检测和数据增强。尽管这些问题都归结为概率质量所在位置的问题，但通常的解决方式是对每个数据集单独拟合一个模型，并配备各自的超参数和调优预算。我们引入了ICED，一种基于上下文的能量密度估计器，消除了这种逐数据集的成本。ICED是一个基于Transformer的模型，在专门为密度估计构建的合成先验上进行一次预训练，其目标函数在信息充分处拟合对数密度，并在其他位置保持其排序。在推理时，它将数据集作为上下文读取，并在单次前向传播中返回任意查询点的非归一化对数密度，无需拟合、采样或超参数选择。一个固定的ICED模型即可驱动通常由四个专门管道处理的四个任务：密度估计、分布外检测、无监督异常检测和生成式增强。在所有四个任务中，它与最强的任务专用方法具有竞争力，同时是唯一一种在它们之间切换时无需重新训练、无需调优且无需标签的方法。代码可在https://github.com/gmum/iced获取。

## Abstract
Density estimation underlies many unsupervised tasks on tabular data such as anomaly detection, out-of-distribution detection, and data augmentation. Although all these problems reduce to questions about where probability mass lies, they are typically solved individually by fitting a separate model to each dataset, with its own hyperparameters and tuning budget. We introduce ICED, an in-context, energy-based density estimator that removes this per-dataset cost. ICED is a transformer-based model pretrained once on a synthetic prior built specifically for density estimation under an objective that fits log-density where it is informative and preserves its ordering elsewhere. In the inference, it reads a dataset as context and returns an unnormalized log-density for any query point in a single forward pass, with no fitting, sampling, or hyperparameter selection. A single frozen ICED model then drives four tasks usually handled by four specialized pipelines: density estimation, out-of-distribution detection, unsupervised anomaly detection, and generative augmentation. Across all four, it is competitive with the strongest task-specific method, while being the only approach that needs no retraining, no tuning, and no labels to move between them. The code is available at https://github.com/gmum/iced.

密度估计是表格数据上众多无监督任务的共同基础——异常检测、分布外（OOD）检测、数据增强等本质上都在回答同一个问题：概率质量落在哪里。然而，现有的密度估计方法存在一个结构性痛点：

- **逐数据集拟合范式**：KDE、高斯混合模型、归一化流、EBM 等方法都必须在每个新数据集上从头训练或拟合，并伴随各自的超参数选择与调优流程，成本高昂。
- **任务各自为政**：即使多个任务共享密度的数学概念，实践中仍为每个任务单独设计流水线（如异常检测用 Isolation Forest、OOD 检测用另一套方法、增强用 GAN），彼此之间不可复用。
- **PFN 范式尚未延伸到密度估计**：Prior-Fitted Network（PFN）已成功将监督分类/回归转变为一次前向传播的上下文学习（如 TabPFN），但现有的无监督 PFN（TabClustPFN、ZEUS、TACTIC）只是分别对聚类、嵌入、异常分数等**任务特定输出**进行摊销，而不是学习底层的密度本身。用 TabPFN 通过自回归分解来获得密度则缓慢、高维下不可靠，且只是监督预测的副产品。

ICED 的目标是填补这一空白：**将密度估计本身变成一个可复用的、摊销化的基础原语**——一个在合成先验上预训练一次、冻结后即可免训练、免调参地驱动多个下游任务的上下文能量密度估计器。

## 2. 方法：ICED 的核心技术

### 2.1 核心思想：在上下文中学习密度估计算法

遵循 PFN 范式，ICED 不针对每个数据集拟合模型，而是在海量合成数据集上训练一个 Transformer，使其学会**执行密度估计算法本身**。形式化地：

\[
f_\theta(q \mid D) \approx \mathbb{E}_{p \sim \mathcal{P}(D)}[\log p(q) \mid D]
\]

即：给定数据集 D 作为上下文，模型对任意查询点 q 直接输出其对数密度的估计。整个过程为单次前向传播，无梯度更新、无超参数选择。

### 2.2 关键设计一：能量（未归一化对数密度）

ICED 估计的是**能量**（高能量=高密度，与通常 EBM 符号约定相反），即对数密度加一个数据集相关的加性常数 \(c_D\)：

\[
f_\theta(q \mid D) \approx \log p(q) + c_D
\]

这一选择是刻意的：异常/OOD 评分只依赖相对密度，生成只依赖能量梯度，均对 \(c_D\) 不变。模型因此绕过了最棘手、最不可解的配分函数，同时保留了下游任务所需的全部信息。

### 2.3 关键设计二：合成预训练先验

先验的质量决定了 PFN 的质量。ICED 的每个训练实例 \((D, Q, \{y_j\})\) 都带有精确的解析对数密度（通过构造保证），其生成过程涵盖：

| 先验组件 | 内容 | 目的 |
|---|---|---|
| 基础混合分布 | 高斯混合或重尾混合（Student-t、Laplace、Cauchy 仿射变换），组件数 K∈[2,20] | 覆盖不同尾部分布与衰减速率 |
| 非线性流扭曲 | RealNVP 或本文新提出的分段点式流（逐点非线性 + 正交混合） | 生成弯曲流形、非简单几何结构，同时保持精确对数密度（变量替换公式） |
| 离散特征 | 以概率 \(p_{cat}\) 附加 1~5 个独立类别特征（Dirichlet 先验采样概率），One-hot 编码与连续特征随机交错 | 模拟混合类型真实表格数据 |
| 查询扰动 | 对 10% 坐标施加高斯噪声 / Mixup / CutMix | 在数据流形周围塑造规则化的能量面，防止 OOD 区域能量失控 |
| 目标归一化 | 用经验 10%/90% 分位数将目标对齐到统一范围 | 稳定训练，避免不同实例的原始对数密度量级差异过大 |

### 2.4 关键设计三：混合回归-排序损失

\[
\mathcal{L} = \mathcal{L}_{\text{reg}} + \mathcal{L}_{\text{rank}}
\]

- **回归项**：对落在高密度区间内的查询使用均方误差精确拟合；对尾部的低密度查询仅要求其预测能量低于区间（单向惩罚），不追求精确尾深度——把模型容量集中在信息充分的高密度区域。
- **排序项**：对所有按真实密度有序的查询对施加基于 margin 的成对 Logistic 损失，直接对齐下游任务依赖的**密度排序**（Kendall's τ、成对准确率）。

### 2.5 模型架构与推理

- **编码器**：TabICLv2 特征提取器（维度 512，接受可变特征数量），从预训练权重初始化并在预训练中微调。
- **主干**：12 层 Transformer 编码器，4 注意力头，FFN 隐藏维度 1024，GELU，无 Dropout。注意力掩码允许查询 token 关注全部上下文，而上下文 token 仅相互关注——保证排列不变性和上下文表征的独立性。
- **头部**：两层 MLP 将查询 token 映射为标量能量。
- **推理**：所有查询点的能量在一次前向传播中同时输出。四个下游任务共享同一份能量输出，仅读取方式不同——直接作为密度排名、取负作为异常分数、或用 SGLD 沿梯度采样生成新样本。

### 3.1 密度估计（合成数据，受控验证）

- **设置**：从先验分布族中采样未见的测试分布（高斯混合、重尾混合、流扭曲混合，含/不含类别特征与扰动），50 个数据集/类。

### 3.2 OOD 检测与无监督异常检测（ADBench 基准）

- **设置**：47 个 ADBench 数据集，5 个随机种子，AUROC 指标。OOD 检测使用干净上下文；异常检测使用含未标记污染物的上下文（与 ADBench 标准一致）。

### 3.3 数据增强（TabEBM 协议）

- **设置**：7 个数据集（biodeg、collins、energy、fourier、protein、steel、stock、texture）× 6 个训练集大小（20~500）× 10 个随机种子 × 4 个下游分类器（KNN、LR、MLP、RF）。
- **对比方法**：SMOTE、TVAE、CTGAN、NFLOW、TabDDPM、ARF、TabEBM、以及无增强基线。
- **结果**：ICED 平均平衡准确率 72.8，与目的专用的 TabEBM（73.0）基本持平并优于基线（71.0），且远远超过其他专用生成增强器。

### 3.4 消融研究

- **先验消融**：逐次移除重尾混合、高斯混合、流扭曲、类别特征、扰动正则化，保留完整先验为最佳或次佳。

## 6. 主要结论与发现

1. **单模型多任务可行**：一个冻结的预训练密度模型可在四个通常由不同专用管道处理的任务上达到与最强任务专用方法相当的性能，且无需任何重新训练、调优或标签。
2. **鲁棒性是核心优势**：在异常的检测任务中，ICED 是唯一在干净上下文和污染上下文两种情况下均保持前三的方法 —— 这归功于两个设计选择：包含重尾与扰动的先验、以及排序项损失。
3. **能量表示是通用性的关键**：未归一化能量在丢弃不可处理的配分函数的同时保留了全部下游任务所需信息，使得同一次前向输出可以同时服务排序、检测和生成。
4. **效率优势显著**：密度估计时 ICED 比 TabPFN 快约 50 倍，因为它是直接联合密度输出而非逐维自回归。
5. **代价与局限并存**：没有形式化覆盖保证、能量不可作为绝对归一化概率、上下文推理成本随数据规模增长、增强阶段仍需 SGLD 迭代。

## 7. 方法亮点与贡献

- **填补范式空白**：首次将 PFN 的"学习算法本身"哲学从监督预测推广到无监督概率建模，确立密度估计作为可摊销的基础原语。
- **精巧的合成先验设计**：重尾/高斯混合 + 流扭曲 + 离散特征 + 查询扰动的组合，在保证解析精确对数密度的前提下系统覆盖真实表格数据的分布结构；其中的随机分段点式流（分段线性/ELU/Softplus 非线性 + 正交混合）是论文自主研发的组件。
- **混合回归-排序损失**直击密度应用的本质：精确拟合高密度区间的能量值，只约束尾部能量不超过区间，并对成对顺序施以直接监督——这与下游任务实际消费密度的方式高度一致。
- **工程整合度高**：直接初始化自 TabICLv2 特征提取器，使模型天生支持可变维度、可扩展至大表格；掩码注意力设计了查询与上下文分离的信息流。
- **单模型是唯一方案**：在所有对比方法中，只有 ICED 可以在四个任务间零成本迁移，而其他方法（TabICL、TACTIC 等）各自只能解决单个任务。

## 8. 不足与局限

1. **先验依赖无保障**：ICED 的性能上限取决于合成先验对真实分布的覆盖程度，且论文未提供任何形式化的泛化保证。虽然实验表明先验在 ADBench 上具有良好的迁移性，但此前的失败模式未被探讨。
2. **能量不可归一化**：输出是未归一化能量，适合排序、检测和采样，但不能直接作为绝对概率使用；若需标准化概率仍需额外的归一化步骤。
3. **上下文扩展成本**：单次前向需对整个上下文做注意力计算，推理成本随数据集规模线性及以上增长；仅以大采样作为缓解措施，未进行系统的大规模上下文性能实验。
4. **生成阶段重回迭代**：虽然密度估计本身是单次前向，但数据增强使用 SGLD 采样时又重新引入了迭代过程，无法做到纯粹的"一步生成"。
5. **实验覆盖偏差风险**：真实数据评估集中于 ADBench，领域多样性有限；数据增强实验未覆盖全部 47 个数据集，也未测试高维表格（>50 维特征）的情况；消融实验未在真实任务上验证。
6. **评测随机性与版本问题**：论文出现两条 arXiv 编号（2608.09348 与 2608.09348v1 的时间线标注存在 2026 年 8 月的未来时间戳），多处引用了尚未正式发表或日期在后的工作（如 TabICLv2、TACTIC），这些预印本结果的成熟度可能影响可复现性。
