## 摘要
区间预测旨在实现目标覆盖率，同时产生尽可能短的区间。许多保形回归流程首先预测不确定性替代量，然后通过校准或选择将其转换为区间。这种分离支持覆盖率校准，但事后规则在很大程度上决定了最终区间，并且没有充分利用学习到的输出分布。我们观察到，所得区间具有天然的层次几何结构：一个区间可以递归地细化为嵌套子区间，而二叉树自然地表示这种结构。我们将这种层次结构定义为下一区间预测，并提出PATH，它学习概率质量如何从每个区间流向其后续嵌套子区间。PATH预测基础叶子分布，并使用自回归解码器来细化分支概率。将分布与区间层次结构匹配，使学习与提取目标一致：PATH在相邻输出区间上累积概率，并返回达到所选概率质量的最短连续范围。我们在包含56个OpenML回归数据集的PATHBench上，将PATH与24种区间预测基线方法进行了比较。PATH大幅缩短了最终区间，实现了最低的平均归一化长度0.1473，同时保持了0.9144的平均覆盖率。这些结果确立了层次输出建模作为表格数据上紧凑区间预测的有效方法。代码可在https://github.com/pxcai/PATH获取。

## Abstract
Interval prediction aims to achieve a target coverage level while producing intervals that are as short as possible. Many conformal regression pipelines first predict an uncertainty surrogate and then convert it into an interval through calibration or selection. This separation supports coverage calibration, but post hoc rules largely determine the final interval and do not fully use the learned output distribution. We observe that the resulting intervals have inherently hierarchical geometry: an interval can be recursively refined into nested subintervals, and binary trees naturally represent this structure. We formulate this hierarchy as next-interval prediction and propose PATH, which learns how probability mass flows from each interval to its next nested subintervals. PATH predicts a base leaf distribution and uses an autoregressive decoder to refine branch probabilities. Matching the distribution to the interval hierarchy aligns learning with extraction: PATH accumulates probability over adjacent output intervals and returns the shortest contiguous range reaching a selected mass. We compare PATH with 24 baselines for interval prediction on PATHBench, comprising 56 OpenML regression datasets. PATH substantially shortens the resulting intervals, achieving the lowest mean normalized length, 0.1473, while maintaining mean coverage of 0.9144. These results establish hierarchical output modeling as an effective approach for compact interval prediction on tabular data. Code is publicly available at https://github.com/pxcai/PATH.

## 1. 核心问题与研究动机

- **核心问题**：在表格数据的区间预测任务中，如何在满足目标覆盖率的前提下，尽可能缩短预测区间长度。区间越短，决策支持信息越有价值。
- **现有方法的局限**：主流保形回归（Conformal Regression）流程通常采用“两阶段”模式：先学习一个不确定性替代量（如残差、分位数、条件直方图），再通过校准或选择规则事后转换为最终区间。
  - 这种分离虽然有利于覆盖率校准，但**事后规则在很大程度上决定了最终区间形态**，未充分利用已学习的输出分布中的信息。
  - 输出端的层次结构被忽视：区间本质上具有递归嵌套的几何特性——一个区间可逐级细化为嵌套子区间，从粗略的不确定区域到精确的边界。
- **核心洞察**：区间天然具有层次几何结构，**二叉树可以自然地表示这种结构**。如果将区间层次结构与学习到的概率分布对齐，则可以直接优化“提取紧凑区间”这一最终目标，而非间接地依赖事后规则。

## 2. 方法论

### 2.1 核心思想：下一区间预测
- 将区间预测重新定义为一个**递归粗到细的概率细化问题**：在每个树层级上，模型预测概率质量如何从当前区间流向下一层级的两个嵌套子区间。
- 这种公式化使“粗略不确定性”和“精细边界定位”融入同一个分布中，**直接对齐模型输出与紧凑区间提取目标**。

### 2.2 技术框架：PATH 模型三大组件

**（1）目标树编码**
- 在训练目标范围上拟合 **B = 2^D 个等宽有序叶区间**（D 为树深度，默认为 8，即256个叶子）。
- 每个目标值通过裁剪叶索引得到二进制路径表示（trace）s = (s₁, ..., s_D)，记录从根到叶的每一步左右选择。
- 使用**等宽边界**而非分位数边界：等宽叶子使连续的叶子集合具有直接的区间长度解释，使目标分辨率与区间效率对齐。

**（2）基础分布与自回归细化**
- **编码器**：采用 FT-Transformer 作为骨干网络（d_model=64，4头注意力，2层），将表格特征编码为上下文记忆 H。
- **基础叶子分布**：直接叶头（leaf head）产生 logits，通过 softmax（含温度 T）得到基础目标分布 q_T(b|x)。
- **残差分支校正**：自回归解码器读取 [SOS] + 前缀位，对每个树节点输出残差分支 logit ρ，用于校正基础分支概率：
  - π^λ = σ( logit(π⁰) + λ·ρ/T )
- **细化叶子分布**：枚举所有根到叶路径，将各层分支概率相乘得到最终细化的叶子分布 p_{λ,T}(b|x)。
- 当 λ=0 时，退化为直接叶子分布，证明自回归解码器是“分布修正”而非“贪婪路径生成器”，所有叶子在提取时仍可用。

**（3）训练目标**
- 三个损失函数叠加，分别作用于直接分布 q 和细化分布 p：
  - **叶子损失**：标准交叉熵
  - **前缀损失**：鼓励每层概率质量保留在真实目标区域内
  - **CDF 损失**：监督有序累积分布
- 最终目标 = 0.5·(q 的三项损失) + (p 的三项损失) + 0.01·残差惩罚

**（4）区间提取与验证选择**
- 点预测：叶中心的后验均值。
- 区间预测：在有序叶区间上累加概率质量，选择**总质量 ≥ M 的最短连续区间**（精确枚举求解）。
- 推理参数 (T, M, λ) 在验证集上通过网格搜索选择，标准为：覆盖率 ≥ η（默认0.905）的前提下最小化验证区间长度。

### 2.3 理论性质（附录A）
- 细化分布是归一化的有效概率分布
- λ=0 时精确退化为直接叶子分布
- 最短质量区间提取为精确最优解
- 网格对齐的区间提取误差随深度以 O(2^(-D)) 缩小
- 有限网格验证选择满足 Hoeffding 浓度界

| 校准扩展实验（对标量边距） | 1 组额外对比 |
| 其他诊断 | 覆盖率剖面、配对bootstrap、条件覆盖率、逐数据集记录、运行时间分析 |

### 充分性与公平性评价
- **充分性高**：560次重复实验覆盖多个数据集和随机分割，消融设计系统（深度、验证目标、自回归贡献、直接分布基线），配对 bootstrap 和符号检验验证了统计学显著性。
- **公平性良好**：所有方法使用相同随机种子；排名先检查覆盖率再比较长度，避免“短但无效”的误导；结果包含逐数据集记录，可独立核验。
- **补充验证充分**：严格0.900覆盖率比较、覆盖率剖面分析、验证-测试迁移诊断、条件覆盖率分析、逐层运行时间对比，多角度验证结论稳健性。

## 6. 主要结论与发现

1. **主实验表现**：PATH 达成平均覆盖率 0.9144（高于名义 0.900 目标），同时取得最低的平均归一化区间长度 0.1473 和中位数长度 0.0547，平均排名 5.25，胜场 163。相比第二名的 QRF-CTI（0.2017），区间长度缩短 **36.9%**。
2. **严格覆盖率下依然有效**：PATH 在 76.6% 的评估中达到 0.900 覆盖率，排名 6.46，胜场 177，均优于对比方法。
3. **覆盖率-长度剖面**：PATH 在 53.6% 的评估中达到最优有效区间长度 25% 容差内，优于 QRF-CTI 的 43.9%。
4. **成对优势显著**：对六个强基线，PATH 在 36/56 至 54/56 的数据集上更短，所有 95% bootstrap 置信区间为正，符号检验 p 值大多 < 10⁻⁶。
5. **深度扩展有效**：D 从 4 增至 8，平均长度从 0.1687 降至 0.1467，排名从 11.46 提升至 5.86，覆盖率保持在 0.914 以上。
6. **消融验证**：移除自回归细化使长度从 0.1473 升至 0.1506；移除层次结构直接预测叶子使长度升至 0.1623。层次结构贡献更大（8.7%），自回归增加一致改善（2.2%）。

## 7. 方法优点

- **创新性视角**：提出“下一区间预测”公式，将区间层次结构与学习分布对齐，在输出端直接优化紧凑区间提取，思路自然且优雅。
- **分布结构的充分利用**：既保留直接叶子分布作为锚点，又用自回归解码器细化分支概率，两者互补。
- **完备的理论支撑**：附录提供了归一化性、特殊情形恢复、最优提取、网格误差、浓度界等核心性质证明。
- **对比基准全面**：24种基线的覆盖范围广（保形、分位回归、条件直方图、局部化树方法、神经网络方法等）。
- **评估协议规范**：统一随机种子、容差排名规则、10次重复、多种统计显著性检验（bootstrap + 符号检验）。
- **多角度诊断**：除主指标外，还分析了覆盖率剖面、条件覆盖率、验证-测试迁移、逐数据集记录、运行时间-性能权衡，分析层次丰富。
- **透明可复现**：代码开源，提供数据集清单和随机种子协议。

## 8. 不足与局限

- **验证选择依赖网格**：推理参数 (T, M, λ) 依赖有限的验证网格和 η 设置，在验证-测试分布漂移时可能出现覆盖失败（如激光、森林火灾数据集，覆盖率低至0.804-0.846），表明小样本和分布转移场景下选择稳定性不足。
- **覆盖失败集中在少数数据集**：5/56 数据集（laser、forest_fires、meta、Titanic、socmob）在代表性分割上未达覆盖率阈值，且伴随明显的上下尾不对称误差，说明方法在极端分布转移下较脆弱。
- **计算成本高于轻量树基线**：相比 CatBoost-SplitCP（3.1s）和 QRF-CTI（88.8s），PATH 的 294.2s 中位数运行时间明显更高，可能限制超大规模或实时推断场景的应用。
- **结果对深度和验证目标敏感**：D 和 η 的设定需要根据任务调节，虽提供了趋势规律，但未提供自动选择的明确准则。
- **等方法在部分数据集上非最优**：如 CPMP-2015、Job_Profitability、Meta_Album 系列、Brazilian_houses 等数据集上，PATH 排名靠后或覆盖率过度（甚至达100%），说明区间紧致优势并非在所有数据分布上一致成立。
- **局限性未明确讨论**：论文未系统讨论特征类型局限（全部为表格数据）、非欧几里得目标空间、多变量目标扩展、时间序列相关性等场景下的适用性。
- **无理论保证覆盖率的严格性**：PATH 依赖验证集经验选择，不提供保形预测般的有限样本覆盖率保证，而仅提供离散网格下的浓度界。
