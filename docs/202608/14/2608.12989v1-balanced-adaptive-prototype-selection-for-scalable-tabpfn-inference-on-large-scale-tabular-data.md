## 摘要
预训练的表格基础模型展示了强大的预测能力；然而，它们在大规模数据集上的应用仍受限于有限的推理上下文。本文介绍了平衡自适应原型选择（BAPS），一种用于构建紧凑、信息保持上下文的框架，以实现可扩展的TabPFN推理。在不修改或重新训练预训练模型的情况下，BAPS联合保持了代表性结构、信息性决策边界、局部密度、类别平衡和特征空间多样性。在百万行HIGGS和SUSY数据集上的实验表明，512个原型保持了强大的预测性能和可靠的校准，对应约1,953倍的上下文压缩。所有实验均在配备16 GB RAM且无GPU加速的Intel Core i7 CPU上进行。这些发现确立了有效的上下文构建作为将预训练表格基础模型扩展到百万级数据集的实用机制。

## Abstract
Pretrained tabular foundation models have demonstrated strong predictive capability; however, their application to large-scale datasets remains constrained by the limited inference context. This paper introduces Balanced Adaptive Prototype Selection (BAPS), a framework for constructing compact, information-preserving contexts for scalable TabPFN inference. Without modifying or retraining the pretrained model, BAPS jointly preserves representative structure, informative decision boundaries, local density, class balance, and feature-space diversity. Experiments on the million-row HIGGS and SUSY datasets show that 512 prototypes retain strong predictive performance and reliable calibration, corresponding to an approximately 1,953-fold context compression. All experiments were conducted on an Intel Core i7 CPU with 16 GB RAM and no GPU acceleration. These findings establish effective context construction as a practical mechanism for extending pretrained tabular foundation models to million-scale datasets.

- **核心含义**：论文将大规模 TabPFN 推理的可扩展性问题重新定义为**信息保持的上下文构建问题**——即如何在固定上下文预算下，最大化保留原始训练数据中的预测信息。作者提出，决定 TabPFN 大规模推理效果的瓶颈主要在于**上下文质量**而非模型容量。

## 2. 提出的方法论：BAPS 框架

### 2.1 核心设计思想

- 不修改、不重新训练预训练模型，只优化输入给 TabPFN 的推理上下文（即原型子集）。
- 联合保持五类互补的预测信息：
  - **代表性结构**（representative structure）：数据的主导分布形态；
  - **决策边界**（decision boundary）：区分相邻类别的判别性证据；
  - **局部密度**（local density）：可靠的局部邻域结构；
  - **类别平衡**（class balance）：防止上下文偏向多数类；
  - **特征空间多样性**（feature-space diversity）：最大化特征覆盖、减少冗余。

### 2.2 问题形式化

- 给定训练集 D，上下文预算 B，目标是构造原型子集 P，最大化信息保留函数：

  \[
  I(P) = \lambda_r R(P) + \lambda_q Q(P) + \lambda_d D(P) + \lambda_v V(P) + \lambda_c C(P)
  \]

  其中 R、Q、D、V、C 分别对应代表性、边界、密度、多样性与类别保持信息；权重系数满足非负且和为 1。
- 最优原型上下文为 \( P^* = \arg \max_{|P|=B} I(P) \)，但由于组合爆炸，精确求解不可行，BAPS 采用分层近似策略。

### 2.3 算法流程（Algorithm 1）

1. **类别感知预算分配（Class-Aware Budget Allocation）**：在候选生成前先将原型预算按类别分布分配，保持类别平衡；
2. **代表性候选生成（Representative Selection）**：捕获各类别的主导统计结构；
3. **边界候选生成（Boundary Selection）**：保留靠近决策边界的信息样本；
4. **密度候选生成（Density Selection）**：保持可靠的局部邻域结构；
5. **候选合并与多样性精炼（Diversity Refinement）**：合并三类互补候选，去除冗余、最大化特征空间覆盖；
6. **多上下文聚合（可选）**：使用不同随机初始化生成多个 BAPS 上下文，分别通过冻结的 TabPFN 推理后对预测概率取平均，以提升稳定性。

### 2.4 计算复杂度

- 额外计算开销仅发生在**原型构建阶段**，对每个数据集只需执行一次；
- 推理时模型仅处理固定大小为 B 的上下文，计算和内存成本与原始数据集规模无关；
- 多上下文聚合的额外推理成本约与上下文数量成正比，但可预测、可控。

## 6. 主要结论与发现

- **BAPS 能在约 1,953 倍压缩下保持强预测性能**：仅 512 个原型即可在百万行数据集上取得与强基线相当或更优的结果，证明"原型质量而非原型数量"是决定上下文有效性的关键因素。
- **BAPS Ensemble 是最稳健的整体方案**：
  - HIGGS 上 Balanced Accuracy 为 0.697，优于所有单上下文方法（Stratified Random 0.670、KMeans Medoid 0.690、BAPS-Density 0.688），但在 Balanced Accuracy 上略低于 KMeans Ensemble（0.703）；
  - SUSY 上 Balanced Accuracy 为 0.782，为所有方法中最高。
- **多上下文聚合能改善校准和稳定性**：BAPS Ensemble 的 ECE 相比 BAPS 单上下文变体有显著改善（HIGGS：0.106 → 0.093；SUSY：0.056 → 0.038）。

- **有效上下文构建是必要的机制**：论文认为这不仅是优化策略，更是将预训练表格基础模型扩展到百万级数据的**基本要求**。

## 7. 方法亮点与优点

- **无需修改或重训预训练模型**：完全兼容原始 TabPFN 架构，即插即用，工程成本低。
- **信息保持视角的转化**：将原型选择从"减少数据量"重新定义为"固定预算下的信息最大化"，理论上更贴合基础模型的推理范式。
- **多源互补信息的联合优化**：同时考虑代表性、边界、密度、类别平衡与多样性，比单一准则（随机、聚类、密度）更全面。
- **CPU 级可运行性**：全部实验在普通 CPU 上完成，无需 GPU，极大降低了硬件门槛。
- **多上下文聚合策略**：利用"多次小推理 + 概率平均"提升稳定性和校准质量，思路简洁且有效。
- **有统计显著性验证**：使用配对 Wilcoxon 检验 + Holm 校正，增强了结论的可靠性。
