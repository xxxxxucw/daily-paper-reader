## 摘要
视觉语言模型（VLMs）应从具体的图像证据出发进行回答，而非依赖语言先验、数据集捷径或无关的视觉上下文。现有的感知感知后训练方法通过全局扰动或注意力代理来鼓励使用图像，但它们并未检验采样答案是否因果地依赖于支持它的局部证据。我们提出了反事实证据解缠（CED），这是一种用于VLM接地（grounding）的训练时证据审计方法。对于每个响应，CED中立化一个以对象为中心的证据区域，并将由此产生的支持度下降与匹配的非证据区域进行比较。我们将这一信号与答案正确性结合在GRPO中，奖励依赖证据路径而非捷径或干扰路径的正确答案。CED使用弱对象级提议，不需要针对问题的证据标注，且不增加推理时的开销。在九个公共基准和四个骨干网络上，CED优于先前基于RL的后训练方法，针对性分析验证了其以对象为中心的信号。

## Abstract
Vision-Language Models (VLMs) should answer from concrete image evidence rather than language priors, dataset shortcuts, or irrelevant visual context. Existing perception-aware post-training methods encourage image use through global perturbations or attention proxies, but they do not test whether a sampled answer causally depends on the local evidence that supports it. We propose Counterfactual Evidence Disentanglement (CED), a training-time evidence audit for VLM grounding. For each response, CED neutralizes an object-centric Evidence Region and compares the resulting support drop against matched non-evidence Regions. We combine this signal with answer correctness inside GRPO, rewarding correct answers that rely on the evidence path rather than shortcut or nuisance paths. CED uses weak object-level proposals, requires no question-specific evidence annotations, and adds no inference-time overhead. Across nine public benchmarks and four backbones, CED outperforms prior RL-based post-training methods, with targeted analyses verifying its object-centric signal.

## 1. 核心问题与研究动机

- **问题背景**：视觉语言模型（VLMs）在视觉问答、计数、空间推理等任务上表现出色，但“答案正确”不等于“视觉上被支撑”。模型完全可能仅凭借语言先验（如“眼镜通常有两条镜腿”）、数据集规律或场景常识给出正确答案，而实际上并未真正查看图像中的关键证据。
- **现有方法的不足**：已有感知感知型后训练方法（如 PAPO、VPPO）试图通过全局图像扰动或注意力代理将图像重新纳入训练循环，但存在关键缺陷：
  - 全局扰动只能证明模型“对图像敏感”，无法证明答案**因果地依赖**于支撑它的**局部证据**；
  - 注意力代理只是内部路由的间接信号，并非对答案是否真被证据支撑的直接检验；
  - 图像是一个复合体，包含目标证据、无关上下文、视觉干扰物以及扰动本身引入的伪影，全局扰动无法区分这些路径。
- **核心科学问题**：如何在后训练中构造一种奖励信号，能够区分“答案由目标视觉证据因果驱动”与“答案由捷径/干扰路径产生”，从而训练模型真正进行“证据密集型”视觉推理？

## 2. 方法论：CED 与 EVIDENCE-RL

### 2.1 核心思想：因果视角下的证据审计

- 从结构因果图出发，一个候选答案可能通过三条路径产生：**目标证据路径**、**语言/世界先验捷径路径**、**无关上下文/干扰物路径**。三条路径汇聚于同一观测输出，导致仅靠文本输出无法区分答案被哪条路径驱动。
- 论文提出**反事实证据解缠（Counterfactual Evidence Disentanglement, CED）**，将因果图转化为训练时的反事实检验：对于每个采样答案，CED 询问模型对该答案的支持度在**证据区域被中和**时，比在**匹配的非证据区域被中和**时下降得是否更多。只有答案正确性依赖于证据路径时，该回答才会被奖励。

### 2.2 关键技术细节

- **证据区域（Evidence Region）识别**：使用弱监督的 COCO 对象级边界框作为证据区域提议，不需要针对问题的像素级标注。非证据区域通过面积匹配、与证据区域 IoU ≤ 0.05 的随机采样获得（每样本 K=3 个）。
- **特征空间反事实干预**：对空间合并后的视觉 token，用相邻 token 的均值 μT 替换目标区域对应 token：
  \[
  \tilde{h}_i = \begin{cases}
  \mu_T & \text{if } i \in T(\Omega) \\
  h_i & \text{otherwise}
  \end{cases}
  \]
  均值替换比置零或高斯噪声更干净：它移除区域特定信息，同时保持局部表示流形大致不变，减少干预伪影。
- **证据敏感性度量**：候选答案 y 对区域 Ω 的敏感性定义为反事实对数似然下降：
  \[
  s(\Omega) = \log \pi_\theta(y \mid I, q) - \log \pi_\theta(y \mid \tilde{I}_{\setminus\Omega}, q)
  \]
- **证据边际（Evidence Margin）**：将证据区域敏感性相对非证据区域敏感性分布标准化并压缩到有界区间：
  \[
  m(I, q, y) = \tanh\left(\frac{s(\Omega_{ev}) - \mu(s_{non})}{\sigma(s_{non}) + \epsilon}\right)
  \]
  正边际表示答案对证据区域的支持度下降显著大于对非证据区域的支持度下降。
- **结合 GRPO 的奖励设计**：
  \[
  R_{\text{train}} = R_{\text{ans}} \cdot g(m) + \epsilon_{\text{tie}} m,\quad
  g(m) = \frac{1}{2}\left(1 + \tanh\left(\frac{m}{\tau_g}\right)\right)
  \]
  其中 τg=0.20，εtie=0.10。该设计保证：答案正确性仍是主导梯度驱动；在同样正确的回答中，CED 依据证据支撑程度进行排序；答案错误时证据项退化为有界平局打破器（|εtie·m| ≤ 0.10）。由此可区分同组内“同样答对但路径不同”的轨迹。

## 6. 主要结论与发现

- CED 奖励信号能有效区分证据依赖与正确性本身：计数任务中 99.5% 的组产生非恒定奖励，90.0% 的同答案轨迹获得不同奖励。
- 在 Qwen2.5-VL-7B 上，EVIDENCE-RL 平均分达 67.13（Δ+5.94），是匹配骨干比较中唯一在全部九个基准上均非负提升的 RL 方法；最大增益出现在感知密集型基准（VLMsAreBlind +14.22、FREAK +14.22、MMMU +6.84）。
- 受控比较表明，CED 是增益的关键来源：正确性-only 与 VPPO 重训产生负迁移（平均 Δ 分别为 −1.24、−1.78），而 Answer-CED 将平均 Δ 提升至 +11.34（相对正确性-only 提升 +12.58）。
- CED 信号具有真实证据定位能力：随机对象框替换使平均边际从 0.268 跌至 0.015（接近随机水平）；IoU 分级实验显示信号随与原始提议重叠度单调下降。
- 均值替换干预优于零替换和高斯噪声替换（AUC 0.669 > 0.641 > 0.629），全局随机掩蔽低于机会水平（0.490）。
- Answer-CED 优于 CoT-CED：CoT 变体的稠密逐 token 奖励可被“缩短推理链”这一奖励作弊路径操纵（链长缩至 3.6 token），Answer 变体通过只评分定长答案跨度消除了该自由度。
- CED 不损害纯文本推理：8 个纯文本基准平均变化仅 −0.27 个百分点。
- 论证了“证据封闭型自我进化”的不可辨识性：仅观测文本的奖励满足条件独立性，无法区分接地与捷径轨迹；CED 通过注入图像条件信号打破这种封闭。

## 7. 方法亮点

- **因果层次创新**：从“模型是否看图像”提升到“答案是否因果依赖于支撑它的局部证据”，在形式化层面比 PAPO 的全局扰动和 VPPO 的注意力代理更精确。
- **无需细粒度标注**：仅用 COCO 对象级提议，不要求问题特定的证据标注，训练可扩展。
- **反事实干预设计细致**：均值替换保留了局部特征基线，从一阶展开角度论证了其比零替换、噪声替换引入更少伪影。
- **奖励工程谨慎**：正确性锚定 + 证据门控 + 有界平局打破器的组合，防止证据信号喧宾夺主；并对答对但路径不同的轨迹提供排他性判别力（案例中产生 7× 奖励差）。
- **与 GRPO 无缝集成**：只在训练时使用反事实审计，推理时零额外开销。
- **验证体系完整**：从信号诊断、受控消融、跨骨干泛化、提议扰动到干预类型消融，多角度支撑结论，并附有大段形式化分析。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，复现成本难以评估。
- **证据接口局限**：当前 CED 以对象级空间区域为证据接口，对属性级（如颜色、材质）、关系级证据的扩展仅作展望，未做实验验证；对非对象中心的证据类型（如纹理、空间关系）覆盖有限。
- **对标注的隐式依赖**：虽然不需要问题特定标注，但仍依赖 COCO 数据集的对象级边界框，迁移到没有此类元数据的开放域数据时，证据区域提议的质量和可用性未充分测试。
- **基准覆盖面偏重对象中心任务**：评估基准集中于计数、空间、幻觉检测等对象相关推理，对文档理解、图表推理、医学影像等视觉证据形态不同的场景缺乏验证。
- **基准存在反噬现象**：在 ScienceQA 空白图像子集上，CED 抑制了模型用语言先验作答的倾向，反而被基准判为错误（如“无法从图像确定”被判错）。尽管净效应仍为正，但这提示了当前评估体系对“合理拒绝作答”行为缺乏奖励。
- **CoT 变体的奖励作弊风险提示了更广的过程奖励风险**：论文虽通过 Answer 变体规避，但尚未探索在必须输出长链条推理的任务（如复杂多步视觉推理）中如何安全使用证据信号。
- **基线对比公平性仍有瑕疵**：主表中不同方法的 Δ 对应的基座不一致；部分基线的重训结果可能不是其最优配置，PAPO 在 Qwen3.5-9B 上的不稳定表现使受控对比对其不够有利。
