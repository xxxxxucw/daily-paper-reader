## 摘要
概率逻辑编程是统计关系人工智能的一种形式，支持因果查询，包括来自系统外部的干预。然而，当从数据中学习概率逻辑程序的结构时，仅使用概率信息，且单一概率分布可能与多种因果顺序兼容。这导致干预推理中的歧义，引发了一个问题：因果顺序何时由分布唯一确定。利用无环概率逻辑程序与贝叶斯网络之间的关系，我们推导了程序中编码的概率信息确定唯一因果顺序的条件。我们还通过考虑由潜在关系词汇引起的指定因果对称性集合，纳入了来自关系结构的约束。结果是一种验证所学概率逻辑程序是否支持明确定义的干预语义的方法。

## Abstract
Probabilistic logic programming is a formalism of statistical relational artificial intelligence that supports causal queries, including interventions from outside the system. When the structure of a probabilistic logic program is learned from data, however, only probabilistic information is used, and a single probability distribution may be compatible with several causal orders. This leads to ambiguity in interventional reasoning, raising the question of when the causal order is uniquely determined by the distribution. Exploiting the relationship between acyclic probabilistic logic programs and Bayesian networks, we derive conditions under which the probabilistic information encoded in a program determines a unique causal order. We also incorporate constraints arising from relational structure by taking into account prescribed sets of causal symmetries induced by the underlying relational vocabulary. The result is a method for verifying when a learned probabilistic logic program supports well-defined intervention semantics.

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 2.1 核心思想

论文的方法建立在**无环概率逻辑程序与因果贝叶斯网络（Causal Bayesian Networks, CBN）之间的等价关系**之上。由于无环概率逻辑程序的语义可以映射为对应依赖图上的贝叶斯网络，因此可以通过贝叶斯网络中Markov等价类的理论来确定因果方向的唯一定义性。

#### 2.2 关键概念与技术细节

- **因果贝叶斯网络**：由有向无环图及条件概率表组成，支持通过干预操作（\(do(A=t)\)）移除指向被干预节点的边并固定其值来计算外部干预的效果。

- **忠实性假设（Faithfulness）**：假设概率分布的所有条件独立性都由贝叶斯网络的结构捕获。在这一假设下，马尔可夫等价图共享相同的邻接关系，仅在边方向上可能存在差异。忠实性在Lebesgue测度意义下几乎总是成立，但确定性变量场景常违反此假设。

- **可定向性（Orientability）定义**：一条有向边 \((X,Y)\) 是可定向的，当且仅当它出现在所有与 \(G\) 马尔可夫等价的图中。论文引用 Meek 的经典结果（Proposition 1），通过以下五条规则迭代判定所有可定向边：
  1. **无遮蔽对撞结构**：\((A,B)\) 和 \((C,B)\) 是边且 \(A\)、\(C\) 不相邻 → \((A,B)\)、\((C,B)\) 可定向；
  2. **前向传播**：\((A,B)\) 可定向、\((B,C)\) 是边且 \(A\)、\(C\) 不相邻 → \((B,C)\) 可定向；
  3. **传递性（链式）**：\((A,B)\) 和 \((B,C)\) 可定向且 \((A,C)\) 是边 → \((A,C)\) 可定向；
  4. **规则4**（对角线传播）：\((B,D)\) 和 \((C,D)\) 可定向、\(A\) 与 \(B\)、\(C\) 相邻但 \(B\)、\(C\) 不相邻、\((A,D)\) 是边 → \((A,D)\) 可定向；
  5. **规则5**（类似地）：\((A,C)\) 和 \((C,D)\) 可定向、\(B\) 与 \(A\)、\(C\) 相邻且 \((B,D)\) 是边 → \((B,D)\) 可定向。

- **命题化概率逻辑程序（Propositional ProbLog Program）**：引入内部词汇（internal vocabulary）与外部词汇（external vocabulary）的区分。外部估值（external valuation）决定哪些子句被激活，激活后的相对程序形成有向无环依赖图。每条子句具有噪声或（noisy-or）语义：效果的概率由所有被满足的原因子句的噪声或函数计算，即 \(1 - \prod(1-\pi_i)\)。

- **干预的定义（Proposition 2）**：在命题化概率逻辑程序中，干预 \(\Pi_{do(L)}\) 的实现方式为：删除以 \(L\) 涉及的原子为头的所有子句，若为正干预则将该原子的真值固定为真。论文引用已有结果证明此操作与贝叶斯网络中的干预语义完全一致。

- **核心定理（Proposition 3）**：若 \(\Pi_V\) 忠实于其依赖图 \(Graph_V(\Pi)\) 且该图可定向，则任何具有相同概率分布且忠实于自身依赖图的另一程序 \(\tilde{\Pi}\) 必然具有相同的依赖图，从而**两个程序上的干预操作产生相同的后干预分布**。这为可验证的干预语义提供了充分条件。

#### 2.3 关系化扩展：因果对称性的引入

- **关系化概率逻辑程序**：将命题化程序提升到一阶逻辑，通过外部数据库（external database）的域常量对程序进行接地（grounding），生成命题化程序。接地后的依赖图中，每条边由某一关系子句的实例化产生。

- **因果对称性的形式化（Definition 17）**：设 \(M\) 为一组有向边集合，若图 \(G\) 满足对所有 \(m \in M\)，要么 \(m\) 中所有边都按原方向出现在 \(G\) 中，要么都按反方向出现，则称 \(G\) 尊重 \(M\) 中的因果对称性。\(M\)-可定向定义为在所有尊重 \(M\) 的马尔可夫等价图中都存在的边。

- **新增定向规则 1（Proposition 4）**：若 \((A,B)\) 是 \(M\)-可定向的边且 \((C,D)\) 与 \((A,B)\) 同属一个对称集合 \(m \in M\)，则 \((C,D)\) 也是 \(M\)-可定向的。这允许将局部的定向信息沿着对称性传播到其他接地实例。

- **新增定向规则 2（Proposition 5）**：若 \(A\) 和 \(C\) 不相邻，\((B,A)\) 和 \((B,C)\) 是边，且 \((A,B)\)、\((C,B)\) 属于同一对称集合 \(m\)，则 \((B,A)\) 和 \((B,C)\) 可定向。这突破了对撞结构（collider）限制，将**对称叉结构（symmetric fork）**也纳入可定向范围。

- **谓词对称性（Predicate Symmetry, Definition 18）**：假定因果关系方向仅由谓词符号决定——任意两个不同谓词 \(P\) 和 \(R\) 之间的所有接地边方向一致。这一假设等价于要求程序的谓词依赖图中不存在 2-环，适合不具有时间分层结构的场景。

- **用户指定的方向/2 谓词**：对于时间分层等不适用谓词对称性的场景，可通过数据库中的 direction/2 谓词预设边方向，作为背景知识约束候选图集合。

### 6. 论文的主要结论与发现

1. **命题化概率逻辑程序的因果验证路径**：在忠实性假设下，若程序的依赖图可定向（可由 Meek 五条规则完全判定），则概率信息足以唯一确定因果结构，从而任意两个具有相同概率分布的程序（满足忠实性条件）具有相同的干预语义。

2. **因果对称性极大增强定向能力**：关系化程序中，源于同一关系子句的不同接地边构成对称集合。利用这种对称性可：
   - 将局部已定向的边传播到所有对称对应的边（Proposition 4）；
   - 定向一般情形下无法定向的**对称叉结构**（Proposition 5）。

3. **谓词对称性是关键假设**：它假定因果方向仅由谓词符号决定（等价于谓词依赖图无 2-环），在 UWCSE 案例中证明该假设能将仅由一条对撞结构锚定的定向信息扩展到整个接地图，使学习到的程序能够支持可靠干预推理。

4. **实现了理论与工具的闭环**：所提出的算法已在 PLP-BN tools（Prolog/Logtalk 实现）中落地，支持谓词对称性和用户自定义对称集合，为实践应用提供了基础。
