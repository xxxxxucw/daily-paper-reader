## 摘要
与图像和文本不同，由于不同领域之间特征类型、结构和语义的异质性，将迁移学习应用于表格数据具有挑战性。现有方法假设数据表之间共享特征以实现领域间的知识迁移，这在实践中是不现实的。\mds{本文引入了广义上下文学习，以消除跨领域共享特征的要求。通过Transformer投影权重（用于$key$、$value$和$query$）捕获的广义上下文提供了基于规则的泛化，而非通常从Transformer激活中学习的领域特定上下文。源域中$key$的投影权重与目标域中$query$的权重相互作用，以数据无关的方式实现跨域注意力迁移学习（CATTLE）。我们在十对不相交的源-目标数据集上的实验表明，CATTLE可以从单个源数据集中学习广义上下文，并且在排名和统计上优于九个最先进的基线方法，包括使用大规模预训练模型的机器学习、深度学习和迁移学习方法。CATTLE实现了最佳平均排名（2.9），并且比基线方法平均AUROC提高了3.7%。} CATTLE源代码可在https://tinyurl.com/pr5s8ywn获取。

## Abstract
Unlike images and text, applying transfer learning to tabular data is challenging due to heterogeneity in feature types, structures, and semantics across disparate domains. Existing methods assume shared features across data tables to enable knowledge transfer between domains, which is unrealistic in practice. \mds{This paper introduces generalized context learning to remove the requirement of shared features across domains. The generalized context captured by transformer projection weights for $key$, $value$, and $query$ provides rule-based generalization rather than the domain-specific context conventionally learned from transformer activations. Projection weights for $key$ from the source domain interact with the weight for $query$ in the target domain to achieve Cross-domain Attention Transfer Learning (CATTLE) in a data-agnostic manner. Our experiments on ten pairs of disjoint source-target data sets show that CATTLE can learn generalized context from a single source data set and is rank-wise and statistically superior to nine state-of-the-art baselines, including machine learning, deep learning, and transfer learning methods using large-scale pre-trained models. CATTLE achieves the best average rank (2.9) and delivers a 3.7% average AUROC gain over the baseline methods.} The CATTLE source code is available at https://tinyurl.com/pr5s8ywn.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：与图像和文本数据不同，表格数据（tabular data）具有特征类型、结构和语义的异质性，使得跨领域迁移学习极具挑战。现有迁移学习方法（如 TransTab、CM2、XTab）均假设源域和目标域数据表之间存在共享特征或特征空间重叠，但现实中来自不同领域（如银行交易与电子健康记录）的数据表往往在特征维度上完全不相交（disjoint），该假设并不成立。
- **研究背景**：传统机器学习（如 XGBoost）在表格数据上仍然极具竞争力，甚至优于深层模型；而深度学习的表征学习、增量学习与迁移学习优势在表格数据上尚未充分发挥。表格数据普遍存在样本量小（常少于 1000 条）、标注困难、难以预训练等问题，进一步增加了迁移学习的难度。
- **整体含义**：论文主张，实现表格数据跨域迁移学习的关键在于**去除对共享特征的依赖**，转而学习一种**数据无关（data-agnostic）的广义上下文（generalized context）**。该上下文应从 Transformer 的投影权重（projection weights）而非激活值中获取，以提供规则层面的泛化能力。

## 2. 论文提出的方法论

### 2.1 核心思想

- 传统跨注意力机制利用数据表示（$key$、$value$、$query$ 激活向量）学习领域特定上下文，不适用于特征空间完全不相交的表格数据。
- 论文提出**在 Transformer 投影权重层面进行交叉注意力**：源域预训练模型的 $W_k$（键投影权重）与目标域模型可学习的 $W_q$（查询投影权重）交互，形成跨域注意力，实现知识迁移。
- 该方法命名为 **CATTLE（Cross-domain Attention Transfer Learning）**，属于数据无关的迁移学习框架。

### 2.2 关键技术细节

1. **预训练阶段（源域）**：

   - 分别进行**自监督预训练**与**监督预训练**以作对比：
     - 自监督：随机掩码 35% 的特征值（伯努利分布），重建被掩码的数值特征（均方误差，式 5）和类别特征（余弦相似度，式 4），总损失为两类损失的归一化和（式 6）。
     - 监督：使用源域类别标签进行交叉熵训练。

2. **跨注意力权重迁移与微调（目标域）**：
   - 取预训练 gFTT 模型**最后一层**的 $W_k$ 与 $W_v$，替换目标域新初始化 gFTT 模型**最底层两层**的对应权重，并**冻结**。
   - 目标域网络的 $W_q$ 及其余权重通过目标域数据微调更新。

### 2.3 算法流程（文字描述）

1. 用源域数据预训练 gFTT_s（自监督或监督）。
2. 提取 gFTT_s 最后一层的注意力权重（$W_{Lk}, W_{Lv}$）。
3. 初始化新的 gFTT_t，将其底层两层的 $W_k$ 与 $W_v$ 替换为上述源域权重并冻结。
4. 用目标域数据微调 gFTT_t 的其余权重（包括 $W_q$、上层注意力、分类头），得到跨注意力模型 gFTT_CA 用于目标域预测。

## 6. 论文的主要结论与发现

1. **广义上下文有效**：基于 Transformer 投影权重（而非激活值）的跨注意力机制，可在源-目标特征完全不相交的情况下实现有效迁移。
2. **自监督优于监督预训练**：CATTLE 自监督版本在 AUROC（平均排名 2.9）和 ACC（平均排名 2.4）上均取得所有方法中的最佳表现；监督版本次之（AUROC 排名 3.9，ACC 排名 4.6）。
3. **单源数据即可**：仅使用一个源表格数据集即可习得数据无关的广义上下文，无需大规模多域数据预训练；这挑战了“预训练模型必须使用海量多域数据”的传统观念。
4. **优于大规模预训练模型**：在多数情况下，仅用单源数据的 CATTLE 可与 TabPFNv2（1.3 亿合成数据集预训练）和 TARTE（维基百科文本预训练）竞争甚至超越。
5. **统计显著性**：Wilcoxon 检验显示，CATTLE 自监督版本在所有存在显著差异的数据对中均获胜，且平均 AUROC 比基线提升约 3.7%。

## 7. 优点
