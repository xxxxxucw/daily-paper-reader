## 摘要
基于上下文学习的表格基础模型近期已成为特定任务模型拟合的强大替代方案。然而，当前性能前沿仍由注意力密集型架构主导，其中注意力贯穿整个建模流程。这引发了一个自然问题：在表格上下文学习的每个阶段都需要注意力吗？我们提出了SOMTab，一种用于高效表格上下文学习的Set-Order Mamba架构。SOMTab将表示构建与查询条件检索分离。对于行和列表示，它将无序表格令牌映射到稳定的潜在槽中，并应用基于Mamba的状态空间混合来构建紧凑表示。对于最终预测，它保留基于注意力的上下文学习，以保留从标记上下文示例中进行的查询条件检索。我们进一步引入了DCH-TailMix，一种合成先验，它将度校正图异质性与混合重尾机制相结合，以多样化合成依赖结构。在各种表格基准测试中，SOMTab接近强Transformer-based表格基础模型的性能，同时实现更快的推理和更低的GPU内存使用，产生了有利的效率-准确性权衡。

## Abstract
Tabular foundation models based on in-context learning have recently emerged as strong alternatives to task-specific model fitting. However, the current performance frontier remains dominated by attention-heavy architectures, where attention is used throughout the modeling pipeline. This raises a natural question: is attention necessary at every stage of tabular in-context learning? We introduce SOMTab, a Set-Order Mamba architecture for efficient tabular in-context learning. SOMTab separates representation construction from query-conditioned retrieval. For row and column representations, it maps unordered table tokens into stable latent slots and applies Mamba-based state-space mixing to construct compact representations. For final prediction, it retains attention-based in-context learning to preserve query-conditioned retrieval from labeled context examples. We further introduce DCH-TailMix, a synthetic prior that combines degree-corrected graph heterogeneity with mixed heavy-tailed regimes to diversify synthetic dependency structures. Across tabular benchmarks, SOMTab approaches the performance of strong Transformer-based tabular foundation models while achieving faster inference and lower GPU memory usage, yielding a favorable efficiency--accuracy trade-off.

## 2. 方法论

### 2.1 核心思想
- 将无序表格 token 通过 set-to-order 机制映射为**稳定潜在槽序列**，再用 Mamba 进行线性复杂度混合；最终预测保留注意力以实现查询条件检索。
- 分离了"表示压缩"与"查询检索"，打破注意力"全阶段默认算子"的惯例。

### 2.2 Set-to-Order Mamba Block
- **输入**：无序 token 集合 S ∈ R^(N×d)；**种子槽** U ∈ R^(K×d) 的固定索引定义潜在序列顺序。
- **Set Read**：通过交叉注意力聚合：
  Z′ = U + Attn(LN(U), LN(S), LN(S))
  Z⁰ = Z′ + FFN(LN(Z′))
- **Mamba 混合**：潜在序列经 Mamba-2 残差块处理：
  Z = Z⁰ + Mamba2(LN(Z⁰)) + FFN(...)
- **Readback**（可选）：将潜在摘要读回原始 token，保持置换等变性。
- **特性**：Set-to-order 映射是置换不变的；读回操作对输入是置换等变的。复杂度为 O(NK)（交叉注意力）+ O(K)（Mamba），远低于全注意力 O(N²)。

### 2.3 SOMTab 整体架构（见图 2）
- **任务布局**：给定 n_tr 个带标签上下文行和 n_te 个查询行，m 个特征。采用 TabICLv2 的**循环特征分组**（offsets 0,1,3），初始 token e⁽⁰⁾ᵢⱼ = ϕₓ(x̃ᵢⱼ) + 1[i ≤ n_tr]·ψ_early(yᵢ)。
- **变量级编码器**（列向）：每列 j 只读取上下文行的 token 集合，经 set-to-order + Mamba 产生 K_v=64 个潜在槽，再读回所有行（含查询行）。共 L_v=3 层。查询行只读取列摘要，不改变摘要。
- **样本级编码器**（行向）：每行 i 的 m 个特征 token + K_r=4 个共享行 token → K_s=4 个有序潜在槽 → 3 层 Mamba 块 → flatten 得 h_i ∈ R^(4d)。
- **注意力 ICL Reader**：为上下文行添加第二标签嵌入 ψ_late(yᵢ)，然后用 12 层 Transformer 块，其中 Q=所有行，K/V=仅上下文行（context-only attention）。最终 MLP 输出查询类概率。
- **复杂度**：表示构建 O(N·m·(K_v+K_s))，线性于单元格数；最终 reader 为 O(N²)但仅作用于行级 4d 表示。

### 2.4 DCH-TailMix 合成先验
- **度校正图采样（DCH）**：在拓扑序 DAG 上采样边，边 logit 联合了：基础稀疏度 τ、任务级密度 g、节点出/入度校正 a_out/a_in、模块对偏好 b、低秩相关项 λ⟨u,v⟩/√r 和边级噪声 ε。
- **TailMix 尾部分布混合**：三种机制按类别概率 (0.70, 0.20, 0.10) 采样：
  - 独立 Student-t（控制尾强度）
  - 分层 Student-t（共享任务级自由度，保持任务内相干异质性）
  - 对称 Pareto（产生极端正负偏差，形成枢纽结构）
- **潜伏传播与任务构造**：根节点初始化后，非根节点经八类随机函数族（线性、神经网络、树集成、离散化、GP 类、二次型、EM 类、乘积等）生成；目标由 1–3 个潜在节点经同一函数机制生成连续信号后离散化为 C≤10 类。

### 2.5 预训练目标

## 6. 主要结论与发现

1. **注意力无需贯穿所有阶段**：将表示构建替换为 Mamba 状态空间混合，仅保留最终查询-上下文匹配的注意力，即可获得接近强 Transformer 基线（TabICLv2、TabPFNv2）的预测性能。
2. **效率优势显著**：SOMTab 的归一化 log-loss 为 0.054，接近 TabICLv2 单估计器的 0.046，但运行时仅 0.019 秒/1K 样本（TabICLv2 单估计器为 0.151，默认 8 估计器为 0.463），快约 8–24 倍。
3. **长上下文优势扩大**：上下文从 512 增至 28,672 行时，SOMTab 始终为最低运行时，且注意力基线的二次显存增长使 SOMTab 在大上下文下显存优势明显（小上下文时略高）。
4. **DCH-TailMix 先验有效**：在相同架构和训练预算下，DCH-TailMix 优于随机 Cauchy 图先验和 TabICL 的 SCM-Tree 混合先验（20K 步时分别约 +2–3 个百分点准确率）。
5. **注意力 reader 优于 Mamba reader**：替换最终 ICL reader 为 Mamba 会降低准确率约 1–2 个百分点，验证了"表示构建用 Mamba、最终检索用注意力"的设计原则。
6. **与树模型相比**：SOMTab 显著优于所有树基线（CatBoost 归一化 LL 0.309、XGBoost 0.509 等），表明表格基础模型范式在大中小型表格上有竞争力。

## 7. 优点

- **架构设计创新**：明确区分"表示压缩"与"查询匹配"两种计算角色并采用不同算子，提出了"注意力选择性分配"的通用设计原则，而非简单的 Mamba 替换 Transformer。
- **置换不变性处理得当**：通过种子槽的固定索引定义潜在序列顺序，使 Mamba 扫描不依赖输入的任意行列排列，同时保持期望的置换不变/等变性质。
- **复杂度分析与实验验证一致**：理论复杂度 O(N·m·(K_v+K_s)) 与实测运行时/显存曲线吻合，且优势随上下文规模扩大而增强。
- **合成先验的设计粒度丰富**：DCH 图采样的多源结构项（度校正、模块化、低秩相关）+ TailMix 三机制尾部混合，覆盖了稀疏、模块化、密集、枢纽等多样依赖结构。
- **实验控制严谨**：统一服务器、统一数据划分；集成配置分离报告；消融实验在同预算下进行，结论可靠。

## 8. 不足与局限

- **性能上限仍有小差距**：归一化 log-loss 0.054 仍低于 TabICLv2 默认（0.029）和单估计器（0.046），即准确率 0.849 vs 0.854 存在约 0.5 个百分点的差距，"逼近但未超越"。

## 8. 不足与局限（续）

- **消融实验的规模有限**：受控消融实验仅训练约 20K 步，远少于主模型 400K 步（Stage 1 + Stage 2），属于早期训练行为比较；其结论只能反映相对趋势，不能直接等同于最终收敛性能的差距。

- **类别数覆盖有限**：预训练任务仅覆盖 C≤10 类，未验证高类别数（如数百类）、多标签或排序类任务的适用性。

## 9. 启发与未来方向

1. **"选择性注意力分配"可迁移至其他模态**：论文的核心思想——区分表示构建与查询匹配，将高复杂度算子部署到必要阶段——可推广至时序预测、图学习、多模态 ICL 等任务，为架构设计提供参考原则。
2. **探索更高效的 reader 替代方案**：最终预测阶段的注意力仍是二次复杂度，未来可尝试稀疏注意力、核近似或混合检索机制，进一步降低长上下文下的推理成本。
3. **扩展任务覆盖范围**：将 SOMTab 扩展到回归、多标签、高类别数、缺失值原生处理等任务，以增强表格基础模型的通用性。
4. **优化训练成本**：探索低精度训练、LoRA 微调、更大批次的调度策略或蒸馏方法，以降低 23 天 × 4 GPU 的预训练门槛。
5. **迭代合成先验**：DCH-TailMix 证明合成数据生成质量是性能关键，未来可引入扩散模型、LLM 辅助的数据生成或图结构学习，构造更接近真实表格分布的任务谱。

## 10. 总结

SOMTab 是一篇结构清晰、实验严谨的表格 ICL 架构论文。它明确区分了表格上下文学习中的"表示构建"和"查询匹配"两个计算角色，将昂贵的注意力从全流程中解放出来，仅在必要的预测阶段保留，从而在保持接近强 Transformer 基线性能的前提下实现 8–24 倍的推理加速，并在长上下文场景中扩大优势。其价值不仅在于提供了一个高效的表格基础模型，更在于提出了一个可迁移的通用原则：**注意力应被选择性分配，而非盲目铺满所有计算阶段**。尽管在最终性能、小上下文显存开销和训练成本方面仍有可改进之处，该工作为表格基础模型的高效化与实用化提供了重要参考。
