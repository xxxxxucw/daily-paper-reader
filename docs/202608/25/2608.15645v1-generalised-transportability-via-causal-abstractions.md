## 摘要
将因果结论从源研究人群迁移到目标人群是因果推断中的一个基本问题。可迁移性理论为此提供了判据：给定来自源的实验数据和来自目标的观测数据，它确定目标查询是否可识别，并且完全如此；即，如果查询可以迁移，判据能找到精确公式。然而，它一次只能处理一个查询，且返回的是表达式而非数值本身。此外，在两种实际重要情形下它也无能为力：当查询不可迁移时，以及当完全没有目标数据时。为应对这两种情形，我们采取一种基于因果抽象理论的模型级视角。源和目标共享变量、图和干预，仅在一组已知机制上不同，这使得可迁移性成为同层抽象的特例。因此，我们不再询问某个查询是否可迁移，而是询问是否存在单一映射能够对齐源和目标在干预行为上的差异。我们刻画了在马尔可夫和半马尔可夫设置下此类映射存在的条件；当存在时，所有目标查询都能一次性迁移。我们的主要贡献在于近似情形。当不存在精确映射时，最优近似映射仍能产生有保证的查询区间，将抽象误差重新诠释为近似可迁移性的定量概念。我们将模型级迁移表述为对未观测目标机制和环境扰动的分布鲁棒优化，并为两种挑战性情形推导出保证：不可迁移查询的界，以及在目标不可知设置下的保证。我们在合成马尔可夫和半马尔可夫基准以及真实生态数据集上评估了我们的框架，并展示了这些有保证的区间确实界定了真实干预查询。

## Abstract
Transporting a causal conclusion from a source study population to a target one is a fundamental problem in causal inference. The theory of transportability provides a criterion for when this is possible: given experimental data from the source and observational data from the target, it determines whether a target query is identifiable and does so completely; i.e. if the query can be transported, the criterion finds the exact formula. However, it works one query at a time and returns an expression rather than the value itself. It is also silent in two practically important regimes: when the query is not transportable and when no target data exist at all. To tackle both, we take a model-level perspective grounded in Causal Abstraction theory. Source and target share variables, graph, and interventions, differing only at a known set of mechanisms, which makes transportability a special case of same-level abstraction. Thus, instead of asking whether one query transports, we ask whether a single map aligns the source and target across their interventional behaviour. We characterise when such a map exists in both the Markovian and semi-Markovian settings; when it does, every target query transports at once. Our main contribution lies in the approximate case. When no exact map exists, the best approximate one still yields certified query intervals, recasting abstraction error as a quantitative notion of approximate transportability. We formulate model-level transport as distributionally robust optimisation over mechanism and environment perturbations of the unseen target and derive certificates for both challenging regimes: bounds for non-transportable queries, and guarantees under target-agnostic settings. We evaluate our framework on synthetic Markovian and semi-Markovian benchmarks and a real ecological dataset, and we show that the certified intervals bracket the true interventional query.

## 1. 核心问题与研究背景

### 研究动机
- **经典问题**：因果结论（如某项治疗对恢复效果的影响）在源人群中估计得到后，能否以及如何迁移到目标人群？这对应因果推断中的**外部效度（external validity）** 与**可迁移性（transportability）问题**。
- **经典理论的局限（本文批判的出发点）**：
  - 经典可迁移性理论（Pearl & Bareinboim, 2011）基于**do-calculus**和**选择图（selection diagram）**，能够判断一个目标因果查询是否**可迁移**，并在可迁移时给出精确的识别公式；但存在三个核心不足：
    - **逐查询工作**：一次只处理一个查询，缺少模型级的统一视角；
    - **只返回二值判定或公式**：不给出查询值的估计/区间；
    - **两类困境**：R1——当查询不可迁移（不可识别）时，理论完全沉默；R2——当**没有任何目标数据**时，即使查询可迁移，也无法代入公式求值。
- **核心洞察**：源与目标模型共享变量、图和干预语义，仅在一组**已知机制（shifted mechanisms）** 上有差异——这恰好是**因果抽象（Causal Abstraction）** 中**同层抽象（same-level/automorphic abstraction）** 的特例。因此应当从**逐查询判定**转向**模型级结构关系**：是否存在单个映射 τ 同时对齐源与目标的全部干预行为？

## 2. 方法论

### 2.1 核心思想：将可迁移性重构为同层因果抽象
- 建模为结构性因果模型（SCM），源/目标 SCM 共享变量、DAG 与干预语义；仅已知节点集合 K 的机制在域间变化。
- 问题从“查询 Qt 是否可迁移”转为“是否存在单一映射 τ 将源干预族 {P_s^(ι)} 映射为目标干预族 {P_t^(ι)}”。
- 论文定义了**四个一致性的层级关系**（由弱到强）：
  1. **观测一致性（Observational consistency）**：存在 Markvo 核 K 使 P_s K = P_t；
  2. **逐干预一致性（Per-intervention consistency）**：每个干预各自有对应的核 K^(ι)；
  3. **干预一致性（Interventional consistency）**：存在单一共同核 K 同时对齐所有干预；
  4. **构造性干预一致性（Constructive IC，CICk/CICm）**：共同核还满足分量式因子分解，且不变节点对应恒等映射。
- 此外定义 **Q-受限一致性（Q-restricted consistency）**，仅要求对齐查询相关的边际分布。
- 关键概念：**兼容性鸿沟（compatibility gap）**——即使每个查询都能单独迁移，也不一定能找到单一共同映射；模型级迁移比查询级迁移严格更强。

### 2.2 精确可迁移的存在性刻画
- **马尔可夫情形（Theorem 8）**：
  - 采用**递归全局组装**思路：沿拓扑顺序逐节点将源的条件机制通过分量核 K_i 对齐到目标机制；
  - 需要**阶段式 Markov 保持**（stagewise Markov-preserving）条件保证部分变换后的分布仍保持 Markov 因子化结构，然后通过前缀归纳证明第 i 个前缀分布与目标一致；
  - **有限状态空间下**，阶段 i 的相容性等价于一个**线性可行性问题**（Theorem 32），并按秩给出唯一性判据（Proposition 33）。
- **半马尔可夫情形（Theorem 12）**：
  - 引入**区域（districts / c-components）** 概念，将图压缩为**区域 DAG（cluster DAG）**；
  - 假设每个被干预的移位区域要么整体被干预、要么完全不被干预（Assumption 1），并要求商图无环；
  - 同理可证**区域级递归组装定理**，有限状态下也能化为线性可行性问题。

### 2.3 近似情形：TraCA 框架
- **模型级传输误差**（Definition 16/17）：定义干预-查询传输误差 e_(ι,Oι)(K) = D(π_Oι(P_s^(ι) K), π_Oι(P_t^(ι)))，聚合为 Q-传输误差 E_Q(K)。
- **线性加性噪声模型（LAN）**：X = WX + U，传播子 A=(I−W)^{-1}，干预传播子 A_ι=(I−R_ιW)^{-1}。
- **精确扰动恒等式**：通过 resolvent identity 和 nilpotency（A∆W 严格下三角）导出有限展开：
  A′_ι − A_ι = Σ_{k=1}^{d−1} (A_ι R_ι ∆W)^k A_ι；
- **结构化稳定性界**：
  - 多项式稳定性界（Proposition 15）：α_ι ≤ ‖A_ι‖ Σ γ_ι^k；
  - Neumann 区稳定性界（Proposition 16）：γ_ι < 1 时 α_ι ≤ ‖A_ι‖²/(1−γ_ι) · sup ‖R_ι∆W‖；
  - 对四种模糊集几何（Frobenius 球、行/列预算、逐项 box、方向性 box）给出显式的 γ_ι 上界（Corollary 19）。
- **分布鲁棒优化（DRO）目标**：
  - min_T max_ξ∈A (1/|I|) Σ_ι F_ι(T, ξ)，其中 ξ = (∆W, μ_t, Σ_t)（高斯情形）或 (∆W, Θ)（经验情形）；
  - 模糊集设在对**未观测目标**的机制与环境扰动上，而非对源数据分布本身（与经典 DRO 的关键区别）；
  - **方向性 box**（Abox_W(δ,B)）可编码先验：预期系数向某个方向偏移 δ。
- **优化算法**：
  - 统一交替 min-max 框架：投影梯度下降更新传输映射 T，投影/近端梯度上升更新对抗变量（机制扰动、环境扰动）；

  - 经验版：Frobenius 预算扰动 ‖Θ‖_F ≤ ε√N，直接投影；
  - **Q-受限目标**：仅对齐查询相关输出边际，而非全后验联合分布。

### 2.4 查询级保证（证书）
- **通用证书（Theorem 24 高斯 / Theorem 25 经验）**：将模型级传输误差分解为三项——**传输失配**（(T−I)A_ι 项）、**机制扰动**（α_ι 项）、**环境模糊**（ε 项）——给出 δ_ι,O_ι(T) 的显式闭合界；

- **多维度评估**：传输误差、覆盖概率、区间宽度（含归一化阈值）、利用率比率、方向先验误设分析、半径校准（观测选择器）、DRO 交叉点（跨半径比较）等；
- **消融类实验**：偏移先验误设（δ 取 −0.5 到 1.0 的扫描）、训练半径 vs 测试半径的交互、方向性证书的失效模式（out-of-ball 欠覆盖）。

### 充分性与客观性评价
- **优点**：实验场景设计精准对应理论声称的两大困境（R1/R2），且对“证书是否只是区间够宽而琐碎”的批评做了正面回应（用宽度归一化和利用率比率双重衡量）；统计检验合理，没有选择性地忽略失败情形（如实报告了 Portland 上观测校准失效、对称先验下 ATE 覆盖失败等负面结果）。
- **值得注意**（非缺陷，但仍需指出）：
  - 合成数据的移位都是从本论文所定义的模糊集几何中采样的（即“因果闭合”验证），这有利于证书的覆盖声称；真实数据 Portland 提供了部分独立验证，但机制不变、仅环境偏移，未覆盖“机制偏移”加“无目标数据”两者的叠加场景。
  - 未见与**经典 transportability 的 do-calculus 基线**的端到端比较（不过作者明确阐述了适用边界：经典方法在 R1/R2 下本就无输出，因此比较意义有限）。
  - 未见与**其他近似传输/部分识别方法**（如 partial identification、partial transportability）的直接数值比较。

## 6. 主要结论与发现

1. **模型级可迁移性**：将可迁移性重构为同层因果抽象后，单一映射可同时迁移全部干预查询；精确映射的存在性在马尔可夫/半马尔可夫情形都可刻画，有限状态下归结为线性可行性。
2. **相容性鸿沟**：查询级可迁移 ≠ 模型级可迁移；模型级视角是更强的、能覆盖所有查询的统一保证。
3. **近似情形仍有价值**：无精确映射时，最优近似映射的残差可转化为**认证查询区间**，在经典理论沉默的两个场景（不可迁移、无目标数据）下依然提供保证。
4. **方向性证书显著更紧**：
   - ATCE 上方向性证书比通用证书紧 2.9 倍（族平均）；
   - LiLUCAS 上方向性证书按查询紧 7.6–17.2 倍（族平均 10.4 倍）；
   - 在通用证书已变空洞（vacuity）时，方向性证书仍是有信息量的唯一区间（如 LiLUCAS 经验配置、Portland 全部半径）。
5. **方向先验的作用**：
   - 偏移先验（δ=0.5）可使 ATE 上观测选择器成功落在有覆盖的半径，而对称先验在小半径下对 E[Y|do(X=1)] 覆盖失败（差距 0.08）；
   - LiLUCAS 经验偏移配置在小移位下误差降低高达 60%；
   - 但错误的小幅偏移是失败模式；大幅度错误偏移反而因区间变宽而覆盖成立。
6. **DRO 交叉点**：不存在单一训练半径在所有 r_test 下最优；小移位时恒等映射最优，大移位时中等的鲁棒半径显著优于基线，过度鲁棒化（r_train=4.0）反而退化——这符合鲁棒优化的一般权衡。
7. **观测校准并非万灵药**：ATE 上观测距离有内部最优点，可成功选半径；Portland 上观测距离单调递增，观测选择器指向最小半径（覆盖失败）——此时半径必须由领域知识给定。

## 7. 优点

- **理论贡献的深度与统一性**：
  - 在可迁移性与因果抽象之间建立了此前未被指出的形式联系；
  - 给出了精确可迁移性的完整分层（观测→逐干预→干预→构造性）和存在性刻画；
  - 将抽象误差定量化为近似可迁移性，提供从“二值判定”到“带区间数值答案”的连续性统一范式。
- **方法设计的实用性**：
  - 显式区分机制扰动与环境扰动（用反例证明二者不可互相替代）；
  - 四种模糊集几何（Frobenius/行/列/逐项）+ 方向性 box，适配不同先验知识的表达形式；
  - 通用证书 + 方向性证书的双重保证，后者对线性查询给出闭式且极紧的界；
  - 观测数据可用于半径校准（在可行场景下），提升实用性。
- **实验报告的可信度**：
  - 如实报告失败情形（对称先验覆盖失败、方向性证书超球欠覆盖、Portland 观测校准失效等）；
  - 大量使用归一化指标（QS、利用率 ū、有信息量/空洞阈值）避免“宽区间琐碎覆盖”的骗局；
  - 配对 t 检验、固定种子、折叠稳定性的报告方式规范。
- **可复现性**：提供公共代码库（https://github.com/yfelekis/traca），并详细给出结构方程和参数。

## 8. 不足与局限

1. **模型类别局限**：
   - 目前仅适用于**线性加性噪声模型（LAN）** 和线性传输映射；
   - 稳定性界、证书闭合形式都依赖 A=(I−W)^{-1} 和 resolvent identity，非线性情形无法直接推广；
   - 要求已知真实 DAG（或准确估计），错误图会直接影响哪些机制可变、传输组件和区域划分。
2. **源模型被视为可信参考**：
   - TraCA 将所有不确定性放在目标侧；源 SCM 的估计误差/抽样误差未纳入最终证书的传播，可能低估真实不确定性；
   - 这正是作者承认的局限，并计划用“双重 DRO”（源 + 目标）扩展。
3. **半马尔可夫情形的假设限制**：
   - 要求商图（cluster DAG）无环，且每个被干预的移位区域要么全干预、要么全不干预（Assumption 1）——部分干预一个混淆块的情形被排除。
4. **应用限制**：
   - 目标不确定性集（半径 ε、几何、方向 δ）需由用户声明；错误声明的小幅方向先验是失败模式；
   - 观测校准并不总是有效（Portland 即为反例），此时需要无数据条件下凭领域知识定半径；
   - 实验覆盖以“查询层面”为准，未对所有查询的联合覆盖做整体声称。
5. **缺少与其他方法的端点比较**：未在可实现范围内与经典 do-calculus 传输公式（对可迁移查询）或 partial identification 方法（对不可迁移查询）进行数值对比——尽管两类的适用边界有实质不同，但若补充对比可使方法定位更清晰。
