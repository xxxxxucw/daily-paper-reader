## 摘要
每个构建大型语言模型（LLM）的团队都面临一个核心挑战：离线基准显示了性能提升，部署后用户参与度也上升，但将因果从效果中分离仍然困难。同步进行的市场营销、媒体报道和季节性需求掩盖了模型更新是否真正推动了参与度增长。本文提出了一种新颖的因果估计方法，利用单一模型版本内不同能力之间的非均匀质量改进。由于能力提升是不均匀的（例如，编码方面的强劲增长与写作方面的温和增长），用户根据其任务分布体验到不同的质量。这种体验质量的差异为估计提供了因果信号。我们在具有已知真实值的合成数据上验证了该方法。原始估计器恢复了真实效应的81%至88%，其余部分损失于使用估计中的测量误差。应用变量误差去衰减调整（使用重测信度比平均相关性0.861）将估计校正为1.017（自举95%置信区间：0.915至1.109）。相比之下，朴素方法明显失败，在没有版本控制的情况下仅恢复63%，而使用实时而非冻结的使用模式时恢复62%。置换检验确认了该框架能够区分真实因果效应与噪声。敏感性分析表明，随着前期长度从3周增加到7周，恢复率从78%单调提高至87%，突显了样本时长与估计器精度之间的明确权衡。种子敏感性测试进一步证实了跨随机抽取的稳定性。

## Abstract
Every team building Large Language Models (LLMs) faces a core challenge: offline benchmarks show performance gains and user engagement rises post deployment, but isolating cause from effect remains difficult. Simultaneous marketing, media coverage, and seasonal demand obscure whether model updates truly drive engagement gains. This paper presents a novel causal estimation approach that leverages non uniform quality improvements across capabilities within a single model version. Because capabilities improve unevenly (e.g., strong gains in coding versus modest gains in writing), users experience varied quality depending on their task distribution. This variation in experienced quality provides causal signal for estimation. We validate this approach on synthetic data with known ground truth. The raw estimator recovers 81% to 88% of the true effect, with the remainder lost to measurement error in usage estimates. Applying an errors in variables disattenuation adjustment (using a test retest reliability ratio mean correlation of 0.861) corrects the estimate to 1.017 (bootstrapped 95% CI: 0.915 to 1.109). By contrast, naive methods fail significantly, recovering only 63% without version controls and 62% using real time rather than frozen usage patterns. Permutation tests confirm the framework distinguishes true causal effects from noise. Sensitivity analysis indicates recovery improves monotonically from 78% to 87% as pre period length increases from 3 to 7 weeks, highlighting a clear tradeoff between sample duration and estimator precision. Seed sensitivity tests further confirm stability across random draws.

- **匹配方法**：需要可比的对照单元，而面对单一部署事件时匹配对象极其有限。

该论文的创新点在于：**利用模型性能改进的不均匀性**——同一模型版本内，各能力域（如代码生成、创意写作、数学推理、任务规划）的质量提升幅度并不一致。这导致不同任务分布的用户在相同模型版本上，体验到差异化的质量提升水平。这种“体验质量差异”由用户的既有行为偏好决定，先于版本迭代存在，且与当前版本的质量变化无内生依赖，因而能够作为因果识别的信号来源。

这从根本解决了“版本级部署效应”与“个体级质量体验”的混淆问题——在控制了版本固定效应和基线用户特征后，版本内仅因任务使用分布导致的质量暴露方差，就蕴含了对用户参与度的因果信息。

## 二、论文提出的方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想：版本内因果识别（Within-Version Causal Identification）

论文的核心识别策略可概括为：**同一模型版本内，不同用户因任务分布不同而体验到不同的质量提升，这种变异性在不违背基本因果假设的前提下，可以解释为对用户参与度的因果影响**。该方法在结构上等价于 **shift-share（Bartik）设计**：

- **“份额”（share）**：用户在基线期（版本迭代前）对各类任务（如 coding、writing、mathematics）的稳定使用权重；
- **“转移”（shift）**：模型当前版本在各任务类别上的质量提升幅度（由离线评测获得）。

通过将“基线期冻结的用户任务分布权重”与“当前版本各类别的质量分数”取内积，就构造出每个用户的**质量暴露量**（quality exposure）。

### 2.2 核心公式

**（1）质量暴露指标（Quality Exposure）：**

$$Q_{it} = \sum_{c} w_{ic} \cdot q_{c, v(t)}$$

其中 $w_{ic}$ 是用户 $i$ 在预周期（基线期）对类别 $c$ 的任务使用权重（在预周期结束后固定，即“冻结权重”），$q_{c, v(t)}$ 是时间点 $t$ 所部署版本 $v$ 在类别 $c$ 上的离线质量评分。

**（2）内部版本居中（Within-Version Centering）：**

$$Q^{c}_{it} = Q_{it} - \bar{Q}_{v(t)}$$

减去版本内人口均值，消除版本之间的阶梯式跃迁，保留个体间差异以进行版本内比较。

**（3）无混淆（Unconfoundedness）假设：**

$$Y_{it}(q) \perp\!\!\!\perp Q^{c}_{it} \mid V, X$$

即：在控制版本效应 $V$ 和基线用户特征 $X$ 后，潜在结果与质量暴露条件独立。

**（4）统计模型（广义可加混合模型）：**

$$E[Y_{it} | Q^{c}_{it}, V, X_i] = \text{logit}^{-1}\left( s(Q^{c}_{it}) + V + s(\text{week}) + u_i + X_i \cdot \delta \right)$$

其中 $s(\cdot)$ 是惩罚样条（最大 10 个基函数），$u_i$ 是用户随机截距。连续结果（如会话时长）则使用对数线性形式。

### 2.3 关键技术细节

1. **冻结权重（Frozen Weights）设计**：将用户的任务使用分布固定在版本更新之前的预周期（基线期），与当前版本质量观测在时间上严格隔开。这消除了反向因果——用户不会因为新版本质量更高而主动增加该类别的任务占比（内生性）。
2. **版本固定效应**：吸收所有版本间的混淆因素（营销、媒体、季节性），使得在版本内比较的用户仅存在任务分布差异。
3. **误差修正**：由于冻结权重是真实偏好的噪声代理，存在经典测量误差导致的衰减偏差。通过估计重测信度比 $\hat{\lambda} = 0.861$（预周期/后周期任务权重的平均跨期相关性），利用经典变量误差消解的**去衰减（Disattenuation）** 公式进行修正：

$$\beta_{KL} = \frac{\hat{\beta}}{\hat{\lambda}}$$

4. **统计推断**：使用用户层面的聚类稳健自助法（100 次迭代，以用户为单位重采样）提供置信区间。
5. **预周期的敏感性分析**：测试 3 周、5 周、7 周三种预周期长度，发现恢复率从 78.5% 单调上升至 86.7%，说明预周期越长、权重估计越稳定，测量误差越小。

### 2.4 整体流程（实现五步骤）

1. 获取类别层面的离线质量评分（人工或 LLM-as-a-judge 评估）；
2. 提取用户层面的匿名化类别使用计数，计算冻结在预周期的类别占比；
3. 以加权平均计算质量暴露，并在版本内进行居中；
4. 拟合 GAMM 模型（含用户随机截距、版本固定效应、基线协变量、时间趋势），采用用户级聚类稳健自助法估计方差；
5. 进行验证检验与信度估计，报告未修正和修正后的估计。

6. **前导质量检验未能通过（被明确承认为局限）**：由于合成数据中各版本质量高度相关（r = 0.97），将当前权重与下一期质量评分结合时，检验无法有效排除“预期效应”或“未观察到的同期趋势”的替代解释。作者指出，这是单调改进生成的 DGP 所带来的结构性限制，需要在非单调或具有负相关质量的真实数据中进一步验证。

## 七、论文的局限性与未来方向

1. **仅基于合成数据验证**：所有数字证据均来自模拟生成的数据，真实产品数据往往存在更复杂的用户异质性、习惯形成（habit formation）、跨任务溢出效应（spillover）以及非线性门槛效应，这些在合成 DGP 中未被充分刻画。因此，方法在真实 LLM 部署场景中的实际恢复率和适用性仍有待检验。
2. **单调质量改进假设的限制**：论文假设所有类别质量均同向、单调提升，导致不同版本间的质量高度相关，无法测试“某些类别下降、某些类别上升”的复杂情况。真实模型迭代中可能出现局部退化（例如增强数学能力但削弱创意写作），这种非单调变化会改变暴露分布的方差结构，也可能使前导质量检验变得可行。
3. **冻结权重的时效性**：将任务权重冻结在预周期，虽然消除了当期行为的内生性，但如果用户偏好随时间系统漂移，冻结的“历史份额”会逐渐失去对当前真实分布的代表性，从而引入时变测量误差。论文仅对预周期长度做了敏感性分析，未讨论版本间间隔过长导致权重过期的问题。
4. **样本外推广**：实验在 10 万用户中抽样 2,000 名进行模型拟合，虽然计算可行，但未验证在更大规模（如千万级用户）或更稀疏的用户行为数据上的表现。低频用户（每周仅 1–2 次交互）可能难以构成稳定的类别权重，导致暴露估计噪声剧增。
5. **去衰减修正的假设**：经典测量误差修正依赖于“误差与真值独立”的假设，重测信度比 λ 是在预周期内估计的，但实际误差结构可能随版本变化而变化，该修正可能过度或不足，这在论文中并未做误差结构的异质性检验。
6. **替代因果解释的排除**：即使有前导检验，当前设计仍不能完全排除“类别权重较高的用户本来就更容易受版本宣传影响”的通道（例如写作用户更关注更新公告），这属于隐性的用户×版本交互混淆，需要在更细粒度（如使用日志、通知点击记录）上做进一步验证。

未来工作方向包括：在真实 LLM 产品数据上部署该方法；构造非单调质量变化的验证集；扩展至多版本长期追踪；引入元学习或贝叶斯方法处理权重不确定性；将方法推广到推荐系统、搜索引擎等其他具有版本更新的智能产品场景。

## 八、总体评价与可借鉴性

该论文提出的“版本内质量暴露”识别策略，在方法构思上具有较强的新颖性：**它不依赖传统控制组，而是利用同一版本内部因用户任务分布不同而产生的“自然实验”**，将离线质量评测结果转化为对线上用户行为的因果解释。这一思路在业界 LLM 团队普遍面临“版本上线不可控、控制组不可得”的背景下，具有显著的实用价值。

从可借鉴性角度，该方法有三个突出优点：

- **成本极低**：无需额外实验系统，只需离线评测分数与用户基线行为统计，即可完成因果推断；
- **实现简单**：核心计算为加权求和、版本内居中和 GAMM 拟合，工程门槛低；
- **对测量误差有显式、可操作的修正方案**：这使得在主数据不理想时仍有补救手段。

但也要清醒看到，其验证强度目前仅处于“合成数据证据”阶段，真实世界中的权重漂移、用户自选择、非线性版本效应等问题未被充分测试。因此，在将其作为生产环境因果报告的标准方法之前，仍需经过真实数据的严格校验。

**综合评分**：方法创新性 ★★★★☆；实验充分性 ★★★☆☆；工程可实现性 ★★★★☆；因果识别可信度 ★★★☆☆。
