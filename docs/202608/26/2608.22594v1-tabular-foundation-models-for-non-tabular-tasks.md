## 摘要
表格基础模型（TFM）近期已成为表格数据机器学习的一种有前景的范式，能够在无需针对特定任务训练的情况下跨数据集泛化。由于许多机器学习数据集都可以表示为表格，这引发了一个问题：TFM的能力是否超越了传统上被视为表格的任务？我们通过将TabPFN v3应用于三个非表格分类问题来探讨这一问题：MNIST上的手写数字识别、法语和德语单词的语言识别，以及Tiny ImageNet上的图像分类。在每种情况下，原始数据都被表示为表格的行，分类被表述为对缺失标签的预测。我们评估了性能作为提供给预训练模型的上下文样本数量的函数，且不进行额外训练或微调。尽管没有显式访问表征数据的空间或序列结构，TabPFN v3在某些情况下达到了与专门针对相应任务设计的模型或方法相当的准确度。

## Abstract
Tabular foundation models (TFMs) have recently emerged as a promising paradigm for machine learning on tabular data, offering the ability to generalize across datasets without task-specific training. Since many machine learning datasets can be represented as tables, this raises the question: does TFM capability extend beyond tasks traditionally regarded as tabular? We address this question by using TabPFN v3 on three non-tabular classification problems: handwritten digit recognition on MNIST, language identification of French and German words, and image classification on Tiny ImageNet. In each case, the original data are represented as rows of a table and classification is formulated as prediction of a missing label. We evaluate performance as a function of the number of context samples provided to the pretrained model, with no additional training or fine-tuning. Despite having no explicit access to the spatial or sequential structure characterizing the data, TabPFN v3 in some cases achieves accuracies comparable with that of models or methods geared specifically toward the corresponding tasks.

# 面向非表格任务的表格基础模型——论文详细总结

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：表格基础模型（Tabular Foundation Models, TFMs）是为表格数据设计的预训练模型，能够在无需任务特定训练的情况下跨数据集泛化。由于几乎所有数据集都可以表示为表格形式，本文提出一个关键问题：**TFM 的能力是否能够延伸到传统上不被视为"表格任务"的领域，如图像分类和文本语言识别？**
- **研究背景**：
  - 表格数据是应用机器学习中最主流的格式，梯度提升决策树（如 XGBoost、LightGBM）长期占据主导地位，但这些方法通常需要针对每个数据集从头训练，迁移能力有限。
  - 在语言和视觉领域，"基础模型"范式（预训练大模型 + 上下文学习）已成为核心范式，而表格基础模型（TabPFN、TabICL、TabFM 等）是近年来将这一范式引入表格数据的新兴方向。
  - 由于 TFM 在预训练时暴露于大量通过**因果图（causal graphs）** 生成的合成数据集，它们可能获得了抽象的因果关系理解能力，这为跨领域泛化提供了理论可能。
- **整体含义**：如果 TFM 确实能在图像、文本等非传统表格任务上取得可观表现，则意味着：
  - 表格与非表格学习之间的传统区分可能需要重新审视；
  - 对因果结构的理解可能是实现跨任务泛化的关键因素；
  - 基础模型的通用性可能比目前认为的更广。

## 2. 论文提出的方法论：核心思想与技术细节

- **核心思想**：将非表格数据（图像、文本序列）**扁平化为表格的行**，把分类任务转化为**表格缺失标签预测**任务，然后直接使用预训练的 TFM（TabPFN v3）在**纯上下文学习（in-context learning）** 模式下完成分类，不进行任何梯度更新或微调。
- **具体做法**：
  - **图像扁平化**：将 MNIST 的 28×28 图像展平为 784 个像素值列 + 1 个标签列；将 Tiny ImageNet 的 64×64×3 RGB 图像展平为 12,288 个像素值列 + 1 个标签列。
  - **文本编码**：将法语/德语单词转换为固定长度 15 的序数向量（a→1, ..., z→26，零填充），剥除重音符号和变音符号。
  - **上下文学习流程**：将带有已知标签的训练/支持样本（context rows）与待预测的查询样本（query rows）一同加载到 TabPFN v3 的上下文窗口中，通过单次前向传播直接输出预测结果。
- **TabPFN v3 关键技术细节**：
  - 模型采用交替的**行注意力**和**列注意力**机制，而非扁平化后的标准注意力——行注意力捕捉样本间关系，列注意力捕捉特征间依赖。这种设计将复杂度从 O((NM)²) 降至 O(NM² + N²M)，并保留行/列置换不变性。
  - 模型预训练于大量通过**结构因果模型（structural causal models，有向无环图）** 生成的合成数据集，从而获得对因果关系的抽象理解。
  - **宽表处理策略（集成/Ensembling）**：当特征数超过单估计器上限（200 列）时，TabPFN v3 自动使用多个估计器，每个估计器看到 200 列的子样本；自动缩放最多 32 个估计器。对于 MNIST（784 列）可完整覆盖，但对于 Tiny ImageNet（12,288 列），32 个估计器只能覆盖 6,400 列，约 48% 的像素不会被任何估计器看到。
  - **配置设置**：本文使用 TabPFN v3 默认配置，仅设置 `ignore_pretraining_limits=True` 以绕过输入尺寸检查（默认软限制为 500 特征、10,000 上下文样本）。
  - **PCA 变体**：对 Tiny ImageNet 额外测试了一种变体——先将 12,288 像素降至 200 个主成分（PCA），使每个集成估计器都能覆盖全部特征。

## 3. 实验设计：数据集、基准与对比方法

### 实验一：MNIST 手写数字识别（10 类）
- **数据集**：MNIST，28×28 灰度图像，展平为 784 原始像素值，无归一化、无增强、无降维。
- **测试集**：固定 5,000 张图像（每类 500 张）；训练/上下文集从剩余数据中采样。
- **训练规模扫描**：每类 1 至 2,000 个样本（即 10 至 20,000 个上下文行）。
- **对比方法**：
  - **CNN**：两层卷积（32/64 通道，3×3 核，ReLU + 2×2 最大池化）+ 两层全连接（128 隐藏单元），共 420k 参数；Adam 优化器，学习率 10⁻³，batch size 128，dropout 0.5，固定训练 100 个周期。
  - **LightGBM**：梯度提升树，正则化参数随训练规模缩放（num_leaves 4–31，min_child_samples 1–20 等），固定 300 棵树、学习率 0.05。

### 实验二：法语 vs 德语单词识别（2 类）
- **数据来源**：wordfreq 词频列表；经小写化、去变音/去变音符（ä→ae、ö→oe、ü→ue、ß→ss、é→e 等）、跨语言去重后得到 78,169 个德语词和 71,757 个法语词。
- **编码**：15 列序数向量（a→1,...,z→26，零填充），截断超过 15 字母的单词；无语言特征。
- **测试集**：固定 4,000 词（每语言 2,000）；训练规模从每语言 50 到 10,000 词。
- **对比方法**：**LightGBM**（两种编码方式）：
  - **数值编码**：直接使用 1–26 的序数值。
  - **分类编码**：每列视为 27 水平的类别因子。
  - 使用 RandomizedSearchCV（40 次随机搜索 + 5 折交叉验证）对每种规模独立调参。

### 实验三：Tiny ImageNet 图像分类（100 类子集）
- **数据集**：Tiny ImageNet 原始含 200 类，本文固定随机选取 100 类；每张 64×64×3 RGB 图像展平为 12,288 原始像素值，无归一化或缩放。
- **测试集**：从官方验证集中固定采样 5,000 张（每类 50 张）；训练集取自官方训练集，天然不相交。
- **训练规模扫描**：每类 1 至 100 个样本（100 至 10,000 个上下文行）。
- **两种 TabPFN v3 配置**：
  - 原始像素直接输入（12,288 列，仅 52% 被集成覆盖）；
  - PCA 降维到 200 主成分后再输入（每个估计器覆盖全部特征）。
- **对比方法**：此任务未提供专门训练的对比模型，主要分析 TabPFN v3 自身两种配置的差异。

## 6. 论文的主要结论与发现

- **核心发现**：TabPFN v3 在完全不进行任务特定训练的前提下，通过纯上下文学习，能够在非表格任务上取得**与专门模型相当的准确率**，尽管它没有显式访问图像的空间结构或文本的序列结构。
- **MNIST 具体结果**：
  - 从 10% 随机基线出发，TabPFN v3 在每类 1 个样本时达 22.5%，每类 2,000 个样本时达 **98.6%**。
  - 排序为 CNN > TabPFN v3 > LightGBM，且在少样本区间（每类 ≤ 20）差距最明显。
- **法德语言识别具体结果**：
  - 从 50% 随机基线出发，TabPFN v3 在每语言 50 个词时达 62.4%，在 10,000 个词时达 **88.2%**。
  - 与 LightGBM 存在**交叉效应**：少样本区间（≤100）TabPFN v3 领先，大样本区间（≥500）调优后的 LightGBM 反超约 3 个百分点。
- **Tiny ImageNet 具体结果**：
  - 从 1% 随机基线出发，原始像素 TabPFN v3 在每类 1 个样本时仅 1.4%，每类 100 个样本时 **11.2%**——远高于偶然水平，但远低于 MNIST 上的近饱和表现。
  - PCA 变体在每类 ≥20 样本时追平并反超原始像素约 2 个百分点（每类 100 时约 13%）。
  - 该任务的瓶颈不在于集成大小（即使全特征覆盖也只多约 2 个百分点），而在于**缺乏空间先验**——高维自然图像需要空间结构理解。
- **跨任务规律**：所有任务上准确率都随上下文/训练集大小单调上升，且**在最大规模处未饱和**——TabPFN 的训练默认假设最多一万行，但在数万行下未见性能下降。
- **理论解释**：预训练时暴露于合成因果结构（随机 DAG 采样）可能赋予模型检测表中条目间因果关系的抽象能力。在 MNIST 的例子中，784 个像素与标签之间的因果关系可以被 TFM 从少量上下文样本中学习，无需卷积等人工设计的结构先验。

## 7. 优点：方法与实验设计的亮点

- **问题定义具有启发性**：将图像/文本分类重新构架为表格缺失值预测，概念清晰、简洁有力，图 1 的示意非常直观。
- **零训练/零微调的严格测试**：完全排除权重更新，纯粹检验预训练模型的上下文学习能力，提供了一个干净的泛化能力度量。
- **公平的实验控制**：所有模型共享相同的数据划分、测试集和重采样种子；LightGBM 经过独立超参数调优，确保对比的公平性。
- **宽泛的规模扫描**：从 few-shot（每类 1–2 个样本）到大上下文（数万行），系统揭示模型行为随规模变化的完整曲线。
- **详细的工程细节**：附录提供了 TabPFN v3 的集成机制、CNN 架构、LightGBM 调参范围、PCA 计算流程等完整技术细节，可复现性强。

## 8. 不足与局限

- **TFM 规模限制**：目前 TFM 的上下文窗口和特征容量有限（TabPFN v3 默认上限 500 特征 / 10,000 行），大尺寸图像（如 12,288 像素的 Tiny ImageNet）已超出处理能力，需要 PCA 降维或特征子采样，限制了在真实大规模图像任务上的适用性。
- **缺乏空间/序列归纳偏置**：TFM 将像素视为独立特征列，不理解局部邻域关系（如像素相邻性）；这不但在 Tiny ImageNet 上导致性能大幅落后于 CNN，也意味着其成功依赖于某种隐式的"因果发现"能力。因此对于需要强结构性先验的任务，TFM 的可扩展性存疑。
- **对比范围有限**：
  - Tiny ImageNet 上没有对比专门的模型（如 CNN、Vision Transformer），无法评判其性能相对水平；
  - 仅使用一个 TFM（TabPFN v3），未验证其他 TFM（TabICL、TabFM）是否具有类似表现；
  - 未与基于大规模预训练的视觉基础模型（如 CLIP、ViT）进行比较。
- **语言任务的数据偏差**：德语法语的数据预处理虽然合理，但去重音和长度截断引入的偏差（德语词系统性更长 → 填充模式泄露语言信息）未被充分讨论为可能的混杂因素；此外"15 字母截断"本身对德语更不利。
- **评估指标单一**：仅报告分类准确率，未评估校准度（calibration）、置信度、计算效率（推理时间/内存）等其他重要维度。
- **因果解释缺乏直接证据**：将 TFM 的成功归因于因果图预训练是推测性的，未做消融实验（如对比在无因果结构预训练的 TFM 上的表现）来验证这一机制假设。
- **实际应用价值有限**：当有充足数据时，专门模型（CNN、调优的 LightGBM）仍明显超越 TFM；TFM 的优势主要体现在 few-shot 场景，但即使在 few-shot 场景，对比的基线也相对简单（未与最近邻、原型网络等经典 few-shot 方法对比）。
