## 摘要
许多因果推断研究专注于优化动态治疗方案的优化方法（Murphy, 2003; Robins, 2004; Schulte et al., 2015），这些方案是根据不断变化的病史来决定应分配哪些治疗以及何时分配。这一努力背后存在一种乐观情绪，即通过足够的调整，我们可能会实现显著的改进。另一项先前仅限于点暴露设置的研究，考虑了任何个体化治疗规则可能达到的性能界限。在此，我们将对Oracle策略性能的严格界限扩展到时间变化设置，该策略根据每个受试者的未观察到的潜在结果或“反应类型”选择最佳治疗制度。对于二元结果，下界（假设越高越好）仅仅是由基于观察到的病史的最优治疗方案所达到的期望结果。对于连续结果，下界可能严格超过基于观测协变量的最大值。在连续设置中，我们还考虑了Oracle连续潜在结果累积分布函数的界限。

## Abstract
Much causal inference research is focused on methods for optimizing dynamic treatment regimes (Murphy, 2003; Robins, 2004; Schulte et al., 2015), which are rules for deciding which treatments should be assigned and when based on evolving history. There is a certain optimism underlying this endeavor that with enough tinkering we might realize consequential improvements. Another strand of research, previously confined to the point exposure setting, considers bounds on how well any individualized treatment rule could possibly do. Here, we extend to the time-varying setting sharp bounds on the performance of an oracle strategy that selects the best treatment regime for each subject based on their unobserved potential outcomes or `response type'. For binary outcomes, the lower bound (assuming higher is better) is simply the expected outcome attained by the optimal treatment regime based on observed history. For continuous outcomes, the lower bound may strictly exceed the maximal observed covariate based value. In the continuous setting, we also consider bounds on the CDF of oracle continuous potential outcomes.

### 1. 核心问题与整体含义（研究动机与背景）

- 论文聚焦于因果推断中的一个关键问题：**个体化治疗（precision medicine）的潜力上限**到底在哪里。
- 现有动态治疗策略（DTR）研究主要致力于从观测数据（满足序贯可交换性等标准因果假设）中估计**基于观测历史的最优动态治疗方案**，其目标函数是最大化整个人群的期望结局。
- 作者指出，这类研究背后隐含一种乐观情绪——通过不断改进决策规则，总能获得实质性的健康结局改善。但实际上，**还存在一个更基础、更极端的性能天花板**：如果某种"神谕式"（oracle）策略能完美知晓每个患者对所有可能治疗策略的潜在结局（即真正的最佳个体化选择），那么结局可以好到什么程度？
- 这一问题的答案直接关系到**临床决策的根本局限性**：如果最优可实现策略与 oracle 上限之间的差距很小，说明现行治疗方法本身已接近极限，进一步的收益应来自于开发新疗法；如果差距很大，则说明还存在大量未被发现的效应修饰因子，值得投入精力寻找新的生物标志物。
- 以往对这一问题的界限研究仅限**点暴露（point exposure）设置**，本文首次将其系统地推广到**时变治疗（time-varying treatment）设置**，在此基础上补充了理论空白。

### 2. 方法论：核心思想、关键技术细节与公式

#### 2.1 因果框架与符号设定

- 设定 T 期序贯决策，时间 t = 0, ..., T−1；Ht 为治疗前的历史信息；At 为治疗，Y 为结局（先考虑二元结局 {0,1}，再推广到 [0,1] 有界连续结局）。
- 一个动态治疗策略 d 由一组函数 dt: Ht → At 组成，D 为所有策略的集合，Y(d) 为对应反事实结局。
- 研究的核心目标量是：
  V_perfect = E[ sup_{d∈D} Y(d) ]
  即完美 oracle 策略（为每个患者选择其最优策略）下的人群平均结局。
- 识别假设：序贯一致性（sequential consistency）、序贯正性（positivity）、强序贯可交换性（strong sequential exchangeability），以及F FRCISTG 模型（细粒完全随机化因果结构化树图模型）。在这些假设下，边际反事实分布可由 g-formula 识别，但不同策略反事实结局的**联合分布**不可识别，因此 V_perfect 无法点识别，只能给出界限。

#### 2.2 二元结局的基于反向递归的边界

- 核心思路：利用类似于动态规划/Bellman 方程的**从最后决策时刻逐步向前的递归**，界定每个历史节点上的条件成功概率界。
- 在最后决策时刻（t = T−1），定义条件成功概率：
  m_{T−1}(h, a) = E(Y | H_{T−1} = h, A_{T−1} = a)
  然后定义
  q⁻_{T−1}(h, a) = q⁺_{T−1}(h, a) = m_{T−1}(h, a)
  v⁻_{T−1}(h) = max_a q⁻_{T−1}(h, a)
  v⁺_{T−1}(h) = min{1, Σ_a q⁺_{T−1}(h, a)}
- 对 t = T−2, ..., 0，递归定义：
  q⁻_t(h, a) = E[v⁻_{t+1}(H_{t+1}) | H_t = h, A_t = a]
  q⁺_t(h, a) = E[v⁺_{t+1}(H_{t+1}) | H_t = h, A_t = a]
  v⁻_t(h) = max_a q⁻_t(h, a)
  v⁺_t(h) = min{1, Σ_a q⁺_t(h, a)}
- 最终 V⁻ = E[v⁻_0(H0)]，V⁺ = E[v⁺_0(H0)]。**定理1**：V_perfect ∈ [V⁻, V⁺]，且该区间是尖锐的（sharp），即区间两端点分别可由与观测数据一致的某个联合反事实分布实现。
- **下界 V⁻ 的实现**：在给定历史下，将不同治疗对应的“最终成功”事件构造为嵌套事件（共享一个均匀随机变量），此时并集概率等于最大的边际概率。
- **上界 V⁺ 的实现**：将不同治疗对应的成功事件构造为互斥事件（在 [0,1] 区间上取不相交的线段），使并集概率等于概率和（上限为 1）。
- FFRCISTG 模型允许对不同互斥分支的跨世界关联不加限制，保证了端点可达性。
- 补充结论：注定失败（doomed）比例 P{Y(d)=0, ∀d} 的界限为 1−V⁺ 到 1−V⁻；完美信息的潜在增益满足 0 ≤ V_perfect − sup_d E[Y(d)] ≤ V⁺ − V⁻。

#### 2.3 连续结局的分布与均值边界

- 采用**阈值二值化（thresholding）**方法：对有界连续结局 Y(d) ∈ [0,1]，对任意阈值 x 定义二值结局 Y_x(d) = I{Y(d) > x}，则 P(M > x) = P(sup_d Y(d) > x) = P(∪_d {Y(d) > x})，其概率正是上述二元结局问题在该阈值下的 oracle 值。
- 将上述递归中的终末成功概率替换为条件生存概率 m_x(h, a) = P(Y > x | H_T = h, A_T = a)，得到 V⁻_x ≤ P(M > x) ≤ V⁺_x，进而得到 CDF 界：
  1 − V⁺_x ≤ F_M(x) ≤ 1 − V⁻_x
- **这是对整个分布 CDF 的联合尖锐界**，而不仅仅是每个阈值处独立地尖锐。下界可通过令各行动分支的连续潜在结局共享同一个均匀分位数（即完全正相依）实现；上界则利用 Lai 和 Robbins（1976）的存在性结论：存在一个联合分布使其 max 的超额概率在一切阈值同时等于点态并集上界。
- 均值界通过对超额概率积分得到：
  ∫₀¹ V⁻_x dx ≤ V_perfect = E(M) ≤ ∫₀¹ V⁺_x dx
- 一个重要且反直觉的发现：连续结果下界 ∫V⁻_x dx 可能严格大于最优可实施策略的值 sup_d E[Y(d)]，因为达到不同阈值最优概率的策略可能随 x 变化，没有任何单一策略能同时达到所有阈值的上包络线。

### 6. 主要结论与发现

- **严谨的理论贡献**：在时变治疗设置下，同时考虑序贯决策和跨策略反事实关联不可识别性，推导出了 oracle 策略性能的**尖锐双侧界**（V⁻ 与 V⁺），并以 FFRCISTG 模型下的构造性证明保证端点可达。
- **二元结局的核心发现**：V_perfect 的下界恰好等于最优可实施 DTR（基于观测历史）的期望结局，而上界来自不完整并集界。对于"多个策略各有成功概率、无单一策略占优"的情形，上界可能显著低于 1，提供有信息量的结论；而若可行的治疗选择多且都中等成功，上界可能退化为 1。
- **连续结局的核心发现**：对于连续结局，积分下界可以严格超过任何基于观测协变量的策略均值，说明在不同阈值下存在"帕累托式"的权衡——不同策略分别在不同的结局水平上最优，而完美信息可以融合这些优势。这拓展并深化了原有点暴露结果（Fan & Park, 2010）。
- **实践含义**：这两类界可用于判断"是否需要寻找新的效应修饰因子/生物标志物"。当上界接近最优已实现水平，说明治疗的潜力空间已不大；当上界远高于当前水平，则存在利用未观测个体差异进行治疗的实质性可能空间。

### 7. 优点

- **填补了领域空白**：是首个将 oracle 治疗策略性能界系统推广到时变设置的工作，与当前热门的动态治疗方案优化研究互补。
- **界是尖锐的（sharp）**：不是只给出宽松界，而是通过构造性证明（嵌套事件、互斥事件、Lai-Robbins 最大相依构造）证明每个端点均可由某种合理的联合反事实分布达到。
- **递归方法优雅实用**：界的形式可以通过修改现有最优 DTR 估计算法（如 Q-learning）直接估计，从最后一步回归逐步回溯，具有很好的可操作性。
- **二元与连续统一处理**：通过对阈值 x 的二值化，将连续分布的问题转化为一族二元问题，一套方法论同时覆盖两类结局，并给出整个 CDF 的界而不仅是均值界。
- **回应了具有现实临床意义的问题**：通过 SMART-BD 等例子说明结果直接可回答"现有治疗到底能好到什么程度"的问题，具有明确的政策与临床含义。

### 8. 不足与局限

- **统计推断未解决**：界端点经由 max/min 和截断递归计算，是非光滑的插值型统计量，普通 bootstrap 不成立，作者本人指出这需要专门的推断方法（如点暴露设置中 Huang et al. (2017) 的做法），但本文未给出解决方案。
- **界可能随问题规模退化**：当决策时点数量 T 增大或每个时点的可行治疗选择增多时，上界 V⁺ 的递归求和（min{1, Σ}）非常容易迅速达到 1（并集界退化），界随之失去信息量。这是并集界方法的固有问题。
- **数值示例有限且理想化**：两个示例均为人工构造且条件概率较为极端/干净，未通过真实临床数据验证界在实践中的宽度和有用性；样本量小、历史高度后会有维度灾难，使估计实际界变得困难，论文未讨论高维协方差情境下的行为。
- **递推构造依赖强因果假设**：序贯一致性要求治疗定义足够明确、无版本误差；强序贯可交换性与正性要求在实际上可能难以满足（未测量混杂、非随机治疗分配等），而这些假设对界有效性的影响至关重要。
- **未讨论多元或非二元/非有界结局的扩展**：如成本－效果综合结局、事件时间结局（time-to-event）、多次结局等情形都未覆盖。
- **有限样本下的推断空白**：论文只讨论了期望水平的界，未提供置信区间构造；递推中估计误差传递、单调性约束投影等问题仅一笔带过，没有深入研究。
