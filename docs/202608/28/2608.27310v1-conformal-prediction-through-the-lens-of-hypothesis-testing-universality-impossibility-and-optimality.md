## 摘要
共形预测与置换检验之间的联系在文献中已是广为人知。一些作者通过这样的方式来阐述共形预测：它为假设 $H_0 : Y_{n+1} = y$ 计算一个置换p值，然后将其反演以形成 $Y_{n+1}$ 的预测集（即，将所有p值较大的 $y$ 值纳入预测集）。在本文中，我们考察一种较少被知晓的替代视角：我们同样通过置换检验的反演来构造共形预测，但针对的是 $n+1$ 个样本联合分布的可交换性原假设。这一视角的转变虽然简单，却更贴近假设检验中的传统形式化，从而带来若干益处。首先，我们利用共形集与检验之间的对偶性，表明共形预测文献中的基础普遍性和不可能性结果可以直接通过经典假设检验理论（归功于Neyman、Lehmann、Scheffé、Kraft、Le Cam等人）重現。此外，我们表明，利用标准的Neyman-Pearson理论可以推导出共形预测的一个最优性结果：对于协变量和响应 $X,Y$ 的任何联合分布以及任何样本量，预测集的最优方法——即在所有对可交换分布具有有效覆盖的方法中产生最有效集合的方法——是一个分数为 $Y|X$ 的条件密度倒数的共形预测器。

## Abstract
The connections between conformal prediction and permutation tests are already widely-known in the literature. Some authors motivate conformal prediction by saying that it computes a permutation p-value for the hypothesis $H_0 : Y_{n+1} = y$, and then inverts this to form a prediction set for $Y_{n+1}$ (i.e., accepts all values $y$ into the prediction set for which the p-value is large). In this paper, we examine an alternative view, which is less well-known: we again cast conformal prediction via the inversion of a permutation test, but for the null of exchangeability of the joint distribution of the $n+1$ samples. This change in perspective, while simple, adheres more closely to traditional formalization in hypothesis testing, which offers several benefits. First, we use the duality between conformal sets and testing to show that foundational universality and impossibility results in the conformal prediction literature can be reproduced directly using classical hypothesis testing theory (due to Neyman, Lehmann, Scheffé, Kraft, Le Cam, and others). Furthermore, we show that an optimality result for conformal prediction can be derived using standard Neyman-Pearson theory: for any joint distribution of the covariates and response $X,Y$, and any sample size, the optimal method for prediction sets---which delivers the most efficient set among all methods with valid coverage for exchangeable distributions---is a conformal predictor whose score is the inverse conditional density of $Y|X$.

## 2. 方法论

- **效率的检验化表示（式 25）**：在 $\mu(\mathcal{Y})<\infty$ 下，预测集的期望测度可写成：
  $$E_P[\mu(C_n(X_{n+1}))] = \mu(\mathcal{Y}) \cdot E_Q[1-\phi(Z)]$$
  其中 $Q = P_{X,Y}^n \times (P_X \times \mu/\mu(\mathcal{Y}))$。这意味着**效率问题等价于在备择假设 $Q$ 下的 type II error（即功效问题）**，为后续利用 Neyman-Pearson 理论奠定基础。

- **普遍性（Theorem 3）**：利用 $U = \{Z_1,\dots,Z_{n+1}\}$（多重集）作为可交换分布类的充分统计量，并证明其满足单侧有界完备性（one-sided bounded completeness），再结合 Neyman structure 定理，得出：**任何在可交换分布类上有效的预测集必然具有共形形式**（即由某个分数函数诱导的置换检验反演得到）。

- **不可能性（Theorem 5 & Corollary 1）**：借助 Kraft (1955)/Le Cam 关于近乎无功效检验的结论（Theorem 4），证明在有限测度情形下，若方法满足条件覆盖（conditional coverage），则其对任意非原子点 $x_0$ 的效率不低于平凡随机方法 $\mu(\mathcal{Y})(1-\alpha)$；在无限测度情形下，效率发散至无穷。这意味着**条件覆盖的追求必然以失去效率为代价**。

- **最优性（Theorem 7）**：对固定 $P_{X,Y}$，在"对 $\mathcal{P}_{\text{exch}}$ 全部有 $1-\alpha$ 覆盖"的约束下，最小化 $E_P[\mu(C_n(X_{n+1}))]$。通过构造最小有利分布（least favorable distribution）$P'_u = \frac{1}{(n+1)!}\sum_{\sigma}\delta_{z_\sigma}$，利用 Neyman-Pearson 引理得出最优检验即为以 $T(Z) = 1/p_{Y|X}(Y_{n+1})$ 为统计量的随机化置换检验；对应的预测集即为分数 $s(z_{n+1};z) = 1/p_{Y|X=x_{n+1}}(y_{n+1})$ 的随机化共形预测器（式 37、38）。

## 6. 主要结论与发现

1. **普遍性**（Theorem 3）：在可交换分布类上有效的预测集方法**必然是共形类型**的——任何有效方法都可以表示为某个分数函数的置换检验反演。这重现了 Vovk 等（2022）和 Angelopoulos 等（2025）的经典结果。

2. **分数对称性非必需**（Section 2.2）：一般的不对称分数函数依然可以通过式 (16) 获得有效覆盖——对称性只是化简置换 p 值的计算装置，而不是有效性前提。

3. **条件覆盖不可能性**（Theorem 5 & Corollary 1）：任何方法若对所有 i.i.d. 分布满足给定 $X_{n+1}=x_0$ 的条件覆盖，则在非原子点 $x_0$ 上平均效率无法超过平凡随机方法；在 $\sigma$-有限无限测度响应空间中，效率必为无穷。这重现了 Vovk (2012) 和 Lei & Wasserman (2014) 的结果。

4. **有限样本最优性**（Theorem 7）：在所有对可交换类有效的方法中，最优预测集由分数 $s = 1/p_{Y|X}$ 的共形预测器给出（可允许随机化处理平局）。这是论文的**新贡献**，区别于已有的仅在大样本（$n\to\infty$）意义上成立的 oracle 最优性结果。

5. **实践指导**（Section 6.3）：在异方差高斯模型下，最优分数启发的是式 (41)（含 $\log\hat\sigma$ 项）而非传统的学生化分数 (42)，说明效率导向的分数设计应包含方差项。
