## 摘要
工业电商搜索系统最终旨在优化用户级长期目标，例如n日累计购买量或每用户商品交易总额（GMV）。然而，这些目标是在用户级定义的，而搜索排序基于每次请求内的物品级分数。现有方法通常通过手动设计的多目标融合来弥合这种粒度差距，其中多个物品级目标的预测（如点击、加购、购买和交易金额）被组合成一个排序分数，作为最终目标的代理。这种手工制作的融合方案依赖于少量手动调整的权重，限制了细粒度个性化，并导致与最终目标的对齐次优。在本文中，我们提出了DCEO（直接因果效应优化），一种数据驱动的框架，用于学习与最终目标更好对齐的物品级代理分数。我们首先将物品级代理分数聚合成用户级代理指标，并使用相对因果效应量化其与最终目标的对齐程度。然后，我们开发了一个演员-评论家框架，其中评论家估计给定用户级代理指标的最终目标，演员动态生成多个目标上上下文相关的融合权重以构建物品级代理分数，并经过训练直接优化相对因果效应。大量的离线实验和分析证明了DCEO的有效性和可解释性。此外，DCEO已部署在大规模工业电商搜索系统中，在41天的在线A/B测试中，GMV比传统GMV代理高出0.36%。

## Abstract
Industrial e-commerce search systems ultimately aim to optimize the user-level long-term objective, such as n-day cumulative purchases or gross merchandise value (GMV) per user. However, such objectives are defined at the user level, whereas search ranking is based on item-level scores within each request. Existing methods typically bridge this granularity gap through manually designed multi-objective fusion, where predictions of multiple item-level objectives, such as clicks, carts, purchases, and transaction value, are combined into a ranking score that serves as a proxy for the ultimate objective. Such hand-crafted fusion schemes rely on a small set of manually tuned weights, limiting fine-grained personalization and leading to suboptimal alignment with the ultimate objective. In this paper, we propose DCEO (Direct Causal Effect Optimization), a data-driven framework for learning item-level proxy scores that are better aligned with the ultimate objective. We first aggregate the item-level proxy scores into a user-level proxy metric and quantify its alignment with the ultimate objective using a relative causal effect. We then develop an actor-critic framework, where the critic estimates the ultimate objective for a given user-level proxy metric, and the actor dynamically generates context-dependent fusion weights over multiple objectives to construct the item-level proxy scores and is trained to directly optimize the relative causal effect. Extensive offline experiments and analyses demonstrate the effectiveness and interpretability of DCEO. In addition, DCEO has been deployed in a large-scale industrial e-commerce search system, outperforming the conventional GMV proxy by 0.36% in GMV in a 41-day online A/B test.

## 论文总结：DCEO（Direct Causal Effect Optimization）

### 1. 核心问题与研究动机

电子商务搜索引擎的最终目标是优化**用户级别的长期价值指标**（如 n 日累计购买量或 GMV），但排序系统运作于**物品级别**（每次请求对候选物品打分排序），两者之间存在**粒度错配**。现有工业系统通常依赖**手工设计的多目标融合公式**（如将点击率、加购率、购买率、GMV 预测线性组合），并反复通过在线 A/B 测试人工调整权重来逼近长期目标。这种方案存在两大不足：

- **个性化受限**：全局共享的少量固定权重无法适配不同用户和请求的差异；
- **调优成本高**：依赖大量昂贵的在线实验，无法实现数据驱动的自动化学习。

作者指出，单纯追求代理指标与长期目标的**预测相关性**是不够的——因为通过排序提升代理指标并不必然带来长期目标的提升（引用 VanderWeele 2013 的替代指标理论）。因此核心问题是：**如何从用户级长期目标出发，端到端学习一个与最终目标因果对齐良好的物品级代理分数？**

### 2. 方法论：DCEO 框架

DCEO 采用 **actor-critic 架构**，整体流程如下：

- **训练阶段**：基于某用户一天内所有曝光样本构成一个训练样本，包含用户特征、请求特征、上游预测分数和最终目标标签。Actor 与 Critic 联合训练。
- **在线服务阶段**：仅部署 actor，输出上下文相关的融合权重，生成代理分数并注入现有多目标融合公式。

**核心组件与公式：**

**（1）Actor —— 生成代理分数**

- 输入用户特征 z_u 与请求特征 z_ur，输出 M 个非负且归一化的融合权重 w_ur：
  ```
  w_ur = f_θ(z_u, z_ur),  Σw = 1
  ```
- 将权重与 M 个上游预测分数 v_uri 线性组合，得到物品级代理分数：
  ```
  p_uri(θ) = Σ w_m * v_m_uri
  ```

**（2）用户级代理指标聚合与校准**

- 对用户所有曝光取平均得 P_raw，再通过校准模型 g_ψ 修正到**固定曝光数 C=100** 下的值：
  ```
  P_u(θ) = P_raw * sg(g_ψ(z_u, C) / max{g_ψ(z_u, N_u), ε})
  ```
- 使用 stop-gradient (sg) 对校准项阻断反向传播，避免干扰 actor 学习。

**（3）Critic —— 估计最终目标**

- 输入用户特征与代理指标 P_u，用 MSE 损失拟合长期目标 Y_u ：
  ```
  L_critic = E[(h_φ(z_u, sg(P_u)) − Y_u)²]
  ```

**（4）优化目标 —— 相对因果效应（RCE）**

- 定义相对干预 P_u → (1+δ)P_u 下的相对因果效应：
  ```
  RCE = E[Y_u((1+δ)P_u) − Y_u(P_u)] / E[Y_u(P_u)]
  ```
- 对应的因果效应损失（固定 critic 参数，只更新 actor）：
  ```
  L_CE = −E[h_φ(z_u, (1+δ)P_u) − h_φ(z_u, P_u)]
  ```
- 用未归一化的差值近似 RCE，规避了直接优化比值带来的梯度不稳定性（分母变化波动大的问题）。

**（5）条件归一化排序损失（LCNR）**

- 由于 L_CE 高度非凸，引入 LCNR 作为**稳定正则项**。
- 通过模型 e_ζ 估计 P_u 和 Y_u 的均值与 log 标准差，做条件归一化后，用 **Bradley–Terry 成对排序损失**约束代理指标与目标指标的排序一致性。
- 最终 actor 损失：L_actor = L_CE + α·LCNR，其中 α=0.3。

**（6）在线融合**

- 代理分数以对数形式加入原有融合公式：
  ```
  s_uri ← s_uri + λ·log(max{p_uri, ε})
  ```

### 3. 实验设计

### 6. 主要结论与发现

- 因果效应优化（L_CE，RCE=0.031）显著优于预测关联优化（RCE=0.022）；加入 L_CNR 后进一步提升至 **RCE=0.053**（2.4 倍提升）。
- 消融实验显示：L_CNR 单独即可达 RCE=0.048，与 L_CE 结合后最优（α=0.3）；完整 17 分数集合优于任何子集，说明不同转化阶段和交易金额档位的信息具有互补性。
- Actor 学到的权重随终极目标定义而变化：优化点击时权重几乎全给 impr2click；优化 GMV 时权重向高金额档位分散；目标窗口从 1 天延长到 4 天时，impr2click 权重上升，表明系统倾向于**鼓励更多探索**以支持更长周期的 GMV。
- 在线 A/B 测试中，DCEO 相比传统 GMV 代理提升 **GMV 0.36%**，同时点击数提升 0.36%、购买数提升 0.12%，说明 GMV 提升并非以牺牲其他指标为代价。

### 7. 优点

- **问题定义清晰**：将代理分数学习形式化为“跨粒度优化”问题，并提出用相对因果效应（而非预测关联）衡量对齐度，理论动机扎实。
- **训练-服务架构解耦**：复杂聚合、校准和 critic 训练全部在离线完成，在线仅部署轻量级 actor，工程落地可行性强。
- **客观公正性**：作者明确承认 RCE 是基于观测数据与 critic 的估计值，不能等同于真实验证，并以在线 A/B 测试作为最终验证，这种自我保护式的讨论较客观。
- **可解释性好**：权重受限于凸组合形式，便于分析每个上游分数对最终排名的贡献和个性化程度。
- **实验设计有层次**：从整体效果到组件消融，再到目标定义的敏感性分析，逐层深入，逻辑清晰。

### 8. 不足与局限

- **因果推断偏差风险**：RCE 基于观测日志和 critic 估计，依赖用户特征充分捕获混杂因素；未观测混杂可能带来偏差。论文没有使用工具变量、倾向得分加权等额外因果识别策略。
- **忽略曝光量变化路径**：固定曝光数校准剔除了用户活跃度和曝光量变化带来的影响，离线 RCE 只反映单一路径，不能全面预测部署后的总效应。
- **Actor 表达力受限**：代理分数被限制为上游预测分数的凸组合，无法挖掘上游分数未包含的信息；直接预测代理分数的方案因训练不稳定被放弃（论文自述）。
- **泛化性未验证**：仅在一个工业系统上验证，且最长目标窗口为 4 天，更长的用户生命周期价值（如 7/14/30 天）尚不明确。
- **对比基线不足**：没有与近期长期价值建模方法（IURO、AURO、FID 等）直接对比，无法确认 DCEO 的相对优势是否超出自身消融范围。
