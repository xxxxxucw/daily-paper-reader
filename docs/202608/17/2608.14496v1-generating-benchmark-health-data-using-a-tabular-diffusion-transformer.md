## 摘要
跨表格数据生成（CTDG）旨在从多个异构表格中学习生成模型，并产生新的合成表格数据集。然而，现有的合成表格数据生成方法主要局限于单输入表格场景，难以有效处理具有不同特征集的多个异构表格。为解决这一局限性，我们提出了一种用于跨表格数据生成的两阶段框架。在第一阶段，每个异构原始表格被转换为具有相同列集合的标准化统计表格。每个统计表格捕获原始列的边际分布以及它们之间的成对相关性。在第二阶段，训练一个扩散Transformer模型来捕捉这些同质统计表格之间的结构模式，并生成合成统计表格。随后，通过多元高斯采样和逆概率积分变换，从生成的统计表格中重建合成原始表格。这种两阶段CTDG框架能够从多个异构表格中学习统一的生成模型，并支持生成无限数量的逼真合成异构表格。实验结果表明，所学统计表示具有高保真度，生成的合成数据在保真度-多样性权衡方面表现良好，验证了所提方法的有效性。

## Abstract
Cross-Tabular Data Generation (CTDG) seeks to learn a generative model from multiple heterogeneous tables and produce new synthetic tabular datasets. However, existing synthetic tabular data generation methods are largely restricted to single-input-table scenarios and struggle to effectively handle multiple heterogeneous tables with diverse feature sets. To address this limitation, we propose a two-stage framework for cross-tabular data generation. In the first stage, each heterogeneous raw table is transformed into a standardized statistical table with the same set of columns across all tables. Each statistical table captures the marginal distributions of the original columns and the pairwise correlations among them. In the second stage, a diffusion transformer model is trained to capture structural patterns across these homogeneous statistical tables and to generate synthetic statistical tables. Synthetic raw tables are subsequently reconstructed from the generated statistical tables via multivariate Gaussian sampling followed by an inverse probability integral transform. This two-stage CTDG framework enables the learning of a unified generative model from multiple heterogeneous tables and supports the generation of an unlimited number of realistic synthetic heterogeneous tables. Experimental results demonstrate high fidelity in the learned statistical representations and a favorable fidelity-diversity trade-off in the generated synthetic data, validating the effectiveness of the proposed approach.

## 1. 核心问题与整体含义

- **问题背景**：现有合成表格数据生成（STDG）方法大多局限于“单输入表”场景，假设固定的特征集合，难以处理来自多个数据源的异构表格（列数、列类型、语义各不相同）。这限制了模型从多表中学习共享统计结构和领域模式的能力。
- **应用需求**：在医疗健康领域，合成数据可用于隐私保护的数据共享、缓解数据稀缺、支持跨机构协作以及构建基准测试数据集。然而，现有基准数据仓库（如 UCI、Kaggle、PMLB）存在数据集选取随意、预处理不一致、多样性不足、非健康领域特定等问题；已有合成基准方法（如 DIGEN、XyGen）不基于真实数据，其统计特征缺乏真实性保障。
- **核心目标**：提出一种跨表格数据生成（CTDG）框架，从大量异构真实表格中同时学习，生成能够反映真实数据多样性、且具有领域代表性的合成表格，用于大规模健康基准测试。
- **整体含义**：将“表格”整体作为学习实例（表级建模），而非传统的“记录级”建模，从而统一不同结构的数据集，并实现可扩展、可复现的基准数据生成。

## 2. 方法论

- **总体框架**：两阶段流程。
  - **第一阶段**：将每个异构原始表转换为“同质统计表”，统一列结构。
  - **第二阶段**：用扩散Transformer学习多个统计表的分布，生成新的合成统计表，再重建为原始格式的表。

- **统计表构造**
  - **边际统计**：
    - 分类列：对唯一值按频次降序排序并映射为整数索引，拟合 Beta-Binomial 分布，得到参数 (α, β, cardinality)。
    - 数值列：先离散化为固定区间数（I_N=100），再同样排序、映射、拟合 Beta-Binomial。
    - 缺失率：记录每列缺失比例。
    - 每列表示为 `(α, β, cardinality, missing rate, a)`。
  - **相关性表示**：
    - 通过概率积分变换将映射后的列转换为正态分布。
    - 计算高斯相关矩阵 Σ，进行特征分解：`Σ = UΛU^T = A A^T`，其中 `A ∈ R^{C_i × K}`，K 为固定超参数（实验中 K=256）。
    - 列数小于 K 的表进行零填充；列数大于 K 的表随机丢弃列至 K。
    - 每列的“a”向量表示该列与其他列的相关系数（通过内积恢复）。
  - **重建原始表**：
    - 从 a 恢复相关矩阵 → 多元高斯采样 → 逆概率积分变换映射回 Beta-Binomial → 按缺失率随机生成缺失值。

- **扩散Transformer（TDT）**
  - 输入：同质统计表（每行是一个列的参数向量，长度为 K+4=260）。
  - 结构：标准Transformer编码器，含输入投影层、时间投影层、编码器（12层、12注意力头、嵌入维度768）、输出投影层。
  - 训练：DDPM 简化损失 `L_simple = E||ε - ε_θ(x_t, t)||^2`，线性扩散调度，T=1000；AdamW 优化器，学习率 1e-4，batch size 64，训练 500 epochs。
  - 采样：标准 T 步去噪过程。
  - 标准化：对统计表各列实施全局分位数变换（映射到标准正态），生成后再逆变换回原取值范围。
  - 训练策略：先在 4,095 个 OpenML 通用数据集上预训练，再在健康领域数据（131 个 OpenML Health 数据集 + 13 个医疗数据集）上微调。
