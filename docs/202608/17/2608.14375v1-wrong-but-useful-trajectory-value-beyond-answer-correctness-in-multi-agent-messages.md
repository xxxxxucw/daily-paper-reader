## 摘要
多智能体推理系统通常使用一致性、置信度或自动评分来决定哪些消息应塑造最终答案。这种过滤假设可能正确的消息也值得保留。然而，一个错误的答案可能包含有用的分解、约束或科学原理。我们通过多样化假设审议（DHD）测试了这一区分，这是一种受控测量协议，它缓存五个独立生成的消息，并在每个消息可用或隐藏的情况下重放相同的下游求解器（称为整合器）。重放比较衡量消息的轨迹价值：使消息可用是否有助于或损害后续推理。在五个数学和科学基准以及两个公开可用的模型系列（gpt-oss-120b和gemma-4-31B-it）中，错误但有用的消息出现在每个基准-模型组合中。在改变最终正确性的错误答案消息中，每个模型中超过十分之四的变化是有帮助的。受控重复表明，可重复消息效应的数量不太可能仅由重放变异引起（p=0.0002）。对可重复的错误但有用消息进行有针对性的干预发现，完整消息效果最佳，而保留其推理比仅保留其答案更能保持成功；完整消息优势的来源仍待探索。在同一问题中，重复的轨迹价值证据也比仅凭答案正确性更能识别更好的保留或移除选择。因此，答案正确性具有信息量，但不能决定轨迹价值。DHD测量了这一缺失属性，并为学习智能体何时应倾听产生了可复用的标签。

## Abstract
Multi-agent reasoning systems often use agreement, confidence, or automated scores to decide which messages should shape a final answer. Such filtering assumes that a message likely to be correct is also worth keeping. Yet a wrong answer can contain a useful decomposition, constraint, or scientific principle. We test this distinction with Diverse Hypothesis Deliberation (DHD), a controlled measurement protocol that caches five independently generated messages and replays the same downstream solver, called the integrator, with each message available or hidden. The replay comparison measures a message's trajectory value: whether making the message available helps or harms subsequent reasoning. Across five mathematics and science benchmarks and two openly available model families, gpt-oss-120b and gemma-4-31B-it, wrong-helpful messages appear in every benchmark-model combination. Among wrong-answer messages that change final correctness, more than four in ten changes are helpful in each model. Controlled repeats show that the number of repeatable message effects is unlikely to arise from replay variation alone (p=0.0002). A focused intervention on repeatable wrong-helpful messages finds that the complete message works best, while retaining its reasoning preserves more success than retaining only its answer; the source of the complete-message advantage remains open. Within the same problem, repeated trajectory-value evidence also identifies a better keep-or-remove choice than answer correctness alone. Answer correctness is therefore informative but does not determine trajectory value. DHD measures this missing property and produces reusable labels for learning when agents should listen.

### 1. 核心问题与整体含义

- **研究动机**：多智能体推理系统在生成多条候选消息后，常依赖答案正确性（proposal correctness）、置信度、一致性或自动评分等代理指标来筛选消息，以决定哪些消息影响最终答案。这种做法的隐含假设是：**"可能正确的消息 = 值得保留的消息"**。
- **核心质疑**：答案是否正确，并不能决定消息内部的推理是否对后续整合有贡献。一个错误答案的消息可能包含有用的分解、约束或科学原理；反之，一个正确答案可能伴随误导性推理，反而损害整合结果。
- **整体含义**：论文将"消息自身答案是否正确"与"消息对整个推理轨迹是否有价值"分离，提出**轨迹价值（trajectory value）**概念，并通过受控测量协议 DHD 证明：**答案正确性不能决定轨迹价值**。这一发现对多智能体系统中的消息筛选、通信剪枝、贡献归因等环节具有直接启示意义。

### 2. 方法论

- **核心概念定义**：
  - **提案正确性（proposal correctness, ci）**：消息自身提出的答案是否与参考答案等价。这是一个局部属性。
  - **轨迹价值（trajectory value）**：在固定问题、固定消息池和固定整合器（integrator）的上下文中，消息的**可用/隐藏**切换对最终整合结果的影响。这是一个上下文相关属性，而非消息文本的内在属性。
  - **错误有用（wrong-helpful）**：消息答案错误，但完整消息可用时使最终结果从错变对。
  - **正确有害（correct-harmful）**：消息答案正确，但完整消息可用时使最终结果从对变错。

- **DHD（Diverse Hypothesis Deliberation）协议流程**：
  1. **招募者（Recruiter）**：针对问题动态分配5个互补的问题特定角色，不接触参考答案。
  2. **假设者（Hypothesizers）**：5个代理各自独立生成一条结构化消息（含推理和提议答案），看不到其他消息、评分、反馈或参考答案。
  3. **整合器（Integrator）**：在给定原始问题和部分缓存消息的情况下，合成一个最终答案。
  4. **评估器（Evaluator）**：仅根据提交答案与参考答案判断等价性。

- **轨迹价值的测量方式**：
  - **单消息重放（Single-message replay）**：比较仅含该消息的整合结果与无消息独立求解的结果。
  - **池内留一重放（In-pool leave-one-out, LOO）**：比较完整 K 消息池与移除目标消息后的池的整合结果，K=2–5。
  - 每种对比产生三种标签：**helpful (+1)、neutral (0)、harmful (-1)**。

- **核心公式**（留一重放的期望轨迹价值）：
  ```
  τᵢ,K = Pr(Y_HK = 1) − Pr(Y_HK\{hᵢ} = 1)
  ```
  其中 Y 为最终整合结果是否正确，HK 为包含 K 条消息的池。正值表示消息平均提升成功率，零为中性/冗余，负值为有害。

- **受控重复重放（Controlled repeated replay）**：每个匹配对重复多次整合调用，以区分真实消息效应与随机输出变异。

### 3. 实验设计

  - **SciBench**（580题，大学理科数值与简答）
  - **LAB-Bench**（741题，长证据多选生物学）
  - **MaScQA**（649题，混合格式材料科学）

- **模型**：两个公开可用的模型系列，均在同一信息边界下承担招募、假设与整合角色：
  - **gpt-oss-120b (OSS)**
  - **gemma-4-31B-it (Gemma)**

- **对比方法（系统级上下文）**：
  - 四个端到端协议：Direct（单次求解）、Iterative（单代理自修正）、PER（规划者–执行者–审查者三级流水线）、Broadcast（多代理审议）。

### 6. 主要结论与发现

- 错误有用于正确有害的消息在**所有 10 个基准–模型组合**中均出现。
- 在改变最终正确性的错误答案消息中：
  - OSS：41.9% 的变化是帮助性的；
  - Gemma：45.3% 的变化是帮助性的。
  - 即**错误-答案消息导致最终结果翻转时，超过四成的翻转是有利的**。
- 受控重复重放表明：汇总效果不太可能由普通重放变异单独产生（p = 0.0002）；但经过 Benjamini–Hochberg 全局多重性控制后，仅 Gemma 保留了 11 个可重复的错误有用问题，OSS 为零。
- 组件掩蔽诊断显示：完整消息效果最好；隐藏推理比隐藏错误答案损失更多成功率，**推理内容比附带的错误答案贡献更大**。
- 同一问题内基于重复轨迹价值的最优单移除选择（+1.68 点 OSS、+2.61 点 Gemma）优于仅基于提案正确性的选择（+0.94 / +1.00 点），证明轨迹价值标签携带超越正确性的决策信息。
- 最终结论：**正确性具有信息价值，但不能决定轨迹价值；DHD 为该缺失属性提供了可测量的定义和可复用的标签。**

  - 多评估器审计为标签可靠性提供保障。
- **实验覆盖面广**：5 个基准涵盖数学、物理、化学、生物、材料科学，跨学科、跨格式（开放式、选择题、数值型），增强了结论的普适性。
- **实践价值**：生成上下文索引的、发布安全的轨迹价值标签记录，可直接用于训练上下文感知的选择器；同问题单移除机会实验证明了实际决策收益。
- **叙事清晰**：图 1 中两个具体案例（错误有用与正确有害）直观展示了所测定义与可能机制的区别。

### 8. 不足与局限

- **可推广性受限**：
  - 轨迹价值是消息–池–整合器三元上下文的属性，不能直接迁移到不同问题或不同整合器；标签不构成通用注解。
  - 所有推理角色由同一模型系列担任，未测试异构代理组合；结果可能不适用于交互式辩论、多种模型混用、前沿模型或没有稳定参考答案的任务。
  - 嵌套前缀（K=1–5）是同一招募结果的子集，不是随机化添加代理的因果效应。
- **方法局限**：
  - 留一对比只反映整体消息的可用性变化，不能彻底分离语义内容与位置/长度等表层因素（组件掩蔽仅作初步尝试）。
  - 同问题交叉拟合机会分析衡量的是事后机会，而非可部署的决策策略；不能证明跨新问题泛化能力。
- **证据强度不均**：
  - 正确有害类别的重复证据较弱，未通过严格的 BY 多重性控制，仅作为次级诊断；
  - 组件掩蔽样本小（22 条），结论是机制提示而非流行率估计；
  - 聚合检验 p=0.0002 不能推广为"每条错误有用消息都可重复"：BH 校正后 OSS 无问题保留，Gemma 仅 11 个问题。
- **评估敏感性**：
  - 复合六类标签依赖三个独立的评估器判断，评估器之间的一致率低于单答案判断（三元组一致率 71.6%–88.7%），标签存在一定的评估器敏感性。
- **数据完备性**：
  - Gemma 的协议样本与 LOO 样本差异较大（如 LAB-Bench 从 741 题降至 492 题），协议准确率与完整 LOO 样本准确率不可直接比较；
  - 缺失结果（如非法输出、解析失败）保留为缺失而不作中性填充，可能影响某些基准（尤其 LAB-Bench）的代表性。
