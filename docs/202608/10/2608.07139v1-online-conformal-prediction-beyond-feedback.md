## 摘要
在安全关键应用中部署机器学习模型时，不确定性量化至关重要。在线共形预测（OCP）通过构建预测集，为用户指定的频率下保证包含真实标签，为任意黑盒分类器和非独立同分布数据流提供了具有理论原则的不确定性量化。OCP通常利用先前部署预测的反馈来更新预测集。我们转而研究超越反馈的OCP设置：在每一轮中，学习器要么输出预测集，要么查询正确标签，但不能同时进行。因此，没有任何部署的预测会被直接评估。我们将此问题简化为一个部分监控博弈，其中预测动作不返回观测，而单独的查询动作揭示标签。奖励函数的构造方式鼓励学习器输出较小的预测集，同时确保以足够高的概率覆盖正确标签。为解决此博弈，我们通过将Cesa-Bianchi、Lugosi和Stoltz（2004）的标签高效预测器适应于我们的设置，开发了带查询的OCP（OCPQ）。对于任何黑盒分类器和任何长度为$T$的（非独立同分布） oblivious 数据流，OCPQ具有$O(T^{2/3})$的期望遗憾，并且对于用户定义的$β$，期望覆盖率至少为$β-O(T^{-1/3})$，同时仅查询期望的$T^{-1/3}$轮次比例。这提供了与基于bandit的OCP方法相当的覆盖率，同时无需来自已部署预测集的反馈。在真实世界数据集上的实验进一步证明了我们方法的有效性。

## Abstract
Uncertainty quantification is essential when deploying machine learning models in safety-critical applications. Online conformal prediction (OCP) provides theoretically principled uncertainty quantification for arbitrary black-box classifiers and non-i.i.d. data streams by constructing prediction sets that are guaranteed to contain the true label at a user-specified frequency. OCP usually updates prediction sets using feedback from previously deployed predictions. We instead study an OCP setting beyond feedback: on each round, the learner can either output a prediction set or query the correct label, but not both. Thus, no deployed prediction is ever evaluated directly. We reduce this problem to a partial monitoring game in which prediction actions return no observation and a separate query action reveals the label. The reward function is constructed in a way that encourages the learner to output small prediction sets while ensuring that the correct label is covered with a sufficiently high probability. To solve this game, we develop OCP with queries (OCPQ) by adapting the label efficient forecaster of Cesa-Bianchi, Lugosi, and Stoltz (2004) to our setting. For any black box classifier and any (non-i.i.d.) oblivious data stream of length $T$, OCPQ has $O(T^{2/3})$ expected regret and expected coverage at least $β-O(T^{-1/3})$ for a user-defined $β$, while querying only an expected $T^{-1/3}$ fraction of rounds. This provides coverage comparable to bandit-based OCP methods while requiring no feedback from deployed prediction sets. Experiments on real-world datasets further demonstrate the effectiveness of our approach.

## 1. 核心问题与整体含义

- **背景**：在线共形预测（Online Conformal Prediction, OCP）是安全关键应用中重要的不确定性量化工具，能够在任意黑盒分类器上、面对非独立同分布数据流时，提供包含真实标签的预测集，并给出用户指定的覆盖率保证。
- **传统 OCP 的反馈依赖**：现有 OCP 方法通常假设学习器在输出预测集后能获得某种反馈（完整标签、覆盖信号、半 bandit 反馈等），并用该反馈修正未来的预测阈值，以弥补历史错误。
- **“超越反馈”问题**：许多现实场景中，学习器不能在预测的同时获得标签反馈，例如 LLM 安全探针：一旦给出部署判断，就不会再得到该输入的标签；只有选择“不预测/查询”时，才会向人类或更强模型索要标签。于是：
  - 每一轮中，学习器**要么输出预测集，要么查询正确标签，但不能同时进行**；
  - 已部署的预测永远不会被直接评估；
  - 传统依赖“部署后反馈”的 OCP 方法无法直接使用。

## 2. 方法论

### 核心思想
- 将“超越反馈的 OCP”建模为**有限部分监控博弈**（partial monitoring game）：
  - **动作集**：有限预测阈值集合 \(M \subset [0,1]\)，额外加上“查询（query）”动作；
  - **反馈结构**：预测动作不返回任何关于标签或覆盖情况的观测；查询动作无预测，但返回真实标签；
  - **辅助奖励函数**（Definition 1）：
    \[
    R(\text{query},t)=0,\qquad
    R(m,t)=
    \begin{cases}
    1-m(1-\beta), & y_t\in \Gamma_C(x_t,m),\\
    0, & \text{otherwise}
    \end{cases}
    \]
    其中 \(\Gamma_C(x_t,m)\) 是超水平集预测集。该奖励鼓励“尽量小的阈值/预测集”，并对未覆盖给予零奖励；参数 \(\beta\) 用于平衡覆盖率和效率。

### 算法 OCPQ（Online Conformal Prediction with Queries）
- 改编自 Cesa-Bianchi、Lugosi 和 Stoltz (2004) 的**标签高效指数加权预测器**。
- 对每个阈值 \(m\) 维护估计累积奖励 \(\hat{Z}_{m,t}\)，初始为 0。
- 每轮流程：
  1. 以概率 \(\epsilon\) 选择查询：若查询，观察到真实标签 \(y_t\)，然后对所有阈值 \(m\) 做无偏估计更新：
     \[
     \hat{Z}_{m,t+1} = \hat{Z}_{m,t} + 1 - \frac{1-R(m,t)}{\epsilon}
     \]
  2. 否则，以 softmax 分布采样阈值 \(m_t\)：
     \[
     p_{m,t} = \frac{\exp(\eta \hat{Z}_{m,t})}{\sum_{i\in M}\exp(\eta \hat{Z}_{i,t})}
     \]
     输出预测集 \(S_t=\Gamma_C(x_t,m_t)\)，但**不接收任何反馈**，仅将 \(\hat{Z}_{m,t+1}=\hat{Z}_{m,t}+1\)（即不更新，保持估计值不变）。

### 理论保证
- **遗憾界（Theorem 1）**：
  - 任意数据流、任意黑盒分类器下，期望遗憾满足：
    \[
    \mathbb{E}[\text{reg}] \le \frac{\ln|M|}{\eta}+\epsilon T + \frac{\eta}{\epsilon}T
    \]
  - 取 \(\epsilon=T^{-1/3}\)、\(\eta=T^{-2/3}\sqrt{\ln|M|}\)，得到 \(O(T^{2/3})\) 遗憾。
- **覆盖率与遗憾的联系（Theorem 2）**：
  - 若遗憾 ≤ \(N\)，则覆盖率至少为 \(\beta - N/T\)。
- **期望覆盖率下界（Corollary 1）**：
  \[
  \mathbb{E}[p_{\text{cover}}] \ge \beta - \frac{2\sqrt{\ln|M|}+1}{T^{1/3}}
  \]
  同时查询轮数比例仅为期望 \(T^{-1/3}\)。
- **高概率界（Theorem 3、Corollary 2）**：给出以接近 1 的概率成立的高概率遗憾和覆盖率界。
- **最优性**：利用 Lattimore and Szepesvari (2018) 的分类结果，证明该部分监控博弈的最优最坏遗憾是 \(\Theta(T^{2/3})\)，因此 OCPQ 是渐进最优的（除 \(\beta=1\) 平凡情形外）。
- 附录还给出扩展：延迟观测、未知/无限时间视野（doubling trick）、集合值分类器、无限标签空间等。

## 6. 主要结论与发现

- 在不获取任何“已部署预测反馈”的前提下，OCPQ 能以仅 \(T^{-1/3}\) 的查询比例达到 \(\beta-O(T^{-1/3})\) 的期望覆盖率，遗憾为 \(O(T^{2/3})\)。
- 该方法适用于任意黑盒分类器、任意非 i.i.d. 的 oblivious 数据流，优于需要每轮反馈或半 bandit 反馈的现有 OCP 方案。
- 实际经验显示：
  - 覆盖率通常**高于理论下界**（即更保守），导致了额外的效率损耗；
  - 覆盖率与效率随 \(\beta\) 呈 S 形变化，\(\beta\) 的选择在实践中较敏感；
  - 在 LLM 安全监控中，对抗性重写会显著增加达到同样覆盖率所需的预测集大小；
  - 与全反馈 ACI 相比，OCPQ 的信息劣势带来的效率差距“出乎意料地小”，尤其在对抗性流上。

## 7. 优点

- **问题新颖**：首次系统提出并求解“超越反馈”的 OCP 设置，切中 LLM 安全探针等现实需求。
- **理论扎实**：给出期望遗憾界、覆盖率下界、最优性结论和高概率界，并证明查询率可极低。
- **通用性强**：不依赖数据分布假设、不依赖分类器内部结构，适用于任意黑箱模型。
- **算法简洁高效**：OCPQ 的权重更新可直接计算，明显快于需每轮求解优化问题的 ExO，且能精确给出遗憾和覆盖率界。
- **扩展丰富**：支持延迟观测、未知时间视野、集合值分类器和无限标签空间，增强了实用性。

## 8. 不足与局限

- **适应性限制**：假设数据流是 **oblivious adversary**（预先固定），不能处理依赖于学习器历史决策的 **adaptive adversary**。作者指出这有本质困难。
- **覆盖率保证较弱**：期望覆盖率的理论下界通常被真实值显著超过，说明方法偏保守；缺乏对效率（平均预测集大小）的无假设上界。
- **\(\beta\) 调参敏感**：覆盖率-效率曲线呈 S 形，转折点集中，实际中如何事先确定合适 \(\beta\) 不明确（通常需先验知识）。
- **高概率界可能不紧**：高概率遗憾界约为 \(O(T^{5/6})\)，与一般的 \(O(T^{2/3})\) 遗憾之间有差距，且定理 3 中的界在大 \(T\) 时虽然可行，但系数复杂。
- **实验覆盖有限**：未在更大规模、更多样化的数据集和现代大模型上验证；未报告训练成本；统计手段较简单。
- **标签空间假设**：主要假设 \(Y\) 有限（虽可在附录中扩展到区间），对更复杂标签结构仍需额外适配。
