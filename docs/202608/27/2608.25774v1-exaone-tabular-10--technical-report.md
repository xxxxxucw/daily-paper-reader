## Abstract
EXAONE Tabular is a compact tabular foundation model family for classification and regression via in-context learning, producing predictions without dataset-specific gradient updates. Pretrained exclusively on a synthetic structural-causal-model (SCM) prior, its central contribution is an architecture-centered redesign of tabular in-context learning. Rather than compressing features into a fixed row embedding before a separate row-level learner, EXAONE Tabular interleaves feature-axis attention within each item with support-conditioned item-axis attention within each feature at every Transformer layer, mediated by item-summary and feature-summary tokens. Across four public benchmarks, EXAONE Tabular combines strong predictive performance with high efficiency. On TabArena, its 20.81M-parameter classification model ranks first overall, surpassing tuned ensembles and 4-hour AutoML pipelines, while regression reaches the performance regime of the 1.64B-parameter TabFM at roughly 1/11 the inference cost. On BCCO and TALENT, EXAONE Tabular ranks second in classification and first in regression. On ScoringBench, it achieves the best mean rank for both point-estimation and predictive-distribution quality, leading the $R^2$, RMSE, and CRPS evaluations. Together, these results establish EXAONE Tabular as a state-of-the-art compact tabular foundation model family, combining strong predictive performance across classification, point regression, and probabilistic regression with an efficient model design.

## 2. 论文提出的方法论

### 核心思想

完全摒弃"先压缩为固定行嵌入，再送入独立行级学习器"的分阶段设计，转而采用**跨轴交织注意力**：在每个Transformer层内，同时进行"物品内特征轴注意力"和"特征内支持条件物品轴注意力"，并通过**物品汇总token（item-summary）**和**特征汇总token（feature-summary）**两个互补的信息通路来协调跨轴信息交换。全网络保持细胞级（cell-level）表示，特征表示与支持集上下文在层层之间持续交互精化。

### 关键技术：Cross-Axis Summary Transformer (CAST)

**整体流程**（以每层为例）：

1. **特征编码**：每个输入特征独立编码，缺失值和无穷值指示符由专门的缺失值处理步骤处理，模型同时利用观测值和缺失模式构建特征表示。
2. **特征轴处理（带物品汇总token）**：
   - 特征轴注意力前，每个细胞通过交叉注意力读取其所属特征上附加的特征汇总状态，并通过残差连接融入。
   - 每个物品将3个物品汇总token与其细胞状态沿特征轴拼接，然后执行自注意力，同时更新物品汇总token和细胞状态。
   - 每层重复该特征轴操作2次。
3. **物品轴处理（带特征汇总token）**：
   - 物品轴注意力前，每个细胞读取其所属物品的3个物品汇总状态，通过残差连接融入。
   - 每个特征将32个特征汇总token与支持集物品细胞状态沿物品轴拼接。
   - 注意力分为**支持路径**（支持集细胞与特征汇总token自注意力）和**查询路径**（查询细胞仅交叉关注支持侧，查询间互不关注）。
4. **可扩展注意力归一化**：使用 Scalable Softmax（SSMax）替代标准softmax，根据上下文token数量调整注意力归一化，以改善长上下文泛化。

**关键配置**：嵌入维度192，6个注意力头，12个Transformer层，前馈扩展4×，分类模型20.81M参数，回归模型21.11M参数。

### 预测头

- **分类头**：两层MLP解码器，映射查询行表示到最多10类的logits，softmax得到概率。更大类别空间通过**纠错输出码（ECOC）**分解处理。
- **回归头**：直接预测999个条件分位数（τ = k/1000, k=1,...,999），点预测通过对排序后的分位数函数中央99.8%区域做梯形平均来近似条件均值，中位数作为替代读出。

### 合成SCM先验（数据生成）

预训练完全基于合成数据，不涉及真实表格数据。生成器分五阶段：

1. **采样任务超参数**：行数、特征数、类别数、图大小、组件结构、机制族等。
2. **采样DAG与节点噪声**：可能包含1-2个弱连通分量，每条边分配三种机制族之一——**神经变换**、**基于树的规则**或**恒等映射**。
3. **按拓扑序计算SCM**：根节点从外生随机分布初始化，其余节点由父节点经过缩放求和计算。
4. **选择观测特征与目标**：部分节点作为输入特征，另一节点作为预测目标，组装成表格数据集，划分支持集和查询集。
5. **后处理与过滤**：类别离散化、非线性特征扭曲、特征量化、按任务注入缺失值，可选质量过滤器筛除过易/过噪/信息不足的任务。

### 预处理与测试时集成

- 提供scikit-learn兼容接口（fit/predict），**fit仅注册和预处理支持集，不更新模型参数**。
- 测试时可跨多个估计器集成：候选特征变换包括原始特征、鲁棒缩放、幂变换、分位数变换；可置换类别编码、特征顺序和类别标签索引。
- 分类默认8个测试时估计器，回归类似。

### 推理流程

- **ECOC分解**：超过10类的分类数据集通过编码矩阵分解为多个子问题。
- **分块推理**：查询样本条件独立于其他查询，可分组处理；缓存执行时支持端到端复用支持侧键值。
- **成本结构**：单估计器单子问题下，主导成本约为 O(Ns² + Ns·Nq)；完整推理涉及 E（集成估计器数）×R（ECOC子问题数）个支持状态。

## 6. 论文的主要结论与发现

1. **TabArena（分类）**：EXAONE Tabular 分类模型在**默认单配置**下排名第一，超越所有调优和集成的基线（包括AutoML管线），比TabPFN-3高出约125 Elo，可比延迟下。

2. **TabArena（回归）**：达到1.64B参数TabFM的性能区间（95%置信区间重叠），但推理成本约为其1/11；超过回归专用Nori模型约140 Elo。

3. **BCCO**：分类以0.792平均准确率排名第二（TabFM为0.799，差距仅0.007，且TabFM使用32个集成成员而EXAONE用8个）；回归以0.799平均R²排名第一。

4. **TALENT**：分类以0.857平均准确率排名第二（TabFM为0.863，差距0.006）；回归以0.736平均R²排名第一。

5. **ScoringBench**：在R²、RMSE和CRPS上**同时获得最佳平均排名**，表明点估计和预测分布质量均领先。

6. **成对胜率分析**：EXAONE Tabular 对除TabFM外的所有竞争方法的最强变体都能赢得多数数分割，对表格基础模型胜率65-92%，对调优+集成的GBDT和神经网络基线至少89%，优势在分割层面一致而非仅由少数数据集驱动。

7. **效率-性能权衡**：位于Pareto前沿，以约20.8M参数达到接近1.64B参数模型的性能，验证了紧凑模型的可行性。

## 7. 优点

- **架构创新**：CAST架构在每层交织特征轴与物品轴注意力，保留细胞级表示，避免早期行压缩带来的信息损失；双向汇总token（物品汇总+特征汇总）提供了清晰的跨轴信息交互机制，设计简洁且可解释性强。
- **纯合成预训练**：完全不依赖真实表格数据预训练，避免了数据泄露风险，同时SCM先验通过因果图、非线性机制、缺失注入等方式模拟了广泛的数据生成过程。
- **原生缺失值支持**：无需插补即可消费缺失数据，在含大量缺失值的BCCO上表现优异，更贴近现实应用。
- **条件独立性设计**：查询样本之间互不依赖，天然支持分块推理和缓存，提升了部署灵活性。
- **预测分布质量**：回归头直接输出999个分位数，在CRPS评估中排名第一，说明不仅点预测准确，不确定性量化也可靠。
- **效率优势显著**：约20.8M/21.1M参数、0.605秒/千样本推理延迟，相比TabFM（1.64B参数、7.0秒/千样本）有数量级效率优势。
- **对比的公平性**：在TabArena上以默认单配置对比其他方法最强变体（调优+集成），依然胜出，增强了结论说服力。

## 8. 不足与局限

- **无消融实验**：未提供架构组件（如汇总token数量、SSMax、特征轴注意力每层次数等）的消融分析，设计选择的经验依据不透明。
- **合成先验的分布偏差风险**：完全依赖SCM先验，如果真实数据分布超出合成先验的覆盖范围，泛化能力可能受限；论文未对不同先验配置进行敏感性分析。
- **统计显著性不足**：BCCO上与TabFM的0.007差距未做正式假设检验，仅基于置信区间重叠推断；多项结果缺乏严格的显著性分析方法（如配对检验、多重比较校正）。
