## 摘要
大语言模型（LLM）在时序推理中通常缺乏深层因果推理能力。受文档布局重排序启发，本文提出从离散叙事到因果拓扑的范式转变。它构建了两种架构：一种是免训练的神经符号框架——时序因果推理智能体（TCR-Agent），通过外部因果图实例化和符号干预引擎实现可解释的因果推断与反事实截断；另一种是端到端模型——时序因果推理模型（TCR-Former），通过因果拓扑注意力掩码和时间跨度偏置将这些机制内化到 Transformer 注意力空间中。在 TempoCausal 基准上的实验表明，TCR-Agent 全面超越现有免训练基线。同时，TCR-Former 的准确率比最先进（SOTA）方法高 16.5%，仅以约 86 亿参数就优于 GPT-5.4 和 DeepSeek-V3.2 等大规模模型。进一步分析揭示了现有方法中的结构—推理脱节现象：外部符号约束和思维链推理可以改进推理步骤，却未能增强深层因果演绎能力。通过将时序因果推理能力内化到模型中，TCR-Former 有效弥合了这一差距，为复杂推理场景提供了高效且可靠的端到端基础。

## Abstract
Large language models (LLMs) generally lack deep causal reasoning capabilities in temporal reasoning. Inspired by document layout reordering, this paper proposes a paradigm shift from discrete narratives to causal topologies. It constructs two architectures: a training-free neuro-symbolic framework, temporal causal reasoning agent (TCR-Agent), which achieves interpretable causal deduction and counterfactual truncation through external causal graph instantiation and a symbolic intervention engine; and an end-to-end model, temporal causal reasoning former (TCR-Former), which internalizes these mechanisms into the Transformer attention space via a Causal-Topological Attention Mask and temporal span biases. Experiments on the TempoCausal benchmark demonstrate that TCR-Agent comprehensively surpasses existing training-free baselines. At the same time, TCR-Former achieves an accuracy 16.5% higher than that of state-of-the-art (SOTA) methods, outperforming large-scale models such as GPT-5.4 and DeepSeek-V3.2 with only approximately 8.6B parameters. Further analysis reveals a structure-reasoning disconnection phenomenon in existing methods: external symbolic constraints and chain-of-thought reasoning can improve reasoning steps, yet fail to enhance deep causal deductive capability. By internalizing temporal causal reasoning capabilities into the model, TCR-Former effectively bridges this gap, providing an efficient and reliable end-to-end foundation for complex reasoning scenarios.

## 2. 方法论

### 2.1 总体思想

论文提出两条互补路线：

- **TCR-Agent**：免训练、模型无关的神经符号框架，通过外部因果图实例化和符号干预引擎实现可解释的因果推断与反事实推理。
- **TCR-Former**：端到端模型，将因果拓扑意识、时间跨度偏置和反事实干预机制内化到 Transformer 注意力空间。

### 2.2 TCR-Agent

- **因果图提取**：
  - 输入文本块序列 \(C\) 和用户提示 \(P\)，由查询感知时空提取器 \(E_\theta\) 调用 LLM 输出中间推理 scratchpad \(S\) 与原始图 \(G_{raw}=(V_{raw},E_{raw})\)。
  - 符号图构造器 \(B\) 将原始图实例化为有向无环图 \(G=(V,E)\)，保留节点时间锚点，并将文本描述与数值字段拼接为统一语义表示。
  - 边包含源节点、目标节点、关系类型和因果推导理由；构造时通过拓扑排序解决时间戳矛盾并强制无环约束。
  - 事件分为三类：无关事件直接过滤；共现事件仅保留状态和时间锚点、不建因果边；因果事件建立有向边并记录理由。
- **反事实干预**：
  - 当提示包含“如果某事件未发生”等反事实假设时，解析干预参数 \(\psi=(v_k,\text{action})\)。
  - `remove`：删除目标节点并保留部分相邻边以维持叙事连通性；`cut_edges`：删除该节点所有出边但保留节点。
  - 扰动后的图 \(G'\) 经深度优先遍历线性化为拓扑描述字符串 \(D(G')\)。
- **双轨推理**：
  - 推理器同时使用原始文本 \(C\) 和结构化轨迹 \(D(G')\)。
  - 生成过程受三段标签约束：`checking` 检查时间计算与因果推导一致性；`reasoning` 基于文本、问题和图进行推理，信息不足返回 Unknown；`reflection` 反思并修正答案。

### 2.3 TCR-Former

- **时序因果编码器**：
  - 以 Qwen-3-0.6B 为骨干，将文本 token 与 \(N=128\) 个可学习事件锚点拼接。
  - 每个锚点由位置无关基础嵌入 \(E_{anchor}\) 和可学习时间跨度偏置 \(E_{span}\) 组成，使不同锚点具有不同时间域先验。
- **因果拓扑注意力掩码**：
  - 文本 token 之间全局双向可见，保证语义理解。
  - 查询 token 可关注全部文本 token。
  - 查询 token 之间采用因果下三角约束，未来查询不能影响过去查询；其余位置屏蔽。
- **时间感知位置偏置**：
  - 对查询和文本嵌入做线性投影后内积得到时间偏置矩阵，仅加到“查询关注文本”的区域，使查询按时间逻辑调整注意力权重。
- **辅助时间戳预测**：
  - 编码器末端接轻量回归头，将查询 token 隐状态映射为归一化时间戳，仅训练时用 MSE 监督，向潜在表示注入物理时间感知。
- **推理解码器**：
  - 以 Qwen-3-8B 为骨干，非线性投影器将编码器因果潜变量对齐到解码器空间。
  - 解码器输入由三部分拼接：原始文本嵌入（事实轨）、对齐后的因果潜变量（逻辑轨）、用户提示嵌入；采用分块注意力掩码。
