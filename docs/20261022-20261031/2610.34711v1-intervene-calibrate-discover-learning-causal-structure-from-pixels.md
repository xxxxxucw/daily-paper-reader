## 摘要
从低层观测中学习高层因果变量是人工智能的一个核心问题。在节点语义已知但图未知的情况下，视觉读出误差可能使模型设置与环境干预值失配。我们通过将图像读出与通过固定轮转干预获得的验证值配对来解决这一失配问题。在编码器和解码器冻结的情况下，逐维可逆校准映射将视觉响应和目标设置置于共享的数值单位中。冻结该映射后，智能体选择干预以确定图的方向，并拟合局部机制以预测后果；逆校准将反事实状态返回到解码器的原始坐标。在 Domino、Pick-and-Place、Balance、Gears、CAUSAL3D 和 CausalWorld 上，我们评估图发现、干预后果和反事实图像。受控多米诺实验表明，干预能够消除相同数量额外观测所遗留的方向歧义。在匹配数据的多米诺对照中，相对于未校准模型，校准降低了同一事实情境下其他变量预测变化的平均误差。

## Abstract
Learning high-level causal variables from low-level observations is a central problem for artificial intelligence. With known node semantics but an unknown graph, visual readout errors can misalign model settings with environment intervention values. We address this mismatch by pairing image readouts with verified values attained through fixed round-robin interventions. With encoder and decoder frozen, a dimension-wise invertible calibration map puts visual responses and target settings in shared numerical units. After freezing this map, the agent selects interventions to resolve graph directions and fits local mechanisms to predict consequences; inverse calibration returns counterfactual states to the decoder's original coordinates. Across Domino, Pick-and-Place, Balance, Gears, CAUSAL3D, and CausalWorld, we evaluate graph discovery, intervention consequences, and counterfactual images. Controlled domino experiments show that interventions resolve orientation ambiguity left by equal additional observations. In a matched-data domino control, calibration reduces the mean error of predicted changes in other variables within the same factual context, relative to an uncalibrated model.
