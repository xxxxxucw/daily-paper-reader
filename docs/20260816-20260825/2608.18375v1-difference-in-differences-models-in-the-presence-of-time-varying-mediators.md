## 摘要
我们研究了双重差分（DiD）设计，其中二元处理改变了一个内生的时变（连续、离散或混合）中介变量，而该中介变量又影响结果。在我们的模型假设下，我们表明通常的DiD估计量混合了处理组的平均直接效应、平均间接效应和趋势偏差项。控制中介变量的双向固定效应（TWFE）回归无法恢复处理组的平均直接处理效应。我们表明，以观测到的中介路径为条件的DiD估计量能够识别该路径上处理组的条件平均直接效应，并且对处理组路径分布进行平均能够在无条件平行趋势不成立时识别平均直接效应。稳定的平均中介效应假设有助于恢复平均中介效应和间接效应。该框架可扩展到多元中介变量、非线性DiD和多处理时期设置。现有的双稳健估计量可用于进行推断。重新审视铁路通达对农业土地价值的影响，该规范产生了未被测量的市场通达性中介的正向直接成分，而相应的间接成分较小且不精确。使用相同样本和基线地理协变量的TWFE基准给出了一个较小且不精确的直接系数，而原始控制变量TWFE系数则改变了符号。

## Abstract
We study difference-in-differences (DiD) designs in which a binary treatment changes an endogenous time-varying (continuous, discrete, or mixed) mediator that in turn affects an outcome. Under our model assumptions, we show that the usual DiD estimand mixes the average direct effect on the treated, the average indirect effect, and a trend bias term. A two-way fixed effects (TWFE) regression that controls for the mediator does not recover the average direct treatment effect on the treated. We show that a DiD estimand conditional on the observed mediator path identifies the conditional average direct effect for treated units at that path, and that averaging over the treated path distribution identifies the average direct effect even when unconditional parallel trends fails. A stable average mediator effect assumption helps recover the average mediator and indirect effects. The framework extends to multivariate mediators, nonlinear DiD, and multiple treatment periods settings. Existing doubly robust estimators can be used to conduct inference. Revisiting the effects of railroad access on agricultural land values, the specification yields a positive direct component not mediated by measured market access, while the corresponding indirect component is small and imprecise. A TWFE benchmark with the same sample and baseline geographic covariates gives a small, imprecise direct coefficient, whereas the original-control TWFE coefficient reverses sign.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：双重差分（DiD）是经济学和社会科学中广泛使用的因果识别方法，其核心前提是平行趋势假设。在实际应用中，处理后常存在一个“时变中介变量”（time-varying mediator）——处理既直接影响结果，又通过改变中介变量间接影响结果。例如：医疗保险扩张通过预防保健影响健康；课程改革通过教育年限影响工资；地方规制通过要素价格影响生产率。
- **核心问题**：当存在这样的内生的、受处理影响的时变中介变量时，传统的 DiD 估计量（无条件对比处理组和控制组的结果变化）是否仍能识别总效应？在 TWFE 回归中直接控制中介变量是否就能识别直接效应？答案都是否定的。
- **主要诊断**：
  - 标准 DiD 估计量会混杂 **平均直接效应（ADTT）**、**平均间接效应（AITT）** 和 **平行趋势偏差项**，本身不具备明确的因果解释。
  - 在 TWFE 回归中控制中介变量，也无法恢复平均直接效应，而是会引入与中介效应异质性、处理对中介的效应以及直接效应异质性相关的额外偏差。
- **论文含义**：论文提出了一个**“以观测到的中介路径（mediator path）为条件的 DiD 识别策略”**，在无需无条件平行趋势假设的前提下识别平均直接效应；再结合“稳定的平均中介效应”假设识别间接效应和平均中介系数。该框架还扩展至多元中介、非线性结果和多期处理场景，为含中介变量的 DiD 应用提供了新的因果推断工具。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程（用文字说明）

- **基础结构模型**：论文从经典两期（基线期 t=0 和处理后 t=1）两组的 DiD 模型出发：
  - 结果方程：`Y_it = θ_it D_it + β_it M_it + λ_i + η_t + U_it`
  - 中介方程：`M_it = α_it D_it + γ_i + δ_t + V_it`
  - 选择方程：`D_i = h(λ_i, γ_i, ε_i)`
- **关键识别假设**：
  - **Assumption 1（外生固定效应）**：处理选择相关的不可观测特征（λ_i, γ_i, ε_i）与中介方程和结果方程中的其他不可观测项独立（除直接效应 θ_i 外）。
  - **Assumption 2（条件独立）**：给定选择不可观测特征后，中介方程的冲击（V, α）与结果方程的冲击（U, β）独立。
  - 这两个假设可视为 Imai, Keele, and Yamamoto (2010) 顺序可忽略性在 DiD 下的类似物。
- **对传统估计量的诊断**：
  - 标准 DiD 估计量 `τ_DiD = E(ΔY|D=1) - E(ΔY|D=0)` 在模型下分解为：
    `τ_DiD = E(θ|D=1) + E(β_1)E(α) + (E(β_1)-E(β_0))[E(γ|D=1)-E(γ|D=0)]`，直接、间接和趋势偏差三项混杂。
  - 控制中介的 TWFE 回归中，直接效应系数 π₁ 和中介效应系数 π₂ 也都被分解为“真实参数 + 多个偏差项”，只有在很强的附加条件下才能一致。
- **中介路径 DiD 识别策略（核心）**：
  - 定义条件 DiD 估计量：比较处理组和控制组在**相同的观测中介路径 (M_i0 = m0, M_i1 = m1)** 下的结果变化差异。
  - **Proposition 1**：在该路径条件下，DiD 对比恰好识别该路径上的**条件平均直接效应**（CADTT）：
    `CADTT(m0,m1) = E(θ|D=1,M0=m0,M1=m1) = τ_DiD(m0,m1)`
  - 对处理组的中介路径分布进行加权平均，得到**无条件平均直接效应（ADTT）**：
    `ADTT = E[τ_DiD(Mi0,Mi1)|D=1]`
  - 这一识别**不需要**以事实中介路径为条件的平行趋势，因为模型隐含的是“以反事实中介路径为条件的平行趋势”，但条件 DiD 估计量恰好能绕过这一不可观测物。
- **间接效应与中介效应的识别**：
  - 引入 **Assumption 4（稳定平均中介效应）**：`E(β_i1) = E(β_i0)`，即中介变量对结果的平均效应不随时间变化。
  - 在此假设下，标准 DiD 估计量可识别平均总效应，而平均间接效应（AITT）即为总效应减去已识别的 ADTT；平均中介系数可由“结果 DiD − ADTT”除以“中介变量的 DiD 效应”得到（Proposition 2）。
- **推广**：
  - **多元中介变量**：中介向量 M_t ∈ R^K，同样以中介路径条件化，得到类似的 ADTT 识别结果。
  - **非线性 DiD**：在 changes-in-changes 框架下（Athey and Imbens, 2006），将单调性和支持条件应用在中介路径上，可识别潜在结果分布和分位数直接效应（Proposition 6）。
  - **多期处理**：分为无动态效应的多期模型和交错采用（staggered adoption）模型，分别给出条件于中介路径的 DiD 识别式（Proposition 7），并允许使用多个处理前期进行假设检验。
- **估计方法**：实证中使用 Sant’Anna 和 Zhao (2020) 的**双稳健 DiD 估计量**，将中介路径作为条件向量（可加入线性或二次项），以处理高维中介路径和协变量。

## 6. 论文的主要结论与发现

- **传统方法失败**：存在时变中介时，标准 DiD 估计量不是简单的总效应，而是直接+间接+趋势偏差的混合；TWFE 控制中介也不能识别直接效应，甚至可出现符号反转。
- **路径条件 DiD 的识别力**：以观测到的中介路径为条件，DiD 对比可以识别条件平均直接效应；对处理组路径分布加权即可得到无条件 ADTT，且不需要无条件平行趋势。
- **间接效应可识别**：在“平均中介效应随时间稳定”的额外假设下，可以用“总效应 − 直接效应”得到平均间接效应，并识别平均中介系数（中介效应比率）。
- **扩展普适性**：结果可推广到连续/离散/混合中介、多元中介、非线性结果和多期（含交错采用）设置，并且可用双稳健估计量进行推断。
- **铁路应用**：
  - 总体效应为正（0.39 左右），主要不是通过成本型市场可达性来实现——未中介化“直接成分”显著为正（ADTT=0.429）；
  - 对应间接效应很小且统计不显著（-0.039）。
  - TWFE 基准（相同控制）给出的直接效应很小（0.090）且不显著；原始控制 TWFE 的直接系数甚至为负（-0.253），符号反转，凸显方法选择的重要性。
- **禁酒令应用**：
  - 在线性路径 DR 规范下，直接效应对生产力存在显著正向影响（ADTT=0.103）；间接效应很小且不显著（0.030）；加入二次项后直接效应基本不变，间接效应进一步缩小，说明通过农场价值渠道的中介证据较弱。
  - 无协变量和含协变量情况下 TWFE 与 DR 的结论差异很大，表明不能简单将 TWFE 系数解释为直接效应。

## 7. 优点：方法或实验设计上有哪些亮点

- **理论创新性强**：首次在 DiD 框架下系统处理内生的、连续/离散/混合的时变中介变量，揭示了标准 DiD 和 TWFE 控制中介的估计量分解，并给出了可行的识别策略。
- **识别思路简洁且具有反直觉性**：虽然“以反事实中介路径为条件”的平行趋势在事实路径下不成立，但事实路径条件 DiD 恰好识别条件直接效应，这为实证研究者提供了可直接操作的估计量公式。
- **统一灵活框架**：将线性结构模型、潜在结果模型、非线性扩展、多元中介、多期处理和交错采用都纳入一个一致的框架，并给出了对应的识别定理和证明。
- **对实证有明确警示作用**：明确指出“不应将处理后的中介作为普通控制变量”，并通过两个真实数据应用展示了传统 TWFE 与新估计量之间可能出现的符号和显著性差异，具有很强的实践指导意义。

## 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

- **识别假设苛刻**：
  - Assumptions 1 和 2（外生固定效应和条件独立）排除了会影响处理选择、中介和结果的共同时变不可观测冲击，这在实际中较难完全满足。论文虽将其类比为顺序可忽略性，但未提供敏感性检验。
  - 间接效应的识别依赖于“平均中介效应稳定”（`E(β_i1)=E(β_i0)`），该假设在现实中可能被违反（如中介对结果的影响随时间自然变化）。
- **方法适用范围的限制**：虽然允许直接效应 θ_i 与选择相关，但模型假设结果方程是线性和可加可分的（直接和间接通道可分离），这限制了处理与中介交互效应、非线性交互等更复杂结构的分析。
- **实验部分的验证深度不足**：
  - 没有对提出的路径 DiD/DR 估计量进行蒙特卡洛模拟以检验其有限样本偏差和方差性能；
  - 没有提供针对识别假设的敏感性分析或安慰剂检验（如仅利用多个前期进行有效性检验的实证演示）。
  - 两个实证应用都是美国历史数据，外部效度有限。
- **计算与推断细节未明确**：论文未提及使用何种软件实现 DR 估计（如 R 包、Stata 命令），也未讨论高维中介路径（多元中介加二次项）下的收敛性和小样本表现。
- **“间接效应”的经济学解释可能受网络外部性影响**：在铁路应用中，市场可达性本身是网络变量，控制县的市场可达性也会因其他铁路建设而变化，论文仅报告了本地采用效应，并未处理一般均衡干扰（SUTVA 假设可能被违反）。
