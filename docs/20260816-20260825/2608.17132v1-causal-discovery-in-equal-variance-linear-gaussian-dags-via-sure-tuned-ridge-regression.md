## 摘要
从观测数据中恢复结构方程模型(SEM)的有向无环图(DAG)是因果发现的核心问题。连续优化方法的迭代梯度下降和逐问题超参数调优不适合两种实际重要场景：样本受限场景（样本数量与DAG节点数相当或更少）和计算受限场景。本文提出SURE-Ridge，一种用于等方差线性高斯SEM的非迭代、闭式估计器。该方法执行并行逐节点回归，通过Stein无偏风险估计(SURE)自适应选择正则化参数，并应用自适应阈值处理从所得软邻接矩阵中提取DAG。数值结果表明，与NOTEARS、DAGMA和GBNSL基线相比，SURE-Ridge在小样本场景中实现了最低的结构汉明距离，在所有测试样本量中运行时间最低。

## Abstract
Recovering the directed acyclic graph (DAG) of a structural equation model (SEM) from observational data is a central problem in causal discovery. The iterative gradient descent and per-problem hyperparameter tuning of continuous-optimization methods are poorly suited to two practically important regimes: the sample-limited regime, where the number of samples is comparable to or smaller than the number of nodes in the DAG, and the compute-limited regime. This work proposes SURE-Ridge, a non-iterative, closed-form estimator for equal variance linear Gaussian SEM. The method performs parallel node-wise regressions with regularization parameters chosen adaptively by Stein's unbiased risk estimate (SURE), and applies an adaptive thresholding procedure to extract a DAG from the resulting soft adjacency matrix. Numerical results show that SURE-Ridge achieves the lowest structural Hamming distance in the small-sample regime and the lowest run time across all sample sizes tested, compared with NOTEARS, DAGMA, and GBNSL baselines.

**核心洞察：** 在等方差线性高斯SEM中，真实DAG由联合分布唯一可识别（Peters & Bühlmann, 2014），且每个节点的结构方程本身就是一个线性高斯回归问题，子问题可解耦，因此适合并行化的非迭代闭式估计。

**整体含义：** 本文提出一种非迭代、闭式、无需逐问题调参的因果发现方法，在样本稀缺和计算受限场景下同时实现高精度和高效率。

## 2. 论文提出的方法论：SURE-Ridge

### 核心思想
将DAG恢复问题分解为**d个独立的节点回归子问题**，对每个节点使用**岭回归**估计其因果系数向量，正则化参数由**Stein无偏风险估计（SURE）**自适应选择，最后通过**自适应阈值化**过程从软邻接矩阵提取有效DAG。

### 关键技术细节

**（1）逐节点SURE目标（Proposition 1）**

对节点i的回归模型 x_i = w_i X_{-i,:} + n_i，岭估计为：

$$\hat{w}_i(\lambda_i) = (G_i + \lambda_i I_{d-1})^{-1} X_{-i,:} x_i^T$$

其中G_i = X_{-i,:}X_{-i,:}^T是Gram矩阵。SURE目标为：

$$SURE_i(\lambda_i) = -n\sigma^2 + \|x_i^T - X_{-i,:}^T(G_i + \lambda_i I)^{-1}X_{-i,:}x_i^T\|_2^2 + 2\sigma^2 tr[(G_i + \lambda_i I)^{-1}G_i]$$

**（2）特征分解加速**

利用Gram矩阵的特征分解G_i = U_iΓ_iU_i^T，将SURE目标转化为特征域中的**标量函数之和**，可在O(d)成本下对每个网格点求值：

$$SURE_i(\lambda_i) = -n\sigma^2 + \|x_i\|_2^2 - 2\sum_{k=1}^{d-1}\frac{z_{i,k}^2}{\gamma_{i,k}+\lambda_i} + \sum_{k=1}^{d-1}\frac{\gamma_{i,k}z_{i,k}^2}{(\gamma_{i,k}+\lambda_i)^2} + 2\sigma^2\sum_{k=1}^{d-1}\frac{\gamma_{i,k}}{\gamma_{i,k}+\lambda_i}$$

**（3）自适应阈值化三阶段流程**

- **第一阶段——信号缩放地板滤波**：设定η_min = max(η₀, β·max|W̃_est|)，其中η₀为绝对安全下界，β为缩放系数，用于过滤脊回归收缩残留的噪声项；
- **第二阶段——二分搜索**：当W_floor仍有环时，在超过地板的候选阈值集合上进行离散二分搜索，找到使图成为DAG的最小阈值η*，利用"无环性关于阈值单调"的性质，至多⌈2log₂d⌉次检验即可定位；使用多项式无环性函数h(W) = tr[(I_d + W⊙W/d)^d] − d 作为判据；
- **第三阶段——回退机制**：若二分搜索过度剪枝（\|W_bisect\|₀ < ½\|W_floor\|₀），则保留W_floor以优先保留信息边。

**（4）算法流程（文字描述）**

1. 对每个节点i，计算Gram矩阵并做特征分解；
2. 在给定网格Λ上计算各λ对应的SURE值，选择最优λ*；
3. 用闭式解恢复节点回归系数w_i*；
4. 组装软邻接矩阵W̃_est（对角线置零）；
5. 计算自适应地板阈值η_min，得到W_floor；
6. 若W_floor无环则返回；否则在超过地板的候选阈值上二分搜索使图无环的最小阈值；
7. 根据稀疏度回退规则决定返回W_bisect或W_floor。

**（5）计算复杂度：** O(d⁴ + d³n + dM(d−1) + d³log d)每DAG，其中M为SURE网格点数。

## 3. 实验设计

### 数据集/场景
- **合成数据**：模拟高斯SEM，节点数d∈{20, 50}，每图边数⌈2d/5⌉（稀疏随机DAG分布，子Erdős–Rényi-1平均入度）；
- 非零权重从[−2.0,−1.0]∪[1.0,2.0]均匀采样；
- 噪声方差固定σ²=1；
- 样本量n从25到200变化，覆盖样本受限（n≤d）到样本充足（n>d）区间。

### Benchmark基线
1. **NOTEARS**：连续优化，多项式无环性约束 + 增广拉格朗日（32个外部迭代×1000内部步，32000 Adam步）；
2. **DAGMA**：对数行列式无环性 + 中心路径方案（T=4阶段×8000内部步）；
3. **GBNSL**：基于精度矩阵的逐叶节点剪枝方法（ℓ1正则化，CLIME估计）。

### 评估指标
- **归一化结构汉明距离（Normalized SHD）**：SHD除以最大可能边数d(d−1)/2；
- **每DAG运行时间**（秒）。

### 公平性保证
每个设置进行**100次蒙特卡洛试验**，各方法在同一(W_true, X)上进行比对；NOTEARS和DAGMA使用相同的优化预算（32000步）；所有基线后处理阈值设为0.1。

### 方法自身局限
1. **适用场景窄**：仅适用于等方差线性高斯SEM，实际应用中噪声方差相等的假设往往不成立；

4. **可扩展性存疑**：虽然非迭代，但每节点的特征分解O(d³)使得d⁴的总复杂度在节点数很大时仍可能成为瓶颈。

### 实验验证局限
1. **无真实数据验证**：合成数据无法完全反映真实因果结构的复杂性（非线性、隐变量、混杂因子等）；
2. **无消融实验**：无法量化SURE调参、阈值策略中各环节的独立贡献；
3. **场景覆盖有限**：未测试不同噪声水平、不同图密度、不同权重分布、更大规模图、非高斯噪声等条件下的表现；

5. **GBNSL的公平性**：GBNSL的ℓ1参数和马尔可夫毯阈值"一次性调好并固定"，其调优过程的具体细节未充分披露。

### 理论分析不足
- 论文未提供SURE-Ridge的**统计一致性分析**或**样本复杂度界**，仅给出计算复杂度；缺乏在何种条件下收敛到真实DAG的理论保证；
- 对SURE估计量的偏差-方差权衡缺乏量化分析，结论多以经验观察为主。
