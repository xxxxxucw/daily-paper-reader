## 摘要
搜索智能体在强化学习（RL）微调过程中面临严重的可靠性危机。启发式Top-K检索常常导致关键证据丢失或噪声混入，而渐进式RL引发的过度自信则会导致幻觉答案和冗余搜索。为了构建高度可靠的智能体，我们引入共形预测（CP）并提出共形化智能体搜索（CAS）。该框架在检索侧和训练侧均建立了可靠性保证：在检索侧，自适应预测集（APS）作为共形预测的一种具体实现，将统计覆盖率转化为动态文档截断，从而构建大小自适应的预测集；在训练侧，自适应共形推断（ACI）作为一种动态共形预测算法，动态构建具有可控覆盖率的预测集以量化答案置信度，并将其用于在组相对策略优化（GRPO）目标中对低置信度轨迹进行惩罚，确保模型仅从可靠轨迹中学习。在单跳和多跳问答数据集上的实验表明，我们的框架显著提高了推理准确率，同时大幅减少了冗余工具调用，建立了一种高度可靠且高效的智能体范式。我们的代码可在 https://github.com/S1llyBird/CAS 获取。

## Abstract
Search Agents face a severe reliability crisis during reinforcement learning (RL) fine-tuning. Heuristic Top-K retrieval often causes critical evidence loss or noise inclusion, while over-confidence induced by progressive RL leads to hallucinated answers and redundant searches.   To build highly reliable agents, we introduce Conformal Prediction (CP) and propose Conformalized Agentic Search (CAS). This framework establishes reliability guarantees on both the retrieval and training sides: on the retrieval side, an Adaptive Prediction Set (APS), a specific CP realization, translates statistical coverage into dynamic document truncation to construct prediction sets that are adaptive in size; on the training side, Adaptive Conformal Inference (ACI), a dynamic CP algorithm, dynamically constructs prediction sets with controllable coverage to quantify answer confidence, which is then used to penalize low-confidence trajectories within the Group Relative Policy Optimization (GRPO) objective, ensuring the model learns only from reliable ones.   Experiments across single-hop and multi-hop QA datasets demonstrate that our framework significantly improves reasoning accuracy while drastically reducing redundant tool invocations, establishing a highly reliable and efficient agent paradigm. Our code is available at https://github.com/S1llyBird/CAS.

  - **训练侧**：RL 训练中模型逐渐产生过度自信（over-confidence），加上稀疏二值奖励，容易生成幻觉答案；同时，不自信或过度自信都会诱导模型进行大量冗余、重复的工具调用，降低效率。
- **整体思路**：论文引入统计学中的共形预测（Conformal Prediction, CP）框架，提出 CAS（Conformalized Agentic Search），从**检索**和**训练**两个层面同时提供可证明的可靠性保证，从而构建高可靠、高效率的搜索智能体。

## 2. 论文提出的方法论

### 2.1 总体框架
- 策略模型使用严格的生成文法，在 `<think>` 与 `</think>` 中进行推理；当知识不足时，生成 `<search>query</search>` 调用外部搜索引擎；检索结果被 APS 动态截断后放入 `<information>` 标签中；最终在 `<answer>` 标签中输出答案。
- 框架由两个协同模块构成：**APS**（检索侧）与 **ACI**（训练侧）。

### 2.2 检索侧：自适应预测集（APS）
- 将共形预测的“边际覆盖率保证”转化为动态文档截断：
  1. 搜索引擎返回候选文档集合 D = {d1, ..., dn} 及原始检索分数。
  2. 对分数做 **softmax** 归一化，得到每个文档的相关性概率 p(di|q)。
  3. 按 APS 的累积概率准则，从概率最高的文档开始累加，直到累积质量首次超过校准阈值 q̂_APS，得到截断索引 k。
  4. 最终得到可靠子集 D_APS = {d1, ..., dk}，其大小随查询 q 的难度动态变化：简单查询集合小，复杂查询集合大。
- 该机制在满足 1−α_APS 边际覆盖保证的同时，近似逼近条件覆盖，避免了固定 Top-K 的刚性缺陷。

### 2.3 奖励设计
- 采用规则式奖励：r(x, y) = r_acc + r_fmt。
  - r_acc：精确匹配（Exact Match）指示。
  - r_fmt：格式奖励，包含 I_valid（语法正确性）和 I_ans（是否生成 `<answer>` 边界）；通过公式(5)防止“reward hacking”，并给错误答案提供稠密的中间信号。

### 2.4 训练侧：自适应共形推断（ACI）
- 背景：标准 CP 依赖 i.i.d./可交换性假设，但 RL 训练中策略不断更新、数据分布持续漂移，静态 CP 不再适用。
- 非一致性分数：对每个生成轨迹 yi，取 `<answer>` 标签内所有生成 token 的**负对数似然（NLL）**平均值作为分数 s(xt, yi)，如公式(6)所示。
- 平滑 ACI 更新：采用指数加权移动平均（EMA）的过去误差频率来更新目标误差率 αt，如公式(7)所示，减少局部波动。
- 动态阈值：在滚动校准窗口（最近 2000 条轨迹）上计算经验分位数 q̂t = Q̂t(1−αt)。
- ACI 引导的 GRPO 损失：对低置信轨迹（s > q̂t）施加折扣权重 ωi = η（η = 0.5，默认），高置信轨迹权重为 1，如公式(9)所示。该权重与 GRPO 优势 Ai 协同：
  - 对“低置信但碰巧正确”（Ai > 0）的样本，削弱正向奖励，防止“盲目猜测学习”。
  - 对“高置信但错误”（Ai < 0）的样本，施加全额惩罚。
- 整体损失为公式(8)的 ACI 加权 GRPO 目标，含 KL 散度惩罚。

  - 将 APS 与可学习检索器联合训练，使相关性概率分布本身参与优化，而非依赖固定 softmax；
  - 在多模态智能体、具身决策、代码生成等更复杂任务中验证共形框架的适用性；
  - 探索在无法获得真实相关性标签时，如何仅用弱监督信号构建可靠的共形校准集。

## 11. 总体评价

CAS 是一篇理论深度与实践效果兼备的工作。它将共形预测这一成熟的统计学工具，创造性地嫁接到搜索智能体的两大核心痛点（检索证据截断与 RL 训练置信度漂移）上，给出了形式化保证、可落地的算法与较完整的实验验证。其核心创新——“检索侧 APS 动态截断 + 训练侧 ACI 加权 GRPO”——在多个 QA 基准上取得了显著且一致的提升，同时有效抑制了冗余搜索行为，兼具可靠性与效率。

尽管在任务覆盖、指标维度和复盘透明度上仍有提升空间，但瑕不掩瑜。这篇论文对搜索智能体的可靠性研究具有明确的方法论贡献和示范意义，值得相关领域研究者精读与借鉴。
