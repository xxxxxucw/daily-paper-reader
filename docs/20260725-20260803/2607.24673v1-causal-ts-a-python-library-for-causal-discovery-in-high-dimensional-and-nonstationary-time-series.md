## 摘要
我们介绍了Causal-TS，这是一个用于高维和非平稳多元时间序列因果发现的开源Python库。Causal-TS提供了四种专门算法——CDNOTS、CDNOTS+、CEDAR和GRACE——以及GES、Granger、LASSO-VAR和LGES的封装器，所有这些都共享一个统一的条件独立性（CI）检验层，并通过PyTorch实现GPU加速。一个机制发现流程通过可插拔的变点检测器检测结构性断裂，并使用特定于机制的参数对每个机制运行发现。命令行界面、合成数据生成器和可选的DoWhy集成提供了从原始时间序列到因果效应估计的端到端流程。该库可通过pip安装，在Python 3.10--3.12上测试，并在https://github.com/bloomberg/causal-ts上可用。

## Abstract
We describe Causal-TS, an open-source Python library for causal discovery in high-dimensional and nonstationary multivariate time series. Causal-TS provides four specialized algorithms-CDNOTS, CDNOTS+, CEDAR, and GRACE-along with wrappers for GES, Granger, LASSO-VAR, and LGES, all sharing a unified conditional independence (CI) test layer with GPU acceleration via PyTorch. A regime discovery pipeline detects structural breaks via pluggable changepoint detectors and runs discovery per regime with regime-specific parameters. A command-line interface, synthetic data generators, and optional DoWhy integration provide an end-to-end pipeline from raw time series to causal effect estimates. The library is pip-installable, tested on Python 3.10--3.12, and available at https://github.com/bloomberg/causal-ts.

### 2. 论文提出的方法论

**总体架构**：所有共享统一条件独立性（CI）测试层，并通过 PyTorch 提供 GPU 加速。四个专门算法之外还封装了 GES、Granger、LASSO-VAR、LGES 等传统基线算法。

**核心算法**：
- **CDNOTS**：将 PC 算法扩展到时序场景，引入一个多维变量 C（由时间索引、季节周期、机制指示器等组成）来捕捉非平稳性。
- **CDNOTS+**：将 CDNOTS 的骨架发现替换为 PCMCI+ 风格的过程，将条件集限制在已发现的父节点上，减少枢纽型/无标度结构图中的过度条件化问题。
- **CEDAR**：使用偏距离相关滞后选择（默认）、AR(p) 感知的 CI 检验和稳定的 MCI 剪枝，以避免条件集指数爆炸；使用确定性 C 节点处理非平稳性。
- **GRACE**：使用 Hard Concrete 门控和 L0 正则化细化 CDNOTS 骨架。

**机制发现流程**：`causalts.regime` 模块通过可插拔变点检测器（PELT、HMM、CUSUM、KS、Levene、集成、分位数、季节性）对时序进行分段，然后按机制分别运行因果发现，再通过并集/多数/加权/交集方式聚合图结果。

**条件独立性检验层**：包含 8 种 CI 检验——ParCorr、KCI、SplitKCI、DFCIT、LinSig（Manten 等人签名核的线性核变体）、RCOT、CMIknn、GCMI，全部支持 GPU 加速，并可作为独立工具使用。

**领域知识和接口**：
- `AncestralKnowledge` 支持直接边约束（骨架发现阶段强制）和路径级祖先约束（定向阶段强制）。
- Python API 简洁，2-3 行即可运行发现算法。
- 结果对象原生支持 DoWhy 效应估计（`.estimate_effect()`、`.fit_scm()`、`.counterfactual()`）。
- 提供命令行界面 `causal-ts discover data.csv --algorithm grace --max-lag 3`，无需 Python 专业知识。
