## 摘要
大型语言模型（LLM）级联通过将简单查询路由到小型模型并将困难查询转交给较大模型来降低推理成本。生产级联通过置信度阈值来管理这种转交，但LLM置信度分数未校准，阈值必须针对每对模型和每个领域进行调整，并且没有设置能产生级联准确性的正式界限。我们引入了共形级联（CC），一种多层推理框架，使用共形预测集大小作为转交规则：当校准集坍缩为单个答案时接受，否则转交。该过程提供了无分布、有限样本的准确性保证。通过逐层联合界，在用户指定的任意$α$下，接受层的预测集以至少$1 - Kα$的概率覆盖正确答案；在选择性保持条件下（与我们边际覆盖结果一致，但不严格隐含），该界限收紧为$1 - α$。我们进一步将预期级联成本描述为$α$和校准集接受率的显式函数。在涵盖科学、医学、常识和标准化考试的18个多项选择基准上，评估了来自四个开放权重模型家族的两层级联，CC在大多数家族-基准对上严格优于最强的校准调优启发式级联，在多数投票不可靠的推理密集型基准上收益最大；在较容易的基准上，级联将绝大多数查询提交给小模型，且不损失准确性。扩展到开放式生成需要答案聚类步骤，我们将其留待未来工作。该方法无需模型训练，仅需黑盒API访问。

## Abstract
Large language model (LLM) cascades reduce inference cost by routing easy queries to a small model and deferring hard queries to a larger one. Production cascades govern this deferral through a confidence threshold, but LLM confidence scores are miscalibrated, the threshold must be tuned per model pair and per domain, and no setting yields a formal bound on cascade accuracy. We introduce \textbf{Conformal Cascade} (CC), a multi-tier inference framework that uses conformal prediction set size as the deferral rule: accept when the calibrated set collapses to a single answer, defer otherwise. The procedure delivers a distribution-free, finite-sample accuracy guarantee. By a per-tier union bound, the prediction set at the accepting tier covers the correct answer with probability at least $1 - Kα$ for any user-specified $α$; under a selection-preservation condition (consistent with, but not strictly implied by, our marginal coverage results), the bound tightens to $1 - α$. We further characterise expected cascade cost as an explicit function of $α$ and the calibration-set acceptance rate. Across 18 multiple-choice benchmarks spanning science, medicine, commonsense, and standardized exams, evaluated on two-tier cascades drawn from four open-weight model families, CC strictly improves over the strongest calibration-tuned heuristic cascade on the majority of family--benchmark pairs, with the largest gains on reasoning-heavy benchmarks where majority vote is unreliable; on easier benchmarks the cascade commits the vast majority of queries to the small model at no accuracy cost. Extension to open-ended generation requires an answer-clustering step that we leave for future work. The method requires no model training and only black-box API access.

## 1. 论文的核心问题与整体含义

**研究动机**：生产环境中的 LLM 级联推理（cascade）通过"小模型处理简单查询、必要时转交大模型"的方式降低推理成本。但现有级联依赖**置信度阈值**（如 softmax 概率、自洽性投票一致率等）来决定是否转交，存在三个根本性问题：

- **校准不良**：LLM 的置信度分数系统性偏移，在推理密集型任务上尤为严重，无法区分"自信但错误"与"真正简单"的输入；
- **阈值需逐场景重调**：每换一组模型对、每个新领域都必须重新在标注集上扫描阈值；
- **无形式化保证**：没有任何阈值设置能对级联的最终准确率给出可证明的边界，部署者无法回答"如果我希望最多 5% 错误答案，阈值该设为多少？"这一关键问题。

**核心贡献**：论文提出 **Conformal Cascade（CC）**，用**共形预测集的大小**取代置信度阈值作为延迟规则——预测集坍缩为单一答案时接受（committed），集合含多个候选时转交。该方法提供**无分布（distribution-free）、有限样本（finite-sample）的级联级准确率保证**，且无需训练、仅需黑盒 API 访问。

## 2. 方法论

### 2.1 核心思想

- **共形预测集作为延迟信号**：分拆共形校准（split conformal calibration）将保留标注集转化为一个阈值 $\hat{q}_k$，使得该阈值构造的预测集以至少 $1-\alpha$ 的概率覆盖正确答案。集合大小（而非置信度数值）成为延迟规则：$|C_k(x)|=1$ 则接受，$>1$ 则转交上一层（更大模型）。
- **延迟本身不引入错误**：只有接受事件才可能提交错误答案，因此逐层保证可以组合成级联级保证。
- **用户参数 $\alpha$ 双重角色**：既是覆盖水平（Theorem 2），又是预期成本的控制手柄（Theorem 4）。

### 2.2 关键技术细节

- **频率基非一致性分数**（Section 3.1）：$s_k(x,a) = 1 - \frac{\#\{i: \hat{y}_i^{(k)} = a\}}{N}$，仅需黑盒 API（自洽性采样 $N=16$ 次）即可计算；Lemma 5 证明查询的可交换性可提升到分数的可交换性。
- **逐层共形校准**（Section 3.2）：在保留校准集上计算真实答案的分数，排序后取 $\hat{q}_k = s_{(k)}(\lceil (1-\alpha)(n+1) \rceil)$；预测集 $C_k(x) = \{a \in A: s_k(x,a) \leq \hat{q}_k\}$。
- **级联算法**（Algorithm 1）：第 $k$ 层构造预测集；若 $1 \leq |C_k(x)| \leq \kappa$ 则接受并返回组内最高频答案，否则转交；最后一层回退到 argmin 频率答案。
- **覆盖保证**（Theorem 2）：$\Pr[\hat{y} \neq y_{true},\, \mathcal{A}] \leq K\alpha$，即每层用 $\alpha/K$ 可保证级联错误率 $\leq \alpha$；在**选择性保持条件**（Assumption 3）下收紧为 $\alpha$。
- **成本-覆盖权衡**（Theorem 4）：两层级联下 $\mathbb{E}[\text{Cost}(X)] = c_1 + c_2 \cdot \Pr[|C_1(X)| \neq 1]$，收益仅取决于校准集上可观测的接受率。

## 3. 实验设计

**模型家族与层级**：四组两层级联，来自四个开放权重指令微调家族——Llama（3.2-3B → 3.1-8B）、Gemma（4-E4B → 4-31B）、Ministral（3-3B → 3-14B）、Phi（3.5-mini → Phi-4）。每查询 $N=16$ 次采样，温度 $\tau=0.7$，成本固定 $c_1=1, c_2=2.7$。

**基准**：18 个多项选择基准，涵盖科学（GPQA-Diamond、ARC-Challenge、SciQ 等）、医学（MedMCQA、MedQA-USMLE-4、PubmedQA）、通识（MMLU、MMLU-Pro）、常识（HellaSwag、PIQA、Cosmos-QA 等）、事实性（TruthfulQA）、标准化考试（AGI-Eval）、数学（MathQA）、多语言阅读（Belebele-Eng）。答案选项数 2–10 个不等。每个基准 30%/70% 划分校准/测试（种子 42），共 72 个家族-基准对。

**对比基线**（5 种、共 12 个可调配置）：
1. Always-Weak / Always-Strong（多数投票，无调优）
2. Agreement 级联（θ ∈ {0.5, 0.6, 0.7, 0.8, 0.9}）
3. Entropy 级联（τ ∈ {-1.5, -1.0, -0.5, -0.3}）
4. Random defer（p ∈ {0.2, 0.5, 0.8}）

**报告协议**：CC 在 15 点网格（5 个 α × 3 个 κ）上扫参，启发式基线在 12 配置网格上扫参，双方均按测试集 argmax 报告最优精度（oracle-tuned）；覆盖率和接受率则报告固定锚点 α=0.10、κ=1 的无调优数值。

## 6. 主要结论与发现

1. **CC 在大多数家族-基准对上严格优于最强启发式级联**：72 对中 49 胜、6 平、17 负；最大增益集中在推理密集型基准——Ministral/MathQA（+4.6 pp）、Phi/GPQA-Diamond（+4.3 pp）、Phi/MedMCQA（+3.6 pp）、Gemma/TruthfulQA（+3.3 pp）。
2. **覆盖率保证经验成立**：在 Llama 级联上，大多数基准的经验误覆盖在 α 附近（而非 Kα），但个别单元（如 MedMCQA 0.130、ARC-Challenge 0.124）轻微超出 α + 0.02 的窄带，全部落在定理 2 的 Kα=0.20 联合界内；其他三个家族类似（7 个单元超窄带、全部满足联合界）。
3. **成本-精度前景良好**：在 MMLU 上，CC（κ=1）在 Llama 和 Ministral 上覆盖整个成本区间的启发式前沿；放宽 κ 到 {2,3} 可进一步降低 53% 成本（Llama，α=0.10，成本从 2.86 降至 1.34），代价是 5.3 pp 精度损失。
4. **增益集中在困难查询**：难度分层显示 CC 相对 Always-Strong 的优势主要来自硬桶（如 Llama/MMLU-Pro 硬桶 +3.8 pp：7.2% vs 3.4%）。
5. **级联自动划分路由**：同一 α=0.10 下接受率从 Belebele-Eng 的 95.6% 到 MMLU-Pro 的 0%（全部转交），无需逐基准调参。
6. **失败模式可诊断**：Phi 在 AGI-Eval 等基准上因 tier-1 模型采样分布过于弥散（集合永不坍缩、100% 转交）而落后 4.5 pp，源于回退规则与 Always-Strong 的差异。

## 7. 优点

- **理论保证扎实**：提供无分布、有限样本、级联级的覆盖保证（Theorem 2），且成本有闭式表达式（Theorem 4），将"误差预算 → 阈值"的映射从经验调参变成可证明的操作。
- **黑盒友好、无需训练**：仅需自洽性采样频率，无需 logprob 访问或模型架构改动，可嵌入现有生产链路。
- **单一可解释超参数**：α 直接对应部署者的误差预算，κ 提供成本-精度的第二坐标轴。
- **经验验证系统**：72 对主结果 + 覆盖率经验验证 + 难度分层 + 成本敏感性 + 失败诊断，分析链条完整，尤其对失败模式（Phi）给出了可操作的诊断与修复建议。
- **与 C3PO 的对比清晰**：明确区分了成本约束（C3PO）与覆盖约束（CC）两种正交设计目标。

## 8. 不足与局限

- **保证是边际的，不是条件的**：覆盖保证对查询分布是边际的，不提供按难度/子群的保证；作者承认条件覆盖在无额外假设下不可能（Vovk, 2012）。
- **可交换性假设**：覆盖保证要求校准-测试可交换；协变量漂移部署需在线重校准（作者指出但未实现）。
- **仅限抽取式答案**：框架要求有限可提取答案集；开放式生成需答案聚类步骤，留作未来工作。
- **oracle-tuned 报告协议**：主结果按测试集选最优超参报告，可能高估实际部署性能；作者同时报告了固定 α=0.10 的无调优结果作为补充，但该锚点的 α 选择本身也带有先验性。
- **离散分数导致上界失效**：频率分数在 N=16 时仅取 17 个离散值，几乎必然不同的假设不满足，经验覆盖率可能显著低于 $1-\alpha+1/(n+1)$ 的上界（作者承认这一缺陷）。
- **Aggregate-only 日志**：无法计算 bootstrap 置信区间，小样本基准（GPQA-Diamond 等）上的微小差异（|Δ| < 0.5 pp）仅能作为点估计；选择性保持假设（Assumption 3）缺乏直接的条件误覆盖验证。
- **未验证 K>2**：理论支持任意 K 层，实验仅两层级联。
- **应用风险**：边际保证不给子群保护，基础模型偏差会传递到级联输出；高风控场景需配合子群条件校准与安全工具。
