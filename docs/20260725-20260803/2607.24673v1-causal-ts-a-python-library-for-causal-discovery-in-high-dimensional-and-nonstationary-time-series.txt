# Causal-TS: A Python Library for Causal Discovery in High-Dimensional and Nonstationary Time Series 

Mohammad Fesanghary mfesanghary1@bloomberg.net 

Bloomberg LP, New York, NY, USA 

Abstract 

We describe Causal-TS , an open-source Python library for causal discovery in high-dimensional and nonstationary multivariate time series. Causal-TS provides four specialized algorithms— CDNOTS , CDNOTS+ , Cedar , and Grace —along with wrappers for GES, Granger, LASSO-VAR, and LGES, all sharing a unified conditional independence (CI) test layer with GPU acceleration via PyTorch. A regime discovery pipeline detects structural breaks via pluggable changepoint detectors and runs discovery per regime with regime-specific parameters. A command-line interface, synthetic data generators, and optional DoWhy integration provide an end-to-end pipeline from raw time series to causal effect estimates. The library is pip-installable, tested on Python 3.10–3.12, and available at https://github.com/bloomberg/causal-ts .

Keywords: Causal Discovery, Time Series, Nonstationarity, GPU Acceleration, Python 

1 Introduction 

Identifying causal relationships from observational time series is a fundamental problem across many scientific disciplines, including climate science, neuroscience, finance, epidemiology, and eco-nomics [Peters et al., 2017]. Time series offer a structural advantage: since causes must precede their effects, temporal order alone rules out many candidate causal directions. A further underexploited signal is nonstationarity —changes in causal mechanisms over time—which recent work shows can resolve causal direction that is otherwise unidentifiable [Huang et al., 2020, Sadeghi et al., 2025]. Existing tools such as Causal-learn [Zheng et al., 2024], Tigramite [Runge et al., 2019], and DoWhy [Sharma and Kiciman, 2020] address related problems but do not combine nonstationarity-aware discovery, GPU-accelerated CI testing, and an integrated discovery-to-effect pipeline.

Regime-aware discovery. When causal lag structures vary across operating conditions (e.g., flood vs. dry season), the regime module segments the series and runs discovery per regime: 

from causalts.regime import run_regime_discovery from causalts.regime import PeltRegimeDetector result = run_regime_discovery(df, cedar_fn, detector=PeltRegimeDetector())

Command-line interface. The causal-ts CLI requires no Python expertise: 

causal-ts discover data.csv --algorithm grace --max-lag 3 

3 Package Design 

3.1 Algorithms 

Causal-TS provides implementations of four recently proposed algorithms (Table 1), plus wrappers for established baselines (GES, Granger causality, LASSO-VAR, LGES) under the same API. 

CDNOTS extends PC with temporal constraints and a potentially multidimensional variable 

C—composed of components such as time index, seasonal cycles, or regime indicators—that captures nonstationarity. CDNOTS+ replaces its skeleton phase with a PCMCI+-style procedure that restricts conditioning to discovered parents, reducing over-conditioning on hub-structured and scale-free graphs. Cedar uses partial distance correlation lag selection (default), AR( p)-aware CI testing, and stable MCI pruning to avoid exponential conditioning sets; a deterministic C-node handles nonstationarity. Grace refines a CDNOTS skeleton with Hard Concrete gates [Louizos et al., 2018] and L0 regularization.

3.2 Conditional Independence Tests and GPU Acceleration 

All algorithms share a modular CI test layer with eight tests: ParCorr, KCI, SplitKCI [Pogodin et al., 2024], DFCIT [Cai et al., 2022], LinSig (our linear-kernel variant of the signature kernel of Manten et al., 2024), RCOT, CMIknn [Runge, 2018], and GCMI. All eight tests include GPU-accelerated implementations via PyTorch. Tests can also be used standalone for general CI testing tasks. 3.3 Software Quality 

Causal-TS targets Python 3.10+ and is installable via pip install causalts (with optional extras [dowhy] and [dev] ). 

• Testing & CI: 22 test modules (pytest) across Python 3.10–3.12; six GitHub Actions workflows for testing, linting (Black/isort/flake8), CodeQL security analysis, and OpenSSF Scorecard. 

• Documentation: Sphinx with API reference, 25 example notebooks, CI test selection guide, and full CLI reference. 

• Dependencies & License: NumPy, Pandas, PyTorch, SciPy, NetworkX, causal-learn (MIT), statsmodels. GPL-3.0-or-later; paper CC-BY 4.0.

Causal-TS fills a complementary niche: nonstationary temporal dynamics at scale, with built-in bridges to DoWhy and Tigramite for the full discovery-to-inference pipeline. 35 Conclusion 

Causal-TS provides a unified Python library for causal discovery in nonstationary and high-dimensional time series, combining temporally aware algorithms, regime-conditional discovery, GPU-accelerated CI tests, and an end-to-end pipeline from CLI to effect estimation. The library assumes sufficiently sampled multivariate time series and does not by itself resolve hidden confounding or selection bias; these assumptions are documented per algorithm. The submitted version is v0.25.0, available at https://github.com/bloomberg/causal-ts with Sphinx documentation and tutorial notebooks.
