## 摘要
大语言模型（LLM）级联通过将简单查询路由到小模型并将困难查询推迟到大模型来降低推理成本。生产环境中的级联通过置信度阈值控制这种推迟，但LLM置信度分数校准不佳，阈值必须针对每个模型对和每个领域进行调整，且没有任何设置能为级联准确性提供正式界限。我们提出了共形级联（CC），一种多层级推理框架，使用共形预测集大小作为推迟规则：当经校准的预测集坍缩为单个答案时接受，否则推迟。该过程提供了免分布、有限样本的准确性保证。通过逐层的并集界，在任意用户指定的$α$下，接受层的预测集以至少$1 - Kα$的概率覆盖正确答案；在选择性保留条件下（与我们边际覆盖结果一致，但并非严格蕴含），该界限收紧为$1 - α$。我们进一步将期望级联成本刻画为$α$和校准集接受率的显式函数。在涵盖科学、医学、常识和标准化考试的18个多项选择基准上，使用来自四个开放权重模型系列的两层级联进行评估，CC在大多数家族-基准对上严格优于最强的校准调优启发式级联，在多数投票不可靠的推理密集型基准上提升最大；在较容易的基准上，级联将绝大多数查询交给小模型且不损失准确性。扩展到开放式生成需要答案聚类步骤，我们将其留作未来工作。该方法无需模型训练，仅需黑盒API访问。

## Abstract
Large language model (LLM) cascades reduce inference cost by routing easy queries to a small model and deferring hard queries to a larger one. Production cascades govern this deferral through a confidence threshold, but LLM confidence scores are miscalibrated, the threshold must be tuned per model pair and per domain, and no setting yields a formal bound on cascade accuracy. We introduce \textbf{Conformal Cascade} (CC), a multi-tier inference framework that uses conformal prediction set size as the deferral rule: accept when the calibrated set collapses to a single answer, defer otherwise. The procedure delivers a distribution-free, finite-sample accuracy guarantee. By a per-tier union bound, the prediction set at the accepting tier covers the correct answer with probability at least $1 - Kα$ for any user-specified $α$; under a selection-preservation condition (consistent with, but not strictly implied by, our marginal coverage results), the bound tightens to $1 - α$. We further characterise expected cascade cost as an explicit function of $α$ and the calibration-set acceptance rate. Across 18 multiple-choice benchmarks spanning science, medicine, commonsense, and standardized exams, evaluated on two-tier cascades drawn from four open-weight model families, CC strictly improves over the strongest calibration-tuned heuristic cascade on the majority of family--benchmark pairs, with the largest gains on reasoning-heavy benchmarks where majority vote is unreliable; on easier benchmarks the cascade commits the vast majority of queries to the small model at no accuracy cost. Extension to open-ended generation requires an answer-clustering step that we leave for future work. The method requires no model training and only black-box API access.

# 论文总结：Conformal Cascade: Distribution-Free Accuracy Guarantees for Multi-Tier LLM Inference

## 1. 核心问题与整体含义

- **背景动机**：LLM 级联（cascade）是生产环境中常用的降本手段——简单查询由小模型处理，困难查询再路由到大模型。传统级联依赖一个置信度阈值（如 softmax、自洽一致性、学习路由器分数）来决定是否推迟（defer）。
- **关键痛点**：
  - LLM 置信度分数校准不佳，尤其在推理密集任务上过度自信；
  - 阈值需针对每个模型对和每个领域重新调参；
  - 没有任何阈值设置能提供形式化的级联准确性保证（错误率是不可控的随机变量）。
- **核心问题**：用户无法回答“如果我承诺最多 5% 的错误答案，θ 应该设为多少？”这一部署中的关键问题。
- **论文回应**：提出 **Conformal Cascade (CC)**，用共形预测集大小替代置信度阈值作为推迟规则，为多层级 LLM 推理提供免分布、有限样本的准确性保证。

## 2. 方法论

- **核心思想**：在每一层上，用分裂共形预测（split conformal prediction）将保留的标注集转换为满足该层覆盖率保证的阈值。预测集大小作为信号：**当集合坍缩为单一答案时接受，否则推迟到更高层**。推迟本身不会造成错误，只有接受事件才可能提交错误答案，因此逐层保证可以组合成级联级别保证。
- **非一致性分数**：采用黑盒 API 友好的**频率分数**：
  $$s_k(x,a)=1-\frac{\#\{i:\hat{y}^{(k)}_i=a\}}{N}$$
  每个查询从模型 mₖ 采样 N 个自一致性样本，分数越低表示答案越“符合”。该分数可证明保持可交换性（Lemma 5），从而适用于裂分共形框架。
- **逐层校准**：每层 k 在独立校准集上计算真实答案分数，取阈值：
  $$\hat{q}_k = \text{Quantile}(\{s_i\}; \lceil (1-\alpha)(n+1)\rceil)$$
  预测集为所有分数不超过阈值的答案集合。
- **级联算法（Algorithm 1）**：
  1. 对每层 k：采样 N 个响应，计算每个答案的频率分数；
  2. 构建共形预测集 Cₖ(x)；
  3. 若集合大小在 1 到 κ 之间（默认 κ=1），则接受，返回集合内分数最低（最频繁）的答案；否则推迟；
  4. 最后一层回退（fallback）。
- **理论保证**：
  - **Theorem 2（级联覆盖率）**：在每层水平 α 下，接受时出错概率 ≤ Kα，即设置每层 α/K 可保证总错误 ≤ α。证明通过对不相交的首批提交事件做并集界完成。
  - **Assumption 3（选择保留）**：若每层在“本层为首个提交层”的条件事件上仍保持覆盖率 ≥ 1−α，则界限收紧为 1−α。
  - **Theorem 4（成本-覆盖率，两层）**：
    $$E[\text{Cost}(X)] = c_1 + c_2 \cdot \Pr[|C_1(X)| \ne 1]$$
    成本仅依赖校准集非接受率；α→0 时成本趋近 c₁+c₂，α→1 时成本趋近 c₁。
  - 部署建议：目标错误率 β 下，最坏情况取 α=β/K，选择性保留下可取 α=β（Remark 12，附校准扫描验证）。
- **技术特点**：无需训练、无需 logprob 访问、仅需黑盒 API，超参数仅 α 和 κ。

## 6. 主要结论与发现

- **准确性提升**：CC 在 72 个族-基准对中的 49 个上严格优于最强启发式级联，6 个平局（0.05 pp 内），17 个略差；最大增益集中在推理密集任务，如 Ministral/MathQA (+4.6 pp)、Phi/GPQA-Diamond (+4.3 pp)、Phi/MedMCQA (+3.6 pp)、Gemma/TruthfulQA (+3.3 pp)。
- **覆盖率保证**：经验误覆盖率几乎全部满足严格 α 目标（少数在 α 与 Kα 之间），从未违反 Kα 并集界；边际结果更接近 α 而非 Kα，说明最坏情况并集界在实践中不紧。
- **成本-精度权衡**：在 MMLU 上 CC 在多数成本区间严格支配启发式方法；放松 κ 可以在保底保证前提下获得更便宜的运行点。
- **自动路由**：容易的基准（如 Belebele-Eng）第 1 层接受率可达 95% 以上，而困难基准（如 MMLU-Pro、GPQA-Diamond）自动全部推迟，无需逐基准调参。
- **失败模式**：当小模型（Phi-3.5-mini）在部分基准上分布过于分散导致预测集永不坍缩时，级联 100% 推迟，且回退规则不如 Always-Strong 的无约束多数投票，导致负增益（如 Phi/AGI-Eval -4.5 pp）。
- **部署建议**：当校准接受率低于盈亏平衡点 1/r（r=c₂/c₁）时，直接用 Always-Strong 更划算。

## 7. 优点

- **方法优雅且实用**：用共形预测集大小代替置信度阈值，将误差预算 α 直接映射为阈值，理论保证清晰——免分布、有限样本、无需分布假设。
- **即插即用**：仅需黑盒 API、复用自一致性采样，不要求训练或 logprob 访问，超参数可解释（α 即用户错误预算）。
- **理论贡献扎实**：给出级联级覆盖率的并集界、选择性保留条件下的收紧界，以及成本-覆盖率闭式关系；并提供了分数可交换性的严格引理。
- **实验覆盖面广**：4 模型族 × 18 基准，推理、医学、常识、事实性等多样任务，对比了多种启发式延迟规则，并做了难度分层和成本敏感性分析。
- **诚实的失败分析**：明确诊断了 Phi 的失败机制，并给出实际部署中的贴地防空护栏建议。

## 8. 不足与局限

- **理论上的保守性**：最坏情况并集界带 K 因子；选择性保留条件未被严格验证（论文仅提供“间接一致”的边际证据），缺乏逐层条件误覆盖率数据。
- **适用场景受限**：要求有限可提取答案集（多项选择或短答案），对开放式生成需要额外的答案聚类步骤，作者留作未来工作。
- **交换性假设的风险**：在协变量漂移（covariate shift）部署下需要在线重新校准；生产级服务中的 KV-cache 共享或固定随机种子可能破坏跨查询独立性。
- **实验局限**：仅测试 K=2；未与学习型路由器（如 RouteLLM）直接对比（仅讨论）；未报告置信区间/bootstrap，小样本差异（如 GPQA-Diamond 上 |Δ| < 0.5 pp）仅被视为点估计。
- **报告方式的偏差风险**：主结果使用测试集 oracle 调参（Best Heuristic vs CC Best），可能不能反映真实部署时无标签调参的表现；CC 网格（15 配置）比启发式网格（12 配置）略大，虽然设置类似但不完全对称。
- **边际保证的局限**：保证是边际的，不提供子群体（subgroup）级别的保证，基础模型歧视可能被传递；高利害部署需要子群体条件校准与安全工具配合。
- **回退规则的次优性**：最后层非单元素集合时采用集合内 argmin 而非未约束多数投票，在部分全推迟场景导致明显性能下降（如 Phi/AGI-Eval）。
