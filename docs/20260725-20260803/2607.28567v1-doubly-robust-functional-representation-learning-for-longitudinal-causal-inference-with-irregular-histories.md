## 摘要
纵向因果研究常将历史记录为不规则的函数片段：实验室值、生理信号、传感器流以及在不相等且有信息的时间点上测量的图像衍生摘要。标准的双重稳健估计量通常需要标量摘要，而序列学习器优化的是预测损失，并不需要稳定高效影响函数。我们提出双重稳健功能表示学习（DR-FRL），一种交叉拟合工作流，将不规则历史转化为针对观测历史机制的目标定向状态。功能和时序编码器将点云和先前的历史映射为状态；干扰头估计结局、治疗和删失函数；基于EIF的验证、校准、重叠、尾部和消融诊断评估该状态是否支持估计方程。如果选定的状态保留了EIF所需的干扰信息，表示误差与普通干扰误差一样进入相同的二阶乘积余项，且均值估计量在显式的速率、重叠、校准和稳定性条件下是渐近线性的。Catoni聚合被单独视为有界影响点估计量，而非Wald推断的替代。模拟表明，当功能混杂高维、测量有信息、支持弱或伪结局重尾时，该方法有收益。一项VitalDB审计显示，DR-FRL可利用不规则的实验室点云并提供有用的阴性发现：对于该ICU处置结局，标量实验室摘要已携带大量结局相关信息。

## Abstract
Longitudinal causal studies often record histories as irregular functional fragments: laboratory values, physiologic signals, sensor streams, and image-derived summaries measured at unequal and informative times. Standard doubly robust estimators usually require scalar summaries, whereas sequence learners optimize prediction losses that need not stabilize the efficient influence function. We propose Doubly Robust Functional Representation Learning (DR-FRL), a cross-fitted workflow that turns irregular histories into estimand-targeted states for observed-history regimes. Functional and temporal encoders map point clouds and prior histories into states; nuisance heads estimate outcome, treatment, and censoring functions; and EIF-targeted validation, calibration, overlap, tail, and ablation diagnostics assess whether the state supports the estimating equation. If the selected state preserves the nuisance information needed by the EIF, representation error enters the same second-order product remainder as ordinary nuisance error, and the mean estimator is asymptotically linear under explicit rate, overlap, calibration, and stability conditions. Catoni aggregation is treated separately as a bounded-influence point estimator, not a replacement for Wald inference. Simulations show gains when functional confounding is high-dimensional, measurement is informative, support is weak, or pseudo-outcomes are heavy-tailed. A VitalDB audit shows that DR-FRL can use irregular laboratory point clouds and deliver a useful negative finding: for this ICU-disposition endpoint, scalar laboratory summaries already carry much endpoint-relevant information.

### 一、论文的核心问题与整体含义

**研究动机：** 纵向因果研究（如围手术期、ICU护理）中，患者历史常记录为**不规则的函数型数据**——实验室值、生理信号、传感器流等在不同时间点、以不同频率观测。传统双重稳健（doubly robust）估计量通常需要**标量摘要**（如基线表格），会丢失大量时序与函数型结构；而序列学习模型（如RNN、Transformer）虽能处理序列数据，但其优化目标是**预测损失**，不保证能稳定高效影响函数（EIF），也不天然服务于因果推断。

**核心问题：** 如何在保留不规则函数历史信息的同时，保持双重稳健因果推断所需的估计方程结构？具体而言：
- 如何将不规则点云（point cloud）历史转化为支持因果估计的状态表示？
- 如何确保表示学习引入的误差不破坏估计的渐近性质？
- 如何在实证中判定函数型特征是否真正带来因果调整增益？

**论文提出的解决方案——DR-FRL：** 一个交叉拟合工作流，将不规则历史映射为**面向估计目标（estimand-targeted）的状态**，通过EIF驱动验证、校准、重叠诊断来保证估计方程质量，将表示误差统一进二阶乘积余项理论框架。

### 二、方法论

#### 1. 核心思想
- **表示学习的因果目标**：表示的好坏不以重构精度或预测性能为判据，而以其能否**保留EIF所需的nuisance信息**为准。
- **估计目标**：观测历史（observed-history）下动态治疗策略的价值函数 \(\theta(g) = E(Y^g)\)，不追求潜在完整函数轨迹（后者需要额外测量模型假设）。

#### 2. 总体流程（Algorithm 1）
```
观测历史（点云、标量、时间信息）
→ 函数编码器 + 时序编码器 → 学习状态 St
→ nuisance 头（结局回归、治疗概率、删失概率）
→ EIF 验证/校准/可选 targeting → 交叉拟合伪结果递归
→ 均值估计 + 诊断输出（Catoni、重叠、尾部等）
```

#### 3. 关键组件

- **函数编码器**：将不规则点云映射为visit级嵌入，置换不变（Deep Sets、Set Transformer），也可用样条/小波摘要或神经CDE处理不规则时序。
- **时序编码器**：将完整历史（标量协变量、嵌入、治疗、随访、时间特征）映射为状态 \(S_t\)。
- **Nuisance头**：估计 \(Q_t\)（结局回归）、\(\pi_t\)（治疗概率）、\(\rho_t\)（删失概率），并进行温度缩放/Platt/保序回归校准。
- **因果充分表示（Definition 1）**：若真实nuisance函数可表示为状态 \(S_t\) 的某个函数，则称表示为因果充分。近似误差定义为：
  \[
  b_{Q,t}(\phi) = \inf_{q \in \mathcal{Q}_t} \| Q^g_t(H_t) - q(e_\phi(H_t)) \|_{L^2(P_0)}
  \]
  （对治疗/删失机制同理）

- **EIF-targeted验证目标**（公式9）：
  \[
  L(\phi, \eta) = \sum_t \{ L_{Q,t} + \lambda_A L_{A,t} + \lambda_R L_{R,t} \} + \lambda_{EIF}\{P_{n,val}\hat\phi^g\}^2 + \lambda_{var}P_{n,val}\{\hat\phi^g\}^2 + \lambda_{cal}L_{cal}
  \]
  在训练折叠内拟合、验证折叠内评估，惩罚EIF不平衡、伪结果方差和校准误差。

- **可选定向波动（Targeted fluctuation）**：在内部训练折叠中按时间反向执行，与TMLE逻辑一致（加权偏移回归、logistic或最小二乘波动）。

- **重叠与稳健聚合**：
  - 裁剪仅作为有限样本稳定化手段，切换裁剪阈值视为敏感性分析；亦可预设重叠加权目标 \(\theta_\omega(g)\)。
  - Catoni聚合（有界影响）用于重尾伪结果的点估计，但**不提供Wald推断**；Wald推断仅对均值聚合成立。

#### 4. 理论结果（Theorems 1–6）

| 定理 | 内容 |
|---|---|
| Theorem 1 | 观测历史目标的识别与EIF（公式6）：\(\phi^*_g = \sum_t H^g_t(Q^g_{t+1}-Q^g_t) + Q^g_0 - \theta(g)\) |
| Theorem 2 | 递归式多重稳健性：逐时间点向后归纳，当 \(\Delta_{t+1}=0\) 时，结局或机制任一nuisance正确即可保证一致性 |
| Theorem 3 | 表示误差进入**同阶乘积余项**：\(|R_{2,n}+R_{rep,n}| \le C \sum_t \{r_{Q,t}+b_{Q,t}\}\{r_{\Gamma,t}+b_{\Gamma,t}\}\)——表示误差非天然无害，须受乘积速率控制 |
| Theorem 4 | 均值聚合下渐近线性 + Wald推断成立 |
| Theorem 5 | 裁剪渐近可忽略（严格正性下）；重叠目标需单独定义其EIF |
| Theorem 6 | Catoni / 中位数聚合只给出集中界，不提供正态性、方差一致性或bootstrap有效性 |

- Proposition 1：有限库选择保证所选候选在验证EIF准则上具竞争性，但不保证表示误差小。
- Corollary 1：为基函数编码器（FPCA/样条）提供充分速率条件（特征值衰减 + 分数估计误差 \(O(K^{-s} + \epsilon_{n,K})\)）。

### 六、主要结论与发现

1. **方法论层面**：DR-FRL成功将函数型编码器嵌入顺序双重稳健估计方程中，表示误差通过显式乘积余项受控，均值聚合下渐近线性并支持Wald推断。
2. **模拟层面**（三个核心结论）：
   - 函数型状态在高维函数型混淆、信息性测量（Scenario G、F）中增益最明显；
   - Catoni聚合在重尾伪结果和弱支持下显著改善点精度（DR-FRL-Catoni平均RMSE 0.208 vs DR-FRL-Mean 0.248，平均绝对偏差0.147 vs 0.190）；
   - 重叠诊断至关重要——弱支持下全总体、裁剪和重叠目标在实践中必须明确区分。
3. **VitalDB实证（有价值的阴性发现）**：调整后血管升压药–ICU入住风险差约1.0个百分点（0.010），标量+实验室摘要（0.0115）与函数型RBF（0.0103）几乎一致——说明对该端点而言，标量实验室摘要已携带足够信息。但DR-FRL提供了将不规则点云纳入正交调整的诊断通路。
4. **方法定位**：DR-FRL首先是一套**诊断审计工具**，其次才是估计器——解决“何时函数型特征真正重要”的问题。

### 七、优点

1. **理论框架清晰统一**：将表示误差、nuisance误差、裁剪误差在同一个二阶展开中分离，明确表示误差“非天然无害”，必须满足乘积速率条件。
2. **估计算法符合现代半参数潮流**：交叉拟合、EIF-targeted验证、向后递归，与DML/TMLE框架一致。
3. **诚实定位Catoni聚合**：明确区分有界影响点估计与Wald推断，不作过度声称。
4. **对目标设定极为谨慎**：严格区分观测历史目标与潜在完整函数目标，不混淆识别前提。
5. **诊断体系完整**：校准、重叠、有效样本量、伪结果尾部、裁剪敏感性、组件审计——输出的不仅是点估计，而是一整套因果调整证据包。
6. **模拟设计有针对性**：六大压力场景对应不同失效模式（高维混杂、信息性测量、弱支持、重尾），而非简单排名竞赛。
7. **VitalDB审计体现了方法的辩证使用**：主动报告阴性发现，展示方法“能证明什么不需要复杂表示”的价值。

### 八、不足与局限

1. **理论条件的实践可达性存疑**：表示充分性的乘积速率假设（Assumption 8）是高层次条件，神经网络编码器下尚无原始速率定理——Corollary 1仅对FPCA/样条类基编码器给出了充分路径。EIF-targeted验证（Proposition 1）本身并不能保证表示误差小。
2. **Catoni聚合的推断真空**：Theorem 6只给集中界，无渐近正态性、方差一致性或bootstrap有效性，实际应用时只能作为点估计敏感性分析。
3. **VitalDB分析范围窄**：是点处理（point-treatment）AIPW而非完整纵向动态策略；ICU入住为实用资源利用端点（无法区分计划/非计划）；未验证的波形级药物时间历史使得完整MAP/血管升压药目标试验无法执行；观察性设计无法排除手术复杂度、麻醉医师决策、计划术后监测等未测量混杂。
4. **模拟存在局限**：未压力测试删失机制；序列基线为CPU近似实现（非原始架构完整复现）；模拟MCsE约0.018（150次复制下的覆盖精度有限）；存在系统性负偏差（作者归因于正则化、弱支持与裁剪），虽与压力设计一致，但提示有限样本行为与理论仍有差距。
5. **计算可扩展性未实证**：虽然给出了复杂度表达式，但未报告实际训练耗时或大规模GPU实验数据。
6. **适用边界**：观测历史目标不能消除潜在函数特征未观测/不可恢复带来的未测量混杂；重叠目标与全总体目标回答不同科学问题，选择需预先定义而非事后裁剪。
