## 摘要
结构因果模型是推理干预和反事实的标准语言，但它们描述的是静态变量，通常只测量一次，并且通常禁止循环依赖。我们关心的许多系统，如患者、气候和经济，反而在时间上连续演化，在不规则的时间点被观测，并且包含反馈回路。我们认为，神经算子学习为这种情境下的因果推理提供了自然基础，并提出了Orca，这是一个框架，其中因果图的每个节点都是时间的函数，每个机制都是函数空间之间的学习映射。我们扩展了现有的神经算子架构来表达因果机制：机制通过将多个父函数作为输入来从父节点计算节点的函数值，尊重时间箭头，并将潜在的外生噪声视为可以被推断和重用于反事实的函数。我们形式化了模型类别，并在合成的连续时间示例上展示了反事实推理。代码可在 https://github.com/gerritgr/orca 获取。

## Abstract
Structural causal models are the standard language for reasoning about interventions and counterfactuals, but they describe static variables, typically measured once, and usually forbid cyclic dependencies. Many systems we care about, such as patients, climates, and economies, instead evolve continuously in time, are observed at irregular time points, and contain feedback loops. We argue that neural operator learning provides a natural foundation for causal reasoning in this setting, and propose Orca, a framework in which each node of the causal graph is a function of time and each mechanism is a learned map between function spaces. We extend existing neural operator architectures to express causal mechanisms: a mechanism computes the function value of a node from its parent nodes by taking several parent functions as input, respects the arrow of time, and treats latent exogenous noise as a function that can be inferred and reused for counterfactuals. We formalize the model class and demonstrate counterfactual reasoning on synthetic continuous-time examples. Code is available at https://github.com/gerritgr/orca

## 2. 方法论

### 核心思想
- 每个节点 \(v\) 对应一个实值函数 \(x_v(t): [0,T] \to \mathbb{R}\)，代表该变量随时间的变化轨迹。
- 因果图允许循环（包含隐式自环），节点的值由其父节点历史的过去值决定，满足**时间优先级原则**（原因必须先于结果）。
- 机制 \(F_v\) 是一个前向算子，根据父节点历史 \(H_v(t)\) 和当前噪声 \(N_v(t)\) 计算节点在时刻 \(t\) 的值：\(x_v(t) = F_v(H_v(t), N_v(t), t)\)，其中 \(H_v(t) = \{(u, t', x_u(t')) \mid u \in pa(v), t' < t\}\)。

### 关键技术细节
- **加性噪声特例**：\(x_v(t) = F_v(H_v(t), t) + N_v(t)\)，此时噪声可从数据中作为残差直接恢复。
- **模拟机制**：在固定时间网格上先采样噪声函数，再前向扫描逐点计算节点值；由于只依赖严格过去的值，即使图中有环，展开后仍是 DAG，因此模拟良定义。
- **DeepSet 架构**：学习机制时使用共享嵌入网络 \(\phi_{\theta_1}\) 和输出网络 \(\rho_{\theta_2}\)：
  \[
  \hat{x}_{i,v}(t) = \rho_{\theta_2}\left(t, \sum_{(i,u,t',x)\in S_v^i(t)} w_{t'} \phi_{\theta_1}(u, t', x)\right)
  \]
  其中 \(S_v^i(t)\) 是同一受试者父节点在 \(t\) 之前的观测集合，\(w_{t'}\) 为基于测量间距的积分权重，使模型分辨率一致。
- **训练目标**：按受试者归一化的均方误差，使得密集和稀疏采样个体贡献均衡。
- **干预与反事实**：
  - 干预：\(do(x_v(t)=e, t\in[t_1,t_2])\)，替换节点机制，其他机制不变，推动噪声分布前向模拟。
  - 剂量反应曲线：\(e \mapsto \mathbb{E}[x_{v^*}(t^*) \mid do(x_v=e)]\)。
  - 反事实：需先推断（abduct）受试者的潜在噪声；加性噪声下直接用残差；非加性噪声下通过秩匹配 + 最优传输将观测个体与采样噪声轨迹耦合。

## 6. 主要结论与发现

- Orca 使用神经算子作为连续时间因果模型的机制类，是自然且有效的：具有分辨率一致性、能处理不规则采样、可强制满足因果图和时间优先级约束。
- 在合成数据上，Orca 能恢复干预剂量反应曲线和个体反事实轨迹，而忽略因果结构或时间结构的基线方法会产生明显偏差。
- 固定核变体最可解释、在机制形式已知时最准确；universal 变体不需要机制先验，也能追踪 ground truth。
- 加性噪声假设下，机制的确定性部分可通过回归学习，噪声可作为残差恢复；非加性场景下，秩匹配 + 最优传输的耦合方法能有效推断潜在噪声轨迹。
