ABSTRACT 

Chain-of-thought (CoT) prompting elicits step-by-step rationales that appear to explain model predictions, but there is no guarantee these steps causally drive the final answer. In standard autoregressive generation, dense attention allows each reasoning step to attend to the full context, enabling the model to derive answers through direct lookup while generating plausible-sounding but post-hoc justifications. We introduce CausalCoT , an inference framework that enforces causal transparency by decomposing problems into a directed acyclic graph of atomic sub-questions, evaluating each node in an isolated context containing only its direct causal parents. This Markovian structure removes attention pathways to non-parent content, making downstream predictions sensitive to local reasoning rather than global context leakage. Across a diverse suite of reasoning benchmarks, 

CausalCoT preserves competitive predictive performance while improving expla-nation faithfulness, increasing causal sensitivity of intermediate reasoning steps by an average of 12 and up to 21 percentage points over the strongest baseline. The structured dependency graph additionally enables test-time interventions in which local corrections propagate predictably through downstream reasoning. 

1 INTRODUCTION 

Large Language Models (LLMs) are increasingly deployed in high-stakes domains like healthcare, where user trust is crucial (Chen et al., 2024). Here, non-experts frequently rely on LLM-generated rationales, treating them as transparent windows into the model’s decision-making (Barez et al., 2025). However, this trust is often misplaced. While techniques like Reinforcement Learning from Human Feedback (RLHF) (Ouyang et al., 2022), Group Relative Policy Optimization (GRPO) (DeepSeek-AI et al., 2025), and Chain of Thought (CoT) (Wei et al., 2023) produce highly plausible text, they optimize for human preference rather than mechanistic transparency. Consequently, these explanations are frequently unfaithful to the model’s internal logic (Mayne et al., 2026; Matton et al., 2025; Turpin et al., 2023; Lanham et al., 2023). Alarmingly, even researchers sometimes misuse these persuasive post-hoc rationalizations with true explanations (Barez et al., 2025). This fundamental disconnect is a critical barrier to safe deployment. Because of this leakage, generated reasoning may appear perfectly logical while remaining entirely disconnected from the final prediction. For instance, Turpin et al. (2023) demonstrate that when provided with subtle context biases or unstated hints, models will heavily exploit these heuristics to derive an answer, yet completely omit them from their generated explanations, fabricating a step-by-step rationale that was never utilized. Furthermore, Lanham et al. (2023) reveal that actively modifying, degrading, or intervening on early CoT steps often yields surprisingly little impact on the downstream output. Together, these phenomena prove that standard autoregressive reasoning frequently acts as a superfi-cial justification, rather than a sequence of causally relevant steps that drive the model’s behavior. Although recent frameworks have attempted to resolve this opacity via alignment training (Paul et al., 2024) or question decomposition (Radhakrishnan et al., 2023), they still evaluate steps within shared contexts, inevitably suffering from continued attention leakage. To bridge the gap between plausible generation and faithful reasoning, we introduce Causal Chain-of-Thought (CausalCoT) 1. CausalCoT enforces a strict transparent inference structure to prevent attention leakage, ensuring that a model’s stated reasoning correctly dictates its final prediction. Our approach operates in two phases: (i) the model decomposes a complex query into a topological plan, a Directed Acyclic Graph (DAG) of interdependent sub-questions; (ii) each node is evaluated in isolation, constrained entirely to its specific query and the explicitly routed answer of its direct parents (or the initial input, for root nodes). By enforcing this Markovian property, we construct a network of question-answer pairs where each step is causally driven only by its local dependencies. This architectural constraint removes the spurious contextual leakage of standard autoregressive generation during the evaluation phase. Furthermore, it natively supports counterfactual simulatability, allowing users to intervene on internal reasoning nodes and propagate those logical changes downstream. 2 BACKGROUND 

Chain-of-Thought and LLM Explanations. LLMs are fundamentally optimized to model and generate human-like text. Because human explanations are typically structured to be clear, helpful, and persuasive, LLMs naturally exploit these stylistic traits, especially when fine-tuned via RLHF, where helpfulness and clarity are explicit reward signals. To enhance complex reasoning capabilities at inference time, prompting strategies such as CoT (Wei et al., 2023; Yao et al., 2023; Besta et al., 2024) and related evolutions encourage the model to output a step-by-step rationale before producing a final answer. Recent training paradigms, such as GRPO (DeepSeek-AI et al., 2025), even bake this step-by-step generation directly into the model’s policy. While these mechanisms produce highly plausible rationales that are easily trusted by non-expert users, they optimize for coherent text generation rather than enforcing strict dependencies between intermediate reasoning steps. 

The Illusion of Faithfulness. Generated reasoning traces frequently fail to reflect a model’s true decision mechanisms (Matton et al., 2025; McMillan et al., 2025; Lanham et al., 2023). This unfaithfulness typically manifests either as counterfactual inconsistency (Turpin et al., 2023; Matton et al., 2025; Mayne et al., 2026), where context perturbations change the model behavior in ways that contradict its stated rules, or as post-hoc rationalization (Lanham et al., 2023; Bogdan et al., 2025), where intermediate steps act merely as superficial justifications lacking causal influence over predictions. Here, we focus on mitigating post-hoc rationalization by enforcing a transparent inference process where each step is causally determined solely by its predecessors or the input. To quantify post-hoc rationalization, we evaluate causal reliance via intermediate step perturbations 

(Lanham et al., 2023): modifying, truncating, or corrupting reasoning steps during inference; if modifying a step leaves the final prediction unchanged, the trace lacks causal efficacy and is unfaithful. See Appendix B for details on faithfulness metrics. 

3 METHOD : C AUSAL CHAIN -OF -T HOUGHT (C AUSAL COT) 

3.1 RATIONALE : T HE ROOTS OF UNFAITHFUL REASONING 

We hypothesize that the unfaithfulness observed in standard LLM reasoning stems from two funda-mental mechanisms inherent to their architecture and training: 

1. Information Leakage via Attention (Lanham et al., 2023; Radhakrishnan et al., 2023): In standard autoregressive generation, the Transformer’s attention mechanism allows every generated token to attend to all preceding tokens. Crucially, this leakage is transitive: because a previous token’s latent representation has already absorbed information from earlier tokens across previous layers, attending to it implicitly carries forward the entire historical context. Consequently, each reasoning step is influenced by the entire context window, both directly and indirectly. Even when tokens are logically unrelated to a specific intermediate deduction, non-zero attention scores permit spurious information to seep through. This explains why intervening on a generated reasoning step often fails to alter the final prediction: the model bypasses the explicit stated logical chain and retrieves the necessary signal directly from the original input (as illustrated in Figure 2).

Modern alignment techniques, such as RLHF (Ouyang et al., 2022), optimize models to fulfill specific criteria (e.g., helpfulness, safety, lack of bias) at the token-sequence level. Consequently, the model learns a policy that maximizes re-ward by generating highly plausible, human-appealing text, rather than a faithful represen-tation of its internal mechanistic process. For example, if the reward model penalizes biased language, the LLM will generate a rationale that explicitly avoids citing sensitive attributes, even if those attributes covertly drove the underlying prediction. Because this deceptive misalignment is fundamentally baked into the model’s learned policy, simply prompting for transparency is in-sufficient; the model will continuously manip-ulate the autoregressive token stream to con-struct a convincing narrative that diverges from its actual internal computation. Overcoming this requires a rigorous structural intervention that binds the stated plan to the final answer, guaran-teeing that if a logical sequence is executed, the resulting prediction aligns with the generated rationale. 3.2 THE CAUSAL COT F RAMEWORK 

To address these fundamental flaws, we introduce Causal Chain-of-Thought (CausalCoT) . Our framework explicitly decouples the generation of a logical plan from its execution, structuring inference to suppress attention-based leakage and enforce strict dependencies. As illustrated in Figure 2, CausalCoT shifts away from the leakage-prone, continuous attention of standard autoregressive reasoning by dividing the inference process into two distinct isolated phases: Graph Generation and 

Context-Isolated Question Evaluation . Further implementation details are provided in Appendix G. 

Formal Problem Setup. Let X ∈ X denote the input prompt (e.g., a complex reasoning question) and Y ∈ Y denote the target final answer. We assume access to a pre-trained LLM, denoted as a policy πθ. In standard autoregressive CoT prompting, the model generates a sequence of intermediate reasoning tokens R = ( r1, r 2, . . . , r m) prior to predicting the final answer, such that 

Y ∼ πθ (· | X, R ). Because the generation of each intermediate token rt is heavily conditioned on the entire preceding context—i.e., rt ∼ πθ (· | X, r <t ). This dense attention mechanism creates severe causal opacity. It makes it impossible to guarantee whether a given token rt is logically derived from relevant predecessors, or spuriously extracted from X or unrelated segments of R<t . Our objective is to replace the opaque autoregressive reasoning trace R with an externally auditable directed graph structure, where each intermediate generation is conditioned only on explicitly routed inputs. This does not claim to expose the model’s internal computation; rather, it constrains the deployed inference procedure so that downstream generations cannot directly attend to non-parent reasoning content. 

Phase 1: Graph Generation. Rather than allowing the model to autoregressively stream a continuous CoT, we first prompt the LLM to act exclusively as a planner. Given an input prompt X, the model decomposes the problem into a set of discrete, atomic sub-questions and constructs a DAG, denoted as G = ( V, E). Here, each node vi ∈ V represents a specific sub-question, and each directed edge 

(vi, v j ) ∈ E indicates that the derived answer ai for question vi is necessary to solve vj . By explicitly mapping these dependencies a priori, we leverage the LLM’s robust zero-shot planning capabilities while strictly preventing it from simultaneously executing the logic. This decoupling reduces one source of entanglement between planning and execution: the structural design of the reasoning path is not contaminated by the model’s bias toward plausible explanations that do not align with the execution. 4Phase 2: Context-Isolated Question Evaluation. Once the graph G is instantiated, we execute the reasoning trace by traversing the graph topologically. Each node is evaluated using the same LLM, but strictly within an isolated context window: • Root Nodes: For any initial node with no parents ( vroot ), the LLM is prompted only with the original input X and the specific sub-question defined by vroot .• Internal and Leaf Nodes: For any descendant node vj , the LLM is prompted with the sub-question vj alongside the answers of its direct parent nodes, denoted as P a (vj ). Crucially, the model does not have access to the overarching global input X, nor to any sibling or parallel reasoning branches. By enforcing this strict topological evaluation, we remove direct attention links from a node to non-parent reasoning content. The generated answer to a specific question vj is determined exclusively by 

P a (vj ). This forced Markovian property guarantees that the final prediction is a faithful product of the intermediate steps. The complete CausalCoT inference procedure is formalized in Algorithm 1. 3.3 INFERENCE PROPERTIES AND HUMAN -IN -THE -L OOP INTERVENTIONS 

The structural transparency of CausalCoT natively unlocks several powerful inference-time properties that are fundamentally intractable under standard autoregressive generation. By decoupling the reasoning plan from its execution, users can actively interact with and steer the model’s logic at multiple stages: • Structural Auditing and Test-Time Interventions: Before reasoning begins, the gener-ated DAG G = ( V, E) is fully exposed for a priori inspection. Experts can rectify flawed logic, value misalignments, or missing steps by adding or removing sub-questions v ∈ V ,modifying context, or redefining edges E. Inspired by concept interventions in interpretable architectures (Koh et al., 2020; Dominici et al., 2024), experts can also perform test-time surgical corrections on incorrect or hallucinated intermediate nodes; due to topological iso-lation, only downstream descendants require recomputation. Unlike standard autoregressive CoT, where dense attention causes localized edits to trigger unpredictable cascades that destabilize reasoning, CausalCoT enables predictable, efficient steering to improve final predictive performance. • Faithful Counterfactual Simulation: The forced Markovian property natively supports counterfactual simulations via explicit causal interventions (conceptually equivalent to Pearl’s do -operator, e.g., do (vi = x)). Users can cleanly intervene on the value produced by a node (or on the information in the input), and dynamically propagate these changes through the graph (keeping it fixed). Since the environment is sealed against non-causal leakage and the ancestors of v are dropped from every downstream context and cannot re-enter the resulting final answer, Y is a faithful reflection of the counterfactual intervention, under the same generated graph. 

4 EXPERIMENTS 

We design our experiments to evaluate the efficacy, faithfulness, and intervenability of CausalCoT compared to standard autoregressive reasoning. Specifically, we aim to answer the following research questions: • RQ1 (Performance): Does enforcing a strict causal graph degrade task accuracy compared to standard CoT? • RQ2 (Faithfulness): Are the intermediate steps genuine drivers of the generation? Specifi-cally, if an intermediate reasoning step is modified, does the model structurally rely on it, and does the final prediction shift in a predictable direction? • RQ3 (Intervenability): Can CausalCoT reliably integrate test-time interventions to correct intermediate reasoning steps? All the remaining information about the experimental settings such as hyperparameters, dataset splits and additional information are defined in Appendix F, while the used prompts in Appendix I. 54.1 EXPERIMENTAL SETUP 

Datasets. We evaluate CausalCoT across performance, faithfulness, and intervenability using diverse benchmarks. We first use GPQA (Rein et al., 2023), a graduate-level science dataset, to ensure our model maintains competitive reasoning capabilities. Next, we incorporate MedQA (Jin et al., 2020) to test multi-step clinical deduction in high-stakes domains. Finally, we leverage the Counterfactual Simulatability Suite (CF Suite) (Mayne et al., 2026) across health, business, and ethics to quantify causal transparency and responsiveness to interventions. Combined, these benchmarks provide a robust foundation for assessing both task accuracy and model interpretability. 

Models and Baselines. We evaluate three families of models (Gemma 3, GPT-5.4, and Claude 4.5/4.6) across varying parameter scales. We compare CausalCoT against standard CoT prompting and Factored Decomposition (Radhakrishnan et al., 2023). Factored Decomposition isolates reasoning by breaking queries into sub-questions and evaluating them in restricted context windows. However, it suffers from two structural flaws: intermediate steps lack explicit parental routing, and the final prediction concatenates all generated text, reintroducing pervasive attention leakage. CausalCoT resolves these vulnerabilities by enforcing a DAG architecture, guaranteeing pure context isolation. Further details on baseline mechanics and comparison with CausalCoT are further explained in Appendix C. 

Evaluation Metrics. We evaluate our three research questions using the following metrics: • Predictive Performance (RQ1): We report standard Accuracy (Acc) to determine if CausalCoT’s strict DAG constraints degrade foundational problem-solving capabilities. We also report Pass@3 (the probability of generating at least one correct answer across three independent inferences). Because CausalCoT strictly enforces the generated topology, a malformed initial graph guarantees predictive failure. We therefore evaluate whether multi-sample generation mitigates zero-shot planning bottlenecks by providing multiple opportunities to produce a valid response. • Faithfulness and Predictability (RQ2): To quantify the causal influence of intermediate reasoning, we adapt established step-perturbation methodologies (Lanham et al., 2023). By injecting targeted errors using a frontier model (GPT-5.4) into intermediate nodes, we measure the frequency of downstream answer changes. To distinguish genuine causal adherence from arbitrary perturbation instability, we introduce a Predictable Change metric. This metric relies on an LLM judge that determines the logical downstream implication of each injected error, accounting for instances where a perturbation is insufficient to alter the final label. We then evaluate whether the model’s corrupted conclusion matches this counterfactual target, confirming that downstream predictions predictably adhere to the modified premise. • Test-Time Intervenability (RQ3): To evaluate the practical utility of our framework’s "human-in-the-loop" capabilities, we simulate expert interventions using a frontier proxy model (GPT-5.4) tasked with identifying and correcting erroneous reasoning steps. Both CausalCoT and Factored Decomposition support multi-level interventions, allowing the proxy to explicitly correct either an initial sub-question (planning) or a generated intermedi-ate answer (execution). However, CausalCoT’s strict DAG topology provides the routing necessary to propagate these surgical edits to downstream dependent steps. On the other hand, CoT supports only the correction of intermediate steps. By measuring downstream predictive improvements across an intervention budget of k ∈ { 1, 2, 3}, we quantify how efficiently these edits correct the model’s reasoning.

CausalCoT achieves high multi-sample success rates (Pass@3) by overcoming initial graph formulation errors through repeated structural attempts (Table 1). However, resampling mitigates this zero-shot planning bottleneck. By taking multiple attempts, the model explores structurally distinct graphs. Once it generates the correct graph, CausalCoT executes the logic to reach the correct answer. Standard CoT obtains smaller Pass@3 gains on several settings, consistent with it generating highly correlated variations of the same text stream. Beyond mere sensitivity, CausalCoT more often causes downstream predictions to shift in the direction predicted by the injected premise (Table 2). While a high answer-change rate proves a model is sensitive to intermediate perturbations, it fails to distinguish between genuine logical adherence and arbitrary instability, a model might simply output random noise when its context is confused. To bridge this gap, our Predictability Change metric (Pred. Change in Table 2) evaluates whether the model’s altered prediction aligns with the specific conclusion dictated by the injected error. As shown, CausalCoT consistently drives high predictability scores, particularly excelling on frontier models where standard CoT most severely ignores corrupted logic. 6 RELATED WORK 

Decomposition and Advanced Exploration Prompting. Breaking complex queries into atomic sub-tasks (Zhou et al., 2023; Wang et al., 2023) is a proven strategy for improving predictive accuracy. However, because these sub-tasks are evaluated within a shared, expanding context window, they suffer from dense attention leakage, leaving the reasoning causally opaque. While Factored Decomposition (Radhakrishnan et al., 2023) attempts to isolate reasoning to solve this, it remains structurally vulnerable: its dynamic updating of pending sub-questions exposes remaining steps to the global context of all prior answers, and its final prediction stage concatenates all generated text. CausalCoT resolves this by utilizing a DAG to enforce Markovian conditional independence ,restricting a node’s context strictly to its explicitly routed parents. A parallel line of research focuses on advanced exploration of the solution space; frameworks like Tree of Thoughts (Yao et al., 2023) and Graph of Thoughts (Besta et al., 2024; Pandey et al., 2025) utilize topological representations not to decompose questions for causal isolation, but to search through different solution paths to find the most accurate outcome. While these search algorithms also lack structural masking and suffer from information bleed, they are complementary to our framework. In future work, their branching and backtracking could refine CausalCoT’s topology prior to isolated execution. 

Faithfulness in Reasoning. Despite advancements in LLM reasoning, recent studies reveal a systemic “unfaithfulness” where models fail to causally rely on their own generated explanations (Xiong et al., 2025; Lanham et al., 2023), a tendency that paradoxically increases as tasks become simpler (Emmons et al., 2025). Mitigation strategies include training-phase interventions via contrastive learning (Paul et al., 2024) or neuro-symbolic frameworks that offload execution to deterministic solvers (Lyu et al., 2023), though the latter are restricted to formalizable domains. Other inference-time methods use factored decomposition to reduce hallucinations (Dhuliawala et al., 2024; Sovrano and Bacchelli, 2026) but lack safeguards against attention leakage, which contributes to causal unfaithfulness. Our framework ensures faithfulness while maintaining linguistic flexibility by enforcing strict causal routing between isolated evaluation contexts (see Appendix D for further connections to formal causality in LLMs). 

7 CONCLUSION 

Limitations and Future Work. CausalCoTs zero-shot nature introduces specific trade-offs, despite its robust faithful framework. First, a malformed initial DAG bottlenecks downstream accuracy. This 9gap systematically narrows in frontier models equipped with stronger zero-shot planning capabilities and are the primary targets for faithfulness interventions. Second, prompt-based DAG generation lacks guarantees; Appendix E outlines ideas for future work to embed graph structural constraints into the planner model via fine-tuning. Third, while CausalCoT promotes causal faithfulness, it does not inherently guarantee counterfactual robustness against input perturbations, though its modularity allows integration with existing regularizers. CausalCoT should not be interpreted as a guarantee of mechanistic faithfulness of the LLM’s internal computation: our claims only concern context-isolated controllability and intervention-based faithfulness. Finally, isolating evaluation contexts introduces additional overhead in inference compared to standard CoT. Yet, unlike strictly sequential baselines, CausalCoT’s DAG topology naturally supports the parallel execution of independent nodes. Appendix H details computational overhead on MedQA. While we follow prior work by evaluating on discriminative tasks, extending CausalCoT to open-ended generation is structurally feasible; the primary hurdle lies in formulating faithfulness metrics independent of discrete answer flips (Appendix J). Broader impacts are discussed in Appendix K. 

Conclusions. In this work, we demonstrate that frontier models can be structurally constrained at test-time to produce faithful explanations without sacrificing predictive performance. Our findings show that CausalCoT maintains competitive accuracy against baselines like standard CoT and Factored Decomposition, while achieving significantly higher faithfulness scores across a diverse suite of model families and reasoning tasks. Furthermore, CausalCoT introduces a highly responsive “human-in-the-loop” property: by allowing domain experts to surgically intervene directly on reasoning nodes or the underlying DAG topology, users can drive deterministic, cascading improvements in final output quality. Ultimately, CausalCoT successfully bridges the gap between reasoning performance and interpretability, providing a rigorous path toward more steerable and trustworthy interactions with LLMs, attributes that are fundamentally essential for safe deployment in high-stakes domains.

B ALTERNATIVE APPROACHES TO EVALUATING FAITHFULNESS 

To systematically quantify explanation unfaithfulness, researchers evaluate models across various levels of abstraction. A significant portion of the literature focuses on counterfactual faithfulness ,utilizing robust datasets to evaluate whether an explanation accurately reflects how the model’s behavior shifts when key variables in the prompt are altered (Mayne et al., 2026; Matton et al., 2025). However, to directly diagnose post-hoc rationalization and evaluate the causality of the reasoning trace itself , evaluations typically rely on two targeted intervention strategies. First, input perturbation 

(Chen et al., 2025; Turpin et al., 2023) measures causality by injecting subtle biases or hints into the prompt. If the model alters its final prediction due to the bias but completely omits it from the generated rationale, fabricating an alternative, logical path instead, the explanation is exposed as causally disconnected from the true decision mechanism. Second, intermediate step perturbations 

(Lanham et al., 2023) measure causal reliance by directly modifying, truncating, or adding noise to the generated reasoning steps during inference. If modifying a logical step fails to alter the final prediction, it reveals that the reasoning trace lacks causal efficacy and is merely a post-hoc fabrication disconnected from the model’s true decision-making process. 

C CAUSAL COT AND FACTORED DECOMPOSITION COMPARISON 

While Radhakrishnan et al. (2023) demonstrate that isolating reasoning steps can significantly improve explanation faithfulness, their proposed Factored Decomposition operates primarily as a heuristic prompting strategy with notable structural limitations. CausalCoT formalizes and generalizes this isolation principle by introducing a strict, graph topology. Below, we detail the algorithmic distinctions and how CausalCoT resolves the critical vulnerabilities present in simple factored decomposition. 

The Vacuum Problem vs. Structured Dependencies. In Factored Decomposition, a model generates an initial list of sub-questions that are evaluated in isolated context windows. While the model can dynamically update the remaining pending questions as early answers are resolved, this sequential heuristic fails to formally define the structural dependencies between the variables. Because the relationships remain implicit and ad-hoc, sub-questions are often evaluated either in a complete contextual vacuum or through an ambiguous, linear updating process that lacks rigorous causal 15 mapping. Conversely, CausalCoT explicitly maps these relationships prior to evaluation via a DAG. Rather than relying on unstructured sequential updates or evaluating nodes in a vacuum, CausalCoT actively routes the generated answers of specific parent nodes directly into the prompts of their designated children. This architectural guarantee provides the exact contextual dependencies required for complex, multi-step logic without exposing the node to the overarching global history. 

Recomposition Leakage vs. Complete Isolation. The most significant limitation of Factored Decomposition occurs at its final inference step (the “recomposition” stage). To generate the final answer, the method concatenates the original input prompt, the entire list of sub-questions, and all corresponding sub-answers into a single context window. As noted by the authors, this dense concatenation inherently reintroduces attention leakage; the model can bypass the isolated reasoning and revert to exploiting spurious correlations from the original input or early sub-questions. CausalCoT entirely eliminates recomposition leakage by enforcing a strict Markovian property across the entire graph, including the final predictive node. In our framework, a node vj evaluates conditionally only on its direct causal parents P a (vj ). The final prediction node does not receive the original input or the overarching graph history unless they are explicitly defined as direct topological parents. This guarantees that the final prediction is forced to rely on the intermediate reasoning steps, structurally enforcing absolute causal transparency from input to output. 

D FORMAL CAUSALITY IN LLM S

A prominent line of work in causal NLP focuses on mechanistic interpretability, utilizing techniques like causal tracing (Meng et al., 2022) and causal abstraction (Geiger et al., 2021) to map high-level causal models onto low-level, dense neural representations. We emphasize that our framework does not claim this form of mechanistic causality; rather, our objective is purely procedural, ensuring that intermediate explanations strictly drive subsequent reasoning steps and the final answer. Beyond internal neural interventions, recent frameworks have begun applying causal metrics directly to LLM outputs to evaluate reasoning. For instance, recent work (Yu et al., 2025) attempts to post-hoc identify which specific generation steps are causally important to the final prediction. Similarly, Fu et al. (2025) try to transform generated CoTs into proper Structural Causal Models (SCMs) in order to being able to perform causal analysis, and on the contrary Jin et al. (2024) directly generate SCMs instead of CoTs. While these methods provide valuable tools for post-hoc causal evaluation and repair, handling formal SCMs often requires rigidly structured reasoning steps, limiting their applicability in free-form generation. CausalCoT is fundamentally different in both goal and execution. Rather than applying causal metrics to evaluate or fix an already-generated sequence, CausalCoT physically restricts the inference architecture itself to proactively guarantee procedural faithfulness by construction. We therefore make no uniqueness claim for the generated causally dependent reasoning steps. Crucially, because our topological routing isolates context without forcing the generated text into strict mathematical variables, CausalCoT fully preserves the LLM’s natural flexibility. This allows it to natively support rich, open-ended question answering where strictly formalized causal models typically fall short. 

Relation to the “stochastic parrot” critique. Zeˇ cevi´ c et al. (2023) conjecture that LLMs answer causal queries by reciting correlated causal facts encountered in training rather than by performing causal inference, and that they are therefore “causal parrots”. We take no position on this conjecture, because our claims do not depend on how it is resolved. The critique concerns where causal knowledge comes from ; our guarantee concerns whether the stated reasoning produced the answer . As stated in Footnote 1 and in the Introduction, “causal” here denotes procedural dependence within the inference process, not possession of causal knowledge about the world. In fact, the critique strengthens the motivation for this work: the more a fluent reasoning trace is a recitation or a post-hoc rationalisation, the more it matters that the plan displayed to the user is the plan that was actually executed. 

Three limits we state explicitly. First, the DAG that CausalCoT generates encodes evidential rather than causal semantics: an edge records that one sub-answer is used to derive another, which is a deliberate trade against SCM-style formalisations (Jin et al., 2024; Fu et al., 2025) in exchange for applicability to free-form natural language. Second, context isolation constrains what a node may condition on; it does not constrain the parametric knowledge the model brings to that node, so an isolated node can still answer from memorised associations. Third, we do not measure how well a generated decomposition covers a true causal structure of the task, because the benchmarks we 16 use carry no graph annotations; establishing such coverage would require datasets with ground-truth reasoning structure and is left to future work. A related open question is whether question decomposition is expressive enough to capture causal dependence in language in general, as opposed to procedural dependence within a single inference. 

E OPTIMIZING GRAPH GENERATION VIA REINFORCEMENT LEARNING 

While CausalCoT demonstrates strong zero-shot performance, its reliance on a prompt-based graph generator presents a natural avenue for future optimization. Specifically, the graph planning phase could be significantly enhanced by fine-tuning the generator model using reinforcement learning paradigms, such as GRPO. Our multi-sample Pass@3 experiments empirically confirm the feasibility of this approach: because resampling frequently yields a graph that successfully reaches the correct final prediction, there exists a clear, exploitable positive reward signal based entirely on downstream task accuracy. In the simplest scenario, a GRPO-like loss function could be designed to directly reward generated graph structures that yield the correct final answer. Beyond pure accuracy, this reward formulation could be naturally extended to include multi-objective structural constraints. For example, auxiliary reward penalties could be introduced to enforce strict Directed Acyclic Graph (DAG) properties (though our zero-shot models have not empirically violated this constraint yet) or to promote sparsity, thereby minimizing computational overhead. Furthermore, dynamic constraints could explicitly penalize excessive graph depth or node counts. Despite the massive potential for performance gains, we leave the exploration of fine-tuned graph generation to future work. The primary theoretical contribution of this paper is to establish a rigorous, training-free inference framework that explicitly isolates and measures causal reasoning. By strictly avoiding weight updates, CausalCoT remains fundamentally model-agnostic, ensuring seamless compatibility across both local open-weights models and closed-source commercial API endpoints. 

F EXPERIMENTAL DETAILS 

Datasets We evaluate all methods using 200 sampled instances from three benchmarks: GPQA, MedQA, and Counterfactuals. To account for generation variability, we perform three independent resamples for every instance. For locally hosted models, this entire evaluation pipeline is initialized using a single fixed random seed (1234) to ensure strict reproducibility. Faithfulness metrics are com-puted uniformly across all generated resamples to maintain a consistent evaluation size. Additionally, intervention experiments are conducted across all instances and their resamples, utilizing a maximum of three structural interventions per generation. Finally, we compute the standard error of the mean across the three independent resamples; this approach deliberately captures generation variability, our primary property of interest, rather than dataset variability. The sole exception is the Pass@3 metric; because it inherently aggregates the three resamples into a single instance-level score, its standard error is necessarily computed across the dataset. 

Model Selection Rationale To rigorously evaluate CausalCoT as a generalized test-time framework, we selected a diverse suite of large language models varying across both architectural paradigm and parameter scale. This variety ensures our findings regarding causal faithfulness and predictive accuracy generalize across distinct levels of model capability. To capture a comprehensive perfor-mance spectrum, we included proprietary frontier models, specifically the GPT (OpenAI) and Claude (Anthropic) families, to represent the current ceiling of commercial LLM reasoning, alongside the open-weights Gemma (Google) family to guarantee transparency and reproducibility. By evaluating multiple size variants within each of these families, we systematically observe how CausalCoT scales from lightweight, efficient models up to advanced reasoning engines. Finally, this selection was naturally bounded by practical technical and economic constraints: the maximum scale of the open-weights models was strictly dictated by the 48 GB VRAM capacity of our local inference hardware, while the proprietary models were strategically sampled to maximize experimental rigor within API budget limitations. 

Generation Hyperparameters To ensure optimal reasoning performance across our diverse suite of LLMs, we tailored our sampling hyperparameters according to the deployment type and model-17 specific guidelines. For all proprietary models accessed via API (i.e., the GPT and Claude families), we utilized a standard generation temperature of 0.7. Conversely, for the locally hosted Gemma models, we strictly adhered to the authors’ officially recommended sampling configurations to maximize generation quality, setting the temperature to 1.0, top_k to 64, top_p to 0.95, and 

min_p to 0.0. 

Code, licenses and hardware All experimental baselines and proposed methods were implemented in Python 3.12.3. Our codebase relies on foundational open-source libraries, including PyTorch 2.10 (Paszke et al., 2019) (BSD License), Hugging Face Transformers (Wolf et al., 2020) (Apache 2.0), and the LM Evaluation Harness (Gao et al., 2023) (MIT License). Local model generation and evaluation were conducted using GPUs with a maximum capacity of 48 GB VRAM, amounting to approximately five days of total GPU compute time. For proprietary API-based models, local hardware usage was restricted to minimal CPU overhead, with execution times dependent entirely on provider-enforced concurrent request limits. To ensure full reproducibility, we will publicly release our complete codebase and evaluation scripts under an MIT license. 

G IMPLEMENTATION DETAILS 

Context Propagation Effective causal dependence within the framework described in Section 3.2 relies on strict context isolation; specifically, the evaluation context for internal and leaf nodes must be restricted to the outputs of their immediate predecessors. However, because these outputs often consist of extensive natural language explanations, propagating raw text down the graph can lead to computational overhead and context window exhaustion. To address this scalability challenge, we instruct the model to generate a concise summary of its conclusion, prefixed with the identifier “FINDING” (see Table 16). This summary, paired with the respective node’s question, constitutes the localized context passed to all child nodes. 

Missing Context Fallback To reduce error rates and graph malformations, we implement a dynamic fallback mechanism for nodes with insufficient context. If an internal node (i.e., neither a root nor a final answer node) indicates a lack of necessary information, identified via keyword parsing of its response, the system dissolves its parental dependencies and reclassifies it as a root node, thereby providing it with the complete initial question. This fallback is particularly effective at mitigating cascading errors in smaller, less performant models.

H.5 DIRECT VALIDATION OF CONTEXT LEAKAGE : T HE COUNTERFACTUAL SWAP 

EXPERIMENT 

The perturbation experiments of RQ2 establish that a standard CoT prediction is largely insensitive to its own intermediate text, but insensitivity alone is compatible with several explanations. To test the specific hypothesis that the final prediction is derived from the input around the displayed reasoning, we manipulate access to that input directly while holding the reasoning fixed. 

Setup. The Counterfactual Simulatability Suite (Mayne et al., 2026) is built from pairs of minimally differing sibling inputs, which makes it the natural testbed. For each pair (xa, x b) we first collect the model’s own CoT answers (ya, y b) under standard generation. We then construct a conflict condition: the model is shown the input xb together with the frozen reasoning trace that it generated for xa, and is asked to regenerate only the final answer yswap . The two outcomes are diagnostic. If the prediction is derived from the reasoning presented to it, then yswap = ya (trace-follow). If instead yswap = yb,the model must have obtained the distinguishing information from the input, since the reasoning it was shown is unchanged and points to ya (input-follow). We run this on every Counterfactuals pair used in the main evaluation. 

Results. Table 8 reports the input-follow rate. It rises monotonically with capability across the GPT family and reaches nearly half of all conflict cases for the strongest model, while the weakest model follows the provided trace in every case. The direction of this trend is the uncomfortable one: the models whose stated reasoning users are most likely to trust are the models least likely to have used it. This is consistent with the scale trends reported by Emmons et al. (2025) and with our own forced-error results in Appendix H.10, where unfaithful overrides also concentrate in the more capable models. 

Scope. This evidence is behavioural, not mechanistic. We do not observe attention weights, which are unavailable for the API models used in most of our experiments, and we do not claim to identify how the bypass is implemented internally. The claim the experiment supports is the one the paper makes: unrestricted context access allows the displayed reasoning to be bypassed, and context isolation binds the prediction to the routed reasoning. Under CausalCoT the analogous swap cannot be constructed , because the final node never receives the original input, and hence it is impossible to bypass the generated reasoning trace, obtaining by design a perfect score. Lastly, we encourage further work investigating the attention weights of CoT to understand more concretely the reasoning bypass. H.6 ABLATING CONTEXT ISOLATION : T HE CAUSAL COT-N OTRIM CONTROL 

CausalCoT differs from standard CoT along two axes at once: it decomposes the problem into a DAG, and it restricts each node’s context to its parents. Factored Decomposition does not separate these, since it differs from CausalCoT in routing structure as well as in what it concatenates at the end. To attribute the measured gains, we therefore hold the plan fixed and vary only context access. 

Setup. Using the identical stored DAGs from the main experiments, we re-execute inference under three conditions: CausalCoT , in which a node sees only its parents’ answers; CausalCoT-NoTrim ,in which every node additionally receives the full original input; and CausalCoT-NoTrim-Full , in which every node receives the full original input together with the answers of all previously evaluated ancestor nodes. Since the graph is identical across conditions, any difference is attributable to context access alone. We run this on GPT-5.4 Mini, GPT-5.4 Nano and Gemma 4B across MedQA and GPQA. 

Faithfulness. Table 9 shows that removing isolation collapses faithfulness. On GPT-5.4 Mini, average Answer Change falls from 58 .72 under isolation to 37 .07 (NoTrim) and 37 .50 (NoTrim-Full), i.e. below the 40 .95 obtained by standard CoT, with Predictable Change following the same trajectory (66 .53 → 49 .87 /46 .63 , against 52 .70 for CoT). GPT-5.4 Nano and Gemma 4B show the same collapse. Two conclusions follow. First, DAG decomposition alone is insufficient: context isolation is the main driver of the faithfulness gains reported in Section 5. Second, the leakage pathway is not limited to the original input. NoTrim-Full additionally exposes procedurally unrelated prior reasoning, and is at least as damaging as NoTrim; with the full input and all prior findings present at every node, an edited node is more redundant, and therefore more bypassable, than an edited step inside CoT’s single sequential stream. This is precisely the situation of standard CoT, where every later step may attend to the entire preceding trace including steps irrelevant to its intended local dependency. 

Accuracy. Table 10 completes the picture and clarifies the trade-off of Section 5. For the weaker models, whose generated graphs are the least reliable, reintroducing context recovers part of the accu-racy gap towards CoT (GPT-5.4 Nano: 59 .25 → 63 .75 average), which supports the interpretation that global-context access is what allows CoT to compensate for a flawed plan. For GPT-5.4 Mini, whose graphs are already strong enough that CausalCoT is within two points of CoT, reintroducing context reduces accuracy while destroying faithfulness. For frontier models, then, isolation delivers its faithfulness benefits at close to no accuracy cost. H.7 RUN -TO -R UN VARIABILITY : P LAN SAMPLING VERSUS EXECUTION

H.8 RELIABILITY OF THE AUTOMATIC EVALUATION PIPELINE 

Our faithfulness and intervenability protocols delegate three operations to a frontier model: editing an intermediate reasoning step (RQ2), predicting the expected label implied by that edit for the Predictable Change metric (RQ2), and correcting an identified reasoning error (RQ3). Since these are automatic proxies for what a human annotator or domain expert would do, their reliability bounds the conclusions that can be drawn from the metrics, and we audit them explicitly. 

Protocol. We audit each of the three operations on 90 records, balanced across datasets and methods. Two authors independently annotated the 60 MedQA and GPQA step-editing and expected-label items. Two cross-family LLM reviewers (GPT-5.6 Sol and Fable 5, chosen to be from different families than the evaluator itself) rated all records. For step edits, an edit counts as valid if it is minimal, coherent, and plausibly capable of changing the answer. 

Results. Edit validity was rated at 81 .7% and 76 .7% by the two authors, 74 .4% by Sol and 73 .3% 

by Fable; inter-annotator agreement between the two authors was 81 .7% , and each LLM reviewer 25 matched the human consensus in 83 .7% of cases. Expected-label validity was between 91 .7% and 

100% for all four raters. For the corrector, Sol rated 92 .2% and Fable 100% of corrections valid, and a manual review of 60 corrector outputs found no case of direct answer leakage. 

Failure modes and their direction. The invalid edits are informative. They are predominantly semantically equivalent to the original step, or they reinforce the original answer, or they map to no available answer option; in all three cases the edit cannot flip an answer even for a perfectly faithful model. The consequence is that Answer Change is deflated rather than inflated. Crucially, edit validity is similar across methods for every rater (within 2 to 3 items out of 30), so the deflation applies roughly equally to CoT, Factored Decomposition and CausalCoT: absolute sensitivity is underestimated for all methods, while the between-method differences that the paper’s claims rest on are preserved. The Predictable Change metric already accounts for part of this, since an unchanged answer following an insufficient edit can be scored as a correct outcome when the judge predicts that the label should not change. Finally, we note that the evaluator never scores outcomes directly, and that model-based step perturbation follows the established protocol of Lanham et al. (2023). J BEYOND QUESTION ANSWERING 

Our evaluation is confined to multiple-choice question answering. This choice is driven by mea-surement rather than by the method: the faithfulness protocol we adopt from Lanham et al. (2023) rests on observing whether a discrete answer changes under an intervention, and Predictable Change additionally requires that the intended post-intervention outcome be statable as a label. Neither graph generation nor context-isolated execution assumes a discrete answer space, and we sketch here how the mechanism transfers, so that the scope of the empirical claim is not mistaken for the scope of the framework. 

A worked example. Consider generating a clinical management plan from a patient record, an open-ended task with no answer options. The planning phase decomposes it as it would any other query: nodes such as extract current medications , identify active comorbidities , derive contraindications for the candidate therapy , determine dose adjustment given renal function , and a terminal node that composes the recommendation. Execution is unchanged: each node is answered only from the answers routed into it, and the terminal node composes the plan from those routed findings rather than from the record. The properties the paper claims carry over directly. The plan displayed to the clinician is the plan that produced the recommendation. A clinician who disagrees with the derived contraindication edits that one node, and exactly its descendants are recomputed, so the correction reaches the final recommendation instead of being absorbed by a second reading of the record, which is the RQ3 operation applied to a non-QA output. The same holds for the sections of the output: because the terminal composition is routed, it is possible to say which findings a given sentence of the plan was built from. 

K BROADER SOCIETAL IMPACTS 

Our work focuses on improving faithfulness and interpretability of LLM. From a positive perspective, frameworks like CausalCoT directly contribute to AI safety and alignment. By enforcing strict reasoning topologies and enabling reliable human-in-the-loop corrections, our method fosters greater trust and accountability in AI systems, which is particularly critical for high-stakes domains eval-uated in this paper, such as medical reasoning (MedQA). Conversely, there are potential negative implications to consider. The explicit context isolation required by CausalCoT introduces greater computational overhead compared to standard autoregressive generation, which could incrementally contribute to the environmental footprint of inference at scale. Additionally, the explicit separation of 28 planning and execution in CausalCoT introduces a novel alignment consideration. As models become highly proficient at topological planning, there is a risk of deceptive graph generation. A sufficiently advanced model could theoretically exploit the initial planning phase to hypothesize how the user or an automated judge will evaluate the subsequent steps. Consequently, it could construct a graph intentionally designed to manipulate the evaluation process or fool the user, rather than faithfully pursuing an objective solution. 29 Table 13: Prompts used in CausalCoT to generate the question graph. Guidelines 

- Before designing sub-questions, carefully read the answer choices. Each sub-question should gather information or perform reasoning with causal power for choosing between the given answer choices. - Every node must be answerable from the information available to that node: root nodes from their own ‘context‘, dependent nodes from their parent answers/FINDINGS alone. - If you need different information from the initial context, you should extract it in different independent questions - When a downstream node needs a specific detail, extract or establish that detail explicitly upstream and include that upstream node in ‘depends_on‘. Do not rely on missing prerequisites being recovered implicitly. - Avoid creating multiple sibling nodes that establish the same information. - Prefer nodes whose answer would plausibly change the final answer if the answer to that node changed. Do not spend graph budget on inert metadata, generic background facts, or restatements unless that fact is causally useful for downstream reasoning. - Every non-final node must be necessary: it must either be directly used by the final_answer node or be required by another necessary node. If removing a node would leave the final answer equally answerable, remove or merge that node. - Non-final nodes must not commit to the final prediction. They may extract evidence, identify mechanisms, infer intermediate entities, or derive intermediate properties, but they must not answer the overall multiple-choice question, predict the final YES/NO outcome, or state which final option should be selected. - Root nodes should ask for the causally useful abstraction, not for an unnecessarily exact value. If the context gives only a qualitative fact, ask for and use that qualitative fact rather than asking for an exact value that would produce "not specified", "not provided", or "cannot be determined". - If the answer choices describe specific properties (e.g. mechanism, gram stain, culture characteristics, structure, side effects), make sure your graph includes nodes that derive exactly those properties for the identified entity — do not stop at identifying the entity alone. - Any node can depend on any combination of earlier nodes at any level — use the structure that best captures the reasoning flow, not a rigid layer-by-layer hierarchy - Every node must ask a DISTINCT question that extracts or reasons about different information. Never repeat or paraphrase the same question across multiple nodes — if two nodes ask the same thing, merge them into one. - Every node must be connected to the final_answer, either directly (listed in final_answer.depends_on) or indirectly (depended on by a node that eventually reaches final_answer). Never create a node that is not part of the reasoning chain leading to the final answer. - Never reference answer choice labels (A/B/C/D) inside subquestion nodes — only the final_answer node sees the answer choices. - Do NOT use phrases like "the answer choices", "the given options", "the choices", or "which of the following" in any subquestion node. Subquestion nodes should reason about facts independently when possible. - Do not default to one subquestion node per candidate answer. Use candidate-answer-specific nodes only when they genuinely improve the reasoning and each node tests a distinct substantive hypothesis rather than mechanically enumerating options. If a subquestion needs to refer to a candidate answer, name the answer content explicitly, not option labels like A/B/C/D. - If the question can be answered directly from general knowledge without extracting specific facts from the context, use a minimal 2-node graph: one root node (Q1.1) that directly addresses the core knowledge question, then final_answer. Only add more nodes when different pieces of information genuinely need to be combined (e.g., identifying a value from context and then applying a formula). - When a question involves a sequence of steps where each step transforms the output of the previous one, do NOT create independent parallel nodes that analyze each step’s inputs in isolation. Instead, chain the nodes so that each step receives the result of the prior step as input — properties of an input only matter in the context of what they produce when applied to the current state. - Before finalizing the graph, make sure every dependent node is answerable from its listed parents alone and every required fact is connected through ‘depends_on‘. For multiple-choice questions, also make sure the graph derives the exact property tested by the choices, so the answer can be chosen unambiguously without falling back to a "closest match" or a missing discriminator.
