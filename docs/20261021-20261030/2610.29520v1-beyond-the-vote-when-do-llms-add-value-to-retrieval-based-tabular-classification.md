## 摘要
基于检索的上下文学习（ICL）使大语言模型（LLM）能够根据相似示例预测表格标签，但尚不清楚 LLM 推理是否优于对相同示例进行直接投票。我们通过在 19 个表格分类数据集上比较四种通用 LLM 与使用相同检索邻居的距离加权最近邻投票（Distance-KNN）来回答这一问题。在演示样本数量固定的情况下，扩大检索候选池可提高所有预测器的准确率，但 Distance-KNN 在每个候选池规模下均取得最高平均准确率。更详细的分析表明，LLM 的增益集中在检索邻居标签一致性较低的情形，且因模型而异。这些增益还取决于测试查询到邻居的平均特征空间距离：在标签一致性较低时，部分 LLM 在近邻和中等邻域上优于 Distance-KNN，但在最远邻域组中平均而言均落后。关于演示样本数量、提示构建、检索表示和标签平衡演示选择的补充实验总体上保持了上述发现。这些结果刻画了在基于检索的表格 ICL 中，LLM 推理何时能在距离加权投票之外增加预测价值。

## Abstract
Retrieval-based in-context learning (ICL) enables large language models (LLMs) to predict tabular labels from similar examples, but it remains unclear whether LLM inference improves on direct voting over those same examples. We address this question by comparing four general-purpose LLMs with distance-weighted nearest-neighbor voting (Distance-KNN) using identical retrieved neighbors across 19 tabular classification datasets. With the number of demonstrations fixed, enlarging the retrieval candidate pool improves accuracy for all predictors, yet Distance-KNN achieves the highest mean accuracy at every pool size. More detailed analyses reveal that LLM gains are concentrated where retrieved neighbors exhibit low label consensus and vary across models. These gains further depend on the average feature-space distance to the test query: under low label consensus, some LLMs outperform Distance-KNN in close and intermediate neighborhoods, but all fall behind on average in the most distant group. Complementary experiments on the number of demonstrations, prompt formulation, retrieval representation, and label-balanced demonstration selection largely preserve the overall findings. These results characterize when LLM inference adds predictive value beyond distance-weighted voting in retrieval-based tabular ICL.

## 1. 核心问题与研究动机

- **背景**：基于检索的上下文学习（Retrieval-based ICL）已成为冻结通用大语言模型（LLM）做表格分类的主流范式之一——把与测试查询最相似的若干带标签表格行序列化为演示（demonstrations），让 LLM 直接预测标签，无需任务特定训练。
- **核心疑问**：现有研究报告的 LLM 表格分类性能，究竟来自「检索到了好的演示样本」，还是来自「LLM 对这些演示的推理能力」？由于不同方法往往使用不同的检索结果，这两个贡献被混淆，无法区分。
- **具体研究问题**：在**完全相同的检索邻居**上，LLM 的推理是否优于对这些邻居做传统的距离加权 K 近邻投票（Distance-KNN）？这种相对优势是否随候选池规模、邻居标签一致性（label consensus）和特征邻近度（feature proximity）而变化？
- **整体含义**：论文试图为「LLM 在表格分类中到底何时真正增值」划定边界，避免把检索收益误归因于 LLM 推理能力，并为后续方法设计（何时该用 LLM、何时该用简单投票）提供实证依据。

## 2. 方法论

### 2.1 核心思想：共享邻居对照协议（Shared-Neighbor Protocol）

- 对每个测试查询，用一个**共同的检索器**从候选池中取出 k=8 个最近邻。
- **Distance-KNN**：只使用这 8 个邻居的**标签 + 检索距离**，做逆距离加权投票。
- **LLM**：使用**完全相同的 8 个邻居**（序列化的特征与标签，按由近到远排序）加上查询特征作为提示，**不提供检索距离**，以 temperature=0 贪心解码，从标签 token 的首 token log-probability 中选最高者。
- 通过**固定 k、只改变候选池大小**，控制「演示选择」变量，从而分离出「推理」本身的贡献。

### 2.2 关键技术细节

- **混合特征距离**（公式 1）：数值特征经 Z-score 标准化后取平方欧氏距离，分类特征取不匹配指示函数（0/1），二者相加。
- **候选池构造**：先每类随机抽 1 个样本保证类别覆盖，再按类频率采样；候选池大小 n ∈ {16, 32, 64, 128, 256, 512, full}，均为同一序列的嵌套前缀。
- **Distance-KNN 投票细节**：逆距离加权；若存在距离 ≤10⁻¹² 的「零距离」邻居，则只由这些邻居等权投票；平票时取最近邻居所属类别。
- **标签一致性（Consensus）**：C(x) = (1/k)·max_c Σ 1[y_i = c]，即 8 个邻居中多数类的占比（如 4/8、5/8 … 8/8）。
- **特征邻近度（Proximity）**：d̄_k(x) = (1/k)Σ d(x, x_i)，即查询到 8 个邻居的平均距离；在每个数据集、每个种子内按升序排名并转为百分位（0–20 为最近组，80–100 为最远组），以消除数据集间距离尺度差异。
- **Override 分析**：定义「有益覆盖」（LLM 对、KNN 错）与「有害覆盖」（LLM 错、KNN 对），其差等于两者准确率差（Acc_LLM − Acc_KNN = B − H）。

### 2.3 补充分析设计

- 演示数量 k ∈ {4, 8, 16}；
- 提示形式：键值序列化（KV）、自然语言序列化（NL）、规则增强 NL（借鉴 InsightTab 的 Summarize–Exemplify–Reflect 规则蒸馏，辅以 XGBoost 辅助生成规则）；
- 检索表示：特征空间检索 vs. 文本嵌入检索（Qwen3-Embedding-4B，2560 维，余弦相似度）；
- 标签平衡演示选择：从最近 32 个候选中选 8 个类别尽量均衡的样本，与最近 8 个直接对比。

## 3. 实验设计

- **数据集**：19 个公开表格分类数据集（UCI + OpenML），覆盖二分类与多分类，领域包括医疗（Diabetes、Cardiotocography、Glioma Grading）、教育（Student Dropout）、金融（Credit G、Iranian Churn）、工业（AI4I、Steel Plates Fault）、软件工程（KC1、PC3、PC4）、垃圾邮件（Spambase）、网页钓鱼（Phishing Websites）等；样本量约 768–19,020，特征数 6–57。
- **划分**：8:1:1 分层抽样为训练/验证/测试；训练集即检索候选池；所有预测器共享同一划分。
- **评估指标**：宏平均准确率（先按数据集多种子平均，再跨 19 个数据集宏平均），并报告平均排名（mean rank）、胜场数（wins）。
- **对比方法**：Distance-KNN（参照基线）vs. 四个冻结 LLM——Qwen3-8B、Qwen3-32B、Gemma3-12B、Gemma3-27B。
- **统计检验**：10,000 次配对 bootstrap 的 95% 置信区间 + 精确符号翻转检验（枚举 2¹⁹ 种符号分配），并在每个池规模下对 4 个 LLM 比较做 Holm-Bonferroni 校正。

## 6. 主要结论与发现

1. **扩大候选池对所有预测器都有益，但 Distance-KNN 始终领先**：KNN 从 16 候选的 72.81% 升至全池 85.50%；最强 LLM（Gemma3-27B）从 72.73% 升至 85.26%，但每个池规模下均值均略低于 KNN。
2. **全池统计对比**：KNN 平均排名最低（2.03）、胜场最多（6.5），Gemma3-27B 为 2.24 / 6.0；配对检验显示 KNN 显著优于 4 个 LLM 中的 3 个（Gemma3-12B −1.93pp、Qwen3-8B −3.53pp、Qwen3-32B −1.95pp 均显著；Gemma3-27B −0.24pp 不显著）。
3. **LLM 增益集中在低标签共识**：在 4/8 共识下，4 个 LLM 中有 3 个超过 KNN，Gemma3-27B 增益最大（+3.60pp）；Qwen3-8B 反而落后，说明增益具有模型依赖性。Override 分析显示这些模型的有益覆盖多于有害覆盖。
4. **高共识下 KNN 明显占优**：5/8–7/8 区间所有 LLM 均落后，Qwen3-8B 在 5/8 时落后达 9.91pp；8/8 时 override 稀少、差距趋近于零。
5. **特征邻近度进一步区分低共识下的增益**：≤4/8 共识时，3 个 LLM 在最近 0–20 百分位优于 KNN（Gemma3-27B +8.1%），全部 4 个模型在 40–60 百分位为正；但在最远 80–100 百分位，所有模型均落后（−9.8% 至 −1.6%）。
6. **高共识下邻近度无法挽回劣势**：5/8–7/8 区间 60 个「模型×邻近度」组合中有 58 个 KNN 占优，仅 2 个 Gemma3-27B 组合为正。
7. **补充分析的稳健性**：
   - k=4/8/16 下主结论基本保持（21 个池×k 设置中 KNN 在 19 个领先；仅 k=16 的最小两池 Gemma3-12B 略优）；
   - 提示形式影响因模型而异（Qwen3-8B 受益于 NL/规则增强 NL，64 候选时 +3.53pp），但 KNN 仍全池最高；
   - 特征空间检索显著优于文本嵌入检索（全池约 +16pp，Qwen3-8B 达 +24.20pp），但两种表示下 KNN 均领先；
   - 强制标签平衡反而降低 LLM 准确率（Gemma3-12B −7.49pp、Qwen3-8B −10.58pp，19 个数据集全部下降）。

## 7. 优点

- **控制变量严谨**：共享邻居协议干净地分离了「检索选择」与「LLM 推理」两个贡献，这是该文最核心的方法论价值。
- **分析维度有解释力**：引入标签一致性与特征邻近度两个可解释的邻域结构维度，把「LLM 何时有用」从笼统的平均准确率细化到条件性子群，并用 override 分解（B − H）给出机制性证据。
- **实验规模与统计严谨性兼顾**：19 数据集、多种子、宏平均、配对 bootstrap + 符号翻转检验 + Holm 校正，结论可信度较高。
- **补充分析覆盖面广**：主动排查了演示数量、提示形式、检索表示、标签平衡等可能推翻结论的因素，且如实报告了 KNN 并非在所有子设置都赢（如 k=16 小池）。
- **诚实的负面/条件性结论**：没有夸大 LLM 能力，明确指出「LLM 并非普遍优于距离加权投票」，对领域有纠偏意义。

## 8. 不足与局限

- **模型覆盖有限**：仅 4 个 8B–32B 开源模型，未涉及更大规模模型或闭源商用模型（如 GPT-4 级别），结论对强模型的推广性未知。
- **任务范围窄**：仅表格**分类**，未涉及回归、缺失值严重

的场景、多标签分类、极端类别不平衡等设置，也未覆盖需要特征语义理解或外部知识的复杂表格任务（如特征名本身承载关键信息的场景）。因此结论主要适用于「中小规模、特征已数值化/类别化、标签空间有限」的标准表格分类基准。

- **检索器单一且固定**：全文只使用一种混合特征距离检索器（Z-score 欧氏 + 类别不匹配），未比较学习型检索器、基于度量学习的表示或图结构检索。共享邻居协议虽然干净，但也意味着结论绑定于「该检索器给出的邻居质量」；若换成更强/更弱的检索器，LLM 与 KNN 的相对优势可能改变。

- **候选池构造带有采样假设**：候选池采用「每类先保底 1 个 + 按类频率采样」的嵌套前缀设计，这一构造会影响类别先验与邻居分布。虽然嵌套前缀有利于控制变量，但与真实部署中「候选池天然不均衡、随时间漂移」的情形仍有差距。

- **子群分析属事后划分，统计功效有限**：标签共识（4/8–8/8）与邻近度百分位是**基于结果的事后分组**，每个子群内的样本量和数据集构成不均衡；论文虽报告了 override 率与置信区间，但子群层面的结论（尤其「某模型在某共识档位领先」）仍可能受少数数据集驱动，存在选择性报告风险。此外共识只有 5 个离散档位，邻近度按 20 分位切分，粒度较粗。

- **成本效益完全未量化**：论文的核心论点是「LLM 相对 KNN 的增量价值有限且条件性强」，但没有报告单位查询的推理延迟、token 消耗、显存占用或美元成本。对于实践者而言，「Gemma3-27B 在全池仅比 KNN 低 0.24pp（不显著）」与「KNN 几乎零成本」之间的权衡，恰恰是部署决策的关键，而这一维度缺失使结论的工程指导性打了折扣。

- **评估指标单一**：仅使用宏平均准确率，未考察校准误差（ECE）、对分布偏移的鲁棒性、预测置信度的可靠性，也未分析方法在类别不平衡下的召回/代价敏感表现。LLM 的 log-prob 解码本可提供不确定性信息，但论文未加以利用或评估。

- **标签解码方式的潜在偏差**：从标签 token 的**首 token log-probability** 选最高者，对多 token 标签或首 token 相同的标签（如 "0"/"1" 之外的中文/长标签）可能存在系统性偏差；论文未讨论该解码策略对多分类标签空间的影响，也未与「生成式自由解码 + 解析」做对比。

- **提示与规则增强依赖外部组件**：规则增强提示借助 XGBoost 蒸馏规则，引入了额外模型与超参数（100 棵树、深度 6、学习率 0.3），使「LLM 单独能力」的归因变得不纯；同时提示模板的具体措辞、序列化顺序等细节可能对结果敏感，论文虽测试了 3 种提示形式，但未做提示措辞的消融。

- **确定性与单次解码**：temperature=0 贪心解码只取一次前向结果，未探索自洽性采样（self-consistency）、多次采样投票或思维链，这可能**低估**了 LLM 在低共识、困难样本上的潜力，使「LLM 增益有限」的结论偏保守。

- **数据集规模与领域覆盖的中等性**：19 个数据集样本量 768–19,020、特征 6–57，属于中小规模基准；未涉及高维稀疏表格、超大规模表格或流式/在线场景，外部效度受限。数据集虽跨多领域，但均来自 UCI/OpenML 的「清洗后」版本，真实脏数据的挑战未被覆盖。

- **统计结论的边界**：宏平均先按数据集多种子平均再跨数据集平均，可能掩盖数据集间异质性；符号翻转检验枚举 2¹⁹ 种符号分配，在 19 个数据集上功效有限，且 Holm 校正后部分「不显著」结果可能只是样本量不足，而非真实无差异。

## 9. 总体评价与启示

- **定位**：这是一篇**方法论导向的受控实证研究**，其最大贡献不在于提出新模型，而在于用「共享邻居协议」把长期被混淆的「检索收益」与「LLM 推理收益」拆开，并给出「LLM 何时增值」的条件性地图——**低标签共识 + 高特征邻近度**是 LLM 相对 KNN 的主要增值区间，而**高共识**下距离加权投票几乎不可战胜。

- **对实践的启示**：在标准表格分类中，距离加权 KNN 是极强且近乎零成本的基线，LLM 不应被默认视为「更聪明的替代品」；若要用 LLM，应针对「邻居标签分歧大且查询确实靠近邻居」的样本做**选择性调用**，并优先使用特征空间检索而非文本嵌入检索，避免强制标签平衡。

- **对未来研究的启示**：需要把成本纳入评价框架（准确率–成本帕累托前沿）、探索学习型检索器与更强模型下的结论稳健性、将确定性解码扩展为多次采样、并把「共识 × 邻近度」的条件性发现转化为可部署的路由/级联策略（何时调用 LLM、何时回退 KNN）。

- **一句话总结**：论文以严谨的对照实验证明——**LLM 在表格分类中的价值是条件性的、局部的，而非普遍的；把它当作「更好的 KNN」会在多数情形下失望，但把它当作「低共识困难样本的补充推理器」则有明确且可量化的收益空间。**
