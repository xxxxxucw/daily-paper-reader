## 摘要
基于检索的上下文学习（ICL）使大语言模型（LLM）能够根据相似示例预测表格标签，但尚不清楚 LLM 推理是否优于对相同示例进行直接投票。我们通过在 19 个表格分类数据集上比较四种通用 LLM 与使用相同检索邻居的距离加权最近邻投票（Distance-KNN）来回答这一问题。在演示样本数量固定的情况下，扩大检索候选池可提高所有预测器的准确率，但 Distance-KNN 在每个候选池规模下均取得最高平均准确率。更详细的分析表明，LLM 的增益集中在检索邻居标签一致性较低的情形，且因模型而异。这些增益还取决于测试查询到邻居的平均特征空间距离：在标签一致性较低时，部分 LLM 在近邻和中等邻域上优于 Distance-KNN，但在最远邻域组中平均而言均落后。关于演示样本数量、提示构建、检索表示和标签平衡演示选择的补充实验总体上保持了上述发现。这些结果刻画了在基于检索的表格 ICL 中，LLM 推理何时能在距离加权投票之外增加预测价值。

## Abstract
Retrieval-based in-context learning (ICL) enables large language models (LLMs) to predict tabular labels from similar examples, but it remains unclear whether LLM inference improves on direct voting over those same examples. We address this question by comparing four general-purpose LLMs with distance-weighted nearest-neighbor voting (Distance-KNN) using identical retrieved neighbors across 19 tabular classification datasets. With the number of demonstrations fixed, enlarging the retrieval candidate pool improves accuracy for all predictors, yet Distance-KNN achieves the highest mean accuracy at every pool size. More detailed analyses reveal that LLM gains are concentrated where retrieved neighbors exhibit low label consensus and vary across models. These gains further depend on the average feature-space distance to the test query: under low label consensus, some LLMs outperform Distance-KNN in close and intermediate neighborhoods, but all fall behind on average in the most distant group. Complementary experiments on the number of demonstrations, prompt formulation, retrieval representation, and label-balanced demonstration selection largely preserve the overall findings. These results characterize when LLM inference adds predictive value beyond distance-weighted voting in retrieval-based tabular ICL.
