## 摘要
上下文学习（ICL）使表格基础模型无需针对特定数据集进行训练或微调即可做出预测。这些模型具有很高的预测准确率，但解释各个特征如何贡献于预测仍然困难。例如，在生物学中，特征贡献有助于识别生物标志物或风险基因。事后可解释性方法会给出特征重要性分数，但这些分数并不能表明模型实际使用了哪些特征，且可能导致解释错误。我们提出 TICL$^3$（表格上下文局部线性学习），这是一种设计上可解释的预测器，它利用表格基础模型来引导一个简单的线性预测规则。TICL$^3$ 首先学习一个共享线性模型以捕捉数据集级特征效应。然后，对于每个查询，它使用基础模型的表示检索相似的训练样本，并在该邻域内对残差拟合第二个线性模型。共享模型捕捉广泛效应，而局部模型在相似样本之间校正误差。它们的组合系数决定了每个特征对最终查询特定线性分数的贡献，因此同一模型既做出预测又解释预测。在 386 个分类基准数据集评估中，TICL$^3$ 落后 TabICLv2 1.1 个百分点，并在 266 次评估中优于 CatBoost。其平均 support F1 较 MAPLE 提升 4.7 个点，并在两个真实数据选定特征效用指标上均取得最佳性能。

## Abstract
In-context learning (ICL) lets tabular foundation models make predictions without dataset-specific training or fine-tuning. These models achieve strong predictive accuracy, but interpreting how individual features contribute to the prediction remains difficult. In biology, for example, feature contributions can help identify biomarkers or risk genes. Post-hoc interpretability methods assign feature importance scores, but these scores do not indicate what the model actually uses and can lead to explanation errors. We introduce TICL$^3$ (Tabular In-Context Local Linear Learning), an interpretable-by-design predictor that uses a tabular foundation model to guide a simple linear prediction rule. TICL$^3$ first learns a shared linear model to capture dataset-level feature effects. Then, for each query, it retrieves similar training samples using representations from the foundation model and fits a second linear model to the residuals in that neighborhood. The shared model captures broad effects, while the local model corrects errors among similar samples. Their combined coefficients determine each feature contribution to the final query-specific linear score, so the same model makes and explains the prediction. Across 386 classification benchmark-dataset evaluations, TICL$^3$ trails TabICLv2 by 1.1 percentage points and outperforms CatBoost in 266 evaluations. It improves average support F1 over MAPLE by 4.7 points and achieves the best performance on both real-data selected-feature utility metrics.

## 1. 核心问题与研究动机

- **背景**：表格数据预测中，单条预测的可解释性常与准确率同等重要（如医疗、信用评分、生物标志物识别）。经典可解释模型（稀疏线性模型、GAM、EBM）提供显式特征贡献，但结构约束可能限制精度。
- **现状矛盾**：表格基础模型（TabPFN、TabPFNv2、TabICLv2）通过上下文学习（ICL）实现强预测且无需数据集特定训练，但多层注意力使"哪个特征贡献了预测"难以归因。
- **事后方法的缺陷**：LIME、SHAP、梯度归因、FastSHAP 等事后解释器给出重要性分数，但这些分数**不参与预测**，未必反映模型实际使用的特征，可能产生解释错误。
- **核心问题**：能否构建一个**设计上可解释（interpretable-by-design）**的预测器，让"做预测的模型"与"解释预测的模型"是同一个，同时保持接近强基线的精度？

## 2. 方法论：TICL³

### 2.1 核心思想
用冻结的表格基础模型（TabICLv2）**引导**一个简单线性预测规则：基础模型不直接做最终预测，而是（i）提供拟合目标（类概率）；（ii）用其表示定义每个查询的邻域。最终预测由显式线性系数完成，系数即特征贡献。

### 2.2 关键流程（global + residual 主配置）
- **预处理 ϕ**：分类特征序数编码、缺失值用训练均值填补、标量变换；**不做特征扩展**，每个保留坐标对应唯一原始列，便于贡献回映射。
- **参考库构建**：5 折分层交叉拟合，每折用其余折的标签作上下文生成该类概率 $\tilde y_i$ 与表示 $h_i$，避免标签泄漏；测试查询用全训练集上下文生成 $h_*$。
- **上下文条件邻域**：按余弦相似度取 top-$k$（$k=400$），以温度 $\tau=0.1$ 的 softmax 权重 $w_i^*$ 加权近邻。
- **共享全局模型**：对全体参考行拟合带无惩罚截距的 ElasticNet（$\alpha=0.01,\ \rho=0.25$），得到 $P, p$，捕捉数据集级特征效应。
- **查询特定残差校正**：对查询邻域内的残差 $r_i=\tilde y_i-(P^\top z_i+p)$ 拟合第二个加权 ElasticNet，得到 $D^*, d^*$。
- **最终规则**：$W^*=P+D^*$，$b^*=p+d^*$；类分数 $\hat z^*_{cls}=(W^*)^\top z^*+b^*$，裁剪到 $[0,1]$ 并归一化得概率。
- **特征贡献**：$a_{j,c}(x^*)=(z^*_j-\bar z_j)W^*_{j,c}$，满足精确分解 $\hat z^*_{cls,c}=b^*_c+(W^*_c)^\top\bar z+\sum_j a_{j,c}$；贡献回映射到原始语义列。
- **优化**：加权中心化 + FISTA（回溯线搜索、KKT 检查），最多 300 迭代、容差 $10^{-4}$。

### 2.3 理论分析
- **定理 1（残差近似界）**：在残差于表示空间满足 Lipschitz 光滑（$L_r$）并允许上下文偏移项 $\epsilon_{ctx}$ 的假设下，
$\|\eta^*-\hat\eta^*_{lin}\|_2 \le (L_r\Delta_k+\epsilon_{ctx})\left(1+\frac{\|z^*-z_k\|_2}{\sqrt{\alpha(1-\rho)}}\right)$，
其中 $\Delta_k$ 为邻域表示半径、$z_k$ 为加权特征质心。该界约束的是**线性分数**，不含裁剪归一化；作者明确说明它不证明斜率一定带来改进，只界定正则化斜率可能引入的额外误差。

### 2.4 变体：regional anchors
- 对参考库表示做 k-means，选锚点，预拟合最多 64 个锚模型（直接拟合 backbone 概率而非残差），查询时按相似度混合最近 8 个锚的系数与截距，无需在线拟合。
- 作者因其预测类解释常全零（合成 73.3%、真实 43.8% 查询），将其定位为**计算变体**而非对等的解释方法。

## 6. 主要结论

- **预测精度**：TICL³（global+residual）在四个分类套件上落后 TabICLv2 **0.3–1.6 个百分点**，超过最强树基线 **0.7–1.8 点**；在 386 次评估中 **266 次优于 CatBoost**。回归 nRMSE 0.515，劣于 TabICLv2（0.482），优于 CatBoost（0.537）及其他可解释方法。
- **特征选择**：合成任务平均 support F1 **0.539**，为所评估可解释预测器中最高（E1–E3 最佳；E4 上 MAPLE 更高，0.624 vs 0.548）。
- **真实数据解释**：Gen-SVM（0.886）与 Gen-kmeans（0.697）**均为最高**，Deletion Spearman（0.470）第二；邻域稳定性与 LIME/梯度方法相当。
- **计算效率**：在线约 **27 ms/查询**；含一次性构建的 50 查询总耗时 1.35 s，比最快的 post-hoc 方案（42.44 s）快 **31.5×**。
- **组件作用**：加入局部校正使共享模型精度从 76.13% 升至 89.90%；共享模型的主要收益是**保证每个查询都有非零解释**（local-only 仅 68%）。

## 7. 优点

- **预测与解释同源**：同一组系数既产生类分数又精确分解分数，避免"解释器与预测器脱节"的根本问题。
- **新颖的局部性定义**：用预训练 ICL

表示定义邻域，而非在原始特征空间做局部加权——这使"局部"与 backbone 实际使用的相似性结构对齐，比 MAPLE 等在高维原始空间取近邻更稳健，也为残差校正提供了有意义的低维几何基础。
- **精确可加分解**：贡献 $a_{j,c}$ 满足严格等式分解，且经"不做特征扩展"的预处理设计保证每个系数可回映射到唯一原始列，避免解释中出现无法归属的派生维度。
- **工程与效率兼顾**：加权中心化 + FISTA 的求解使在线拟合仅约 27 ms/查询，比最快的 post-hoc 方案快一个数量级以上，说明"设计上可解释"不必以牺牲部署可行性为代价。
- **诊断诚实**：作者主动报告 regional 变体的解释全零率（合成 73.3%、真实 43.8%），并据此将其降格为"计算变体"，而非包装成对等方法；对定理 1 也明确声明其只约束线性分数、不证明斜率带来改进，避免了过度声称。

## 8. 局限与不足

- **精度仍有可感知差距**：相对 TabICLv2 落后 0.3–1.6 个百分点，回归上差距更明显（0.515 vs 0.482 nRMSE）。论文定位是"接近强基线"，但在精度敏感场景中这一差距可能不可接受。
- **表达能力受限于线性形式**：最终规则是特征空间的线性函数，尽管邻域加权使其具备分段线性/局部非线性的近似能力，但对强交互、强非线性结构（如高阶特征交叉）的拟合仍依赖 backbone 表示与邻域选择间接实现，缺乏显式建模手段。
- **强依赖 backbone 质量**：拟合目标 $\tilde y_i$ 与邻域几何 $h_i$ 均来自冻结的 TabICLv2。若 backbone 在目标数据集上表现差或表示退化，TICL³ 的预测与解释会同步受损；论文仅用单一 backbone，未报告跨 backbone（如 TabPFNv2、TabICL 其他版本）的敏感性分析。
- **理论保证较弱**：定理 1 只给出线性分数相对 backbone 概率的近似误差上界，且需 Lipschitz 与上下文偏移假设；未覆盖裁剪与归一化步骤，也未给出解释保真度（如贡献排序与真实支撑的一致性）的理论刻画。
- **解释评估的覆盖面有限**：真实数据解释基准仅 10 个 CC-18 数据集、500 条查询，且为 capped 低数据 regime；Gen-SVM/Gen-kmeans 在不同配置下使用不同有效查询群体，作者自认不可作匹配比较；Deletion Spearman 仅列第二，稳定性与 LIME/梯度方法相当而非领先，说明解释优势并非全面。
- **合成特征选择的结论有条件**：E4（含 46 个冗余特征）上 MAPLE 的 support F1（0.624）高于 TICL³（0.548），说明在冗余特征多、支撑稀疏的场景下线性 + 邻域加权并非最优。
- **消融的统计严谨性有限**：9 种配置的配对 bootstrap 区间未做多重比较校正，且仅基于单一划分种子，配置间的小幅差异可能不稳健。
- **资源报告不完整**：仅说明使用大学服务器 GPU（L4、A100 80GB），未给出 GPU 数量、总训练/评估时长与能耗，不利于复现成本评估与绿色 AI 比较。
- **公平性上的残余问题**：梯度类解释器依赖可微 surrogate，其保真度未量化；post-hoc 方法被定位为"参考"而非直接竞争者，削弱了"设计上可解释优于事后解释"这一核心主张的直接证据强度。

## 10. 总体评价

TICL³ 针对表格预测中"解释器与预测器脱节"这一实质性问题，提出了一个结构清晰、工程可行、评估较全面的解决方案：以冻结表格基础模型提供目标与邻域几何，用全局 + 残差两级加权 ElasticNet 生成可精确分解的线性预测规则。其核心贡献不在于刷新精度纪录，而在于证明"设计上可解释"可以在仅损失约 0.3–1.6 个百分点精度的前提下，同时获得非零、忠实、低延迟的特征贡献，并在合成特征选择与部分真实数据解释指标上达到所评估可解释预测器中的最优或次优水平。

主要待改进之处在于：线性形式的表达力上限、对单一 backbone 的依赖、理论保证仅覆盖线性分数、解释基准规模与统计校正不足，以及资源报告不完整。总体而言，这是一篇问题意识明确、方法自洽、实验扎实且表述克制的工作，为"可解释性内生于预测器"这一路线提供了有说服力的实证支持，也为后续在更强 backbone、非线性扩展与更严格解释保真度理论方面的研究留下了清晰接口。
