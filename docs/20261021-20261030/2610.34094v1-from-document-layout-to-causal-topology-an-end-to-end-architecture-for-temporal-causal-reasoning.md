## 摘要
大语言模型（LLMs）在时序推理中通常缺乏深层因果推理能力。受文档布局重排序启发，本文提出从离散叙事到因果拓扑的范式转变，并构建了两种架构：一种是免训练的神经符号框架——时序因果推理智能体（TCR-Agent），它通过外部因果图实例化与符号干预引擎实现可解释的因果推演和反事实截断；另一种是端到端模型——时序因果推理模型（TCR-Former），它通过因果拓扑注意力掩码（Causal-Topological Attention Mask）与时间跨度偏置，将这些机制内化到 Transformer 注意力空间中。在 TempoCausal 基准上的实验表明，TCR-Agent 全面超越现有的免训练基线；同时，TCR-Former 的准确率比当前最先进（SOTA）方法高 16.5%，仅以约 8.6B 参数就优于 GPT-5.4 和 DeepSeek-V3.2 等大规模模型。进一步分析揭示了现有方法中的结构-推理脱节现象：外部符号约束与思维链推理可以改进推理步骤，却无法增强深层因果推演能力。通过将时序因果推理能力内化到模型中，TCR-Former 有效弥合了这一差距，为复杂推理场景提供了高效且可靠的端到端基础。

## Abstract
Large language models (LLMs) generally lack deep causal reasoning capabilities in temporal reasoning. Inspired by document layout reordering, this paper proposes a paradigm shift from discrete narratives to causal topologies. It constructs two architectures: a training-free neuro-symbolic framework, temporal causal reasoning agent (TCR-Agent), which achieves interpretable causal deduction and counterfactual truncation through external causal graph instantiation and a symbolic intervention engine; and an end-to-end model, temporal causal reasoning former (TCR-Former), which internalizes these mechanisms into the Transformer attention space via a Causal-Topological Attention Mask and temporal span biases. Experiments on the TempoCausal benchmark demonstrate that TCR-Agent comprehensively surpasses existing training-free baselines. At the same time, TCR-Former achieves an accuracy 16.5% higher than that of state-of-the-art (SOTA) methods, outperforming large-scale models such as GPT-5.4 and DeepSeek-V3.2 with only approximately 8.6B parameters. Further analysis reveals a structure-reasoning disconnection phenomenon in existing methods: external symbolic constraints and chain-of-thought reasoning can improve reasoning steps, yet fail to enhance deep causal deductive capability. By internalizing temporal causal reasoning capabilities into the model, TCR-Former effectively bridges this gap, providing an efficient and reliable end-to-end foundation for complex reasoning scenarios.

## 2. 方法论

### 2.1 总体思路
- 先以**外部因果图 + 符号干预**显式重建并扰动因果拓扑（TCR-Agent），验证"拓扑化"本身的价值；再把这套逻辑**下沉到 Transformer 前向计算**（TCR-Former），用注意力掩码、时间跨度偏置与掩码级干预实现端到端拓扑感知。

### 2.2 TCR-Agent（免训练神经符号框架）
融合结构因果模型（SCM）与潜在结果框架（POF），三阶段流水线：

- **阶段一：因果图提取**
  - 查询感知时空提取器 Eθ 以文本块 C 与提示 P 为输入，调用 LLM 同时产出中间推理草稿 S（记录日期差、数量累计、时间边界判定，抑制长上下文信息衰减与幻觉）与原始图 G_raw=(V_raw,E_raw)。
  - 符号图构造器 B 将 G_raw 实例化为严格 DAG：每个节点保留时间锚点 t_i，并把文本描述与数值字段拼接为统一语义表示（desc_i ⊕ Annotate(d_i)），形成"时间—语义—数值"三维表示；边携带源/目标、关系类型与因果推导依据 reason_ij；通过拓扑排序消解时间戳矛盾并强制无环约束。
  - **事件三分法**：无关事件直接过滤；共现事件只保留状态与时间锚点、不建因果边；因果事件建立有向边并生成 reason 字段。
- **阶段二：反事实干预**
  - 图干预引擎 I 等价于 SCM 的 do-算子：解析反事实语句得到干预参数 ψ=(v_k, action)，action ∈ {remove, cut_edges}。
  - remove：删除节点 v_k 并保留必要邻接边 E_preserve(v_k) 以维持叙事连通；cut_edges：保留节点但删除其全部出边。
  - 扰动图 G′ 经深度优先遍历线性化为拓扑描述串 D(G′)，显式编码时间间隔、语义描述与因果依据。
- **阶段三：双轨推理**
  - 推理器 R 同时接收原始文本 C 与结构化轨迹 D(G′)，用三类串行标签约束自回归生成：**Checking**（自然语言复述 D(G′)、校验时间计算与因果一致性并纠错）→ **Reasoning**（依据 C、P、D(G′) 推理，信息不足返回 Unknown）→ **Reflection**（反思答案与 C、D(G′) 是否一致并修正）。

### 2.3 TCR-Former（端到端架构）
由时序因果编码器（Qwen-3-0.6B 骨干）与推理解码器（Qwen-3-8B）构成。

- **输入序列处理**：文本 token 嵌入 V 与 N=128 个可学习**事件锚点**查询 token Q 拼接为 X=[V;Q]；每个锚点 q_k = E_anchor(k) + E_span(k)，前者为位置无关基向量，后者为可学习**时间跨度偏置**（使不同锚点偏好短期或长程事件）；文本 token 标为 type 0、查询 token 标为 type 1。
- **因果拓扑注意力掩码 M**（逐层动态构造）：
  - 文本 token 之间（i,j ≤ L_c）：全双向可见，保证语义连贯；
  - 查询→文本（i > L_c, j ≤ L_c）：全部可见，实现全文事件信息检索；
  - 查询 token 之间（i,j > L_c 且 j ≤ i）：仅允许"过去查询→当前查询"，即未来查询不能影响过去，形成因果序；
  - 其余位置置 −∞。
- **时间感知位置偏置**：B_time = Proj_Q(Q)·Proj_V(V)ᵀ，仅加到"查询→文本"区域，使查询按时间逻辑调节聚合权重。
- **辅助时间戳预测**：查询 token 隐状态经两层 FC+GELU 回归头输出归一化时间戳，仅训练时以 MSE 监督，把物理时间位置注入隐空间。
- **推理解码器**：非线性投影器 P（两层 FC+GELU）将 Z_causal 对齐为 Z_aligned；采用**事实—逻辑旁路融合**，解码输入 E_input=[V_text; Z_aligned; E_prompt]，对应块对角注意力掩码（文本内标准因果掩码、Z_aligned 全局可见、prompt 自回归）。
- **原生反事实干预**：提示中出现反事实表述时，匹配事件锚点得到索引 k_ψ，对掩码做逐元素修剪 M_ψ = M·I(i≠k_ψ)·I(j≠k_ψ)，切断该查询 token 的全部出入连接，使 Z_causal 隐式反映因果链断裂后的拓扑变化，无需重编码文本或调用外部引擎。
- **三阶段训练**：
  - 阶段一（编码器预训练）：冻结基座，仅更新锚嵌入、时间偏置与回归头；损失 L_phase1 = αL_time + βL_sem + γL_cf（α=1.0, β=0.5, γ=0.2），其中 L_time 为时间戳 MSE、L_sem 为潜变量与文本全局池化表示的余弦重建损失、L_cf 为反事实对比损失（ReLU(m−‖Z_factual−Z_cf‖₂)，配合课程调度：前 30% 步关闭，31%–70% 步 p_cf=ρ_cf=0.1，后 30% 步为 0.2）。
  - 阶段二（跨模态投影对齐）：冻结编码器与解码器，仅训练投影器；采用旁路感知标签掩码，损失只作用于 prompt 之后的目标回答 token。
  - 阶段三（端到端指令微调）：冻结编码器与投影器，对解码器施加 LoRA（r=64, α=128），作用于注意力投影层与前馈线性层。

### 2.4 TempoCausal-Bench 构建
- 基于 TimeQA-Hard 困难样本，经"五维重构"把线性时序 QA 升级为结构化时序因果推理任务：
  - D1 隐式时间窗口与条件过滤；D2 并发多实体状态跟踪；D3 时间滞后与多跳依赖；D4 反事实级联推演；D5 微小扰动的滞后放大（受供应链牛鞭效应启发）。
- 三阶段流水线：LLM 批量生成 → GPT-5.4 与 DeepSeek-V3.2 双裁判校验（初版准确率 77.21%，19.53% 标为 Unknown）→ Unknown 样本二次重构（准确率达 98.2%，余下人工修正）；由 1500 个原始样本重构出 6000 个样本，按 4:1 划分训练/测试，且同一原始样本的所有变体保证落在同一集合以防泄漏。
