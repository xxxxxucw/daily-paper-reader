## 摘要
表格基础模型利用上下文学习来估计特定人群的条件期望结果和平均处理效应。利用这些估计指导科学决策需要可靠的不确定性量化。挑战在于同时考虑两种不确定性来源：有限上下文偏差，以及推理时提供的小规模标注样本所引起的上下文变异。预测离散度并不能直接量化这两种不确定性来源；我们观察到，普通 bootstrap 可能显著高估上下文变异，而子采样可能低估它。我们提出 TabCUQ，一个基于扰动的框架，它向观测结果中注入噪声，并将基础模型应用于受扰动的上下文。TabCUQ 使用 wild bootstrap 离散度估计上下文变异，并利用扰动估计与原始估计之间的最大偏差来考虑有限上下文偏差。对于一个核回归类比模型——其估计误差可精确分解为这两个分量——我们证明该框架提供渐近有效的逐点覆盖。在模拟中，TabCUQ 显著提高了覆盖率，平均区间宽度通常约为一个 oracle 偏差感知基准的两倍。在七个真实世界任务中，它还提高了对从大得多样本中学习到的参考函数的覆盖率。

## Abstract
Tabular foundation models use in-context learning to estimate conditional expected outcomes and average treatment effects for specific groups of individuals. Using these estimates to guide scientific decisions requires reliable uncertainty quantification. The challenge is to account simultaneously for two sources of uncertainty: limited-context bias and context variation arising from the small labeled sample supplied at inference. Predictive spread does not directly quantify both sources of uncertainty, and we observe that the ordinary bootstrap may substantially overestimate context variation, whereas subsampling may underestimate it. We introduce TabCUQ, a perturbation-based framework that injects noise into observed outcomes and applies the foundation model to the perturbed contexts. TabCUQ estimates context variation using wild-bootstrap dispersion and accounts for limited-context bias using the maximum deviation between perturbed and original estimates. For a kernel-regression analogue whose estimation error admits an exact decomposition into these two components, we show that our framework provides asymptotically valid pointwise coverage. In simulations, TabCUQ substantially improves coverage, with average interval widths typically about twice those of an oracle bias-aware benchmark. Across seven real-world tasks, it also improves coverage of reference functions learned from much larger samples.

- **背景**：表格基础模型（TabPFN、TabICL、TabFM 等）通过“上下文学习”工作——模型在大量合成/真实数据上预训练，推理时把用户提供的小规模标注数据集（context）和查询点一起输入，冻结参数直接输出预测，无需在新任务上重新训练。
- **应用动机**：化学（判断平均反应产率是否超过开发阈值）、临床（判断某类患者接受治疗是否缩短平均康复时间）等科学决策，依赖条件均值 μ(x) 与条件平均处理效应 CATE τ(x) 的估计。
- **核心问题**：仅有点估计不足以支撑决策，需要**置信区间**。但为表格基础模型做有效区间面临两类不确定性：
  - **上下文变异（context variation）**：同一总体反复抽取同样大小的标注上下文，估计值会波动；
  - **有限上下文偏差（limited-context bias）**：即便把抽样波动平均掉，估计的期望仍可能系统性偏离真值（类似正则化偏差），TabPFN 在小上下文下常见。
- **关键观察**：
  - 模型的“预测分布离散度”包含结果噪声，不能直接量化上述两类不确定性；
  - 普通 bootstrap 会**高估**上下文变异（方差比约 1.64），子采样会**低估**（约 0.45）；
  - 即使标准误估得准，偏差相对标准误不可忽略时，Wald 区间仍会欠覆盖。
- **真实案例佐证**：

## 二、方法论

- **核心思想**：对观测结果注入噪声（wild bootstrap），把扰动后的上下文反复喂给基础模型；用扰动估计的**离散度**估计上下文变异，用扰动估计相对原始估计的**最大偏离**作为有限上下文偏差的经验“缓冲垫”（bias cushion），二者相加构成区间半宽。
- **关键技术细节（条件均值，算法 1）**：
  1. 用原始上下文 D_n 得到原始估计 μ̂(x)；
  2. **五折交叉拟合**：对每一折，用其余四折作上下文，对该折每个观测做折外预测 μ̂(X_i)，避免过拟合；
  3. 计算折外残差 r_i = Y_i − μ̂(X_i)，并中心化 e_i = r_i − r̄；
  4. 对第 b 次重抽样，独立抽取 Rademacher 乘子 v_{i,b} ∈ {−1, +1}，构造扰动结果
     **Y_{i,b} = μ̂(X_i) + v_{i,b} e_i**，得到扰动上下文 D_b（特征与行序不变）；
  5. 对每个 D_b 计算 μ̂_b(x)；
  6. **标准误**：ŝ(x) = {μ̂_b(x)} 的样本标准差；
  7. **偏差缓冲**：r̂(x) = max_b |μ̂_b(x) − μ̂(x)|；
  8. **区间**：C_α = [μ̂(x) − R, μ̂(x) + R]，其中 **R = z_{1−α/2} ŝ(x) + r̂(x)**。
- **CATE 扩展（算法 2）**：采用 T-learner，对处理组和对照组分别执行上述步骤（各自交叉拟合、独立乘子），得到 τ̂_b(x) = μ̂_{1,b}(x) − μ̂_{0,b}(x)，再由 {τ̂_b} 计算 ŝ_τ 与 r̂_τ，构造对称区间（式 12）。
- **理论支撑（核回归类比）**：
  - 在 Nadaraya–Watson 核回归下，估计误差可精确分解为“上下文变异（oracle 波动）”+“有限上下文偏差”；
  - **定理 1**：在 nh_n^{2β+d}/log B → 0 条件下，偏差缓冲 r̂(x) 是偏差 b_n(x) 的高概率上界；
  - **定理 2**：区间具有渐近逐点覆盖 ≥ 1−α，宽度为 O_p(ρ_n √log B)；取最优带宽和 B = ⌈n^c⌉ 时长度 O_p(n^{−β/(2β+d)}√log n)，仅比对数因子差于最优。
- **说明**：理论针对核回归这一可解析的代理模型，用以解释方法机理，**并非对真实表格基础模型的保证**。

## 七、讨论、局限与批判性评估

- **方法层面的局限**：
  - 偏差缓冲 r̂(x) 取的是扰动估计相对原估计的**最大偏离**，这是一个偏保守（conservative）的经验量，缺乏对“扰动分布最大偏离”与“真实偏差”之间关系的精细刻画；在 B 较小时 r̂ 的蒙特卡洛误差不可忽视，论文虽做了 B=100–500 的敏感性分析，但未给出 r̂ 自身稳定性的理论保证。
  - 五折交叉拟合的折外残差在 n 较小时估计粗糙，残差中心化假设了同方差式对称噪声；对强异方差或重尾结果，Rademacher wild bootstrap 的有限样本性质可能退化（论文的异方差设计部分缓解了这一担忧，但未系统检验重尾）。
  - CATE 采用 T-learner 分别扰动两组，处理组与对照组的偏差缓冲简单相加，未考虑两组估计误差的相关性，可能进一步保守。
- **理论层面的局限**：
  - 定理 1、2 建立在 Nadaraya–Watson 核回归这一**代理模型**上，而非真实表格基础模型；基础模型的“有效带宽”“隐式正则化”如何映射到核回归的 h_n、β，论文未给出可操作的对应，因此理论更多是**机理解释**而非对实际算法的保证。
  - 渐近结果要求 nh_n^{2β+d}/log B → 0，这在实际中难以核验；覆盖保证是逐点、渐近的，未覆盖一致覆盖或函数整体推断。
- **实验层面的局限**：
  - 缺少与同期不确定性量化路线的**直接实证对比**：如基于后验/贝叶斯视角的方法（martingale posterior、TabMGP 类）与 conformal 类方法（如 C-USIM），使得“TabCUQ 相对现有方案是否更优”缺乏横向证据；论文主要以 Wild bootstrap 与不可得的 OBA 作为参照，对比面偏窄。
  - 真实数据以“大样本参考函数”为覆盖目标，这一目标本身依赖参考模型的选择与交叉验证，存在“以模型验模型”的循环风险；论文对此有声明但仍影响结论强度。
  - 评估以逐点覆盖与宽度为主，未系统报告区间分数的 proper scoring（如 Winkler score、区间交叉熵），也未讨论多重查询点下的同时覆盖。
- **表述与透明度**：
  - 未报告算力与推理成本，B 次前向传播加交叉拟合的实际开销对 practitioners 是重要决策信息，属明显缺口；
  - 部分负面结果（覆盖不均、上下文增大不改善）报告得较简略，缺少对失败模式的深入归因。

## 八、启示与可借鉴点

- **问题定位值得借鉴**：把基础模型推断的不确定性明确拆成“上下文变异 + 有限上下文偏差”，并指出后者是现有 bootstrap/conformal 方法常被忽略的部分，这一分解框架可迁移到其他“冻结模型 + 上下文学习”的场景（如 in-context 视觉、时间序列基础模型）。
- **“扰动重抽样 + 偏差缓冲”是低成本、模型无关的工程方案**：只需黑盒调用基础模型，不需访问参数或似然，适合作为基础模型 UQ 的基线/兜底方法。
- **实验设计的可复用要素**：固定查询点与模型种子、只重抽上下文、用 OBA 作为不可得上限参照、构造“真 CATE=0”的 LaLonde 式基准——这些做法对评估任何上下文条件推断方法都有参考价值。
- **对使用者的实践提醒**：在上下文较小、查询点位于数据边缘、或处理组样本稀少时，应预期基础模型的点估计存在系统偏差，仅报标准误会严重低估不确定性；此时应优先扩大上下文或改用偏差稳健的区间构造。

TabCUQ 提出用 wild bootstrap 式扰动重抽样为表格基础模型的上下文条件均值与 CATE 构造置信区间，以扰动离散度估计上下文变异、以最大扰动偏离作为有限上下文偏差的保守缓冲，在模拟与多个真实任务上显著改善了覆盖率，其“方差 + 偏差双管齐下”的思路清晰且工程可行，但理论保证限于核回归代理、缺乏与后验/conformal 方法的横向对比，且算力成本未披露。
