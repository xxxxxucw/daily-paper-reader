## 摘要
随着大语言模型的思维链推理能力不断提升，评估和校准其推理置信度对于量化其答案的不确定性正变得越来越重要。当前估计大语言模型置信度的方法通常基于所选关键词元的概率，但其底层机制仍不清楚。我们的初步研究发现，用粗略替代量替换所选词元概率也能改善校准，这促使我们进一步探索模型置信度的有效信号。我们提出发散词元置信度（Divergent Token Confidence, DTC）框架，通过计数两个模型在解码过程中强烈不一致的词元来估计置信度。DTC 利用沿同一推理轨迹评估的下一词元分布之间的 Jensen-Shannon 散度来识别这些发散词元。我们发现，其计数与答案准确率几乎呈负相关，因而可作为不确定性量化的简单而有效的信号。DTC 借助辅助模型同时支持白盒和黑盒评估，无需显式训练，也不影响生成过程。在多个模型系列和六个数学基准上的实验表明，其校准效果优于基于概率和言语化的基线。在白盒评估下，仅计数估计器达到平均期望校准误差 13.0%，而标准全序列置信度方法为 32.7%-42.4%。在黑盒设置下，它也优于原始言语化得分的校准效果。例如，在 DeepSeek-V3.2 上，平均期望校准误差从 32.1%-40.2% 降至 13.7%-16.3%。这些发现为改进大语言模型中的推理不确定性量化提供了新见解。代码发布于 https://github.com/szu-tera/DTC.git。

## Abstract
As the chain-of-thought reasoning capabilities of large language models improve, evaluating and calibrating their reasoning confidence is becoming increasingly important for quantifying the uncertainty of their answers. Current methods for estimating the confidence of large language models are generally based on probabilities of selected key tokens, but the underlying mechanism remains unclear. Our pilot study finds that replacing selected token probabilities with coarse substitutes can also improve calibration, motivating us to further explore effective signals of model confidence. We introduce Divergent Token Confidence (DTC), a framework that estimates confidence by counting tokens at which two models strongly disagree during decoding. DTC identifies these divergent tokens using the Jensen-Shannon divergence between next-token distributions evaluated along the same reasoning trajectory. We find that their count is almost negatively associated with answer accuracy, thereby serving as a simple yet effective signal for uncertainty quantification. DTC supports both white-box and black-box evaluation using auxiliary models, without explicit training and affecting the generation process. Experiments across multiple model families and six mathematical benchmarks demonstrate improved calibration over probability-based and verbalized baselines. Under white-box evaluation, the count-only estimator achieves an average expected calibration error of 13.0%, compared with 32.7%-42.4% for standard full-sequence confidence methods. In black-box settings, it also improves calibration over the original verbalized scores. For example, mean expected calibration error falls from 32.1%-40.2% to 13.7%-16.3% on DeepSeek-V3.2. These findings provide new insights for improving reasoning uncertainty quantification in large language models. The code is released at https://github.com/szu-tera/DTC.git.

## 1. 核心问题与整体含义

- **研究背景**：随着大语言模型（LLM）的思维链（CoT）推理能力不断增强，如何评估与校准其推理路径的置信度（即推理不确定性量化，Reasoning Uncertainty Quantification）变得愈发重要。一个推理轨迹即使得到正确答案，其中间步骤仍可能不可靠；反之亦然。
- **核心问题**：现有置信度估计方法大多基于所选关键 token 的概率（如 UQAC 通过注意力链选取答案相关 token 并连乘其概率），但其**底层机制并不清晰**——校准收益究竟来自所选概率本身，还是来自所选 token 的数量？
- **关键动机（预实验发现）**：作者固定 UQAC 的 token 选择集合，将其概率替换为轨迹平均概率（C^S_mean）甚至全体共享常数（C^S_global），校准效果**反而普遍更好**。当替换为共享常数时，得分只依赖于所选 token 数量，这提示 **token 计数本身可能就是有效的校准信号**。
- **整体含义**：论文据此提出以**模型间分歧 token 的计数**作为不确定性信号，为 LLM 推理不确定性量化提供了一条不依赖具体概率值、无需训练、且同时适用于白盒与黑盒的新思路。

## 2. 方法论：DTC 框架

### 2.1 核心思想
- **假设**：不可靠的推理路径包含更多"两模型强烈分歧"的 token。
- **做法**：沿同一条固定推理轨迹，用 teacher forcing 比较两个模型的下一 token 分布，用 **Jensen–Shannon 散度（JSD）** 度量分歧，统计超过阈值 θ 的 token 数量，将其作为置信度信号。

### 2.2 关键技术细节
- **分歧度量**：对推理位置 t，两模型分布 P_t、Q_t 的 JSD：
  - `JSD(P_t, Q_t) = H((P_t+Q_t)/2) − ½H(P_t) − ½H(Q_t)`
  - 选用 JSD 是因为其**对称性与有界性**（附录 C.4 对比了前向 KL、反向 KL）。
- **发散 token 定义**：`T_div(θ) = { t : JSD(P_t, Q_t) > θ }`，计数记为 `m = |T_div(θ)|`。
- **阈值 θ 的设定**：不同模型家族分歧程度不同，按家族在小型验证集上分别设定（白盒：Qwen2.5 取 0.50、Qwen3 取 0.60、Gemma3 取 0.85；黑盒：0.70）。

### 2.3 两种置信度估计器
- **DTC_lin（仅计数线性映射）**：
  - 置信度从 a=0.95 开始随 m 线性下降，到 m≥n=10 时降为下限 b=0.05：
    `DTC_lin(m) = a − (a−b)/n · m (0≤m<n)；= b (m≥n)`
  - 选定发散 token 后，该映射**只依赖计数**。
- **DTC_prod（轨迹均值乘积）**：
  - 用计数 m 对轨迹平均 token 概率 C_mean 做再校准：`DTC_prod(m) = C_mean^(m+k)`，取 k=4。
  - 白盒下 C_mean 来自生成器；黑盒下来自较大的辅助模型。
  - 更大的 m 得到更低的置信度；相比 DTC_lin，它为相同 m 的轨迹提供了更细粒度的置信度。
- **白盒与黑盒适配**：
  - **单辅助（白盒）**：生成器 G 与辅助模型 A 比较。
  - **双辅助（黑盒）**：无法访问生成器 logits 时，假设"发散 token 数与路径可靠性之间的关系在不同模型对间大致稳定"，用两个同家族外部辅助模型 A′、A″ 比较。

### 2.4 算法流程（文字版）
1. 生成器在给定 query 上产生完整推理轨迹 τ（含 CoT 与最终答案 y）。
2. 沿固定轨迹，用 teacher forcing 计算两模型在每个位置的下一 token 分布。
3. 逐位置计算 JSD，标记超过 θ 的 token。
4. 统计发散 token 数 m。
5. 用 DTC_lin 或 DTC_prod 将 m（及 C_mean）映射为 [0,1] 置信度。
6. 全程不改变生成过程、无需训练。

## 6. 主要结论与发现

- **计数是有效信号**：发散 token 数与路径准确率近似负相关（图 1c、图 11），且除以路径长度后仍成立（r=−0.985 vs. −0.937），说明**计数不是长度的简单代理**。
- **白盒结果**：DTC_lin 与 DTC_prod 将平均 ECE 降至 **13.0% 与 13.2%**，而 C_NSL、C_mean、Entropy 为 32.7%–42.4%；AUROC 分别达 75.3 与 80.8，兼顾校准与排序。
- **优于 UQAC 改进版**：相对 UQAC_mean，DTC_prod 平均 ECE 降低 10.4，说明"选择发散 token"比"选择注意力相关 token"更能捕获不确定性。
- **黑盒结果**：在 DeepSeek-V3.2 上，DTC_lin 的平均 ECE 为 13.7%–16.3%，而三种言语化方法为 32.1%–40.2%；言语化方法还会降低准确率（57.5 → 44.9–51.5）。
- **可与言语化分数结合**：用 DTC 计数对言语化分数再校准后，ECE 普遍下降，部分场景降幅超过 20 个百分点，AUROC 变化很小甚至提升。
- **标准全序列置信度**：排序信息尚可（AUROC 72.7–73.8）但严重过度自信，校准曲线位于对角线下方。

## 7. 优点

- **方法简洁且机制清晰**：把校准信号从"概率值"转向"分歧计数"，并通过预实验（概率替换为常数）严格论证了动机。
- **无需训练、不干扰生成**：仅在生成后的冻结轨迹上做 teacher forcing 评分，可即插即用。
- **白盒/黑盒双支持**：单辅助与双辅助设计覆盖了无法访问 logits 的闭源模型场景。
- **校准与排序兼顾**：DTC_prod 在保持低 ECE 的同时显著提升 AUROC，弥补了 UQAC 类方法排序能力下降的问题。
- **可组合性**：计数可与其他过度自信分数（如言语化置信度）结合，通用性强。
- **实验较扎实**：多家族、多基准、多基线，并对 θ、辅助规模、度量选择、n、k 做了系统敏感性分析。
- **指标论证严谨**：附录 A.3 明确解释了为何以 ECE 为主、AUROC 为辅（AUROC 无法反映置信度是否可解释为正确概率）。

## 8. 不足与局限

- **任务覆盖单一**：所有实验均在数学推理基准上，未验证开放域问答、代码生成、多跳推理等场景，结论的泛化性有待检验。
- **黑盒假设较强**：双辅助设定假设"发散 token 数与可靠性关系在不同模型对间稳定"，该假设缺乏理论保证，仅在实验中被间接支持。
- **阈值依赖调参**：θ 需按模型家族在验证集上单独搜索（0.50/0.60/0.85/0.70），跨家族迁移性有限，增加了部署成本。
- **需要辅助模型**：黑盒下需额外两个外部模型，带来额外推理开销与模型选择问题。
- **排序性能不稳定**：在部分黑盒场景（如 Qwen3-30B-A3B 的 Verb. TopK），DTC 的 AUROC 反而低于原始言语化分数。
- **有监督方法仍有优势**：PRM 在多数设置下 ECE 更低（如 6.0–13.1），DTC 与有监督方案仍存在差距。
- **资源信息缺失**：未披露 GPU 型号、数量与耗时，影响复现与成本评估。
- **评估偏差风险**：类平衡子采样会改变样本分布，可能导致 ECE 与真实部署场景下的校准表现存在偏差。
