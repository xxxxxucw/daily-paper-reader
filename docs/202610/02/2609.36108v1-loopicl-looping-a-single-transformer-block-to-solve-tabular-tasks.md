## 摘要
使用上下文学习的表格基础模型最近在预测性表格任务上超越了梯度提升树。然而，近期的机制性研究见解表明，这些模型中的参数在很大程度上是冗余的。我们提出了 LoopICL，一种循环 Transformer，其核心设计将参数数量与计算深度解耦。LoopICL 仅由一个块组成，通过两个耦合流处理数据：捕获逐单元格特征表示的单元格流，以及捕获上下文示例表示的行流，二者通过列内注意力和跨列注意力联合细化。在预训练期间，我们改变循环次数，使该块在测试时可以展开为可变数量的迭代，并使用学习到的退出门自动退出。在标准设置下，LoopICL 在 TabArena 和 TALENT 上以相同的计算成本（FLOPs）与 TabICLv2 表现相当，同时使用的参数减少近 90%。此外，其循环设计使用户还能够权衡推理成本与性能，提供了一种资源感知的表格基础模型（TFM）。

## Abstract
Tabular foundation models using in-context learning have recently surpassed gradient-boosted trees on predictive tabular tasks. However, recent mechanistic insights suggest that parameters in these models are largely redundant. We introduce LoopICL, a looped transformer whose core design decouples parameter count from computational depth. LoopICL consists of a single block, processing data through two coupled streams: a cell stream capturing per-cell feature representations and a row stream capturing in-context example representations, jointly refined through within-column and cross-column attention. During pre-training, we vary loop counts, allowing the block to be unrolled for a varying number of iterations at test-time and use a learned exit-gate to automatically exit. In its standard setting, LoopICL performs competitively with TabICLv2 on TabArena and TALENT at the same computational cost (FLOPs), while using nearly 90% fewer parameters. Furthermore, its recurrent design enables users to also trade off inference cost and performance, providing a resource-aware TFM.

## 1. 核心问题与整体含义

- **背景**：表格基础模型（TFM）通过上下文学习（ICL）在预测性表格任务上已超过梯度提升树（如 TabICLv2、TabPFN-3、TabFM）。但当前前沿模型主要靠增大参数量与层数提升性能，例如 TabPFN-3 比 TabPFNv2 大约 7 倍。
- **核心矛盾**：机制性分析表明，这些 TFM 的参数存在较大冗余，模型能力更多来自“迭代式精炼”而非单纯记忆知识；任务感知块剪枝也显示其高度可压缩。
- **论文动机**：挑战“不断堆参数”的趋势，探索是否可以用更少参数、更多循环计算来获得同等甚至更好的表格 ICL 性能。
- **整体含义**：LoopICL 将参数量与计算深度解耦。它只使用一个共享 Transformer 块，通过反复循环增加有效计算深度。结果表明，表格 ICL 可能更依赖“学习迭代求解算法”，而不是“扩大参数以记忆事实”。这为资源感知 TFM 提供了新方向：不一定要扩大参数预算，也可以扩大循环预算。

## 2. 方法论：核心思想与关键技术

- **核心思想**：用单个共享 Transformer 块循环 L 次，权重跨所有循环共享。参数固定，但测试时可通过改变循环次数调节计算量。
- **双流结构**：
  - **单元格流（cell stream）**：形状为 \(R \times C \times E\)，捕获逐单元格、细粒度特征表示，默认 \(E=128\)。
  - **行流（row stream）**：形状为 \(R \times D\)，捕获逐示例、上下文 ICL 表示，默认 \(D=4E=512\)。
  - 两个流非对称耦合：单元格流先建模局部特征交互，再读出到行流；行流经 ICL 注意力更新，同时更新后的单元格流保留到下一轮。
- **单次循环内的轴向块**：
  - **列内注意力**：对每列独立使用 ISAB，含 \(K=128\) 个诱导点，建模同一特征列内不同行之间的关系。
  - **跨列注意力**：对每行使用带 RoPE 的自注意力，建模行内不同特征之间的关系。
  - **CLS 读出**：用每行 4 个可学习 CLS token，将单元格流投影到行流。
  - **ICL 注意力**：对行流使用因果掩码注意力，使测试行可关注训练行。
  - 所有子块采用 sandwich normalization，即 pre- 和 post-RMSNorm。
- **分布输入编码**：
  - 原始特征按列标准化，缺失值用列均值填充；使用循环特征分组（\(G=3\)）形成单元格嵌入。
  - 类标签通过正交初始化嵌入矩阵注入，并在每次循环中重新注入。
  - 额外引入三类分布信号：边际直方图、判别直方图、Fourier 分位数编码。它们分别刻画边际分布、类判别分布、相对排名与 OOD 信息。
  - 这些条件 MLP 输出层零初始化，训练初期不干扰主干，随后逐渐激活。
- **残差缩放**：
  - 每轮更新：\(x \leftarrow x + \alpha(\tilde{x}-x)\)，其中 \(\alpha \in (0,1]\)。
  - 论文比较三种设置：\(\alpha=1\)、\(\alpha=1/\sqrt{L}\)、\(\alpha=1/L\)。
  - \(\alpha=1\) 适合早退，因为早期循环即可获得较好性能；\(\alpha=1/L\) 使计算更均匀地分配到 L 步，并能外推到预训练循环上限之外。
- **解码器**：
  - 使用基于注意力的检索解码器，测试行表示作为 query，训练行表示作为 key。
  - 通过 one-hot 标签加权，按类别累积注意力质量，再跨 head 平均得到类概率。
  - 该解码器具有目标排列等变性。
- **早退门（Early-Exit Gate）**：
  - 每轮后由轻量 MLP 判断是否停止。输入为 43 维向量，包括压缩状态、状态变化、循环深度编码、前三次门输出、数据集大小编码。
  - 输出退出概率 \(\lambda_t\)，累计退出概率 \(F_t=1-\prod_{s=1}^t(1-\lambda_s)\)，当 \(F_t>q\) 时退出，默认 \(q=0.5\)。
  - 门参数量少于 20K，仅使用训练样本表示，不使用测试集信息。
- **预训练流程**：
  - **Stage 1**：500K 步，batch size 64，合成数据 2–100 特征、最多 10 类、最多 1024 行；完整 BPTT。
  - **Stage 2**：30K 步长上下文继续预训练，1–2000 特征、最多 100K 行，受特征×行预算 \(10^6\) 限制；使用 TBPTT，窗口 \(k=5\)。
  - **Stage 3**：4K 步训练早退门，冻结主干，最大训练循环数为 16，是预训练上限 8 的两倍。
- **循环次数训练分布**：训练时 L 从 log-normal Poisson 分布采样，截断到 [1,8]，均值约 6，实际平均约 5.32；只在最终循环计算交叉熵损失。
- **推理集成**：默认使用 8 个成员集成，通过特征顺序置换、类别置换、不同预处理制造多样性；每个成员可独立早退。
