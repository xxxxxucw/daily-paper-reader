## 摘要
表格基础模型（TFMs）日益流行，因为它们通过上下文学习即可在新数据集上给出强预测，无需针对特定任务进行训练或大量调参。然而，已发布的 TFM 在预训练先验、架构和目标上同时存在差异，使其各自的归纳偏置难以辨明。因此，我们考察一项具体能力：无关特征抑制。在合成任务与真实数据集上，加入空特征会使行 token 模型 TabDPT 的预测性能出现明显更大的下降，而单元格 token 的交替轴模型 TabPFN v2 及其他 TFM 则相对稳定。这一差距促使我们追问：架构是否对无关特征抑制有所贡献。由于已发布的 TFM 仍与其他设计选择相互混淆，我们在相同的稀疏到稠密线性先验下训练了精简的行 token 与交替轴 transformer。精确贝叶斯分析表明，稀疏预测需要依赖上下文的特征门控，而稠密端点仅需统一的特征加权。与这一区分一致，交替轴模型在稀疏任务上明显更接近贝叶斯最优预测器，而在稠密任务上架构差距变得可忽略不计；稀疏任务上的差距几乎全部来自线性系数的估计误差。最后，在受控模型与冻结的 TabPFN v2 中，我们考察了对特征注意力输出进行干预对线性系数的影响，发现了依赖任务、经由特征索引路径对计算进行选择性路由的证据。总体而言，这些结果支持架构—先验对齐：保留可寻址的特征轴为任务自适应的相关性推断提供了归纳偏置。代码见 https://github.com/Tianqi-Zhao/ArchitecturePriorTFMs。

## Abstract
Tabular foundation models (TFMs) are increasingly popular because they deliver strong predictions on new datasets through in-context learning, without task-specific training or extensive tuning. Yet released TFMs differ simultaneously in their pretraining priors, architectures, and objectives, obscuring their respective inductive biases. We therefore examine one concrete capability: irrelevant-feature suppression. Across synthetic tasks and real-world datasets, adding null features causes substantially greater predictive degradation in the row-token model TabDPT, whereas the cell-token alternating-axis model TabPFN v2 and other TFMs remain comparatively stable. This gap motivates us to ask whether architecture contributes to irrelevant-feature suppression. Because released TFMs remain confounded by other design choices, we train streamlined row-token and alternating-axis transformers under identical sparse-to-dense linear priors. Exact Bayes analysis shows that sparse prediction requires context-dependent feature gating, whereas the dense endpoint requires only uniform feature weighting. Consistent with this distinction, the alternating-axis model is substantially closer to the Bayesian optimal predictor on sparse tasks, while the architecture gap becomes negligible on dense tasks; almost all of the sparse gap arises from linear coefficient-estimation error. Finally, in both the controlled model and frozen TabPFN v2, we examine the effect of interventions on the feature-attention outputs on the linear coefficients, finding evidence of task-dependent selective routing of computation through feature-indexed pathways. Together, these results support architecture-prior alignment: preserving an addressable feature axis provides an inductive bias for task-adaptive relevance inference. Code is available at https://github.com/Tianqi-Zhao/ArchitecturePriorTFMs.

## 2. 方法论

### 2.1 第一阶段：已发布模型的配对压力测试（观测性）
- **配对设计**：每个数据集构造"干净版"与"加噪版"，加入与响应无关的**空特征（null features）**；空特征比例 ρ ∈ {0, 0.2, 0.4, 1, 2, 4, 7}。
  - 合成任务：在 Friedman 数据上加入独立同分布（Uniform）空列；
  - 真实任务：加入**按行置换的原始列副本**，保留边缘分布但切断与目标的关联。
- **度量指标**：
  - **R² 下降**：Drop = R²(0) − R²(ρ)；
  - **空特征位移（null-feature shift）**：固定上下文与其他查询特征，仅置换一个空查询特征，将预测变化用查询目标标准差归一化，直接度量**函数依赖**；
  - **单变量 PDP 变异**：在 5 个经验分位点上评估部分依赖曲线。
- 采用 5 次独立"构造重复"（只重抽增广，底层任务固定），配对跨模型、跨剂量嵌套。

### 2.2 第二阶段：匹配先验下的受控架构对比
- **匹配先验族**：固定设计正交回归 y = Xβ + ε，ε ~ N(0, σ²Iₙ)，XᵀX = nI_d；先验 P_k 抽取大小为 k 的支撑集 S ~ Unif(S_k)，β_S | S ~ N(0, (v²/k)I_k)，β_{S^c} = 0。
  - 关键设计：缩放 1/k 使 E[ββᵀ] = (v²/d)I_d **对所有 k 相同**，即只改变支撑结构、不改变系数协方差与信号能量（"匹配先验"）。
  - k < d 为稀疏，k = d 为稠密端点。
- **精确贝叶斯目标**：正交性使 c = Xᵀy/n 为充分统计量，后验系数均值为
  **η\*_k(c) = λ_k · q_k(c) ⊙ c**，其中 q_{k,j}(c) = P(j ∈ S | c) 为后验包含概率，λ_k = nv²/(nv² + kσ²) 为收缩因子。
- **稠密 vs 稀疏的计算差异**（核心洞察）：
  - 稠密端点：q_d(c) ≡ 1，贝叶斯规则退化为**固定线性核回归**（对所有坐标施加统一收缩）；
  - 稀疏情形：需要**依赖上下文的特征门控 q_k(c)**，且因指数归一化而**关于 c 非线性**。
- **定理 1（响应仿射屏障）**：对任意形如 f = a(X,x) + b(X,x)ᵀy 的仿射预测器，其平方风险唯一最优解恒为 λ_d xᵀc（即稠密贝叶斯规则）；而当 k < d 时，该仿射类到稀疏贝叶斯预测器的逼近误差**严格大于零**。由于线性核回归等价于无 softmax 的单层行 token 注意力，这为行 token 架构在稀疏任务上的困难提供了理论解释。
- **交替轴可实现性（命题 3）**：以 k = 1 为例，交替轴网络可通过"响应路由 → 观测轴聚合成 c_j → 特征轴 softmax（logits ∝ c_j²，values 为 λ₁c_j x_j）"三阶段精确实现 f\*₁；一般 k 用三层注意力与 O(k) 池化统计量，配合牛顿恒等式由初等对称多项式恢复包含概率，从而在紧集上**一致逼近**贝叶斯预测器。
- **受控模型**：在相同先验与训练协议下训练精简版
  - **交替轴模型**（基于 nanoTabPFN 改造，每格一个 token + 响应 token，3 个 block，355,873 参数）；
  - **行 token 模型**（线性投影整个协变量向量 + 标签嵌入，5 个 block，393,985/394,945 参数）。
  - 两者嵌入宽度 96、FF 宽度 192、4 头、GELU、post-norm、两层标量 MLP 解码器，参数量近似匹配。
- **误差度量与分解**：
  - 任务归一化贝叶斯逼近误差 E_{a,k}（按贝叶斯预测能量归一化）；
  - **引理 2** 将误差严格分解为**系数误差 + 截距平方误差 + 非线性残差误差**三项正交分量。

### 2.3 第三阶段：特征注意力干预（机制追踪）
- **干预方式**：在某层 ℓ 的某个特征注意力头上，将来自源特征 j 的加权消息按 (1−δ) 衰减（δ = 0.1，稳健性检验取 0.05/0.2），注意力权重**不重新归一化**、残差路径保留，下游计算全部重跑；分别作用于**仅上下文行 / 仅查询行 / 两者联合**。
- **系数响应**：bJ^(ℓ)_{rj} = (η̂_{0,r} − η̂_{δ,ℓ,j,r})/δ，即单位衰减导致的第 r 个系数变化（j 为源特征，r 为目标特征）。

  - **敏感度（sensitivity）** w^(ℓ)_j：自身系数响应幅度除以观测到的特征—响应统计量 |c_j|；
