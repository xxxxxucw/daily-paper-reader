## 摘要
可靠的自评估对大语言模型（LLMs）至关重要，然而它们在答案错误时往往仍高度自信。我们研究同步置信度校准，即在提升能力的同时学习置信度，而不是仅在训练后进行校准。基于可验证奖励的强化学习（RLVR）为该范式提供了天然场景，因为它持续生成与可验证正确性反馈配对的响应。然而，现有的同步方法在共享策略参数内通过强化学习同时学习能力和置信度，可能将两个根本不同的学习问题耦合在一起。我们转而提出“共享经验但独立学习”：能力和置信度从相同轨迹中学习，但通过独立的优化机制和参数进行。基于这一原则，我们提出 CoCal（Companion Confidence Calibration，伴随置信度校准），它利用 rollout 隐藏状态和由验证器导出的正确性监督来训练一个轻量级伴随模型，同时保持任务优化不变。在 Qwen3-8B 和 Qwen3-14B 上的实验表明，CoCal 在不牺牲任务性能的情况下提升了置信度估计，优于基于 RL 的同步方法和匹配的事后校准。学习到的伴随模型进一步泛化到不同领域和策略偏移，且 CoCal 的收益在两种规模上均持续存在。

## Abstract
Reliable self-assessment is essential for large language models (LLMs), yet they often remain highly confident when their answers are wrong. We study \emph{concurrent confidence calibration}, where confidence is learned alongside capability improvement rather than calibrated only after training. Reinforcement learning from verifiable rewards (RLVR) provides a natural setting for this paradigm, as it continuously produces responses paired with verifiable correctness feedback. Existing concurrent methods, however, learn both capability and confidence through reinforcement learning within shared policy parameters, potentially coupling two fundamentally different learning problems. We instead propose \emph{shared experience but separate learning}: capability and confidence learn from the same trajectories, but through separate optimization mechanisms and parameters. Based on this principle, we introduce \textbf{CoCal (Companion Confidence Calibration)}, which trains a lightweight companion from rollout hidden states and verifier-derived correctness supervision while leaving task optimization unchanged. Experiments on Qwen3-8B and Qwen3-14B show that CoCal improves confidence estimation without sacrificing task performance, outperforming both RL-based concurrent methods and matched post-hoc calibration. The learned companion further generalizes across domains and policy shifts, while the benefits of CoCal persist at both scales.

## 1. 核心问题与整体含义
- **研究动机**：大语言模型（LLM）在数学推理、代码等任务上能力不断增强，但常对错误答案表现出高置信度，可靠自评对何时回答、拒答、检索或增加推理算力至关重要。
- **核心问题**：现有“并发置信度校准”方法在 RLVR 训练中同时学习任务能力与置信度，但多数把两者耦合在共享策略参数中，通过 RL 优化同一模型，可能让两个本质不同的学习问题相互干扰。
- **整体含义**：论文提出“共享经验，但分离学习”原则：能力与置信度可复用同一批 RLVR rollout 经验，但应通过不同优化机制和参数学习，从而在提升置信度估计的同时不牺牲任务性能。

## 2. 方法论
- **核心思想**：任务能力继续由策略模型通过 RLVR/GRPO 优化；置信度由一个独立、轻量的“伴随校准器”从 rollout 隐藏状态和验证器正确性标签中直接监督学习。
- **策略学习**：采用 GRPO。对同一问题采样一组响应，根据验证器给出的正确性奖励计算组内相对优势，并更新策略参数；任务优化流程不被 CoCal 改变。
- **置信度学习**：
  - 每个训练步采样 \(B\) 个问题，每个问题生成 \(K\) 个响应，验证器输出二值正确性 \(y_{i,j}\in\{0,1\}\)。
  - 从响应生成过程中提取最终 Transformer 层隐藏状态；表示形式为“最后一个 token 隐藏状态”与“响应 token 平均池化隐藏状态”的拼接。
  - 伴随模型为四层 MLP，带 LayerNorm、GELU、dropout 和 sigmoid 输出，预测置信度 \(c_{i,j}=g_\phi(z_{i,j})\in[0,1]\)。
  - 用均方误差训练：\(\mathcal L_{\text{conf}}=\frac{1}{BK}\sum_{i,j}(c_{i,j}-y^{\text{conf}}_{i,j})^2\)。
- **监督目标**：
  - **Binary 监督**：直接使用验证器正确性 \(y_{i,j}\) 作为置信度目标，学习区分正确与错误响应。
  - **Group 监督**：对正确响应使用该问题组准确率 \(\bar y_i\)，错误响应目标为 0，以区分“稳定正确”和“偶然正确”。
- **实现流程**：缓存 RLVR rollout 的隐藏状态和验证器标签，按策略训练步骤的时间顺序离线重放训练伴随模型，近似在线伴随学习，同时避免修改 RLVR 主流程。
- **推理**：策略生成响应时提取内部状态，由伴随模型输出置信度；校准器独立于策略，参数不共享。

## 6. 主要结论与发现
- **CoCal 提升置信度估计且不损任务性能**：在 Qwen3-8B 上，CoCal(binary) 平均 ECE 约 0.096、AUROC 约 0.896，优于 RLCR 和 DCPO；同时任务准确率保持稳定。
- **优于 RL 并发校准**：RLCR、DCPO 在共享策略参数中学习置信度，任务准确率平均分别比 CoCal 低 9.9 和 5.0 个百分点，显示能力-校准耦合可能损害任务学习。
- **优于匹配的事后校准**：CoCal 在多数设置下 ECE 更低、AUROC 更高，并避免 PostCal 所需的额外 14.22 小时响应采样。
- **跨域泛化更强**：从数学迁移到事实 QA 时，CoCal 相对 RLCR、DCPO、PostCal 的优势扩大，说明从多阶段能力训练经验中学习置信度有助于跨域校准。
- **跨策略迁移较稳定**：CoCal 在不同训练阶段策略间迁移时，AUROC 约 0.869–0.893，ECE 约 0.092–0.119；对 DCPO 策略迁移较好，对后期 RLCR 策略迁移因表示偏移较大而不一致。
- **早期经验即有效**：仅用前 10 步 rollout 数据，CoCal(binary) 已达到 ECE 0.090、AUROC 0.868。
- **规模与表示稳健**：Qwen3-14B 上仍有效；中后层表示均能提供强置信信号；不同 token 聚合方式表现稳健；预生成置信度可行但精度低于后生成，时间开销低约 \(10^2\)–\(10^3\) 倍甚至更多。

## 7. 优点
- **原则清晰**：将“能力学习”和“置信度学习”解耦，避免两个目标在同一策略参数中互相干扰。
- **重用经验、成本低**：直接复用 RLVR rollout 和验证器反馈，无需额外采样，伴随模型训练和推理开销极小。
- **简单有效**：四层 MLP + 内部状态 + MSE 监督，架构轻量，易于插入现有 RLVR 流程。
- **泛化分析充分**：不仅报告同分布数学评测，还覆盖事实 QA 跨域、跨训练阶段和跨策略迁移。
- **公平对照较细致**：与 PostCal 在相同架构、目标、预算下比较，并分析训练数据组成和成本。
- **实用信号**：早期训练即可获得有用置信度，预生成置信度虽弱但可支持低延迟决策。

## 8. 不足与局限
- **白盒限制**：CoCal 需要访问模型内部隐藏状态，只能用于白盒场景，难以直接用于仅 API 可访问的 LLM。
- **未内化置信度**：置信度由外部伴随模块给出，不能直接改善模型自身口头表达的置信度。
- **模型与任务覆盖有限**：主要验证 Qwen3-8B/14B 和 RLVR 数学训练；未覆盖更多模型家族、更大规模、非数学 RLVR 任务或多模态场景。
- **迁移并非总是稳定**：对 RLCR 后期策略的迁移效果不一致，说明内部表示大幅变化会影响伴随校准器复用。
- **OOD 准确率仍低**：事实 QA 上任务准确率普遍不高，ECE 虽改善但并非完美校准。
- **算力披露不完整**：只明确单 B200 计时与部分成本，未给出完整训练集群规模、总 GPU 数、总能耗。
- **潜在偏差**：训练数据以数学为主，事实 QA 仅用于 OOD 评测；组监督依赖每题 8 个 rollout 的组准确率，可能受

组内样本数、问题难度分布与验证器噪声影响；当某题 8 个 rollout 全对或全错时，Group 监督几乎无法提供组内区分信号，Binary 监督也只能反映二值正确性，而非真实概率。由此还可补充以下局限：

- **标签质量瓶颈**：置信度目标完全依赖验证器正确性标签，若验证器在开放域、事实问答或复杂推理上误判，伴随校准器会继承并放大标签噪声。
- **置信度定义偏窄**：CoCal 预测的是“当前 rollout 是否被验证器判对”，不等同于模型对答案的语义自信、知识边界意识或口头置信度；因此难以直接替代模型自我表达的不确定性。
- **离线重放只是近似在线**：缓存隐藏状态并按策略训练步重放，虽避免修改 RLVR 主流程，但伴随模型看到的表示分布与真实在线策略同步更新时仍可能存在时间错位，尤其当策略表示快速漂移时。
- **决策阈值未系统研究**：论文主要报告 ECE、AUROC 等校准指标，未深入分析实际部署中如何选阈值、如何权衡误拒与误答、以及置信度用于检索/拒答/加算力时的风险收益。
- **统计显著性与方差披露有限**：部分基准样本量小，虽采用多响应采样和 5 个随机种子，但未系统报告置信区间、显著性检验或种子间方差，结论稳健性仍可进一步量化。
- **可复现与工程依赖**：方法需要可访问内部隐藏状态、缓存 rollout 表示并维护离线训练管线；对仅提供 API 的模型、不同推理框架或表示接口不统一的系统，复现和迁移成本会上升。
- **安全与滥用边界**：外部校准器可支持拒答和风险控制，但论文未充分讨论校准失败时的安全后果、分布外攻击、阈值漂移以及误校准对下游决策的影响。

总体而言，CoCal 在“共享经验、分离学习”的原则下提供了一种低成本、可插拔的白盒 RLVR 校准方案，但其有效性仍主要建立在二值验证器、数学训练场景和可访问内部表示的假设之上。
