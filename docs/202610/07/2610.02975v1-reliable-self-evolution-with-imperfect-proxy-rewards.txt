# ABSTRACT 

Large language model (LLM)-based self-evolving search is a promising approach to scientific discovery. However, high-fidelity evaluation of every candidate is prohibitively expensive in some domains. Self-evolving systems in such settings therefore rely on low-cost but imperfect proxy rewards, which may assign high scores to infeasible candidates. These false positives may contaminate both the final output and the feedback used to guide subsequent generations. This moti-vates statistically calibrated reward intervals for more reliable self-evolving search. We propose Conformal Interval-Driven Self-Evolution (CISE), which constructs candidate-specific reward intervals using conditional conformal inference and iteration-wise online density-ratio estimation. CISE uses conservative interval-based rewards for evolutionary feedback and returns candidates only when all required property intervals lie entirely within their respective feasible regions. We derive fixed-iteration coverage results under explicit assumptions of independence and covariate shift. We evaluate CISE on three self-evolving search tasks in materi-als science. In our experiments, all candidates returned by CISE are true positives under high-fidelity evaluation, whereas the baselines return more candidates but include false positives. These results highlight the value of a smaller, more pre-cise shortlist when downstream validation budgets are limited. Our repository is available at https://github.com/MLAI-Yonsei/CISE.git .

# 1 INTRODUCTION 

Self-evolving search uses large language models (LLMs) to generate candidates and improve subse-quent candidates using feedback from previous evaluations. This paradigm has recently emerged as an approach to scientific discovery (Romera-Paredes et al., 2024; Novikov et al., 2025; Liu et al., 2026). These methods retain previously evaluated candidates together with their rewards and reuse them to guide subsequent search. The effectiveness of self-evolution therefore depends on the reliability of the rewards that determine which candidates are treated as successful and reused in later iterations. However, obtaining the true reward for every generated candidate is often slow or expensive in iterative search. In such settings, self-evolving systems often rely on computationally inexpensive proxy rewards that approximate the true reward. For example, in materials discovery, evaluating every candidate with high-fidelity density functional theory (DFT) calculations or experimental validation is prohibitively expensive. Property prediction models are therefore often used as proxy rewards during search (Abhyankar et al., 2026). Although proxy rewards make iterative search practical, prediction errors may produce false positives: candidates that satisfy the target constraints under the proxy reward but fail under the true reward. In self-evolving search, such errors affect more than the returned candidates. Once a false positive is assigned a favorable reward and stored as a successful example, it is reused to guide subsequent generations. This false-positive propagation may steer the search toward regions where the proxy reward is overly optimistic rather than toward candidates with genuinely high true rewards. This motivates uncertainty-aware reward estimates rather than relying solely on point-valued proxy rewards. Conformal inference (Vovk et al., 2005; Angelopoulos & Bates, 2022) provides a principled way to construct such estimates by converting model predictions into calibrated intervals with

In particular, conditional conformal inference (Gibbs et al., 2025) incorporates candidate characteristics into calibration, which is useful when proxy-reward reliability varies across candidates. These calibrated intervals support conservative decisions about which candidates guide subsequent evolution and which candidates are returned as outputs. We propose Conformal Interval-Driven Self-Evolution (CISE), a self-evolving framework that re-places point-valued proxy rewards with candidate-specific calibrated reward intervals. CISE uses conditional conformal inference to construct candidate-specific reward intervals with adaptive widths. The resulting reward interval is stored in the archive and used to guide subsequent generations, while only candidates whose entire reward intervals satisfy the task-specific constraints are returned as outputs. Because the candidate distribution can change as the archive, selected parents, and generation context evolve, CISE additionally performs iteration-wise online density-ratio estimation (Kanamori et al., 2009) to characterize the difference between the source distribution and the current candidate distribution and incorporates the estimated ratio into conditional conformal inference. As a result, calibrated reward intervals are used for both evolutionary feedback and final candidate selection. Theoretically, we analyze fixed-iteration marginal coverage under explicit independence and covariate-shift assumptions and characterize how density-ratio estimation error affects the resulting guarantee. Empirically, we evaluate CISE on three self-evolving material-property search tasks and validate the returned candidates using high-fidelity DFT calculations. Across the reported experiments, CISE trades output yield for higher observed DFT-validated output precision: all CISE outputs with resolved DFT evaluations are true positives, whereas the baseline methods return false positives. We further show under a matched downstream validation budget that the reliability improvement cannot be explained solely by CISE returning fewer candidates. These results demonstrate the potential of calibrated reward intervals to make self-evolving search more reliable when accurate true rewards are too expensive to use throughout evolution. To the best of our knowledge, CISE is the first framework to use conformal proxy-reward intervals for both evolutionary feedback and final candidate selection in LLM-based self-evolving candidate search. 

# 2 RELATED WORK 

Self-evolving search reuses previously generated candidates and their rewards to guide subsequent generations across domains, including program discovery (Romera-Paredes et al., 2024; Novikov et al., 2025), video-prompt optimization (Ji et al., 2024), scientific hypothesis generation (Gottweis et al., 2026), and materials discovery (Abhyankar et al., 2026). While some settings provide directly verifiable rewards, others rely on learned or LLM-generated proxy rewards to enable efficient iterative search. In such cases, proxy-favored candidates may not correspond to true improvements, and reusing them as successful examples can propagate reward errors across subsequent generations. This motivates accounting for proxy-reward uncertainty in both evolutionary feedback and final selection. Recent work has sought to improve the reliability of proxy evaluations and rewards through cali-bration and uncertainty-aware optimization. For LLM-as-a-judge, post-hoc score calibration learns regression models from limited human feedback to adjust judge scores using their original scores and rationales (Sahoo et al., 2026), while linear probes on judge hidden states provide calibrated confidence estimates for the correctness of their judgments (Radharapu et al., 2025). Related work on learned reward models addresses uncertainty and overoptimization directly: ensemble-based conser-vative objectives use disagreement among reward models to reduce optimization against errors in an imperfect reward model (Coste et al., 2024). Process reward models have also been calibrated using quantile regression to better align their predictions with empirical success probabilities and support uncertainty-aware allocation of inference-time computation (Park et al., 2025). These approaches improve the calibration, interpretation, or robustness of model-derived rewards. However, they do not statistically control false-positive rewards under task-specific true-reward constraints in iterative self-evolving search. Conformal inference provides a complementary framework for uncertainty quantification by con-verting model predictions into calibrated prediction sets or intervals with finite-sample coverage guarantees under explicit assumptions (Vovk et al., 2005; Angelopoulos & Bates, 2022). Condi-tional conformal inference formulates conditional validity through classes of covariate shifts and provides finite-sample guarantees for shifts represented by a finite-dimensional calibration function space (Gibbs et al., 2025). More recently, conformal inference has been applied to LLM-as-a-judge 2Preprint. evaluation, replacing point-valued judge scores with calibrated intervals that explicitly represent evaluation uncertainty (Sheng et al., 2025; Noh et al., 2026). Building on this line of work, we use conformal inference to construct calibrated intervals for proxy rewards and use these reward intervals in both evolutionary feedback and final candidate selection in self-evolving search.

We consider a self-evolving agent that searches a candidate space X for solutions satisfying task-specific constraints. For each candidate x ∈ X , r(x) ∈ R denotes a scalar true reward, and 

ˆr(x) ∈ R denotes an inexpensive and imperfect proxy reward. During search, generated candidates are evaluated using the proxy reward. The task-specific constraints are specified before evolution. Let 

Fr and Fˆr denote the sets of candidates satisfying these constraints according to the true and proxy rewards, respectively. Membership in Fˆr is determined by computing ˆr(x) and checking it against the specified constraints. A candidate x ∈ F ˆr \ F r is a false positive: it satisfies the constraints under the proxy reward but violates them under the true reward. The archive Ht stores candidates generated through iteration t together with their proxy rewards. The parent-selection policy πt(· | H t) selects K candidates from the archive to form the parent set 

St, which guides candidate generation at the next iteration. We treat {πt}Tt=0 as a given sequence of selection rules; we do not consider a separate policy-learning step. As the archive and its stored rewards change, the selected parents and the resulting candidate generation can nevertheless change across iterations. Algorithm 2 summarizes the proxy-reward-driven search process. At iteration t, the agent uses the previous parents St−1 and their stored rewards to generate a batch 

Ct = {xt, 1, . . . , x t,M } of M new candidates. The proxy reward is computed for each candidate, and the resulting candidate-reward pairs are added to the archive. Candidates whose proxy rewards satisfy the task-specific constraints are also added to the cumulative output set, giving Ot = Ot−1 ∪(Ct ∩F ˆr ).The updated archive is then used to select the next parent set. The archive and output set serve different purposes: the archive retains generated candidates as search experience, whereas the output set contains only candidates that satisfy the proxy-reward constraints.

A candidate is counted as a task hit only when all correspond-ing constraints are satisfied. We provide detailed descriptions of each task in Appendix A.2. We set

To examine whether the higher reliability of CISE is simply a consequence of returning fewer candidates, we perform an equal-budget comparison on the PV task. CISE returns six candidates in this experiment, so we restrict LLEMA to the same downstream validation budget of six structures. Among the proxy-qualified LLEMA outputs, we select the six candidates whose proxy-predicted band gaps are closest to 1.2 eV, representing a natural point-estimate-based prioritization strategy for PV screening. Importantly, this selection is performed before DFT evaluation, so the true-positive and false-positive labels are unavailable when the candidates are ranked. As shown in Table 2, only three of the six selected LLEMA candidates satisfy the PV band-gap constraint after DFT evaluation, while the remaining three are false positives. In contrast, all six candidates returned by CISE are confirmed as true positives. This result indicates that the reliability gain of CISE cannot be explained solely by its smaller output set: even under the same validation budget and a stricter post-hoc truncation of the LLEMA output, point-estimate-based prioritization can still select candidates whose apparent quality is caused by proxy error, whereas interval-based selection excludes such uncertain candidates before expensive validation. 

# 6 CONCLUSION 

In this work, we study reliable self-evolution when accurate true rewards are too expensive to obtain throughout iterative search. We propose CISE, which replaces point-valued proxy rewards with calibrated reward intervals constructed using conditional conformal inference and iteration-wise online density-ratio estimation. These intervals are used for both evolutionary feedback and final candidate selection, allowing proxy-reward uncertainty to directly influence the search process. Under explicit independence and covariate-shift assumptions, we provide fixed-iteration coverage guarantees and characterize the effect of density-ratio estimation error. Across three material-discovery tasks, CISE consistently returns a smaller but more reliable set of candidates, with no observed false positives among its DFT-validated outputs and improved reliability under a matched validation budget. Our results suggest that calibrated interval rewards provide a practical route toward more reliable self-evolving agents when true rewards are costly to obtain. 9Preprint.

A.1 IMPLEMENTATIONS 

Calibration set. We construct the calibration set Dcal using 10,000 material structures from JARVIS-QE-TB (QETB) (Choudhary, 2025). The calibration samples are separated from the model-fitting data at the composition-group level to avoid overlap between the two sets. 

Model-fitting set. We use Dfit consisting of 423,205 structures from QETB to train the conditional quantile regression model. The proxy models remain fixed throughout the evolution process. 

Probe generation. At each generation context, we generate eight valid probe structures using the same parent structures and prompt context as the main candidate generation. These probes are used to characterize the current candidate distribution for online density-ratio estimation. 

Conditional quantile regression. We implement the conditional quantile regression model using a gradient-boosted regression model (HistGradientBoostingRegressor) with quantile loss. The model is trained to predict the conditional 0.95 quantile of absolute proxy error. Its input consists of 27 structural features together with the corresponding proxy prediction. 

CCI features. For conditional conformal inference, the structural features are used to capture heterogeneous proxy uncertainty across materials. The online density ratio estimated from the probe structures and a fixed source set is additionally incorporated into the finite-dimensional Gibbs calibration basis, allowing the calibration procedure to adapt to the candidate distribution at the current generation step. 

DFT evaluation. Selected material structures are evaluated using Quantum ESPRESSO under a PBEsol fixed-structure protocol consistent with the QETB calculations. # B ADDITIONAL EMPIRICAL RESULTS 

Interval rewards mitigate false-positive propagation. Figure 3 qualitatively illustrates how proxy errors can propagate through self-evolving search and how CISE changes this feedback process. In contrast, the corresponding CISE intervals extend beyond the feasible band-gap range, preventing these candidates from being treated as reliable successes under the interval-based criterion. Together, these examples illustrate how interval rewards can suppress the propagation of uncertain proxy successes while retaining candidates whose uncertainty-aware rewards remain feasible.
