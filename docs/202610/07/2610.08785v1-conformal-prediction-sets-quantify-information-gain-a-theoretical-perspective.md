## 摘要
共形预测是一种流行的不确定性量化工具，它输出具有有限样本覆盖保证的预测集。尽管预测集大小通常被用作不确定性的启发式度量，但这种解释的信息论基础仍然理解不足。在这项工作中，我们通过一种面向集合值预测的熵的决策论推广，提供了这样的基础。特别地，我们引入了一族基于共形预测集的大小和覆盖率的广义信息度量。值得注意的是，香农互信息可以用这些度量给出精确的积分表示。然后我们表明，在标准分类设置中，由额外信息带来的共形集大小缩减 (i) 被夹在该族中依赖于校准的成员之间，并且 (ii) 满足数据处理不等式，二者均在有限样本校准和模型误差项意义下成立。总之，我们的结果正式将共形预测与经典信息论量联系起来，并证明了使用集合大小缩减作为信息增益度量是合理的。在实验上，我们在 11 个分类设置中验证了我们的理论，并表明在贪心特征选择实验中，集合大小缩减与香农互信息可能对特征给出不同的排序。

## Abstract
Conformal prediction is a popular tool for uncertainty quantification that outputs prediction sets with finite-sample coverage guarantees. While prediction set size is commonly used as a heuristic measure of uncertainty, the information-theoretic basis for this interpretation remains poorly understood. In this work, we provide such a foundation using a decision-theoretic generalization of entropy tailored to set-valued prediction. In particular, we introduce a family of generalized information measures based on the size and coverage of conformal prediction sets. Notably, Shannon mutual information admits an exact integral representation in terms of these measures. We then show that, in standard classification settings, the reduction in conformal set size from additional information (i) is sandwiched between calibration-dependent members of this family and (ii) obeys a data processing inequality, both up to finite-sample calibration and model error terms. Together, our results formally relate conformal prediction to classical information-theoretic quantities and justify using set-size reduction as an information gain metric. Empirically, we validate our theory across 11 classification settings and show that set-size reduction and Shannon mutual information can rank features differently in a greedy feature selection experiment.

## 2. 方法论：核心思想与关键技术细节

- **决策论广义熵与互信息**：
  - 固定动作空间 \(\mathcal A\) 与损失 \(\ell\)，定义广义熵  
    \[
    H_\ell(Y|X)=\mathbb E\left[\inf_{a\in\mathcal A}\mathbb E[\ell(Y,a)|X]\right]
    \]
  - 广义互信息  
    \[
    I_\ell(X;Y|Z)=H_\ell(Y|Z)-H_\ell(Y|X,Z)\ge 0
    \]
  - 香农熵是取动作空间为概率单纯形、损失为对数损失时的特例。

- **共形熵与共形互信息**：
  - 对集合值预测 \(\Gamma\subseteq\mathcal Y\)，定义损失  
    \[
    \ell_\lambda(Y,\Gamma)=|\Gamma|+\frac1\lambda \mathbf 1(Y\notin\Gamma)
    \]
    同时惩罚预测集过大与未覆盖真实标签。
  - 定义共形熵  
    \[
    H_\lambda(Y|X)=\mathbb E\left[\inf_{\Gamma\subseteq\mathcal Y}\mathbb E[\ell_\lambda(Y,\Gamma)|X]\right]
    \]
    以及共形互信息  
    \[
    I_\lambda(X;Y|Z)=H_\lambda(Y|Z)-H_\lambda(Y|X,Z)
    \]
  - 最优集合预测器为概率超水平集  
    \[
    \Gamma_\lambda^*(X;p)=\{y:p(y|X)\ge \lambda\}
    \]
    这正好对应概率分数共形预测集，校准阈值满足 \(\hat\lambda_\alpha=-\hat\tau_\alpha\)。

- **香农互信息的精确积分表示**：
  - 论文证明  
    \[
    I(X;Y|Z)=\int_0^1 I_\lambda(X;Y|Z)\,d\lambda
    \]
    即香农互信息是共形互信息族在 \(\lambda\in(0,1]\) 上的均匀平均。
  - 这意味着共形互信息对应香农互信息的“局部切片”，而集大小缩减只与校准阈值附近的 \(I_\lambda\) 相关。

- **概率分数下的夹逼定理**：
  - 定义训练条件误覆盖 \(\varepsilon^{(i)}\)、校准阈值 \(\hat\lambda_\alpha^{(i)}\)、模型误差散度 \(D^{(i)}\)，以及集大小缩减  
    \[
    \Delta_\alpha=\mathbb E|C_\alpha(X^{(1)})|-\mathbb E|C_\alpha(X^{(2)})|
    \]
  - 主要夹逼形式为  
    \[
    I^{(2)}-D^{(2)}+\frac{\varepsilon_\Delta}{\hat\lambda_\alpha^{(2)}}
    \le \Delta_\alpha \le
    I^{(1)}+D^{(1)}+\frac{\varepsilon_\Delta}{\hat\lambda_\alpha^{(1)}}
    \]
    其中 \(I^{(i)}=I_{\hat\lambda_\alpha^{(i)}}(X;Y|Z)\)。
  - 在期望意义下，校准项可由 \(O(1/\sqrt n)\) 控制，得到  
    \[
    \mathbb E[I^{(2)}]-\mathbb E[D^{(2)}]-s^{(2)}/\sqrt n
    \le \mathbb E[\Delta_\alpha]
    \le
    \mathbb E[I^{(1)}]+\mathbb E[D^{(1)}]+s^{(1)}/\sqrt n
    \]

- **数据处理不等式（DPI）**：
  - 若 \(Y\to(X,Z)\to(\tilde X,Z)\) 构成 Markov 链，则退化特征 \(\tilde X\) 带来的集大小缩减 \(\tilde\Delta_\alpha\) 满足近似 DPI：  
    \[
    \tilde\Delta_\alpha \le \Delta_\alpha + D^{(2)}+\frac{\tilde\varepsilon^{(2)}-\varepsilon^{(2)}}{\hat\lambda_\alpha^{(2)}}
    \]
  - 期望版本为  
    \[
    \mathbb E[\tilde\Delta_\alpha]\le \mathbb E[\Delta_\alpha]+\mathbb E[D^{(2)}]+s^{(2)}/\sqrt n
    \]

- **APS 分数扩展**：
  - 对 APS 分数，校准阈值不再是全局常数，而是输入相关随机阈值 \(\hat\Lambda_\alpha\)。
  - 引入随机索引 \(\Lambda\) 与随机化变量 \(U\)，定义随机 \(\Lambda\) 下的共形熵、互信息和散度。
  - 证明 APS 版本的夹逼定理与 DPI，形式类似，但校准项含条件误覆盖和 \(1/\hat\Lambda_\alpha\)，通常额外松弛更大；在 oracle 模型下部分松弛可消失。
