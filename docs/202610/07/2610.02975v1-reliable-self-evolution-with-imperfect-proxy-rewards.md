## 摘要
基于大语言模型（LLM）的自演化搜索是科学发现的一种有前景的方法。然而，在某些领域中，对每个候选进行高保真评估的成本高得令人望而却步。因此，这类场景下的自演化系统依赖低成本但不完美的代理奖励，这可能给不可行的候选赋予高分。这些假阳性可能同时污染最终输出以及用于指导后续代际生成的反馈。这促使我们采用经统计校准的奖励区间，以实现更可靠的自演化搜索。我们提出共形区间驱动自演化（Conformal Interval-Driven Self-Evolution, CISE），它利用条件共形推断和逐迭代在线密度比估计来构造候选特定的奖励区间。CISE 将保守的基于区间的奖励用于演化反馈，并且仅当所有所需性质区间都完全落在各自可行区域内时才返回候选。我们在独立性和协变量偏移的明确假设下推导了固定迭代的覆盖性结果。我们在材料科学的三个自演化搜索任务上评估 CISE。在实验中，CISE 返回的所有候选在高保真评估下均为真阳性，而基线方法返回更多候选，但包含假阳性。这些结果凸显了下游验证预算有限时，更小、更精确的候选短名单的价值。我们的代码仓库见 https://github.com/MLAI-Yonsei/CISE.git。

## Abstract
Large language model (LLM)-based self-evolving search is a promising approach to scientific discovery. However, high-fidelity evaluation of every candidate is prohibitively expensive in some domains. Self-evolving systems in such settings therefore rely on low-cost but imperfect proxy rewards, which may assign high scores to infeasible candidates. These false positives may contaminate both the final output and the feedback used to guide subsequent generations. This motivates statistically calibrated reward intervals for more reliable self-evolving search. We propose Conformal Interval-Driven Self-Evolution (CISE), which constructs candidate-specific reward intervals using conditional conformal inference and iteration-wise online density-ratio estimation. CISE uses conservative interval-based rewards for evolutionary feedback and returns candidates only when all required property intervals lie entirely within their respective feasible regions. We derive fixed-iteration coverage results under explicit assumptions of independence and covariate shift. We evaluate CISE on three self-evolving search tasks in materials science. In our experiments, all candidates returned by CISE are true positives under high-fidelity evaluation, whereas the baselines return more candidates but include false positives. These results highlight the value of a smaller, more precise shortlist when downstream validation budgets are limited. Our repository is available at https://github.com/MLAI-Yonsei/CISE.git.
