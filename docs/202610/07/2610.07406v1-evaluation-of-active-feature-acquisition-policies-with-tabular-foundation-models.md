## 摘要
主动特征获取学习按序获取特征以最大化关于目标变量信息的策略。我们研究如何利用先验数据拟合网络（PFNs）从有限离线数据中学习和评估此类策略；PFNs 是无需任务特定训练即可输出后验预测分布的现成模型。我们表明，在离线数据覆盖不均衡的情况下，使用总预测熵作为奖励会产生认知偏差，惩罚获取稀疏观测的特征。具体而言，该奖励将认知不确定性（源于缺乏离线数据）与偶然不确定性（源于无信息特征）混为一谈。为解决这一问题，我们针对后验期望（偶然）熵来评估特征获取，而不是 PFN 输出的总预测熵。在合成和真实数据集上的实证评估表明，我们的方法持续减少价值估计偏差，并产生具有强经验覆盖率的可信区间，这可以转化为下游策略选择的改进。

## Abstract
Active feature acquisition learns policies that sequentially acquire features to maximize information about a target variable. We study how to learn and evaluate such policies from finite offline data using prior-data fitted networks (PFNs), which are off-the-shelf models that output posterior predictive distributions without task-specific training. We show that under the imbalanced coverage of offline data, using total predictive entropy as a reward creates an epistemic bias that penalizes acquiring sparsely observed features. Specifically, this reward conflates epistemic uncertainty (arising from lack of offline data) with aleatoric uncertainty (arising from uninformative features). To address this, we target the posterior expected (aleatoric) entropy instead of the total predictive entropy output by a PFN for evaluating feature acquisitions. Empirical evaluations on synthetic and real-world datasets demonstrate that our approach consistently reduces value estimation bias and yields credible intervals with strong empirical coverage, which can translate to improved downstream policy selection.

# 论文总结：使用表格基础模型评估主动特征获取策略

## 1. 核心问题与整体含义

- **研究背景**：主动特征获取（Active Feature Acquisition, AFA）将特征采集建模为序贯决策问题，在临床风险预测等场景中，采集完整信息受成本、延迟或物理风险限制（如侵入性 CSF 采样）。AFA 策略需要动态决定“下一步测哪个特征”以最大化对目标变量的信息。
- **核心问题**：在离线数据上评估候选 AFA 策略（off-policy evaluation, OPE）是学习/优化策略的前提。作者指出：当离线数据由未知的行为策略生成、存在**回顾性缺失**与**覆盖不均衡**时，直接使用 PFN 输出的**总预测熵**作为奖励会引入**认知偏差（epistemic bias）**。
- **偏差来源**：总预测熵 = 偶然不确定性（aleatoric，源于特征本身无信息或内在噪声）+ 认知不确定性（epistemic，源于离线数据不足）。在稀疏覆盖区域（如仅在低危亚组采集的 CSF），认知不确定性被错误地当作“该特征信息量大”而抬高，导致对获取稀疏观测特征的**信息增益被系统性低估**。
- **整体含义**：论文提出用**后验期望（偶然）熵**替代总预测熵来评估特征获取，从而获得去偏的策略价值估计，并借助表格基础模型（PFN）实现免任务特定训练的贝叶斯推断。

## 2. 方法论

### 2.1 核心思想：不确定性分解
- 将总预测熵分解为：
  - **偶然不确定性** \(U_a(s_T) = \mathbb{E}[H(Y|s_T, \tilde{P})|z_{1:n}]\)：不可通过采集更多数据消除。
  - **认知不确定性** \(U_e(s_T) = I(Y; \tilde{P}|s_T, z_{1:n})\)：随样本量增大趋近于 0。
- 目标函数（式 1）：策略价值 = 终态期望熵的负值 − 确定性采集成本：
  \[
  G(P_{tar}) = -H(Y|S^{(\pi_\alpha)}_T, P_{tar}) - \mathbb{E}_{\tau}\left[\sum_{t=0}^{T-1} c(A_t)\right]
  \]
- 代理目标与真实目标的差恰为终态认知不确定性：\(\hat{J}(\pi) = J(\pi) - U_e(S^{(\pi)}_T)\)，由此推出后悔上界（式 7）：
  \[
  0 \le J(\pi^*) - J(\hat{\pi}) \le U_e(S^{(\pi^*)}_T) - U_e(S^{(\hat{\pi})}_T)
  \]
  即代理目标会惩罚终态落在数据稀疏区域的策略。

### 2.2 贝叶斯预测推断（BPI）
- 不显式指定先验-似然对，而是用**一步预测分布序列** \((P_i)_{i\ge0}\) 进行贝叶斯估计；由 de Finetti 表示定理与鞅性质保证极限测度 \(F_\infty\) 存在，有限样本下 \(F_\infty|z_{1:n}\) 的后验即为认知不确定性来源。
- 两种实例化方式：
  - **鞅后验（Martingale Posterior）**：用 PFN 初始化 \(P_0\)，随后通过 Copula 更新与**预测重采样**（自回归模拟伪观测）近似 \(F_\infty|z_{1:n}\)。
  - **预测中心极限定理（Predictive CLT）**：避免重采样，用预测序列增量 \(\Delta_k = P_k - P_{k-1}\) 的波动率估计协方差 \(V_n = \frac{1}{n}\sum k^2 \Delta_k \Delta_k^T\)，得到渐近正态后验，再通过矩匹配与高斯 Copula 转换为 Beta 边缘。

### 2.3 AFA 策略价值的贝叶斯估计流程
- **识别条件**：正性（Positivity）、缺失随机（MAR）、无直接效应（NDE）。
- **点估计**：采用逆倾向加权（IPW）估计 \(\bar{G}(P_{obs}) = \mathbb{E}[w_T(\tau) H(Y|S_T)]\)，其中轨迹级权重
  \[
  w_T(\tau) = \frac{I[R \ge R_T]\prod_t \pi_\alpha(A_t|S_t)}{\pi_\beta(R \ge R_T|X_o)\prod_t \pi_{sim}(A_t|S_t,R)}
  \]
  模拟器 \(\pi_{sim}\) 为被“阻断”的目标策略（不可采集未观测特征），避免对反事实特征值建模。
- **后验构造**：对 \(\mu = P(Y|S_T)\)、\(\pi_\beta\) 放置独立先验，后验因子分解；用 BPI 抽取函数后验样本，用**贝叶斯自助法**处理 \(d_{S_T}\) 的非参数后验；最后对偶然熵取后验均值得到去偏价值估计 \(\hat{U}_a(S_T) = \mathbb{E}_{F_\infty|z_{1:n}}[\tilde{G}(P_{obs})]\)。

## 3. 实验设计

### 3.1 数据集与场景
- **合成数据（3 类 DGP，每类 200 个随机 DGP）**：
  - Linear：类条件独立高斯，线性决策边界。
  - GMM：每类混合各向同性高斯，非线性边界。
  - BNN：随机单隐层 MLP，Bernoulli 输出。
  - 缺失机制：随机线性 MAR，不同特征缺失率不同（覆盖不均衡）。
- **OpenML 表格基准**：Adult、Credit、Electricity、Magic Telescope、HIGGS、Default Credit Card、Covertype、California（共 8 个），注入不同缺失率的 MCAR 缺失。
- **真实临床场景（ICU Sepsis）**：PhysioNet/CinC 2019 脓毒症任务，29 个特征，按临床检验面板（血气、CBC、凝血、乳酸、肝功、代谢）分组，天然缺失，倾向模型用 logistic 拟合。

### 3.2 Benchmark 与对比方法
- **参考值**：合成数据用闭式解；真实数据用无缺失的大样本 oracle 数据集。
- **6 种估计器**：
  - 总不确定性（有偏）：(1) Total (plug-in)、(2) Total (bootstrap)。
  - 偏差校正的偶然估计器：(3) Bootstrap、(4) Marginal、(5) Copula、(6) CLT。
- **评估指标**：点估计偏差（绝对/带符号）、95% 可信区间覆盖率与宽度、策略排序的成对准确率、后悔值。

### 3.3 模型
- 合成实验：从零训练 PFN（约 3.17M 参数，6 层、宽度 256、4 头），以贴近理想贝叶斯极限。
- 真实数据：使用现成 **TabICL-V2** 作为 PPD 估计器。

## 6. 主要结论与发现

- **总预测熵导致系统性负偏差**：Total (plug-in) 与 Total (bootstrap) 在所有合成 DGP 上均低估真实特征获取价值，偏差大小与终态在离线数据中的覆盖稀疏程度正相关。
- **偶然熵估计器去偏有效**：Bootstrap、Marginal、CLT、Copula 等偶然估计器显著减小绝对偏差，合成数据上成对准确率提升（高缺失率下增益最大，如 BNN 在缺失率 0.3–0.4 时 CLT/Marginal 提升约 +0.01~0.02，p<0.05）。
- **联合采样对覆盖至关重要**：Marginal 与 CLT 点估计几乎相同，但 CLT 的 95% 覆盖率显著优于 Marginal，说明必须对 \(Y|S_T\) 做函数型后验抽样。
- **Copula 存在欠覆盖**：在协变量重叠差的区域（如 California、HIGGS）低估不确定性，与既有文献一致。
- **真实数据结果混合**：Sepsis 上偏差校正估计器降低偏差、CLT 覆盖良好、后验散布与低估负相关（ρ≈−0.57/−0.61），但**下游策略排序未显著改善**，作者归因于 TabICL 的近似误差与校正量相对策略价值差距不够精确。
- **理论刻画**：代理目标与真实目标的差恰为终态认知不确定性，给出后悔上界。

## 7. 优点

- **理论清晰**：严格证明总熵目标与偶然熵目标的差异等于终态认知不确定性，并给出后悔界，把“偏差”问题形式化。
- **方法实用**：将 BPI 与现成表格基础模型（TabPFN/TabICL）无缝结合，无需任务特定训练、无需显式先验设计与超参调优，可扩展性好。
- **识别框架严谨**：沿用 AFA OPE 的因果识别假设（Positivity、MAR、NDE），通过阻断模拟器避免对反事实特征建模，权重设计合理。
- **实验设计客观**：合成数据使用闭式真值，避免基准污染；提供多维度诊断（偏差、覆盖、宽度、排序、后悔、后验收缩、相关性分析）。
- **消融有针对性**：清晰分离“点估计偏差”与“不确定性传播”两个问题，揭示 Marginal 与 CLT 的覆盖差异。

## 8. 不足与局限

- **真实场景排序改善有限**：Sepsis 与 OpenML 基准上，去偏估计器未带来统计显著的下游策略选择提升，削弱了“去偏→更好决策”的实践说服力。
- **依赖模型质量**：结果受限于 TabICL 的 PPD 估计精度；作者承认真实数据参考值本身也是估计值，且 TabICL 未必能产生理想的偶然熵估计。
- **规模限制**：仅关注中小规模数据集（样本量 100–2000 量级），作者明确将大规模扩展留作未来工作。
- **估计器选择保守**：仅使用标准 IPW，未采用双重稳健/半参数估计器（如 DRL），理论上更强的渐近保证尚未纳入。
- **假设较强**：MAR、正性、NDE、静态特征等假设在复杂真实场景（如灵活缺失机制、时序依赖）可能不成立。
- **算力报告不完整**：未给出训练时长与总计算量，复现成本不够透明。
- **Copula 欠覆盖风险**：在低重叠区域不确定性被低估，可能误导策略选择。
