# Abstract 

Matrix completion underlies problems from tabular imputation to causal infer-ence, yet existing tabular foundation models treat it as entry-by-entry prediction, repeating context for every target and discarding the matrix’s two-dimensional structure. We introduce MatrixFormer, a pre-trained matrix-native transformer that predicts a full distribution for every missing entry in a single forward pass. Matrix-Former is trained entirely on synthetic low-rank and latent-factor matrices under diverse missingness patterns. Applied zero-shot and with the same model weights, MatrixFormer achieves competitive performance on causal inference panel-data tasks, language-model benchmark-score completion, tabular imputation, and rec-ommendation systems matrix completion. These results position MatrixFormer as a general-purpose foundation model for matrix completion. 

# 1 Introduction 

Clinical measurements, user ratings, and language-model benchmark scores [Smola, 2026] are often recorded in partially observed matrices. Predicting untreated outcomes in panel data creates a related completion problem [Athey et al., 2021]. Across these settings, observed entries supply information about both rows and columns. We study how to pretrain a completion model that can use this information across different matrix sizes and observation patterns. Low-rank methods capture matrix structure through shared row and column factors [Candès and Recht, 2009, Salakhutdinov and Mnih, 2007], while chained-equation and model-selection imputers fit conditional prediction models [van Buuren and Groothuis-Oudshoorn, 2011, Jarrett et al., 2022]. These methods estimate their parameters from the observed entries of each new matrix. Synthetic pretraining moves part of that computation into a reusable model. Prior-data fitted networks learn prediction rules from synthetic tasks, then use observations from a new dataset as context [Müller et al., 2022, Hollmann et al., 2025]. TabImpute [Feitelberg et al., 2025] applied synthetic pretraining to missing-data imputation. Its configurable missingness generator produces specialists for particular observation patterns. An entry-wise representation makes tabular prediction models applicable to completion: each matrix entry becomes a supervised example containing its row and column context. An R × C matrix therefore produces a table of RC examples whose features repeat the same observed values. This expansion raises the memory and runtime cost of completing larger matrices. We replace the expanded feature table with a shared two-dimensional representation. We introduce MatrixFormer , an observed-error ensemble of two fixed pretrained experts: the general-purpose MatrixFormer-Impute and the recommender-specific MatrixFormer-RecSys .MatrixFormer-Impute is a transformer pretrained for matrix completion. The input is a grid of cell

tokens with explicit missingness indicators. Attention alternates across the columns of each row and the rows of each column, following work on axial and cross-datapoint attention [Ho et al., 2019, Kossen et al., 2021, Rao et al., 2021, Hollmann et al., 2025]. These operations let a cell combine information about other measurements of the same unit with information about the same measurement across units. A shared decoder predicts all missing entries in an inference window together, using the means of its cellwise predictive distributions. In the fixed-width runtime experiment on an NVIDIA H200, MatrixFormer completes the 1024 × 10 synthetic matrix in a median of 0.0389 s, compared with 4.167 s for TabImpute. This is a 107 × speedup (section 3.1). MatrixFormer-Impute is trained entirely on synthetic matrices with varied ranks, singular-value profiles, dimensions, and missingness patterns. The training distribution includes sparse rows and columns to model limited observation support. At deployment, observed entries provide context and the model weights remain fixed. MatrixFormer combines MatrixFormer-Impute with MatrixFormer-RecSys, a recommender specialist also trained on synthetic data. One mixture weight per input matrix minimizes the blend’s normalized squared reconstruction error on observed entries. Both networks retain their pretrained parameters. Since the observed entries are also part of the input, this fit uses in-sample evidence. We assess the blend on separately hidden entries. MatrixFormer requires both expert forward passes. We evaluate on tabular imputation, recommender-system rating prediction, language-model bench-mark completion, and a causal panel-data benchmark. Across these tasks, we test dense and sparse observation patterns and matrices much larger than those used in pretraining. MatrixFormer achieves state-of-the-art results in each of these categories with the same fixed model parameters. 

# 2 Architecture and Training 

Both MatrixFormer-Impute and MatrixFormer-RecSys use the following architecture; MatrixFormer ensembles their predictions as described in section 3.2. Let X ∈ (R ∪ { NaN })R×C denote a partially observed matrix and let M ∈ { 0, 1}R×C be its missingness mask, with Mrc = 1 when Xrc is unobserved. We suppress the batch dimension throughout. The central design choice in MatrixFormer-Impute is to preserve this two-dimensional structure throughout the network. This differs from TabImpute [Feitelberg et al., 2025], which converts imputation into a supervised prediction problem by constructing an entry-level example containing the corresponding row and column context. That representation makes a strong tabular foundation model directly applicable, but it repeats context across target entries. MatrixFormer-Impute instead applies transformer self-attention [Vaswani et al., 2017] directly to a grid of cell tokens, propagating information along the matrix’s two natural axes.

2.1 Synthetic pre-training 

As in prior-data fitted networks [Müller et al., 2022, Hollmann et al., 2023, 2025] and TabImpute [Feit-elberg et al., 2025], MatrixFormer-Impute is pre-trained only on synthetic complete matrices, masked to define reconstruction tasks. Pre-training has three phases with the same architecture, each contin-uing from a selected checkpoint of the previous one: a base phase on small latent-factor matrices with MCAR masking; a main phase with the more diverse data and objective described below; and a short size-extension phase on matrices with up to 2000 rows and 1000 columns. The last phase is analogous to context-length extension in language models [Chen et al., 2023]: because attention cost grows with matrix size, most training uses moderate sizes, and a brief final phase adapts the model, including the range of its rotary positions, to large matrices. Section A.3 gives all settings. 

Data. The main phase mixes four equally likely matrix families: low-rank signals [Candès and Recht, 2009], two broader-rank spectral families with slow or steep tails, as in many real data matrices [Udell and Townsend, 2019], and latent-factor matrices [Salakhutdinov and Mnih, 2007]. This prior varies not only rank but also spectral shape, singular-vector geometry, matrix dimensions, and the amount and pattern of observed support. We distinguish the complete target T ∈ RR×C from the complete, potentially noisy input A ∈ RR×C ; masking and normalization subsequently produce the network input X and standardized target y.

# 3 Results 

We introduce our method MatrixFormer, a convex blend of two expert models MatrixFormer-Impute and MatrixFormer-RecSys, and evaluate it against standard benchmarks on a variety of domains such as causal inference, imputation, recommendation systems, and LLM evaluation.

3.4 Tabular imputation: MissBench and UCI 

We evaluate missing-value imputation on two suites. MissBench is the OpenML-based suite used with TabImpute [Feitelberg et al., 2025]: 42 datasets under eleven missingness mechanisms at the nominal 40% setting, for 462 cases. Our local UCI-style suite, motivated by HyperImpute [Jarrett et al., 2022], contains 12 datasets under MCAR, MAR and MNAR at 10%, 20%, 30%, 40% and 50% nominal missingness with ten repeats per setting, for 1,800 cases. Neither suite has a row train/test split: all rows and columns are retained, observed entries provide context, and predictions are scored only on the masked cells. We retain every dataset and case rather than a subset selected by performance or CACTI’s ten-dataset list; published CACTI scores [Gorla et al., 2025] are not directly comparable to this no-row-holdout protocol.

3.6 Benchmark-score completion for language-model evaluation 

Evaluating a language model on every benchmark is expensive. We study whether MatrixFormer can reconstruct a model’s unmeasured benchmark scores after observing a small subset of its evaluations. Rows represent models and columns represent benchmark tasks; this is score-matrix completion, not a new evaluation of generated answers. # 4 Conclusion 

We introduced MatrixFormer, a model for matrix completion that represents a partially observed matrix as a grid of cell tokens, alternates attention over rows and columns, and is pretrained only on synthetic matrices. With no fine-tuning, the same model was applied to tabular imputation, rating prediction, benchmark-score completion for language models and causal panel data. It has the lowest overall error on both imputation suites, lower rating error than the collaborative-filtering baselines on MovieLens 100K and Netflix small, higher R2 than the Gaussian estimator on three of the four benchmark-score matrices, and the lowest normalized score in five of the six causal-panel comparisons. A single forward pass completes a 1024 × 10 matrix 107 × faster than TabImpute; MatrixFormer uses two such passes. A.3 Pre-training Teachers. The teachers ψ1 and ψ2 in eq. (11) are the best synthetic-validation checkpoints of two earlier 64k-update main-phase runs from the same base-phase model. Both were trained with eq. (11) using the true value yrc in place of ¯μrc , one on the mixture of section 2.1 and one on a continuous-spectrum variant of it. 

Base phase. The base phase trains on latent-factor matrices of rank 1–11 with 10–50 rows, 5–50 columns and 40% MCAR missingness for 17k updates, using AdamW (peak learning rate 2 × 10 −4,weight decay 0.025 ) with BF16 parameters and optimizer state. 

Main phase. Each episode draws one of eight equally weighted components: four families, each with two masking mechanisms. MCAR hides each entry independently with probability 0.4. The mixed mechanism draws, per matrix, MCAR (probability 0.30), MAR (0.20), MNAR (0.20) or a structured MNAR pattern: censoring below or above a quantile (0.10), two-phase subsampling (0.10), skip logic (0.05) or cluster-level missingness (0.05). Its missing rate is 0.4 with probability 0.25 and otherwise 0.05 + 0 .7B with B ∼ Beta(2 , 2) . Spectral matrices have 80–320 rows and 35–100 columns; latent-factor matrices keep their base-phase sizes and are included as rehearsal [Robins, 1995] because training on spectral matrices alone degraded performance on them. Singular vectors come from random orthogonal, coherent, smooth or offset-bearing bases with equal probability. A sparse-support episode transposes the matrix with probability one half, picks 10–40% of its rows, and keeps each picked row’s observed entries in only a random log-uniform 1–60% of the columns; 

S is the set of hidden entries in the picked rows. Each column is standardized with the mean and standard deviation of its observed entries. In sparse-support episodes, where some columns keep few observed entries, the variance of column c is instead estimated as (SS c + ¯ v)/(nc + 1) , where 

nc and SS c are the number and centered sum of squares of its observed entries and ¯v is the pooled within-column variance. AdamW uses β = (0 .9, 0.999) . The 128k horizon was chosen because an 15 otherwise identical 64k run was still improving when it ended. Validation every 2k updates on a fixed synthetic suite selects the checkpoint with the lowest macro RMSE, reached after 98k updates. 

Size-extension phase. Starting from the selected main-phase checkpoint, this phase runs 5k updates with the same objective and teachers. The row/column ranges grow from 256–512/128–256 (updates 1–500) to 512–1024/256–512 (501–1500), 768–1536/384–768 (1501–3000) and 1024–2000/512– 1000 (3001–5000); with probability 0.2 an episode is instead drawn at the main-phase sizes. Each update accumulates the matrix-mean losses of two independently sampled matrices. The peak learning rate is 5 × 10 −6, with 200 warmup updates and cosine decay to 5% ; the other optimizer settings are unchanged. Activation checkpointing [Chen et al., 2016] and microbatching of attention sequences, feed-forward cells and decoding keep memory bounded without shortening any attended sequence. Selection minimizes the mean macro RMSE, relative to the starting checkpoint, on fixed synthetic panels of main-phase-sized and large matrices, subject to the error on the former rising by at most 3%; it selects the checkpoint after 4k updates.
