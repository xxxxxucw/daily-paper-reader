## 摘要
从观测数据中估计处理效应通常依赖于无未测量混杂假设（NUCA），而该假设在实践中很少成立。近端因果学习（PCL）通过代理变量来处理未测量混杂，但现有方法要求代理变量预先指定。因此，我们提出 PCL-U，一个直接从观测协变量中学习代理变量的框架。PCL-U 使用神经编码器将协变量分解为处理诱导型、结果诱导型和共享代理变量，并以极小极大互信息目标为指导，通过实用的基于矩的风险函数获得因果估计。基准实验表明，PCL-U 与现有基线持平或优于现有基线。此外，两类具有不同维度和混杂强度的合成数据集表明，我们的方法能保持稳定的估计精度。

## Abstract
Estimating treatment effects from observational data typically relies on the No Unmeasured Confounding Assumption (NUCA), which rarely holds in practice. Proximal causal learning (PCL) addresses unmeasured confounding via proxy variables, yet existing methods require the proxy variables to be pre-specified. Thus, we propose PCL-U, a framework that learns proxy variables directly from observed covariates. PCL-U uses neural encoders to decompose covariates into treatment-inducing, outcome-inducing, and shared proxies, guided by minimax mutual information objectives, and obtains causal estimates through a practical moment-based risk function. Experiments on benchmarks show that PCL-U matches or outperforms existing baselines. Besides, there are two types of synthetic datasets with varying dimensions and confounding strengths that illustrate that our method maintains stable estimation accuracy.

# 论文总结：未测量混杂下的近端因果学习（PCL-U）

## 1. 核心问题与整体含义（研究动机与背景）

- **现实痛点**：从观测数据估计处理效应（ATE）通常依赖**无未测量混杂假设（NUCA）**，即所有混杂因素均可观测。但该假设在实践中几乎无法验证、也极少成立；一旦存在潜在混杂因素 U，估计将产生偏倚。
- **现有路线及其局限**：
  - **基于表示学习的方法**（CFR-MMD/WASS、SITE、ABCEI、CBRE、DRRL、CITE、DeR-CFR、DDRN 等）通过平衡表示或分解协变量来缓解**可观测**混杂，但本质上仍依赖 NUCA，无法处理隐藏混杂。
  - **近端因果学习（PCL）**（Miao et al., 2018；Tchetgen et al., 2020）借助三类代理变量——处理诱导型 Z、结果诱导型 W、共享型 X——在存在 U 的情况下识别因果效应，但现有方法（DFPV、NMMR、DML-CMR 等）**要求代理变量事先由领域知识指定**。
- **论文目标**：提出 **PCL-U**，首次将**代理变量学习**与**表示学习**结合，直接从观测协变量 C 中自动学习代理变量，并端到端地完成神经桥函数估计，从而摆脱对预先指定代理变量的依赖。

## 2. 方法论

### 2.1 核心思想
- 使用三个神经编码器 Φ_Z、Φ_X、Φ_W 将观测协变量 C 映射为学习到的代理表示 **Ẑ、X̂、Ŵ**；
- 通过**极小极大互信息（MI）目标**引导各编码器扮演其“指定角色”：
  - **Ẑ（处理诱导代理）**：保留与处理 A 相关的信息，排除对 Y 的额外信息；
  - **Ŵ（结果诱导代理）**：保留与结果 Y 相关的信息，排除对 A 的额外信息；
  - **X̂（共享代理）**：同时保留与 A 和 Y 均相关的混杂信息。
- 再以学习到的代理为输入，用**基于矩的桥函数估计（NMMR-V 形式）**得到反事实均值与 ATE。

### 2.2 关键技术细节

- **变分条件拟合**：对任意变量对 (S, T)，用神经网络 q_θ(T|S) 近似条件分布，最小化负对数似然 L_LLD。
- **MI 相关性/排他性代理目标**：以正负样本条件对数似然差构造 MI 估计式 L_MI；**最大化** L_MI 作为相关性代理（保留信息），**最小化** L_MI 作为排他性代理（排除信息）。
- **具体角色训练**：
  - Ẑ：最大化 L_MI(Ẑ; A)（相关性），最小化 L_MI(Ẑ; Y)（排他性）；
  - Ŵ：最大化 L_MI(Ŵ; Y)，最小化 L_MI(Ŵ; A)；
  - X̂：同时最大化 L_MI(X̂; A) 与 L_MI(X̂; Y)。
- **正交正则项 L_O**：将各编码器从输入到最后一层的有效权重矩阵取绝对值并按行平均得到向量 v_R，惩罚三个向量间的两两点积（v_Z^T v_X + v_Z^T v_W + v_X^T v_W），促使不同编码器关注不同协变量子集，实现角色特化。
- **桥函数估计（NMMR-V）**：以核函数 k(G, G′) = exp(−‖G−G′‖²/(2ℓ²))（G = (ẑ, a, x̂)）构造经验矩损失 L_h，训练两个结果桥网络 h_0、h_1 满足 E[Y − h(W, A, X) | A, X, Z] = 0。
- **总目标函数**：
  - L_total = α·L_proxy + β·L_O + γ·L_h + λ‖θ_h‖²
  - 其中 L_proxy = L_LLD + L_MI，四项权重分别为 α、β、γ、λ。
- **识别假设**：一致性/正性、潜在可交换性与条件独立性（Y ⊥ Z | A,U,X；W ⊥ (A,Z) | U,X）、完备性（要求代理信息足够丰富，连续情形以 min(d_z, d_w) ≥ d_u 作为结构启发式）。
- **ATE 估计**：τ̂_POR = (1/N) Σ [h_1(Ŵ_i, X̂_i) − h_0(Ŵ_i, X̂_i)]。

### 2.3 算法流程（文字版）
1. 输入数据 {(c_i, a_i, y_i)} 与超参数 α、β、γ、λ；
2. 初始化三个编码器、六个变分网络、两个桥网络；
3. 循环 T 步：采样 mini-batch → 计算归一化代理 Ẑ、X̂、Ŵ → 计算 L_proxy 与 L_O → 计算桥损失 L_h → 合成 L_total → Adam 联合更新全部参数；
4. 输出学习到的代理、桥网络及 τ̂_POR。

## 3. 实验设计

### 3.1 数据集 / 场景

## 6. 主要结论与发现

- **标准基准表现**：
  - IHDP：样本外 PEHE 0.461、ε_ATE 0.129，均为最低；PEHE 相对最佳基线 DeR-CFR（0.566）降低 **18.6%**；样本内 PEHE 降低 **23.8%**。
  - Twins：AUC 0.873（最高）、ε_ATE 0.007（最低，相对最佳基线降低 **22.2%**）。
  - Jobs：DDRN 在 R_pol 最优，PCL-U 在 ε_ATT 上样本内最优（0.029），样本外与最佳基线接近。
- **合成数据表现**：
  - 随 **混杂强度增加**，PCL-U 优势更明显：h 设置下误差 0.084，较 CBRE 降低 **56.9%**，较 NMMR（0.128）也更好；

- **总体判断**：PCL-U 能在**不预设代理变量**的情况下达到与使用真代理的 NMMR 相当甚至更优的经验性能，并优于依赖 NUCA 的主流方法。

## 7. 优点

- **问题切入新颖**：首次将代理变量学习与表示学习统一到一个端到端框架，消除了 PCL 对专家预设代理的依赖，拓展了 PCL 的实用边界。
- **方法设计自洽**：MI 相关性/排他性代理目标 + 正交正则 + NMMR 桥估计，三层机制相互配合，理论动机（Assumption 2）与实现细节对应清晰。
- **实验覆盖面广**：同时覆盖半合成、真实观测与自建合成（维度、强度两个维度），并做消融与敏感性，验证较全面。
- **结果有说服力**：在 6 个指标中取得 4 个最优；特别是在混杂强度增大的极端场景下优势显著，说明方法确实针对“未测量混杂”这一核心问题发力。
- **诚实报告局限**：论文主动指出 d_u > min(d_z,d_w) 时的性能退化，以及学习代理的可识别性缺乏理论保证，学术态度审慎。

## 8. 不足与局限

- **理论保证缺失**：MI 代理目标只是“代理角色”的启发式替代，U 不可观测导致这些条件无法从目标函数本身验证；学习到的代理是否满足近端识别假设，论文明确承认是开放问题。
- **维度限制**：当潜在混杂维度超过代理维度（d_u > min(d_z, d_w)）时性能显著下降，8-4-4-4 中误差大幅上升，说明方法的可扩展性受代理维度瓶颈制约。
- **超参数敏感性与调参负担**：α、β、γ、λ 以及核宽 ℓ 需按数据集分别设置（表 9 中差异明显），且不同项数值尺度差异大，实际应用需较多调参。
- **计算复杂度**：L_h 的成对核计算带来 O(b²) 时间与内存开销，大样本场景下可扩展性存疑。
- **实验公平性细节**：部分基线结果直接引用而非全部重跑；合成数据规模较小（1,000 样本）；真实基准中 IHDP/Twins 为半合成，真正存在未测量混杂的真实数据验证仍然有限。
- **应用限制**：方法假设存在三类代理结构且完备性成立，实际场景中这一结构是否成立无法直接检验，可能限制其在真实医疗、经济决策中的可信部署。
