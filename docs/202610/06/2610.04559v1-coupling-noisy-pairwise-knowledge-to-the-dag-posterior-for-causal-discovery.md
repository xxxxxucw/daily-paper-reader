## 摘要
外部因果报告能够改善基于有限观测的结构学习，但其可靠性因来源和变量对而异。我们提出HB-NoisyKG，一个贝叶斯框架，将观测数据与来自大型语言模型等来源的重复因果报告相结合。每份报告都是对由某个DAG所蕴含的直接成对状态的含噪观测。一个以特征为条件的Beta先验汇集关于成对可靠性的信息，而一个共享误差矩阵捕捉系统性错误。交替推断利用图后验来细化可靠性估计，而这些估计决定报告如何影响后续的图更新。报告似然仅使用图的成对状态边际，因此同一观测层在仅图推断和联合推断中支持离散与连续似然。相对于80次重启的无KG基线，HB最多使用总共80次重启，并在五个离散基准上将平均SHD从22.39降至16.06。在具有随机变量ID并保留描述的物理光隧道上，HB将SHD从无KG的39.00降至27.30。在连续Sachs上，仅图BGe相较于无KG Top-K将AUROC提高了0.121。在一项受控合成研究中，与一次性估计相比，持续更新还降低了平均可靠性估计误差和留出报告对数损失。

## Abstract
External causal reports can improve structure learning from limited observations, but their reliability varies across sources and variable pairs. We introduce HB-NoisyKG, a Bayesian framework that combines observational data with repeated causal reports from sources such as large language models. Each report is a noisy observation of a direct pair state implied by one DAG. A feature-conditioned Beta prior pools information about pair reliability, and a shared error matrix captures systematic mistakes. Alternating inference uses the graph posterior to refine reliability estimates, which determine how reports influence subsequent graph updates. The report likelihood uses only graph pair-state marginals, so the same observation layer supports discrete and continuous likelihoods in graph-only and joint inference. Against an 80-restart no-KG baseline, HB uses at most 80 total restarts and lowers mean SHD from 22.39 to 16.06 on five discrete benchmarks. On a physical light tunnel with random variable IDs and retained descriptions, HB lowers SHD from 39.00 for no-KG to 27.30. On continuous Sachs, graph-only BGe raises AUROC by 0.121 over no-KG Top-K. In a controlled synthetic study, continued updating also reduces mean reliability estimation error and held-out report log loss compared with one-time estimation.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：在因果发现中，观测数据往往有限，而外部因果知识（通路数据库、文献、大语言模型等）可以提供补充信息。然而，这些外部报告的质量参差不齐：有的正确识别直接关系，有的方向颠倒，有的描述的是由中介变量介导的间接影响。
- **核心痛点**：
  - 报告的可靠性因**来源**和**变量对**而异，不能用一个全局置信参数简单概括。
  - 重复查询会产生不一致、冲突或弃权的报告，需要合理聚合。
  - 现有方法（如 Harmonized-Prior 使用全局置信 c；专家模型估计来源级准确率）无法同时刻画**成对可靠性差异**与**来源级系统性错误模式**。
- **整体含义**：论文提出 **HB-NoisyKG**，一个基于 Dawid–Skene 传统的贝叶斯观测模型，把重复因果报告视为对"某个 DAG 所蕴含的直接成对状态"的含噪观测，使报告影响力可以在贝叶斯图推断内部被估计，从而将含噪成对知识稳健地耦合到 DAG 后验中。

## 2. 论文提出的方法论

### 核心思想
- 每个 DAG 为每对无序变量赋予一个**直接状态** $Z_{ij}(G) \in \{\text{none}, i\to j, j\to i\}$。
- 每份报告 $Y^{(r)}_{ij}$ 是该状态的含噪观测，由**成对可靠性** $\rho_{ij}$ 和**共享误差矩阵** $B$ 共同生成。
- 通过**交替推断**：图后验 → 成对状态边际 → 闭式更新可靠性/误差矩阵 → 生成报告奖励 → 再更新图后验，形成反馈闭环。

### 关键技术细节

- **观测似然**（式 3）：
  $$p(Y=y \mid Z=z, \rho_{ij}, B) = \rho_{ij}\mathbb{I}[y=z] + (1-\rho_{ij})B_{zy}$$
  其中 $B$ 为 3×3 矩阵，对角线固定为 0，每行非对角元素和为 1，刻画"报错时倾向于报什么"。

- **特征条件 Beta 先验**（式 4）：
  $$\mu_{ij}=\sigma(\phi_{ij}^\top\beta),\quad \rho_{ij}\sim \text{Beta}(\tau\mu_{ij},\tau(1-\mu_{ij}))$$
  $\phi_{ij}$ 含 12 个成对统计特征（平均置信度、覆盖率、方向一致率、显式"无关系"率、矛盾率等），$\beta$ 用高斯先验，$\tau$ 用 Gamma 先验，通过 MAP 经验贝叶斯更新。

- **闭式奖励与交替推断**（式 9–14）：
  - 用 digamma 函数计算期望对数似然 $\mathbb{E}_q[\log\rho]$、$\mathbb{E}_q[\log(1-\rho)]$、$\mathbb{E}_q[\log B_{zy}]$。
  - 构造未中心化奖励 $\psi^{\text{raw}}_{ij}(z)$，再在每对内中心化 $\psi_{ij}(z)=\psi^{\text{raw}}_{ij}(z)-\frac{1}{3}\sum_{z'}\psi^{\text{raw}}_{ij}(z')$，去除与状态无关的偏移。
  - 图后验更新（式 13，仅图坍缩版）：
    $$q(G)\propto p_0(G)p(D\mid G)\exp\Big(\sum_{i<j}\psi_{ij}(Z_{ij}(G))\Big)$$
    联合推断版（式 14）保留 $\Theta$ 同理。
  - 只需图的成对状态边际 $q_{ij}(z)$，即可更新 $\rho$ 与 $B$，使同一观测层复用于离散/连续、仅图/联合推断。

- **热启动**：初始图后验弥散时，用数据后验与经验报告频率按报告一致度加权混合，避免过早压低一致报告。

- **后端**：连续联合推断用 DiBS + SVGD；离散基准与仅图 Sachs 用 Top-K 局部搜索；数据模型支持 BDeu、BGe、线性/非线性 SEM。

- **理论性质**：
  - **命题 1**（退化为仅数据）：所有报告弃权时，奖励项消失，恢复普通贝叶斯结构学习。
  - **命题 2**（可靠性集中）：当图后验收敛到真实成对状态时，$\mathbb{E}_q[\rho]\to\rho^*$ 依概率成立，方差 $O(1/R)$。
  - **命题 3**（中心化不变性）：逐对加常数不改变图排序。
  - **命题 4**（有限影响）：有限报告数下奖励有界。
  - 还给出非完美边际下的有限样本界（式 15），分离图状态误差、报告采样误差、先验收缩三项。

## 6. 论文的主要结论与发现

- **结构恢复提升**：五离散基准上，相对 80 次重启无 KG 基线，HB 用 ≤80 次总重启将平均 SHD 从 22.39 降至 16.06，五个网络均改善。
- **物理系统验证**：光隧道随机 ID 条件下，N=1000 时 SHD 从 39.00 降至 27.30，AUROC 从 .738 升至 .764。
- **连续任务有效**：连续 Sachs 仅图 BGe 使 AUROC 相对无 KG Top-K 提升 .121（.702→.823）。
- **持续更新有益**：受控合成中，交替更新将可靠性 MAE 从 .240 降至 .152，留出报告对数损失从 .874 降至 .762。
- **可靠性可辨识**：推断可靠性随生成准确率单调上升（Spearman=1.0）；报告数从 2 增至 20，MAE 从约 .19 降至约 .045。
- **正确与错误报告分离**：正确报告的平均推断可靠性比错误报告高约 .24。
- **报告质量决定上限**：严重方向翻转（翻转率 .7）时 HB 反而比无 KG 差（SHD 19.13 vs 17.93）；完全弃权时精确退化为仅数据推断。
- **变量语义重要**：匿名 ID 且无描述时报告 F1 骤降，多数网络退化为无 KG；保留描述的随机 ID 仍有效。
- **扩展性**：$d=100/125$ 时 SHD 降低 47.9/55.4，内存占用仅 .202/.254 GiB。

## 7. 优点

- **理论扎实**：给出 4 个命题（退化为仅数据、可靠性集中、中心化不变性、有限影响），并提供有限样本误差界

分离图状态误差、报告采样误差与先验收缩三项，为"报告越多越可靠"这一直觉提供了形式化保证，也明确了错误报告主导时方法失效的边界。

- **建模层次精细**：与只用一个全局置信度 $c$ 的 Harmonized-Prior、或只估计来源级准确率的专家模型相比，HB-NoisyKG 同时刻画了**成对可靠性 $\rho_{ij}$** 与**共享误差矩阵 $B$**，能够区分"某对变量报告特别靠谱"与"某来源系统性地把 $i\to j$ 说成 $j\to i$"两类现象，且 $B$ 的非对角结构直接对应用户可解释的错误模式。

- **推断闭环自洽**：图后验、成对状态边际、可靠性与误差矩阵通过交替更新形成反馈闭环，且更新全部有闭式或半闭式表达式（digamma 期望），无需额外采样器即可复用同一观测层，工程实现简洁。

- **后端解耦**：同一奖励机制可插入 DiBS/SVGD、Top-K 局部搜索、BDeu/BGe、线性/非线性 SEM 等多种后端，说明该观测层是"即插即用"的模块而非绑定特定推断算法，实验中也确实在离散、连续、物理系统上分别验证。

- **实验严谨**：采用配对检验、Holm 校正、bootstrap 置信区间；消融覆盖局部搜索、热启动、$B$ 更新、$\beta/\tau$ 更新、真实报告替换等关键组件；并主动报告"方向严重翻转时反而不如无 KG"这类不利结果，学术诚实度较高。

- **可解释与可诊断**：推断出的 $\rho_{ij}$ 与 $B$ 本身可读，能回答"哪对变量被错误报告""错误偏向哪个方向"，为知识库质量审计提供副产品。

- **计算可行性**：奖励项仅依赖成对状态边际，$d=100/125$ 时内存占用仍低于 0.3 GiB，说明该方法在大规模稀疏图上具备实用潜力。

## 8. 局限与不足（客观评价）

- **错误主导时的失效**：当报告方向翻转率过高（如 .7）时，HB 的 SHD（19.13）反而劣于无 KG 基线（17.93）。方法本质上是"放大可靠信号、抑制不可靠信号"，而非"从错误中恢复真相"，因此对系统性、高比例的误导性报告缺乏鲁棒性。

- **对变量语义的依赖**：匿名 ID 且无描述时报告 F1 骤降，多数网络退化为无 KG。这意味着方法在真实场景中高度依赖 LLM 能否通过变量名/描述识别变量含义，变量命名不规范时收益会大幅缩水。

- **部分对比的公平性存疑**：作者自己承认 ER 联合研究中 HB 与无 KG 使用了不同的基础先验与总预算，属于"描述性"对比而非严格受控对比，因此该组结论的强度弱于其他实验。

- **误差矩阵 $B$ 的共享假设**：$B$ 在所有变量对间共享，虽降低了参数规模，但若不同来源/不同变量对存在截然不同的错误模式，共享 $B$ 可能欠拟合；论文虽研究了异质/相关错误，但仍是受限设定。

- **可靠性先验的模型依赖**：$\rho_{ij}$ 由特征 $\phi_{ij}$ 经 logistic 映射到 Beta 先验，特征的选取（12 个统计量）带有一定先验经验成分，特征设计不当可能限制可靠性辨识的上限。

- **可辨识性的条件性**：命题 2 的可靠性集中依赖"图后验收敛到真实成对状态"这一前提，若图后验本身偏离，可靠性估计会被污染，形成误差耦合；论文的有限样本界虽分离了三类误差，但未给出在坏图上避免正反馈的机制。

- **真实知识库验证有限**：报告主要来自 LLM（GPT-4.1-mini 等）而非真实通路数据库（如 Reactome、KEGG），因此"含噪知识库"这一核心动机在实证上偏向 LLM 幻觉/不一致场景，与文献型知识库的噪声结构可能有别。

- **超参数与热启动的敏感性**：热启动强度、$\tau$ 先验等超参数虽做了 3×3×3 网格与因子研究，但仍需在具体应用中调参，增加了落地成本。

## 9. 启示与未来方向

- **方法论启示**：将"知识可靠性"作为可推断的潜变量纳入图后验，而非外部固定的超参数，是处理含噪先验知识的一条通用思路，可推广到其他带先验的结构学习、特征选择或因果效应估计任务。

- **误差结构建模**：共享误差矩阵 $B$ 的思想可进一步扩展为来源级、主题级或变量级的分层误差矩阵，以更好匹配真实知识库的系统性偏差。

- **稳健性增强**：可引入对恶意/高翻转报告的鲁棒损失或截断机制，避免命题 2 失效时被错误报告反向牵引。

- **与真实知识库结合**：未来可在 Reactome、KEGG、OpenTargets 等真实数据库上验证，检验 $B$ 的估计是否捕捉到已知的数据库偏差（如通路级过度报告间接关系）。

- **大模型协同**：既然报告质量决定上限，可探索让 LLM 自评/交叉验证报告可靠性，或利用 HB 推断出的 $\rho_{ij}$ 反过来指导 LLM 重新查询，形成"推断—查询"主动学习闭环。

- **规模化**：$d=125$ 上仍可行，未来可探索 $d$ 上千的稀疏图与分布式实现，以及在其他领域（基因调控、神经连接、社会经济）的迁移验证。

## 10. 总体评价

HB-NoisyKG 在"如何把质量参差、来源各异、可能自相矛盾的成对因果报告稳健地融入 DAG 后验"这一问题上，给出了一个建模层次清晰、推断闭环自洽、理论性质可证、实验覆盖广泛的方案。其最大贡献在于把可靠性从"全局常数"提升为"成对可推断的潜变量 + 共享误差结构"，并用闭式交替更新实现了与多种推断后端的解耦。方法的边界同样明确：当错误报告占主导或变量语义不可辨时，收益会消失甚至反转。因此它更适合作为"中等质量知识库 + 有限观测数据"场景下的增强工具，而非对任意噪声都免疫的通用解。整体上，这是一篇理论、方法、实验三方面都较为完整、且对自身局限有清醒认识的因果发现工作。
