## 摘要
表格数据的生成模型通常针对每个数据集单独训练，这限制了知识迁移，并且需要存储大量专用模型。本文提出 CDMD，一种表格扩散模型，可在具有不同模式以及数值型和类别型特征数量可变的异构数据集上联合训练。与在连续表示空间中运行的现有跨数据集表格扩散模型不同，CDMD 直接在混合类型特征空间上定义扩散过程，并进行端到端训练。为适应异构类别域，我们为掩码扩散模型引入了一种受模式约束的逆向过程参数化方法，其中输出空间会动态适应每个特征的词汇表。然后，我们将数值型和类别型特征级扩散过程组合为依赖于模式的行级过程。一个共享的模式感知 Transformer 去噪器捕获特征之间的依赖关系，并对不同模式下的逆向过程进行参数化。在七个真实世界数据集上，单个联合训练的 CDMD 在强单数据集和跨数据集基线中取得了最高的平均生成质量，同时总参数量远少于分别训练的模型集合。此外，在包含 337 个数据集的语料库上进行预训练，可在目标数据有限和适应轮数有限的情况下，提升在先前未见数据集上的生成效果。这些结果展示了直接混合类型扩散在共享且可迁移的表格数据生成方面的潜力。我们的代码可在 https://github.com/ketatam/cdmd 获取。

## Abstract
Generative models for tabular data are typically trained separately for each dataset, limiting knowledge transfer and requiring the storage of many specialized models. In this paper, we introduce CDMD, a tabular diffusion model trained jointly across heterogeneous datasets with different schemas and variable numbers of numerical and categorical features. Unlike existing cross-dataset tabular diffusion models that operate in continuous representation spaces, CDMD defines diffusion directly over the mixed-type feature space and is trained end-to-end. To accommodate heterogeneous categorical domains, we introduce a schema-restricted reverse-process parameterization for masked diffusion models, in which the output space dynamically adapts to each feature's vocabulary. We then compose numerical and categorical feature-level diffusion processes into a schema-dependent row-level process. A shared schema-aware Transformer denoiser captures dependencies between features and parameterizes the reverse process across varying schemas. On seven real-world datasets, a single jointly trained CDMD achieves the highest average generation quality among strong single-dataset and cross-dataset baselines, while using substantially fewer total parameters than the collection of separately trained models. Furthermore, pre-training on a corpus of 337 datasets improves generation on previously unseen datasets under both limited target data and limited adaptation epochs. These results demonstrate the potential of direct mixed-type diffusion for shared and transferable tabular data generation. Our code is available at https://github.com/ketatam/cdmd.

- **整体含义**：论文提出 CDMD，直接在原始混合类型特征空间上定义扩散过程，端到端联合训练跨异构 schema 的表格生成模型，避免共享连续潜表示，并支持不同数量、不同类型的数值/类别特征。

## 2. 方法论

### 2.1 核心思想

- 采用“**从特征级到行级**”的构造：
  1. 为数值和类别特征分别定义一维特征级扩散过程；
  2. 根据目标表 schema，将特征级过程组合为行级混合类型扩散过程；
  3. 用共享的、schema 感知的 Transformer 去噪器参数化逆向过程。
- 所有参数跨数据集、跨同类型列共享，模型输入/输出维度由 schema 动态决定。

### 2.2 数值特征扩散

- 对归一化数值特征采用 **Variance Exploding 高斯扩散**：
  - 前向过程：\(q_{\text{num}}(x_t|x_0)=\mathcal N(x_t;x_0,\sigma_t^2)\)；
  - 网络 \(\mu_\theta(x_t,t,s)\) 预测干净值 \(x_0\)，以 L2 去噪损失训练；
  - 采样时求解概率流 ODE：\(dx=-\frac{\sigma'_t}{\sigma_t}(\mu_\theta(x,t,s)-x)dt\)。

### 2.3 类别特征扩散

- 采用 **广义掩码扩散**：
  - 定义全体类别宇宙 \(U\) 加特殊 `[MASK]`；
  - 前向过程以概率 \(1-\alpha_t\) 将干净类别变为 mask；
  - 逆向过程中，若当前非 mask 则保持；若为 mask，则按概率恢复干净值或继续保持 mask。
- **关键创新：schema 受限逆向过程参数化**：
  - 网络输出被限制在当前类别特征的有效词汇表 \(V\) 上，即输出为 \(\Delta^{|V|-1}\) 上的概率分布；
  - 公式上可看作 SUBS 参数化的推广，当所有类别共享同一词汇表时退化为 SUBS；
  - 只需预测 \(|V|\) 个类别概率，通常 \(|V|\ll |U|\)，因此可扩展到大量异构类别特征；
  - 训练目标为加权交叉熵损失，与掩码扩散的简化似然界一致。

### 2.4 行级混合类型扩散

- 对给定 schema \(S\)，行级前向噪声按特征类型独立组合：
  \[
  q(x_t|x_0,S)=\prod_{j\in J_{\text{num}}}q_{\text{num}}(x_{t,j}|x_{0,j})\prod_{j\in J_{\text{cat}}}q_{\text{cat}}(x_{t,j}|x_{0,j})
  \]
- 网络 \(\mu_\theta\) 输入变长混合类型行和 schema，输出：
  - 数值列：标量干净值预测；
  - 类别列：对应词汇表上的概率向量。
- 总损失由数值 L2 项和类别交叉熵项组成，按各类型列数归一化。
- 采样时采用类似 TabDiff 的混合类型随机采样器，基于 EDM 采样器：数值用 Euler 步更新 ODE，类别按反向转移采样，并在每步前注入噪声和概率性重新 mask。

### 2.5 Schema 条件去噪网络架构

- **Schema 嵌入**：使用冻结的预训练文本嵌入模型 GTE，对表名、列名、类别值编码，再经线性投影得到 schema 嵌入。
- **Tokenizer**：
  - 数值特征经 MLP；
  - 未 mask 类别使用类别嵌入；
  - mask 类别用共享 mask 嵌入对当前列类别嵌入
