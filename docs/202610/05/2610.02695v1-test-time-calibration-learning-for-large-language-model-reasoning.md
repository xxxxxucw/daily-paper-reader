## 摘要
可靠的大语言模型（LLMs）不仅必须给出准确的答案，还必须表达能够忠实反映其答案正确概率的置信度。这种校准对于识别不确定预测并支持实际部署中的可靠决策至关重要。近期研究将校准学习纳入强化学习（RL），利用真实正确性监督联合优化答案正确性和言语化置信度。然而，它们对标注数据的依赖限制了其在实际测试时场景中的适用性，在这些场景中真实标签不可用，且校准可能需要适应新遇到的目标任务。为解决这一挑战，我们提出测试时校准学习（TTCL），一种无标签框架，可直接在无标签目标任务数据上联合适配推理准确性和言语化置信度。具体而言，TTCL 从模型生成的多个响应中推导出用于正确性和校准的自监督信号，使得无需真实标签即可在测试时进行校准学习。理论分析进一步证明 TTCL 是理想校准目标的一个有界替代。在数学推理和事实问答上的大量实验表明，TTCL 在不同模型和任务上均能持续提升准确性和校准。在基座模型上，TTCL 在八个基准上实现了平均相对准确率提升 +40.13% 和 ECE 降低 +70.80%。此外，TTCL 还能在领域偏移下进一步提升已校准模型的准确性和校准，尤其是当源领域校准难以迁移到目标任务时。在数学到事实问答（math-to-factQA）设置中，TTCL 实现了平均相对准确率增益 +20.35%，并将 ECE 降低 +53.83%。源代码发布于 https://github.com/tmlr-group/TTCL。

## Abstract
Reliable large language models (LLMs) must not only produce accurate answers but also express confidence that faithfully reflects their probability of being correct. Such calibration is essential for identifying uncertain predictions and supporting reliable decision-making in real-world deployment. Recent studies incorporate calibration learning into reinforcement learning (RL), jointly optimizing answer correctness and verbalized confidence using ground-truth correctness supervision. However, their reliance on labeled data limits their applicability in practical test-time settings, where ground-truth labels are unavailable and calibration may need to adapt to newly encountered target tasks. To address this challenge, we propose Test-Time Calibration Learning (TTCL), a label-free framework that jointly adapts reasoning accuracy and verbalized confidence directly on unlabeled target-task data. Specifically, TTCL derives self-supervision signals for both correctness and calibration from multiple model-generated responses, enabling calibration learning at test time without ground-truth labels. Theoretical analysis further establishes TTCL as a bounded surrogate for the ideal calibration objective. Extensive experiments on mathematical reasoning and factual question answering demonstrate that TTCL consistently improves both accuracy and calibration across diverse models and tasks. On base models, TTCL achieves an average relative accuracy improvement of +40.13% and an ECE reduction of +70.80% across eight benchmarks. Moreover, TTCL can further improve both accuracy and calibration for already calibrated models under domain shift, particularly when source-domain calibration transfers poorly to target tasks. In the math-to-factQA setting, TTCL achieves an average relative accuracy gain of +20.35% and reduces ECE by +53.83%. The source code is released at https://github.com/tmlr-group/TTCL.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）正被广泛部署于用户交互与决策支持系统中，其输出可能直接影响现实决策。因此，可靠的 LLM 不仅需要答案准确，还需要其表达的置信度忠实反映答案正确的概率。
- **核心问题一：过度自信**。当前 LLM 普遍存在过度自信现象，即对错误回答仍赋予很高的置信度，导致错误难以被检测，在高风险场景中后果严重。理想情况下，置信度应满足 `Pr(Z=1 | C=c) = c`，即置信度为 c 的预测应有约 c 的比例是正确的。
- **核心问题二：现有校准学习依赖真值标签**。近期方法（如 RLCR）将校准学习融入强化学习，利用 Brier 分数等适当评分规则联合优化答案正确性与言语化置信度，但**正确性和校准两个目标都需要真实答案 a\***，这带来高昂的标注成本，且在测试时真实标签不可用的场景下无法应用。
- **核心问题三：源域校准难以迁移**。实验观察发现，在 DAPO-Math-14K 上经 RLCR 校准的 Qwen3-8B 能很好地迁移到数学类 AMC 基准，但在事实类 NQ 基准上校准仍然很差（ECE 从 0.730 仅降至有限水平），说明学到的校准行为对领域偏移高度敏感。
- **核心挑战**：如何在不依赖真实标签的前提下，让模型在测试时直接对未见过的目标任务自适应其校准行为？为此，作者提出**测试时校准学习（TTCL）**。
- **整体含义**：TTCL 是首个无需真值标签、直接在无标签目标数据上联合适配推理准确率与言语化置信度的校准范式，使模型能在部署时针对新分布重新校准，弥补源域校准迁移能力的不足。

## 2. 论文提出的方法论

### 2.1 核心思想

- 基于一个简单假设：**在多次采样中收到更强共识（更高频次支持）的答案更可能正确，应被赋予更高置信度**。
- 从同一问题的多次 rollout 中构造两个自监督信号：正确性信号与校准信号，分别监督答案 token 与置信度 token。

### 2.2 关键技术细节

- **问题设定**：给定问题 x，模型生成 G 个响应 `{y_i = (τ_i, a_i, c_i)}`，其中 τ_i 为推理轨迹，a_i 为最终答案，c_i ∈ [0,1] 为言语化置信度。令 `q(a|x)` 为 rollout 组诱导的经验答案分布。
- **正确性自监督信号**：取支持度最高的答案为伪正确性目标：
  - `ã_x = argmax_a q(a|x)`，其中 `q(a|x) = (1/G) Σ_j I[a_j ≡ a]`
  - 正确性奖励：`r_corr_i = I[a_i ≡ ã_x] ∈ {0,1}`
- **校准自监督信号**：不同于只用最高支持答案，校准需要更细粒度监督。以每个生成答案的经验支持度作为其置信度目标：
  - `p̃_i = q(a_i|x)`
  - 校准奖励（负 Brier 分数）：`r_cal_i = -(c_i - p̃_i)²`
- **分离式优势与优化目标**：为避免正确性与校准之间的干扰（如正确答案 token 因置信度不佳而被惩罚），TTCL 分别计算两组组相对优势：
  - `Â_corr_i = r_corr_i - mean(r_corr)`，`Â_cal_i = r_cal_i - mean(r_cal)`
  - **正确性优势仅作用于推理轨迹与答案 token（o_corr）**，**校准优势仅作用于置信度 token（o_cal）**
  - 总目标 `J_TTCL` 为两部分之和，采用 PPO 风格裁剪重要性比 ρ_{i,t}(θ)。
- **目标缓存（Target Cache）**：直接使用当前 rollout 的瞬时分布会引发奖励黑客——多数投票监督鼓励答案一致性，使经验频率升高，进而抬高置信度目标，形成正反馈，导致模型坍缩到同一错误答案且置信度趋近 1.0。为此：
  - 为每个问题维护一个时间滞后的答案分布 `q_cache^(e)(a|x)`，在每个 epoch 内冻结用于监督；
  - 初始化于初始模型的答案分布；
  - epoch 结束时用 EMA 更新：`q_cache^(e+1) = (1-η) q_cache^(e) + η q^(e)`，其中 η 为更新率（实验取 0.01）。
  - 监督目标从缓存读取：`ã_x^(e) = argmax_a q_cache^(e)(a|x)`，`p̃_i^(e) = q_cache^(e)(a_i|x)`。
- **算法流程**：初始化缓存 → 冻结缓存训练一个 epoch（采样 G 个响应、读取缓存目标、计算两个奖励、组相对优势、更新策略）→ 用新观测分布 EMA 更新缓存 → 重复直至收敛。

### 2.3 理论分析

- **定理 4.1**：设 TTCL 校准目标 `J_TTCL(c) = E[(c(X,Y) - s(X,Y))²]`，理想目标 `J_ideal(c) = E[(c(X,Y) - p*(X,Y))²]`，估计误差 `ε = E[|s(X,Y) - p*(X,Y)|]`，则对任意置信度估计器 c ∈ [0,1]，有 `|J_TTCL(c) - J_ideal(c)| ≤ 2ε`。即 TTCL 是理想校准目标的有界替代。
- **命题 4.2**：经验答案概率是总体答案概率的无偏、一致估计量；当答案分布反映模型对正确答案的不确定性时，`q_πθ(a|x)` 可作为条件正确概率 `p*(x,y)` 的代理。
- **命题 4.3**：若置信度估计器满足 `c(X,Y) = p*(X,Y)`，则完美校准；最小化期望 Brier 分数的最优估计器 `c* = p*`。

## 6. 论文的主要结论与发现

- **TTCL 持续提升基座模型的准确率与校准**：数学推理上平均相对 ACC 提升 +41.35%、ECE 降低 +73.12%；事实 QA 上对应为 +31.02% 与 +66.37%；八项基准总体平均相对准确率提升 +40.13%、ECE 降低 +70.80%。AUROC 提升表明置信度对正确/错误响应的区分能力增强。
- **TTCL 可进一步适配已校准模型**：在 RLCR 校准模型上，域内 math-to-math 继续提升 ACC 与 ECE；域外 math-to-FactQA 与 FactQA-to-math 中，当源域校准迁移不佳时，TTCL 能显著改进目标域校准（math-to-factQA 平均相对 ACC +20.35%、ECE 降低 +53.83%）。
- **TTCL 优于现有无标签校准方法**：在 ACC、ECE、AUROC 上普遍优于 P(True)、Verbalization、Elicitation、BaseCal；由于这些方法多为事后估计不训练模型，其 ACC 不变，而 TTCL 通过目标任务适应还能提升准确率。在部分场景（如 Llama-3.1-8B-Instruct 在 MATH500 上），TTCL 无需标签即可匹配甚至超越有标签的 RLCR。
- **不牺牲其他领域能力**：在 ARC、GPQA-D、IFEval、MMLU-Pro、TruthfulQA 上，TTCL 训练后模型性能与适应前基本相当，说明校准提升未以通用能力退化为代价。
- **两个奖励互补**：仅优化正确性会保持准确率但校准显著变差；仅优化校准可降低 ECE 但准确率明显下降；两者结合取得最佳平衡。
- **频率监督优于二值伪标签**：TTCL 以答案频率作为置信度目标，比 Pseudo-RLCR 的二值伪正确性监督在 ECE、ACC、AUROC 上普遍更优。
- **训练动态验证理论**：训练过程中平均置信度逐步向经验准确率靠拢，初始过度自信被修正，置信度与准确率差距缩小。
- **无标签 RL 方法不天然校准**：Self-Certainty、Entropy、Majority-voting、Co-rewarding 等虽提升准确率，但 ECE 仍高、平均置信度普遍超过 0.8 甚至 0.9，说明缺乏显式校准目标时过度自信依旧存在。

## 7. 优点

- **方法创新性强**：首次提出无标签测试时校准学习范式，将校准学习从"需要真值标签的离线训练"扩展到"无标签在线部署场景"，填补了实际部署中标签不可用的空白。
- **自监督信号设计巧妙**：利用多次采样的一致性构造正确性伪标签（多数投票）与校准软目标（答案频率），将经验频率自然转化为置信度监督，无需任何外部标注。
- **分离式优势设计合理**：正确性奖励仅更新推理与答案 token，校准奖励仅更新置信度 token，避免两类目标相互干扰导致正确 token 被错误惩罚。
- **目标缓存机制针对性强**：识别出多数投票监督与置信度目标之间的正反馈会导致奖励黑客（rollout 坍缩到同一错误答案且置信度趋近 1.0），并用 EMA 滞后缓存切断该反馈，附录 F.4 用具体案例（图 13）验证了这一失效模式。
- **理论支撑完整**：定理 4.1 给出 TTCL 与理想校准目标之间有界偏差；命题 4.2 与 4.3 分别论证答案频率作为条件正确概率代理的统计合理性、以及条件正确概率作为理想校准目标的充分性，形成从频率到校准的完整理论链条。
- **实验覆盖全面**：跨模型系列（Qwen3、Llama）、跨规模（4B/8B）、跨任务（数学推理、事实 QA）、跨场景（基座、域内预校准、域外迁移）、跨领域泛化（ARC、GPQA、MMLU-Pro 等），并包含多组消融与基线对比。
- **对比公平透明**：明确区分"有标签泄漏"的 RLCR 与"无标签"方法，避免将 TTCL 与使用真值的强基线混同比较。
