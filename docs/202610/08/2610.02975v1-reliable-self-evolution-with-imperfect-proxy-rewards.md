## 摘要
基于大语言模型（LLM）的自演化搜索是科学发现的一种有前景的方法。然而，在某些领域中，对每个候选进行高保真评估的成本高得令人望而却步。因此，这类场景中的自演化系统依赖低成本但不完美的代理奖励，这可能会给不可行的候选赋予高分。这些假阳性可能同时污染最终输出以及用于指导后续生成的反馈。这促使我们采用经过统计校准的奖励区间，以实现更可靠的自演化搜索。我们提出共形区间驱动的自演化（Conformal Interval-Driven Self-Evolution, CISE），它利用条件共形推断和逐迭代在线密度比估计来构建候选特定的奖励区间。CISE 使用保守的基于区间的奖励作为演化反馈，并且仅当所有所需性质区间都完全位于各自的可行区域内时才返回候选。我们在独立性和协变量偏移的明确假设下推导了固定迭代次数下的覆盖性结果。我们在材料科学中的三个自演化搜索任务上评估 CISE。在我们的实验中，在高保真评估下，CISE 返回的所有候选均为真阳性，而基线返回更多候选但包含假阳性。这些结果凸显了当下游验证预算有限时，更小、更精确的候选短名单的价值。我们的代码库见 https://github.com/MLAI-Yonsei/CISE.git。

## Abstract
Large language model (LLM)-based self-evolving search is a promising approach to scientific discovery. However, high-fidelity evaluation of every candidate is prohibitively expensive in some domains. Self-evolving systems in such settings therefore rely on low-cost but imperfect proxy rewards, which may assign high scores to infeasible candidates. These false positives may contaminate both the final output and the feedback used to guide subsequent generations. This motivates statistically calibrated reward intervals for more reliable self-evolving search. We propose Conformal Interval-Driven Self-Evolution (CISE), which constructs candidate-specific reward intervals using conditional conformal inference and iteration-wise online density-ratio estimation. CISE uses conservative interval-based rewards for evolutionary feedback and returns candidates only when all required property intervals lie entirely within their respective feasible regions. We derive fixed-iteration coverage results under explicit assumptions of independence and covariate shift. We evaluate CISE on three self-evolving search tasks in materials science. In our experiments, all candidates returned by CISE are true positives under high-fidelity evaluation, whereas the baselines return more candidates but include false positives. These results highlight the value of a smaller, more precise shortlist when downstream validation budgets are limited. Our repository is available at https://github.com/MLAI-Yonsei/CISE.git.

## 1. 核心问题与整体含义
- **研究背景**：基于 LLM 的自演化搜索在科学发现中很有前景，通过生成候选、用历史奖励反馈来改进后续生成。
- **核心痛点**：高保真评估（如材料科学中的 DFT 计算或实验验证）对每个候选都过于昂贵，因此自演化系统通常依赖低成本但不完美的代理奖励。
- **关键风险**：代理奖励会产生假阳性——在代理指标下满足约束、但在真实奖励下不满足的候选。假阳性不仅污染最终输出，还会作为“成功经验”被存入 archive，继续指导后续生成，导致错误在演化过程中传播和放大。
- **整体含义**：论文主张用统计校准的奖励区间替代点值代理奖励，使自演化搜索在真实奖励昂贵时仍能可靠运行。作者提出 CISE（Conformal Interval-Driven Self-Evolution），目标是在下游验证预算有限时返回更小但更精确的候选短名单。

## 2. 方法论
### 2.1 核心思想
- 用**条件共形推断（Conditional Conformal Inference, CCI）**为每个候选构造候选特定的真实奖励预测区间，而非依赖单一点预测。
- 奖励区间同时用于：
  - **进化反馈**：将保守的区间奖励存入 archive，指导父代选择和后续生成。
  - **最终输出选择**：仅当所有目标属性的奖励区间完全落在可行区域内时，才返回该候选。
- 为应对演化过程中候选分布变化，引入**逐迭代在线密度比估计**，将当前候选分布与源分布的差异纳入共形校准。

### 2.2 关键技术细节
- **数据划分**：
  - `D_fit`：训练条件分位数模型，预测绝对代理误差 `|r(x)-r̂(x)|` 的上分位数。
  - `D_cal`：用于共形校准。
  - `D_src`：密度比估计的源参考。
- **非一致性分数**：  
  `S(x,u;r̂)=|u-r̂(x)|-q̂(x)`，其中 `q̂(x)` 是拟合的条件代理误差分位数。分数越大，表示候选的真实奖励与代理预测差异越异常。
- **增广分位数回归**：  
  在校准中额外加入待测候选 `X'` 和一个假想分数 `s`，在有限维线性空间 `G` 上求解 pinball 损失最小化问题。由对偶变量 `η_s(X')` 得到分数截断 `τ_t(X')`，再反转为奖励区间 `I_t(X')`。
- **密度比校正**：
  - 每轮生成未标注探针批次 `B_t`，用最小二乘重要性拟合（LSIF）估计密度比 `ŵ_t`。
  - 将 `ŵ_t` 加入校准空间：`G_t = G + span{ŵ_t}`。
  - 估计误差 `ε_t` 定义为 `P_X^t` 与归一化估计密度比诱导分布之间的总变差距离。
- **输出规则**：
  - 若区间为空或无界，则弃权。
  - 下界约束用区间下端点检查，上界约束用上端点检查，范围约束要求整个区间落入范围。
  - 只有全部所需属性区间均满足约束的候选才进入输出集 `O_T`。

### 2.3 理论保证
- **定理 1（可交换性下）**：固定迭代 t，若校准样本与新鲜候选同分布且独立，则 `P(r(X')∈I_t(X')) ≥ 1-α`。
- **定理 2（演化协变量偏移下）**：在条件奖励分布不变、候选边际发生有界偏移的假设下，覆盖率为 `≥ 1-α-ε_t`，其中 `ε_t` 反映密度比估计误差。
- **假阳性控制**：接受且为假阳性的联合事件概率受 `α+ε_t` 控制，但注意这不是条件于接受后的假阳性率，也不是整条搜索轨迹的同时覆盖。

## 3. 实验设计
### 3.1 数据集与场景
- 使用 **LLEma benchmark** 中的三个多约束材料发现任务：

## 6. 主要结论与发现
- **CISE 返回更少但更可靠**：
  - WBG：CISE 返回 41/200，DFT 验证全为 TP；LLEMA 返回 102/200，其中 94 TP、8 FP。
  - SSE：CISE 返回 51/200，全为 TP；LLEMA 返回 104/200，其中 71 TP、33 FP。
  - PV：CISE 返回 6/200，全为 TP；LLEMA 返回 60/200，其中 39 TP、21 FP。
- **假阳性传播被抑制**：SSE 轨迹显示 LLEMA 后期候选越来越多落入 DFT 失败区域，包括被选中的假阳性；CISE 输出均值始终保持在可行区域内。
- **等预算下仍更可靠**：PV 任务中，在相同 6 个验证预算下，LLEMA 的 top-6 点估计优先候选有 3 个 FP，而 CISE 的 6 个候选全为 TP。
- **总体结论**：校准奖励区间能同时改善进化反馈和最终输出选择，在真实奖励昂贵时提供更可靠的候选短名单。
