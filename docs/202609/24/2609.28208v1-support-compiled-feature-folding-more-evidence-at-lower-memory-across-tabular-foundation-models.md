## 摘要
表格基础模型面临特征侧扩展困境：全宽成对混合随列数二次增长，而特征选择通过丢弃证据来节省内存。我们提出支持编译的特征折叠（Support-Compiled Feature Folding, SCFF），一种无需训练的推理框架，可在不改变冻结主干的情况下解决这一困境。SCFF 将按支持度排序的特征路由通过原生特征编码器的有界叶节点，对残差证据进行支持度校验，并在单次上下文预测前合并编码消息。由此，它将二次的特征交互计算转化为随宽度线性的计算，并具有有界局部工作集，且无需集成预测或训练新参数。在固定 AMLB-29、TabZilla 和 TabArena 快照的穷举式 18 数据集宽表切片上，SCFF 在全部六个被评估主干上提升了数据集宏平均准确率和 NLL。所有四个匹配宽度比较在锁定折上都保持有利的 95% 数据集自助法区间，相对误差降低最高达 26.1%。配对 GPU 内存节省中位数为 2.09 倍至 2.36 倍，分别观测到的最大峰值之比达到 34.3 倍。在实测峰值内存上限下，SCFF 利用节省的预算保留更多支持度选中的证据，在预先声明的 TabICLv2 和 TabPFN-3 宽 Core 分层上，相比最宽可行单叶分别提升准确率 4.06 和 3.72 个百分点。

## Abstract
Tabular foundation models face a feature-side scaling dilemma: full-width pairwise mixing grows quadratically with the number of columns, whereas feature selection saves memory by discarding evidence. We introduce Support-Compiled Feature Folding (SCFF), a training-free inference framework that resolves this dilemma without changing the frozen backbone. SCFF routes support-ranked features through bounded leaves of the native feature encoder, support-checks the residual evidence, and merges the encoded messages before a single contextual prediction. It thereby converts quadratic feature-interaction work into linear-in-width work with a bounded local working set, without ensembling predictions or training new parameters. On the exhaustive 18-dataset wide-table slice of fixed AMLB-29, TabZilla, and TabArena snapshots, SCFF improves dataset-macro accuracy and NLL on all six evaluated backbones. All four matched-width comparisons retain favorable 95 percent dataset-bootstrap intervals on locked folds, with relative error reductions up to 26.1 percent. Median paired GPU-memory savings are 2.09x to 2.36x, and the ratio of separately observed maximum peaks reaches 34.3x. Under a measured peak-memory ceiling, SCFF uses the saved budget to preserve more support-selected evidence, improving accuracy by 4.06 and 3.72 points over the widest feasible single leaf on predeclared wide-Core strata of TabICLv2 and TabPFN-3.

## 1. 核心问题与整体含义

- **研究背景**：表格基础模型（TabPFN-3、TabICLv1/v2、TabPFNv1、LimiX、RefineICL-24L 等）将表格预测建模为上下文学习（ICL）情景。模型结构为：特征编码器先混合 D 列得到固定维度行表示，再由上下文编码器跨支持行推理。
- **核心矛盾（特征侧扩展困境）**：
  - 全宽成对特征混合的开销为 **Θ(TD²)**，随列数二次增长；例如 TabICLv2 在 robert（7,200 特征）上峰值 GPU 内存高达 **59.3 GiB**。
  - 特征选择虽省内存，但会**永久丢弃**截断之外的信号。
- **关键洞察**：特征编码器只需看到**窄的特征组**，而上下文编码器仍需看到**每一行**。这一"行表示接口"允许在宽度维度上分解计算。
- **整体含义**：推理内存需服务三类能力来源——上下文（样本）、模型容量（计算）、特征宽度（候选证据）。本文研究的是"特征侧预算应如何花费"，提出免训练、冻结骨干的宽度外推方案。

## 2. 方法论

### 2.1 核心思想

SCFF 将宽表预测转化为"有界宽度特征计算序列 + 单次常规 ICL 预测"。暴露的接口为：
```
fθ(Xs, ys, Xq) = Hθ(Cθ(Fθ([Xs; Xq], ys); ys))
```
其中 Fθ 为宽度相关的特征编码器，Cθ 为上下文编码器，Hθ 为标签头。**所有预训练参数冻结**，只改变 Fθ 的执行方式。

### 2.2 算法流程（Algorithm 1）

**步骤一：ROUTE（路由）**
- 在中位数填充的支持集副本上做单因素 **ANOVA** 排序。
- 用 **Benjamini–Hochberg（FDR 0.05）** 确定 Core 大小 K，而非手工 top-K；最强的 max(1, K) 列构成 Core **C**，其余构成候选 Tail **T**。
- 路由只看支持集，**不使用查询标签**。

**步骤二：FOLD + ENCODE（折叠编码）**
- 在每个层内按 round-robin 分成不相交叶节点，每叶宽度 ≤ M（默认 **128**）。
- 每个叶用**同一特征编码器**处理：`mg = Fθ([Xs; Xq]Pg, ys) ∈ R^{T×dICL}`。
- 每个特征恰好被编码一次，保留全部支持/查询行。

**步骤三：CORE + 可选 TAIL**
- Core 消息平均：`c = |GC|^{-1} Σ_{g∈GC} mg`。
- Tail（仅二分类任务）：平均后中心化，去除与 Core 对齐的投影：`ρ = ⟨uS, bS⟩/||bS||²`，`r = u − ρb`（原始残差在支持集上与中心化 Core 正交）。
- 考虑两个候选方向：**原始残差方向** 与 **支持原型映射方向**（用全支持类质心，支持行用留一自身类质心）。
- **互反支持子集接受检验**：每类交替分成两半 A、B，每半拟合 Fisher 步长并在另一半上测试，要求 Fisher 分离度提升、原型 NLL 下降、且两半精度不下降；取最差方向 NLL 增益最大的更新。
- 未通过检验则 α = 0，返回**精确的 Core 表示**；多分类任务同样回退。

**步骤四：PREDICT**
- 最终表示 `h = c + αv`，单次调用上下文编码器与标签头：`p(yq|...) = Hθ(Cθ(h; ys))`。

### 2.3 理论性质

- **特征覆盖**：叶划分不相交且穷尽，Σ|Pg| = D，每特征编码一次。
- **局部份额提升**：若注意力 logits 在 [−B, B]，宽度 K 竞争下权重下界为 e^{−2B}/K；全宽为 e^{−2B}/D，叶宽 M 为 e^{−2B}/M，比值 D/M（仅为归纳偏置，非最终影响力保证）。
- **复杂度**：成对特征混合从 Θ(TD²d) 降为 G·Θ(TM²d) = **Θ(TDMd)**，顺序执行工作集为 **O(TM²)**。
- **条件性迁移**：支持侧接受检验建立 ∆S(v) > 0，但需稳定性条件 |∆Q(v) − ∆S(v)| ≤ ε 才能推出查询侧改善。

### 2.4 架构接口差异

- TabPFN-3、TabICLv1/v2、TabPFNv1、RefineICL-24L 暴露兼容的**行表示接口**。
- LimiX 保留特征 token 轴，需 **token-preserving adapter**（Core 槽保留、Tail 槽折叠、支持 RMS 重缩放），不使用行表示 Tail 更新。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **主面板（18 个宽表分类数据集）**：来自固定快照 AMLB-29、TabZilla、TabArena v0.1，穷举式纳入满足元数据规则（≥128 原始特征、2–50 类、无缺失目标、无重复）的所有数据集版本。
- 原始特征跨度 **128–7,200**，代表数据集包括 arrhythmia、scene、sylva、gina、musk、gas-drift、christine、jasmine、madeline、philippine、guillermo、riccardo、dilbert、fabert、robert、hiva、kddcup09 appetency 等。
- **折设计**：确定性分层 5 折（split seed 20260904），**折 0 用于方法选择，折 1–4 锁定确认**；支持 ≤2048、查询 ≤1024。

### 3.2 对比方法

- 与每个骨干的**原生推理（native）** 对比，共享同一 checkpoint、预处理、划分与查询行。
- **配对机制控制**：Raw Core vs. Bounded Core；Tail Off vs. Tail On。
- **组件消融（7 个 TabICLv2 变体）**：随机 Core/Tail 分配、无 Core 投影、原始残差、固定原型更新、Fisher 选择更新、无单叶回退的验证更新、无二分类限制的验证更新。
- **宽度/资源干预**：叶宽 M ∈ {32, 64, 128}；嵌套支持上下文 128/512/2048；追加最多 512 个标签无关列；固定内存研究；TabPrep 生成特征空间应用面板（11 个数据集）。

### 3.3 评估指标

- 数据集宏平均准确率、NLL（相对误差/NLL 下降）、端到端时间、峰值分配 GPU 内存。
- 100,000 次数据集自助法（dataset-bootstrap）95% 区间；留一数据集（LODO）敏感性分析。
