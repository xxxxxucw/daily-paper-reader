## ABSTRACT 

What reusable computation should a tabular foundation model learn when every table defines a new supervised task? We develop in-situ representation refinement :support labels guide updates to the episode’s representations, and these updates transfer to unlabeled queries without changing model parameters. A regularized leave-one-out objective yields a support correction and its query extension. The leading term separates attention-based reading from state-dependent scaling, moti-vating R EFINE ICL: an attention-gated, FFN-free contextual stack with selected low-rank feature interaction and typed memory. R EFINE ICL-L24 reaches 0.93836 OVR-AUC and 0.87173 accuracy on AMLB29. A benchmark-informed contin-uation reaches 1644.8 Elo on the 38-dataset TabArena snapshot, 31.4 Elo above TabPFN-3 under the same evaluation. It also improves all four reported metrics over TabPFN-v3 on both TabZilla views. In a matched 100K-update depth grid, an expanded FFN gives no consistent validation benefit and uses 60.2% more peak inference memory at L8. Internal interventions show that support represen-tations are more than a static source of labels: removing one intermediate support update, while preserving the query output, increases final query cross-entropy in all 72 tested episodes . Together, the derivation and interventions explain how attention-gated updates can construct a task-specific predictor in context. 

## 1 INTRODUCTION 

Tabular foundation models turn supervised learning into a forward-pass computation: labeled rows are supplied as context and a pretrained network predicts the remaining rows (M¨ uller et al., 2022; Hollmann et al., 2025; Qu et al., 2025). Their rapid empirical progress raises a more basic question than benchmark rank: what reusable computation converts a labeled table into its predictor? 

In language modeling, Transformer feed-forward networks (FFNs) can act as parameterized key–value memories (Geva et al., 2021). A tabular episode has a different source of task information: feature meanings, class identities, and the decision boundary can all change, while task-specific supervision is supplied by the support rows. Parameters can therefore encode a procedure for recovering predictors across tables, while the context defines the predictor for the current table. Existing views of in-context learning as optimization show that Transformers can emulate gradient-based or closed-form predictor updates in restricted settings (von Oswald et al., 2023; Aky¨ urek et al., 2023). We make this view constructive for multiclass tabular ICL: rather than posit an optimizer in parameter space, we derive how labeled examples can reshape the representations of the current episode. We define a class-separation objective on the support representations. A regularized local optimization of this leave-one-out supervised neighborhood objective yields support corrections; a kernel extension gives the following approximate update for query state zq and support states {zi}ni=1 :

## 2 RELATED WORK 

ICL as an optimization algorithm. Transformers can implement gradient descent, preconditioned updates, and closed-form linear predictors in context (von Oswald et al., 2023; Aky¨ urek et al., 2023). These results establish an important optimizer view of ICL, while subsequent work questions whether a literal gradient-descent equivalence transfers to pretrained models outside those controlled settings (Shen et al., 2024). We complement the optimizer view by studying updates to episode representations rather than predictor parameters. Our objective follows supervised neighborhood learning (Goldberger et al., 2004; Frosst et al., 2019); the contribution is its regularized support correction, extension to unlabeled queries, and use in model design. 

Conditional interaction versus standalone FFNs. Transformer FFNs have been analyzed as parameterized key–value memories (Geva et al., 2021). Recommendation models instead emphasize efficient explicit feature interaction: DCN and DCN-V2 construct bounded-degree and low-rank feature crosses (Wang et al., 2017; 2021), while HSTU fuses contextual aggregation with multiplica-tive gating (Zhai et al., 2024). R EFINE ICL uses selected low-rank feature interaction before row compression and an attention-gated update within the contextual stack. Its distinguishing contribution is the episode-representation account that motivates these operations, together with tests of how support labels, query state, and depth affect the learned update. 

Tabular foundation models. Prior-data fitted networks amortize Bayesian-style prediction over synthetic tasks (M¨ uller et al., 2022). TabPFNv2 established strong small-data performance (Holl-mann et al., 2025), and subsequent systems extend table scale, training distributions, and test-time computation (Grinsztajn et al., 2025; 2026). TabICL separates column representation from row-level inference (Qu et al., 2025; 2026); TabFM scales alternating feature and row computation (Google Research, 2026); and EXAONE-Tabular demonstrates that compact interleaved architectures remain competitive (Eo et al., 2026). We study how a pretrained model uses labeled rows to form a new predictor, using controlled experiments on internal states in the medium-scale regime.

Depth repeats the update, width provides its representation dimensions, and labeled rows define the task. Figure 3 tests these roles through changes to the inputs or hidden states. 

Depth improves predictions from the task representation. On 72 held-out RBF episodes, each class prototype is the normalized mean of its labeled support states. Within one L24 forward pass, blocks 12–24 increase a query’s correct-versus-wrong prototype margin by 0.0509 (95% CI [0.0403, 0.0616]) and nearest-prototype accuracy by 2.77 points; query labels are never supplied. Support states include their labels; scoring excludes self-votes. Learned updates reduce this objective, whereas row-permuted updates increase it (Appendix E.2). 

Later queries benefit from updated support states. We preserve block 12’s query output, replace its support output with its input, and run later blocks normally. Final query CE increases in all 72 episodes, by 0.0510 on average (95% CI [0.0417, 0.0608]); accuracy falls by 1.44 points. Thus updating support representations improves later predictions even when the current query output is preserved (Appendix E.2). 8Width provides dimensions for task-specific updates. Keeping eight input features fixed, we broaden the labeling rule with the first B eigenfunctions of the support RBF kernel. Projecting the 1,024-dimensional state after block 4 to rank 32 raises projection loss from 1.04 points at B = 4 

to 8.66 at B = 64 (increase 7.62; 95% CI [6.03, 9.05]): broader rules use more representation dimensions. 

Additional labeled rows widen the L24–L12 gap. Across 72 matched task cells and fixed queries, nested support sets grow from 128 to 1,024 rows. Analytic and learned updates. The proof concerns a locally smooth leave-one-out support ob-jective with at least two examples per class. The kernel approximation requires small β∥K∥2/α ;neither its exact gradient nor its scale is computed explicitly by the network. Query risk and repeated learned-block descent are empirical questions, not consequences of the proposition. 

Scope of the interventions. Mechanism tests emphasize synthetic classification with known rules. The real-table recovery panel tests a narrower transfer claim. A shared final decoder can miss intermediate information, and disabling components at inference can create states not encountered during training. Short recovery does not replace training all ablated architectures to convergence. The fixed-budget FFN grid has one training seed; paired episode intervals do not quantify training variance. 

What scale comparisons establish. L12 and L24 differ in depth, width, and training history. The change in their accuracy gap with context size therefore applies only to this pair of checkpoints. The rank-32 projection measures sensitivity inside one trained model. The sparse-rule deficit and intermediate reversals rule out uniform improvement with additional depth or context. Parameter ratios against TabFM are storage comparisons; they do not establish a matched-compute training advantage. 

Benchmark and release scope. Section D.4 records which headline results were reaggregated from task or fold outputs and identifies the distinct L24 checkpoints used by AMLB29 and TabArena. The TabArena ranking belongs to the fixed 38-dataset, fold-0 snapshot and its heterogeneous reference budgets. Overlapping OpenML views and metrics are not independent trials, and small mean differences alone do not establish statistical superiority. Complete RefineICL TALENT evaluations are unavailable in the reported evidence and do not enter a comparison. Regression is outside scope. The code supplement contains the model, synthetic priors, training loop, optimizer, and JSON recipes, plus focused tests and a CPU smoke run. It documents the benchmark-checkpoint mapping and training stages. Trained weights, benchmark data, and the real-informed continuation manifests are not included; the supplied source therefore supports model construction and synthetic training rather than a complete replay of the TabArena continuation. 27
