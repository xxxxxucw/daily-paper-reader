## 摘要
当每个表格都定义一个新的监督任务时，表格基础模型应学习何种可复用计算？我们提出原位表示精炼：支持集标签引导对该情景表示的更新，而这些更新在不改变模型参数的情况下迁移到未标注查询。一个正则化留一目标产生支持集校正及其查询扩展。其主导项将基于注意力的读取与状态相关的缩放分离开来，从而启发了 RefineICL：一个注意力门控、无 FFN 的上下文堆栈，具有选定的低秩特征交互和类型化记忆。RefineICL-L24 在 AMLB29 上达到 0.93836 OVR-AUC 和 0.87173 准确率。一种由基准信息引导的继续训练在 38 个数据集的 TabArena 快照上达到 1644.8 Elo，在同一评估下比 TabPFN-3 高 31.4 Elo。它还在两个 TabZilla 视图上相较于 TabPFN-v3 提升了全部四项报告指标。在匹配的 100K 次更新深度网格中，扩展的 FFN 没有带来一致的验证收益，并且在 L8 处多使用 60.2% 的峰值推理内存。内部干预表明，支持表示不仅仅是静态的标签来源：移除一个中间支持更新，同时保持查询输出不变，会在所有 72 个测试情景中增加最终查询交叉熵。综上，推导和干预共同解释了注意力门控更新如何在上下文中构建任务特定的预测器。

## Abstract
What reusable computation should a tabular foundation model learn when every table defines a new supervised task? We develop in-situ representation refinement: support labels guide updates to the episode's representations, and these updates transfer to unlabeled queries without changing model parameters. A regularized leave-one-out objective yields a support correction and its query extension. The leading term separates attention-based reading from state-dependent scaling, motivating RefineICL: an attention-gated, FFN-free contextual stack with selected low-rank feature interaction and typed memory. RefineICL-L24 reaches 0.93836 OVR-AUC and 0.87173 accuracy on AMLB29. A benchmark-informed continuation reaches 1644.8 Elo on the 38-dataset TabArena snapshot, 31.4 Elo above TabPFN-3 under the same evaluation. It also improves all four reported metrics over TabPFN-v3 on both TabZilla views. In a matched 100K-update depth grid, an expanded FFN gives no consistent validation benefit and uses 60.2% more peak inference memory at L8. Internal interventions show that support representations are more than a static source of labels: removing one intermediate support update, while preserving the query output, increases final query cross-entropy in all 72 tested episodes. Together, the derivation and interventions explain how attention-gated updates can construct a task-specific predictor in context.

## 一、核心问题与整体含义（研究动机与背景）

- **核心问题**：表格基础模型（Tabular Foundation Model）将监督学习转化为一次前向传播——把带标签的行作为上下文输入，让预训练网络预测剩余的行。然而，**当每一张新表都定义一个新的监督任务时，模型究竟应该学到什么样的可复用计算？** 这比单纯比较基准排名更基本。
- **背景观察**：
  - 在语言建模中，Transformer 的 FFN 可被视为参数化的键值记忆；但表格情景的任务信息来源不同——特征含义、类别身份、决策边界都可能改变，而任务特定的监督由支持集（support rows）提供。
  - 既有关于上下文学习（ICL）即优化的观点表明，Transformer 能在受限设定下模拟梯度下降或闭式预测器更新。本文在此基础上，将 ICL 视角**建设性地**用于多分类表格任务：不假设参数空间中的优化器，而是推导**带标签样本如何重塑当前情景的表示**。
- **整体含义**：支持集不仅是"被检索的固定示例"，而是**计算的一部分**——支持表示在预测查询之前被更新，深度则同时精炼支持表示与查询预测，而非反复读取同一组固定支持特征。

## 二、方法论

### 2.1 核心思想：原位表示精炼（In-Situ Representation Refinement）

- 支持集标签引导对**当前情景表示**的更新，这些更新在不改变模型参数的情况下迁移到未标注查询。
- 目标函数采用**正则化留一法（leave-one-out）** 监督邻域目标：预测每个支持行时排除其自身投票，只利用其他带标签行。

### 2.2 关键技术细节

- **局部几何目标**：对支持状态 \(Z=[z_1,\dots,z_n]\)，定义相似度 \(\kappa(z_i,z_j)=\exp(\tau z_i^\top z_j)\)，正确类邻域质量 \(q_i(Z)=\sum_{j\neq i} a_{ij}(Z)\mathbb{1}[y_j=y_i]\)，损失为
  \[
  J(Z)=-\frac{1}{n}\sum_i \log q_i(Z)
  \]
- **命题 1（降低目标的支持更新）**：令 \(K=[\kappa(z_i,z_j)]_{ij}+\epsilon I_n\succ 0\)，\(F=-\nabla_Z J(Z)\)，\(\alpha>0\) 为正则化强度。若 \(J\) 在更新段上 \(\beta\)-光滑，则存在支持状态解
  \[
  U^*=FK(\beta K+\alpha I_n)^{-1},\quad J(Z+U^*)-J(Z)\le -\tfrac{1}{2}\langle F,U^*\rangle\le 0
  \]
- **查询扩展**：对查询状态 \(z_q\)，定义 \(k_q=[\kappa(z_q,z_1),\dots,\kappa(z_q,z_n)]^\top\)，核扩展为
  \[
  u(z_q)=F(\beta K+\alpha I_n)^{-1}k_q
  \]
  当 \(\beta\|K\|_2/\alpha\) 较小时，主导项为
  \[
  u(z_q)\approx \frac{1}{\alpha}\sum_i \kappa(z_q,z_i)\, f_i
  \]
- **读取与缩放分离**：令 \(s(z_q)=\sum_j\kappa(z_q,z_j)\)，\(a_i(z_q)=\kappa(z_q,z_i)/s(z_q)\)，\(r(z_q)=\sum_i a_i(z_q)f_i\)，则 \(u(z_q)\approx \frac{s(z_q)}{\alpha}r(z_q)\)。其中 \(a_i\) 是注意力权重（softmax 形式），\(r(z_q)\) 是注意力输出，\(s(z_q)/\alpha\) 是查询相关的缩放因子。这揭示了"**读什么**"与"**读多少**"的分离。

### 2.3 网络实现：RefineICL

- **注意力门控的残差块**：
  \[
  h_{\ell+1}=h_\ell+W_{o,\ell}\Big[\mathrm{Norm}(A_\ell(\bar h_\ell))\odot \mathrm{SiLU}(W_{g,\ell}\bar h_\ell)\Big]
  \]
  其中 \(A_\ell\) 为学习到的注意力读出，\(\mathrm{SiLU}\) 门控按维度缩放，\(\odot\) 为逐元素乘，\(\mathrm{Norm}\) 为归一化。
- **三项设计后果**：
  1. 更新支持状态（校正 \(f_i\) 依赖当前邻域，而非仅标签）；
  2. 分离读取与缩放（注意力归一化相对相似度，门控控制施加强度）；
  3. 以乘积作为非线性更新，**无需独立的扩展 FFN**。
- **表格特征处理**：
  - **选定低秩特征交互（Selected Low-rank FI）**：在行压缩前，对数值、类别身份、缺失性分别编码；两轮特征图打分，仅保留每个特征 i 的 16 个最强邻居参与消息计算（FI 秩分别为 32 与 64）。
  - **行压缩与类型化记忆重入**：三块行编码器 + RowCLS 将可变特征集压缩为固定宽度行状态；存储两轮交互后的特征状态，在相对深度 1/3 和 2/3 处以 8 头门控读取重入，每读初始化为零且限制为当前行状态 RMS 的 0.25。
- **模型规模**：L12 和 L24 特征嵌入维度 256，上下文（深度, 宽度）分别为 (12, 2048) 和 (24, 1024)；L24 参数 159.5M。

## 六、主要结论与发现

1. **基准表现**：
   - RefineICL-L24 在 AMLB29 达 **0.93836 OVR-AUC / 0.87173 准确率**，较 L12 提升 1.51 / 0.84 个百分点，较 TabPFN-v3 提升 0.30 / 0.22 个百分点。
   - TabArena 达 **1644.8 Elo**，同一评估下比 TabPFN-3 高 **31.4 Elo**。
   - 在两个 TabZilla 视图上**全部四项指标（accuracy、F1、AUC、log loss）均优于 TabPFN-v3**。
   - 参数 159.5M，仅为 TabFM 1.639B 的 **9.7%**。
2. **FFN 无益于该预算**：匹配 100K 更新网格中，扩展 FFN 在 L2/L4 恶化 CE，L8 虽有微小增益（+0.27pp 准确率），但峰值推理内存增加 **60.2%**（202.97→325.12 MiB）。
3. **支持表示不是静态标签来源**：
   - 保留块 12 的查询输出、仅跳过其支持更新，会使最终查询 CE 在 **72/72 个情景中上升**，平均 +0.0510，准确率下降 1.44 个百分点。
   - 实际学习更新使留一目标平均下降 **−0.0204/块**（72/72 情景），而行置换更新使其上升 +0.0258（0/72）。
4. **深度、宽度、上下文各自贡献**：
   - 块 12–24 使正确-错误原型边际提升 0.0509，最近原型准确率提升 2.77 个百分点。
   - 更宽规则（B 从 4 到 64）使 rank-32 投影损失从 1.04 升至 8.66 个百分点。
   - 支持行从 128 增至 1024，L24–L12 差距从 0.24 扩至 4.25 个百分点（增加 4.01）。
5. **查询特异性**：在 1024 行时，置换注意力输出、门控、配对更新分别导致准确率下降 **52.28 / 34.27 / 56.89 个百分点**。
6. **标签选择预测器**：相同点云仅切换支持标签，匹配规则准确率平均 0.985，非对角仅 0.515。
7. **边界条件**：L12 在 32 个独立行时识别 39/48 条规则，L24 仅 32/48；说明**更大深度并非在所有方面都更优**。

## 七、优点

- **理论驱动设计**：从正则化留一目标出发，推导出支持校正与查询扩展，并将主导项分解为"读取"与"缩放"，直接映射到注意力 + 门控 + 残差的网络结构。
- **架构简洁高效**：FFN-free 上下文栈在匹配预算下不牺牲验证性能，且显著节省内存。
- **机制可解释性强**：通过支持更新移除、查询置换、标签切换等**因果干预**，而非仅报告基准分数。
- **实验控制严谨**：大量配对设计、共享输入、固定检查点、明确标注 HPO/成员预算差异；重叠视图不合并统计。
- **诚实的边界条件报告**：主动报告稀疏规则识别中
