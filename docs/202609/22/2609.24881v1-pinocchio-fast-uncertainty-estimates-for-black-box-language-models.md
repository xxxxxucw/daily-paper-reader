## 摘要
在大语言模型（LLM）的高风险决策应用中，从业者不仅需要准确的 LLM，还需要对其预测进行不确定性估计。现有的 LLM 不确定性估计方法需要访问模型输出的对数概率，或需要微调权限。然而，许多工业级 LLM 产品使用闭源 API 模型，而许多此类 API 模型（如 GPT）不返回对数概率，也可能不允许微调。我们提出 Pinocchio，一种外部校准器，用于估计黑盒 API 模型响应的正确性。它在来自七个 LLM 的响应上联合训练，在预测这些相同模型留出响应的正确性时达到 0.862 AUROC，并展现出对八个组织下十三个未见模型的零样本迁移能力。我们的模型只需一次前向传播即可生成不确定性估计，且无需访问目标模型的 logits、权重或内部状态。一个轻量级的纯文本 0.8B 检查点即可匹配我们最大模型的 AUROC。我们发布了相关代码，只需额外两行代码即可将不确定性估计添加到现有代码库中。

## Abstract
In high-stakes decision-making applications of large language models (LLMs), practitioners require not only accurate LLMs but also uncertainty estimates for their predictions. Existing approaches to uncertainty estimation for LLMs require access to log-probabilities output by the model or require fine-tuning access. However, many industrial LLM products use closed-source API models, and many such API models like GPT do not return log-probabilities and may not allow fine-tuning. We introduce Pinocchio, an external calibrator that estimates the correctness of responses from black-box API models. Trained jointly on responses from seven LLMs, it achieves 0.862 AUROC predicting the correctness of held-out responses from those same models, and shows zero-shot transfer to thirteen unseen models across eight organizations. Our model needs only a single forward pass to generate an uncertainty estimate and requires no access to the target model's logits, weights, or internal states. A lightweight text only 0.8B checkpoint matches our largest model's AUROC. We release code for adding uncertainty estimation to existing repos in only two additional lines of code.

## 1. 核心问题与整体含义

- **研究动机**：在高风险场景（医疗、法律、科研、软件工程）中，LLM 不仅需要准确，还需要知道“自己什么时候可能错”。但生产环境常用闭源 API 模型（如 GPT、Claude、Gemini），它们往往不返回 log-probabilities，也可能不允许微调。
- **现有方法的张力**：白盒方法依赖 logits、隐藏状态或微调权限，黑盒方法中口头置信度校准差，自评估会继承模型盲点，语义熵需要 5–10 倍推理预算。因此，“黑盒、单次前向、可学习、可迁移”的不确定性估计仍是开放问题。
- **论文含义**：Pinocchio 提出一种外部校准器，不读取目标模型内部信号，只根据“问题 + 回答 + 可选模型身份标签 + 可选图像”预测回答正确概率。它为闭源 API 模型提供低成本、可部署的不确定性估计。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：训练一个小型外部校准器 `f(Q, A, M) ∈ [0,1]`，估计目标模型回答 `A` 正确的概率，即输出 `P(y=1 | Q, A, M)`。训练集为 `D={(Qi, Ai, Mi, yi)}`，其中 `yi∈{0,1}` 表示正确/错误。
- **基础模型与微调**：以 `Qwen3-VL-8B-Instruct` 为底座，使用 LoRA 微调，rank=32，α=64，覆盖所有线性层。文本和视觉语言任务统一到一个 VLM 输入格式中。
- **输入处理**：输入为 chat-style prompt，包含问题、回答、可选 benchmark 与模型身份元数据。文本任务没有图像时，用 `28×28` 灰色占位图填充图像槽位。问题截断至 1,500 字符，回答截断至 800 字符。
- **输出与损失**：模型预测单个 token：`i` 表示错误，`ii` 表示正确。正确概率为：
  `P(correct)=exp(z_ii)/(exp(z_i)+exp(z_ii))`
  训练使用最终 token 的交叉熵损失。
- **模型身份标签**：训练时允许条件于目标模型身份 `M`，以利用模型特定模式；面对新目标模型时省略身份标签，实现零样本迁移。
- **训练数据构造**：联合 7 个模型、20 个 benchmark 的 32,419 条响应，其中视觉语言 17,778 条、文本 14,641 条。拒绝回答和空回答保留并标为错误。15 个 benchmark 用精确/模糊匹配评分，5 个用 GPT-5-mini 按 rubric 评分。
- **轻量发布版**：发布的 0.8B 纯文本检查点性能接近 8B 校准器，可通过 `pinocchio-uq` 包以两行代码集成。
