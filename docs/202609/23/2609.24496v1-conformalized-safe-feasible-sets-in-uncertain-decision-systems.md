## 摘要
安全关键决策系统通常要求下游优化器从一个由未观测标签 $Y$ 决定的未知可行集中进行选择。给定上下文 $X$，目标是以至少 $1-α$ 的概率构造一个包含在 oracle 可行集 $A(X,Y)$ 中的安全子集 $D(X)$。现有的共形方法通常构造未观测标签 $Y$ 的预测集，并保留对该集合中每个取值都安全的决策。尽管有效，但这要求一个比集合包含更强的中间事件。我们提出定向包含安全校准（DISC），一种共形框架，通过将包含事件的验证归约为标量临界包含分数，直接控制该事件的概率。给定一个预训练的候选可行集嵌套族，DISC 为每个有标签观测分配对应子集包含在 $A(X,Y)$ 中的最小嵌套层级，并在测试时使用经验分位数构造安全可行集。在数据可交换性下，这产生有限样本、分布无关的包含保证。在两个实用集合族下，我们表明 DISC 产生的安全可行集包含相应校准基线所得到的可行集。我们进一步开发了基于优化的分数计算和用于学习子集族的决策感知过程。在连续和结构化决策问题上的实验表明，DISC 在实现目标包含保证的同时产生更大的可行域。

## Abstract
Safety-critical decision systems often require a downstream optimizer to choose from an unknown feasible set determined by an unobserved label $Y$. Given a context $X$, the goal is to construct a safe subset $D(X)$ contained in the oracle feasible set $A(X,Y)$ with probability at least $1-α$. Existing conformal approaches typically construct a prediction set of the unobserved label $Y$ and retain decisions that are safe for every value in this set. Although valid, this requires a stronger intermediate event than set inclusion. We propose Directed Inclusion Safety Calibration (DISC), a conformal framework that directly controls the probability of this inclusion event by reducing its verification to a scalar critical-inclusion score. Given a pretrained nested family of candidate feasible sets, DISC assigns each labeled observation the smallest nestedness level at which the corresponding subset is contained in $A(X,Y)$, and constructs the safe feasible set using an empirical quantile at test-time. With data exchangeability, this yields a finite-sample, distribution-free inclusion guarantee. Under two practical set families, we show that DISC produces a safe feasible set containing that obtained by the corresponding calibration baseline. We further develop optimization-based score computation and decision-aware procedures for learning subset families. Experiments across continuous and structured decision problems show that DISC achieves the target inclusion guarantee while producing larger feasible regions.

## 1. 核心问题与研究动机

- **问题背景**：安全关键决策系统（如资源分配、自动驾驶规划、LLM 推理链筛选、目标检测）常需在不确定性尚未完全揭示时就作出决策。此时决策变量 $u \in \mathcal{U}$ 面临一个由未观测标签 $Y$ 决定的**未知可行集**：
  $$A(X,Y) = \{u \in \mathcal{U} : f(u;X,Y) \le 0\}$$
  其中 $X$ 为可观测上下文，$Y$ 为决策阶段不可见的标签，$f$ 为依赖数据的约束函数。
- **目标**：构造一个数据依赖的安全子集 $D(X) \subseteq \mathcal{U}$，使其满足**集合级包含保证**：
  $$P\{D(X) \subseteq A(X,Y)\} \ge 1-\alpha$$
  由于空集平凡满足该式，真正的挑战是构造既有效又足够大的可行集，以支撑下游目标 $\min_{u\in D(X)} \phi(u)$ 的优化。
- **现有方法的不足**：经典路线是"先共形预测标签、再做鲁棒优化"——先用共形预测构造 $Y$ 的预测集 $C(X)$（满足 $P\{Y\in C(X)\}\ge 1-\alpha$），再保留对所有 $y\in C(X)$ 都安全的决策：
  $$D_{\text{Base}}(X) = \{u : f(u;X,y)\le 0,\ \forall y \in C(X)\}$$
  该做法虽有效，但控制的是**标签覆盖**这一比集合包含**更强的中间事件**。即使 $Y \notin C(X)$，所得子集仍可能完全安全。这种不匹配会导致可行集过度收缩、甚至为空，从而损失决策效率。
- **整体含义**：论文主张**直接对包含事件本身做共形校准**，而非通过标签覆盖这一充分条件间接保证，从而在保留有限样本安全性的同时显著提升可行集的"可用性"。

## 2. 方法论：DISC 框架

### 2.1 核心思想

- 给定一个**预训练的嵌套候选可行集族** $\{D(X;\lambda): \lambda \in \mathbb{R}\}$，满足 $\lambda_1 \le \lambda_2 \Rightarrow D(X;\lambda_2) \subseteq D(X;\lambda_1)$（$\lambda$ 越大越保守）。
- 将集合包含事件**精确归约为标量阈值事件**：由于 $D(X_i;\lambda)$ 随 $\lambda$ 单调收缩，包含事件对 $\lambda$ 单调，故每个样本对应唯一的临界嵌套层级（**DISC 分数**）：
  $$V_i = \inf\left\{\lambda \in \mathbb{R} : \sup_{u\in D(X_i;\lambda)} f(u;X_i,Y_i) \le 0\right\}$$
  于是 $D(X_i;\lambda) \subseteq A(X_i,Y_i) \iff V_i \le \lambda$。
- 测试时取经验分位数：$\hat\lambda = Q_{1-\alpha}(\{V_i\}_{i=1}^n, \infty)$，输出 $\hat D_{\text{DISC}}(X_{n+1}) = D(X_{n+1};\hat\lambda)$。

### 2.2 理论保证（定理 2.1）

- 在数据可交换性下：$P\{\hat D_{\text{DISC}}(X_{n+1}) \subseteq A(X_{n+1},Y_{n+1})\} \ge 1-\alpha$。
- 若分数几乎必然互异，还有上界 $P \le 1-\alpha + 1/(n+1)$，即**有限样本、分布无关、紧致**的保证。

### 2.3 两类实用嵌套族与显式分数

- **预测集边际族（PS）**：$L_\lambda(u;X) = \sup_{y\in C(X;\lambda)} f(u;X,y)$，其中 $C(X;\lambda)=\{y: s(X,y)\le\lambda\}$ 为嵌套预测集。分数化为
  $$V_i = \sup_{u\in A^c(X_i,Y_i)} \left\{ \inf_{y:\,f(u;X_i,y)>0} s(X_i,y) \right\}$$
  即"最难排除的不安全决策"所需的最小预测集阈值。
- **加性残差边际族（Add）**：$L_\lambda(u;X)=\hat f(u;X)+\mu(u)+\lambda\sigma(u)$，分数为
  $$V_i = \sup_{u\in A^c(X_i,Y_i)} \frac{-\hat f(u;X_i)-\mu(u)}{\sigma(u)}$$
  当 $A^c$ 为多面体、$\hat f+\mu$ 与 $\sigma$ 仿射时，该线性分式规划在顶点处取到最优。
- **与基线的严格比较（命题 2.2、2.4）**：
  - PS 族下 $V_i \le V_i^{\text{Base-PS}} = s(X_i,Y_i)$（标签覆盖分数）；
  - Add 族下 $V_i \le V_i^{\text{Base-Add}} = \sup_{u\in\mathcal{U}} \frac{f-\hat f-\mu}{\sigma}$（全局均匀残差分数）。
  - 因此 $\hat D_{\text{Base}} \subseteq \hat D_{\text{DISC}}$ 几乎必然成立，即 **DISC 的可行集总是包含对应基线的可行集**。

### 2.4 分数计算

- 定义认证值 $g_i(\lambda)=\sup_{u\in D(X_i;\lambda)} f(u;X_i,Y_i)$，对 $\lambda$ 做二分求根。
- 三类可精确求解的情形：$f_i$ 凹且 $D$ 凸（凸优化）；$f_i$ 仿射/最大仿射且 $D$ 多面体（线性规划）；$f_i$ 凸且 $D$ 为紧多面体（顶点枚举）。
- 当精确求解不可行时，构造可计算的**上界** $\tilde g_i(\lambda)\ge g_i(\lambda)$ 与保守分数 $\tilde V_i$，定理 2.2 表明有限样本包含保证仍成立（代价是可行集可能更小）。

### 2.5 效率感知的族优化

- **O-DISC**：将族参数化为 $D_\theta(x;\lambda)$，用经验风险最小化同时学习形状参数 $\theta$ 与分位数阈值：
