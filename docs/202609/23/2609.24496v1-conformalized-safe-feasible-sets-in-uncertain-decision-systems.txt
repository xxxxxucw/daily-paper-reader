Abstract 

Safety-critical decision systems often require a downstream optimizer to choose from an unknown feasible set determined by an unobserved label Y . Given a context X,the goal is to construct a safe subset D(X) contained in the oracle feasible set A(X, Y )with probability at least 1 − α. Existing conformal approaches typically construct a prediction set of the unobserved label Y and retain decisions that are safe for every value in this set. Although valid, this requires a stronger intermediate event than set inclusion. We propose Directed Inclusion Safety Calibration (DISC ), a conformal framework that directly controls the probability of this inclusion event by reducing its verification to a scalar critical-inclusion score. Given a pretrained nested family of candidate feasible sets, DISC assigns each labeled observation the smallest nestedness level at which the corresponding subset is contained in A(X, Y ), and constructs the safe feasible set using an empirical quantile at test-time. With data exchangeability, this yields a finite-sample, distribution-free inclusion guarantee. Under two practical set families, we show that DISC produces a safe feasible set containing that obtained by the corresponding calibration baseline. We further develop optimization-based score computation and decision-aware procedures for learning subset families. Experiments across continuous and structured decision problems show that DISC achieves the target inclusion guarantee while producing larger feasible regions. 

Keywords: Conformal inference; Constrained optimization; Data-driven decision; Inclusion guarantee; Setwise calibration.

1arXiv:2609.24496v1 [stat.ME] 21 Sep 2026 1 Introduction 

Modern decision systems often act before safety-relevant uncertainty is fully resolved. For example, resource allocations are determined before future demand is realized, while an autonomous vehicle plans its motion without knowing the future trajectories of surrounding obstacles. In such problems, the object passed to a downstream optimizer is often not a prediction of the unknown label itself, but a feasible set that includes a set of admissible decisions and typically depends on the unknown label. The key problem is therefore how to construct a decision set that is contained in the unknown feasible set with high probability. Let u ∈ U denote a decision variable, where U is the decision space that can be discrete or continuous. Let ( X, Y ) ∈ X × Y denote a pair of random variables associated with the system, where X represents the observed context and Y denotes the label that remains unobserved at the decision stage. Let ϕ(·) : U → R be the deterministic objective function, and let f (·; X, Y ) : U → R be the data-dependent constraint function. We consider the following constrained optimization problem: min

ϕ(u) s.t. f (u; X, Y ) ≤ 0.

The oracle (true) feasible set of the problem above is thus 

A(X, Y ) = {u ∈ U : f (u; X, Y ) ≤ 0} . (1) When the true label Y is unknown, a pretrained point predictor ML (·) : X → Y provides a natural plug-in estimate of A(X, Y ) by replacing the true label Y with its prediction ML (X)in (1). However, prediction error may cause the resulting set A(X, ML (X)) to contain decisions that are infeasible under Y .Given independent and identically distributed (i.i.d.) data {(Xi, Y i)}ni=1 , together with the predictor ML (·), our goal is to construct a safe feasible set D(X) ⊆ U satisfying the 2following safety inclusion guarantee: 

P{

≥ 1 − α, (2) where α ∈ (0 , 1) is a prespecified safety level. This is a setwise feasibility guarantee: on the inclusion event D(X) ⊆ A(X, Y ), every decision u ∈ D(X) satisfies the feasibility condition under the true label Y , allowing an arbitrary objective ϕ(u) to be optimized over the same 

D(X). Since an empty D(X) satisfies (2) trivially, the key challenge is to construct a valid safe feasible set that is sufficiently large and flexible to support effective decision-making. A canonical application is chance-constrained programming (Charnes and Cooper, 1959; Nemirovski and Shapiro, 2006), which seeks to minimize the objective ϕ(u) subject to a probabilistic constraint P{f (u; X, Y ) ≤ 0} ≥ 1 − α. Here, X denotes observed contextual information, and Y captures unresolved future uncertainty, such as demand or system disturbances. In this case, the safe feasible set D(X) satisfying (2) provides a data-dependent inner approximation to the unknown feasible set A(X, Y ), and any downstream solution ̂

u(X) ∈ arg min u∈D(X) ϕ(u) inherits the probabilistic feasibility. For another example of the control or planning problem, Y may represent the future positions of a moving obstacle or another agent, and f (u; X, Y ) measures violation of a required separation between the decision trajectory and the obstacle (Lindemann et al., 2023; Dixit et al., 2023). In this case, the safe feasible set D(X) is a region where every trajectory can avoid collision with the obstacles with high probability. The same formulation can also extend to structured output problems, such as LLM reasoning problems, where Y records the validity of generated claims and f (u; X, Y ) measures whether the claims retained by a candidate output satisfy the desired validity criterion (Wei et al., 2022; Zhou et al., 2023). Although the decision spaces and feasibility criteria differ across these applications, they share the same target: identifying a collection of decisions that are feasible under the unknown realization Y .31.1 Our framework and contributions 

Classical predictive inference provides a baseline route to achieving the inclusion target (2). Given labeled data and an arbitrary predictive model, conformal prediction (Vovk et al., 2005; Lei et al., 2018) constructs a prediction set C(X) ⊆ Y satisfying P{Y ∈ C(X)} ≥ 1−α

under exchangeability. Robust optimization (Ben-Tal et al., 2009; Chenreddy et al., 2022) then retains only decisions that are safe for all y ∈ C(X), producing the feasible set 

DBase (X) = {u ∈ U : f (u; X, y ) ≤ 0, ∀ y ∈ C(X)}. (3) Whenever Y ∈ C(X), this subset DBase (X) is contained in the oracle feasible set A(X, Y ), and hence the label coverage, P{Y ∈ C(X)} ≥ 1−α, implies the desired safety guarantee (2). However, the label coverage is sufficient but not necessary for (2). Even when Y /∈ C(X), the constructed subset may still be entirely safe under the realized Y . Controlling label coverage therefore controls a stronger intermediate event than the required feasibility. This mismatch can unnecessarily shrink the feasible set and exclude useful decisions, or even produce an empty set. Motivated by the gap between label coverage and set inclusion, we propose a new framework Directed Inclusion Safety Calibration (DISC ) that directly controls the probability of the desired inclusion event. Specifically, we consider a nested family of candidate feasible sets {D(X; λ) : λ ∈ R}, where D(X; λ) ⊆ U and D(X; λ2) ⊆ D(X; λ1) whenever λ1 ≤ λ2.Thus, larger values of λ correspond to more conservative feasible sets. This formulation separates the construction of a safe feasible set into two components: specifying a nested set family that incorporates available predictive or structural information, and calibrating the nestedness level λ using labeled data. To calibrate λ, for each labeled observation ( Xi, Y i), 

DISC defines the score Vi = inf {λ ∈ R : D(Xi; λ) ⊆ A(Xi, Y i)}, the smallest nestedness level required for the candidate subset to be contained in the corresponding oracle feasible set. The test-time nestedness level is then chosen as an appropriate empirical quantile of these 4scores. By using the target inclusion event directly, rather than stronger sufficient conditions such as label coverage, DISC can reduce conservativeness while retaining feasibility. Our contributions are summarized as follows. • For any fixed nested feasible set family, DISC provides a finite-sample, distribution-free inclusion guarantee under exchangeability. Specifically, we consider two practical nested set families. The first is termed the prediction-set family, which follows the robust optimization construction in (3), with C(X) replaced by a sequence of nested prediction sets. The second is termed the additive residual family, which adds a tunable margin to the predicted constraint value f (u; X, ML (X)) to account for prediction error and retains decisions for which the adjusted value is nonpositive. For both families, we show that the DISC safe feasible sets contain those returned by the existing baseline calibration methods. • Computing the DISC score typically requires verifying set inclusion over a potentially continuous decision space. We formulate this verification as a constrained optimization problem at each fixed nestedness level λ and use bisection over λ to locate the score. We further provide family-specific reductions to simplify the optimization. When an exact solution of the constrained optimization is unavailable, we construct computable upper bounds on the DISC scores while preserving the finite-sample inclusion guarantee. • We develop O-DISC , which optimizes a parameterized family of feasible sets according to downstream decision risk. We establish an upper bound on the inclusion error of the optimized subset that quantifies the effect of family optimization, together with a nonasymptotic excess decision-risk bound relative to a population benchmark. We further develop FO-DISC , which restores the exact finite-sample inclusion guarantee at an additional computational cost. 51.2 Related work

Next, we review related work in two application areas relevant to the inclusion target (2). For chance-constrained programming, classical approaches (Ben-Tal et al., 2009; Nemirovski and Shapiro, 2006) use structural and distributional information to construct tractable safe approximations of the chance constraint P{f (u; X, Y ) ≤ 0} ≥ 1 − α. More recently, Zhao et al. (2024) propose conformal predictive programming, which replaces chance constraints with empirical-quantile constraints and uses an independent calibration set to obtain a posteriori feasibility guarantees for the resulting decision. In planning and control problems, several works (Lindemann et al., 2023; Dixit et al., 2023; Yang et al., 2023) construct safe decision regions of the baseline form (3) by enforcing feasibility uniformly over conformal prediction sets. These approaches obtain simultaneous feasibility through label coverage. 

DISC instead targets the inclusion event itself, avoiding a sufficient condition that can be 6unnecessarily restrictive. Several works apply conformal prediction to related decision-making tasks. For example, Johnstone and Cox (2021), Sun et al. (2023) and Patel et al. (2024) use conformal prediction sets as the uncertainty set in contextual robust optimization problems (Chenreddy et al., 2022), where the robustness of decisions can be guaranteed by the coverage of prediction sets. In addition, another line tailors the construction of conformal prediction sets to the downstream decision cost (Kiyani et al., 2025; Cortes-Gomez et al., 2025; Yeh et al., 2025; Bao et al., 2026; Wang and Dobriban, 2026). Specifically, Hu et al. (2026) develop a new method to directly control the robustness of the solution of robust optimization, instead of label coverage of prediction sets.

2.2 Instantiation of DISC under two nested families 

The validity result above requires only a fixed nested family. To turn this general calibration rule into practical constructions, we specify the candidate subset family through a margin function Lλ(·; X) : U → R, that is 

D(X; λ) = {u ∈ U : Lλ(u; X) ≤ 0}. (5) Here Lλ(u; X) is nondecreasing in λ, i.e., Lλ1 (u; X) ≤ Lλ2 (u; X) if λ1 ≤ λ2, ensuring the required nestedness of D(X; λ). This representation is not required for the general validity of DISC , but it provides a convenient structure for constructing practical safe feasible sets and deriving tractable DISC scores. The representation (5) admits two practically useful instantiations. Under both families, the structure of Lλ yields an explicit representation of the DISC score in (4) and facilitates comparison with existing calibration rules. 92.2.1 Prediction-set margin family

2.3 Computation of DISC scores 

Section 2.2 derives explicit representations of the DISC scores in two margin families. We now consider the computation of Vi for a general margin function family. Recall the score definition in (4). The margin representation (5) turns score computation into a verification problem at each nestedness level. For each labeled observation, write fi(u) ≡ f (u; Xi, Y i)and Li,λ (u) ≡ Lλ(u; Xi), and define the certification value 

gi(λ) = sup 

> u∈D(Xi;λ)

f (u; Xi, Y i), (10) which represents the worst-case violation over the candidate subset D(Xi; λ). Whenever 

gi(λ) ≤ 0 can be verified for any λ, the score Vi can be computed by bisection. If U is finite, as in the LLM reasoning problem (Wei et al., 2022; Zhou et al., 2023), gi(λ) can be computed exactly by enumerating the points satisfying Li,λ (u) ≤ 0. For continuous decision spaces, exact evaluation of gi(λ) remains possible in the following three standard optimization regimes. 

(1) Concave safety function. If fi is concave and D(Xi; λ) is convex, then computing gi(λ) in (10) is a standard convex optimization problem, since it maximizes a concave objective over a convex set (Boyd and Vandenberghe, 2004). This case includes the collision-avoidance problem and can be handled using off-the-shelf algorithms. 

(2) Affine safety function. If fi is affine (or max-affine) and D(Xi; λ) is polyhedral, then 

gi(λ) can be computed by solving a linear program. Such a polyhedral subset arises when U

14 is polyhedral and Lλ(u; Xi) is affine or max-affine in u, as in the resource allocation problem and related chance-constrained applications (Nemirovski and Shapiro, 2006). 

(3) Convex safety function. If fi is continuous and convex and D(Xi; λ) is a nonempty compact polyhedron, then the maximum is attained at a vertex of D(Xi; λ). Hence, gi(λ)can be computed exactly by enumerating the vertices of D(Xi; λ), although the number of vertices may grow exponentially with the problem dimension. # 3 Efficiency-Aware Optimization of Safe Feasible Sets 

Section 2 establishes finite-sample validity for any fixed feasible set family, but does not 15 distinguish among families with different downstream efficiency. Let ϕ : U → R denote the downstream cost function, where smaller values indicate more efficient decisions. Given a safe feasible set D(X) ⊆ U , the corresponding decision solves the problem min u∈D(X) ϕ(u). The optimal value measures the decision cost of D(X) and therefore provides a natural criterion for optimizing the safe feasible set while controlling inclusion error. We parameterize the candidate feasible set as Dθ(x; λ) = {u ∈ U : Lθ,λ (u; x) ≤ 0},where Lθ,λ is nondecreasing in λ for each fixed θ. The parameter θ controls the shape of the candidate set, whereas λ controls its nestedness level. For example, the prediction-set family can use Lθ,λ (u; x) = sup y∈Cθ (x;λ) f (u; x, y ) with Cθ(x; λ) = {y ∈ Y : sθ(x, y ) ≤ λ},while the additive residual-margin family can take Lθ,λ (u; x) = ˆf (u; x) + μθ(u) + λσ θ(u).

4.1 Chance-constrained resource allocation experiment 

Contextual resource allocation under uncertain demand is a continuous chance-constrained programming problem. The context is sampled as X ∼ Unif([ −1, 1] 5), and the demand 

Y = ( Y1, Y 2) is generated by Yj = [ mj (X) + ςj (X)ξj ]+, j = 1 , 2, where ξ1, ξ 2 are independent noise variables. # 5 Real Data Applications 

In this section, we evaluate DISC in two real-data applications: LLM reasoning-chain verification and safe object detection, with discrete decision spaces.

# 6 Concluding Remarks 

This paper formulates feasible set inclusion as a setwise conformal inference problem and proposes DISC to control the probability of this target directly. For a fixed nested family, DISC converts set inclusion into a scalar critical threshold and yields a finite-sample, distribution-free marginal guarantee under exchangeability. In particular, we show that 

DISC is no more conservative than the corresponding label coverage and uniform-residual calibration rules for the prediction-set and additive residual-margin families, respectively. The numerical studies show that our method maintains the inclusion rate near the target safety level while producing larger or more useful decision regions and lower decision costs. Several extensions follow naturally from the present framework. First, Appendix I characterizes a theoretically optimal safe feasible set, but turning this design into a practical method requires efficient estimation of conditional distributions. Also, the guarantees established here are marginal over the joint distribution of ( X, Y ), and so it warrants further study of feasible conditional inclusion guarantees.

This appendix describes implementation details of experiments in Section 5.1. We use additive residual-margin families throughout, since there is no tractable conformal 69 prediction set for the latent reasoning chain that can be propagated through the constraint function in closed form. We compare four directed-calibration procedures, DISC-Const ,

DISC-Mean , DISC-Linear , and DISC-Sqrt , with their uniform-residual counterparts,

G.1 Detailed settings 

Generation, decomposition, and candidate output family. We use Qwen-Flash for response generation, claim decomposition, dependency graph induction, claim confidence scoring, and reference-based claim judging, with stage-specific prompts. Following Rubin-Toles et al. (2025), we represent each generated response as a reasoning graph. For each prompt X, a base LLM first generates one complete response by a fixed “solve step by step” instruction.
