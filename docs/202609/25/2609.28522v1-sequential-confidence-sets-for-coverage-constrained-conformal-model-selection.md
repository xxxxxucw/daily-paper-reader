## 摘要
现代共形预测系统通常维护若干自适应流程，这些流程在基础预测器、符合性评分、校准窗口和更新规则上各不相同。比较它们很困难，因为覆盖率是硬约束，而效率只应在可行流程中进行优化。我们将该问题表述为随机约束 argmin 的序贯推断。在每个时刻，目标是满足多个前缀平均条件未覆盖约束的最小成本流程集合。我们提出覆盖约束序贯模型置信集（CC-SMCS），它将流程划分为可认证可行、可能可行以及可能约束最优的流程。利用同时鞅置信序列，CC-SMCS 将矩形置信区域投影到约束 argmin 上，并具有精确的闭式规则。以至少 $1-δ$ 的概率，它在所有时刻同时包含每个约束最优流程。这一有限样本保证不需要平稳性或混合性假设，并且在数据依赖停止下仍然有效。我们还建立了一个关于覆盖边界处安全认证的不可能性结果，并将该构造扩展到延迟多时域反馈和结果依赖的效率目标。

## Abstract
Modern conformal forecasting systems often maintain several adaptive pipelines that differ in base forecasters, conformity scores, calibration windows, and update rules. Comparing them is difficult because coverage is a hard constraint, whereas efficiency should be optimized only among feasible pipelines. We formulate this problem as sequential inference for a stochastic constrained argmin. At each time, the target is the set of minimum-cost pipelines satisfying multiple prefix-average conditional miscoverage constraints. We introduce Coverage-Constrained Sequential Model Confidence Sets (CC-SMCS), which separate certifiably feasible, possibly feasible, and possibly constrained-optimal pipelines. Using simultaneous martingale confidence sequences, CC-SMCS projects a rectangular confidence region onto the constrained argmin and admits an exact closed-form rule. With probability at least $1-δ$, it contains every constrained-optimal pipeline simultaneously over all times. This finite-sample guarantee requires no stationarity or mixing assumptions and remains valid under data-dependent stopping. We also establish an impossibility result for safe certification at the coverage boundary and extend the construction to delayed multi-horizon feedback and outcome-dependent efficiency objectives.

## 1. 核心问题与整体含义

- **背景**：现代共形预测系统常并行维护多个自适应流程，它们在基础预测器、符合性评分、校准窗口、名义水平、更新规则等方面不同，且相对表现会随分布漂移变化。
- **核心矛盾**：覆盖率是**硬约束**，效率只能在满足覆盖约束的可行流程中优化。把宽度与欠覆盖合并成标量目标会偏离原问题，可能偏向欠覆盖方法；先筛覆盖率再选最窄流程的两阶段法也有缺陷——未能拒绝不可行不等于可行。
- **推断目标**：不追求选出一个流程，而是问“在每个时刻，哪些流程仍可能是覆盖约束下的最优流程”。形式化为随机约束 argmin 的序贯推断：在每个时刻 \(t\)，目标是满足多个前缀平均条件未覆盖约束的最小成本流程集合 \(M_t^\star\)。
- **整体含义**：提出覆盖约束序贯模型置信集（CC-SMCS），以至少 \(1-\delta\) 的概率在所有时刻同时包含所有约束最优流程，且无需平稳性、混合性或交换性假设，并允许数据依赖停止。

## 2. 方法论：核心思想、关键技术与算法流程

- **问题设定**：
  - 有 \(M\) 个候选共形流程、\(R\) 个监控约束。
  - 对方法 \(m\)、约束 \(r\)，定义未覆盖指示 \(B_{mrt}=1\{Y_t\notin C_{mrt}\}\)，可预测暴露权重 \(a_{rt}\in[0,1]\)，容忍未覆盖率 \(\tau_r\)。
  - 前缀平均条件超额未覆盖为
    \[
    \Gamma_{mr,t}=A_{r,t}^{-1}\sum_{s=1}^t \mu_{mrs},\quad \mu_{mrt}=E[X_{mrt}\mid G_{t-1}],\quad X_{mrt}=a_{rt}(B_{mrt}-\tau_r).
    \]
  - 可行集 \(V_t^\star=\{m:\Gamma_{mr,t}\le 0,\forall r\}\)，约束最优集 \(M_t^\star=\arg\min_{m\in V_t^\star}Q_{m,t}\)，其中 \(Q_{m,t}\) 是可观测的加权前缀平均集合成本（如区间宽度）。
- **核心思想**：用同时鞅置信序列为每个 \((\Gamma_{mr,t})\) 构造时间均匀上下界 \(L_{mr,t},U_{mr,t}\)，再把矩形置信区域投影到约束 argmin 上。
- **置信序列构造**：
  - 采用 empirical-Bernstein 构造与 gamma-exponential mixture boundary \(\hat b_{\eta,\rho}(v)\)。
  - 分配误差 \(\eta_{mr}=\delta\pi_{mr}\)，\(\sum_{m,r}\pi_{mr}=1\)，经联合界得到
    \[
    P(\forall t,m,r: L_{mr,t}\le \Gamma_{mr,t}\le U_{mr,t})\ge 1-\delta.
    \]
- **三类流程划分**：
  - 可认证可行集：\(\hat V_t^{cert}=\{m:U_{mr,t}\le 0,\forall r\}\)。
  - 可能可行集：\(\hat V_t^{pos}=\{m:L_{mr,t}\le 0,\forall r\}\)。
  - 在联合置信事件上，有 \(\hat V_t^{cert}\subseteq V_t^\star\subseteq \hat V_t^{pos}\)。
- **矩形投影与闭式规则**：
  - 定义 \(q_t^{cert}=\min_{j\in \hat V_t^{cert}}Q_{j,t}\)，空集时为 \(+\infty\)。
  - 则
    \[
    \hat M_t^{proj}=\{m\in \hat V_t^{pos}: Q_{m,t}\le q_t^{cert}\}.
    \]
  - 该规则是精确的矩形投影，计算复杂度为 \(O(MR)\)。
- **理论保证**：
  - 在可测性与有界增量条件下，
    \[
    P(\forall t\ge 1: \hat V_t^{cert}\subseteq V_t^\star\subseteq \hat V_t^{pos},\; M_t^\star\subseteq \hat M_t^{proj})\ge 1-\delta.
    \]
  - 对任意停止时间 \(T\)，若 \(T<\infty\)，则 \(M_T^\star\not\subseteq \hat M_T^{proj}\) 的概率至多 \(\delta\)。
  - 持续暴露下置信半径以 \(O(\sqrt{(\log t+\log(MR/\delta))/t})\) 收缩。
- **边界不可能性**：
  - 在覆盖边界处，即使已知某候选成本严格更优，也未必能以高概率识别唯一 oracle。
  - 若 \(p\uparrow\tau\)，高概率识别所需样本量至少为 \((\tau-p)^{-2}\) 量级。
  - 预设容忍 \(\tau_r=\alpha_r+\epsilon_r,\epsilon_r>0\) 可制造严格可行边际，使认证最终可行。
- **扩展**：
  - **延迟多时域反馈**：按预测起点模 \(h\) 的余数类划分，每个 \((m,r,h,k)\) 流单独构造置信序列，并分配总误差。
  - **结果依赖效率目标**：为成对目标差构造同时下置信序列，得到外集合 \(\hat M_t^{loss}\)，但一般不是精确联合投影。
