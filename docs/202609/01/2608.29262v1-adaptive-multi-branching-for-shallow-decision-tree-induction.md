## 摘要
决策树因其每个预测都遵循可解释的特征阈值测试序列，在表格预测任务中颇具吸引力。然而，在严格的最大深度预算下，传统二叉树可能表达能力不足，因为每个内部节点仅做出单一阈值决策。我们研究浅层树归纳问题，其目标是在保持根到叶路径较短的同时提高准确性。我们提出带有自适应剪枝的多分支神经决策树（MBNDT），这是一种通过端到端训练、具有可微多路分裂的单一轴对齐树。每个内部节点学习所选特征上的有序阈值以及一个自适应调整其有效分支数的分支掩码，训练后的模型被转换为确定性单路径树用于推理。在21个OpenML二分类基准测试中，MBNDT在深度受限的单树基线中取得了最佳平均排名和平均平衡准确率；一项受控消融实验将多路分裂确定为增益来源。这些增益伴随着明确的权衡：MBNDT比其它单树基线产生更多叶节点，使其最适用于在短而有界的决策路径下优先考虑准确性而非最小全局树大小的场景。

## Abstract
Decision trees are attractive for tabular prediction tasks because each prediction follows an interpretable sequence of feature-threshold tests. Under a strict maximum-depth budget, however, conventional binary trees can be under-expressive, since each internal node makes only a single threshold decision. We study shallow-depth tree induction, where the goal is to improve accuracy while keeping root-to-leaf paths short. We propose the Multi-Branch Neural Decision Tree with Adaptive Pruning (MBNDT), a single axis-aligned tree trained end-to-end with differentiable multi-way splits. Each internal node learns ordered thresholds over a selected feature and a branch mask that adapts its effective arity, and the trained model is converted to a deterministic single-path tree for inference. Across 21 OpenML binary-classification benchmarks, MBNDT achieves the best average rank and mean balanced accuracy among depth-constrained single-tree baselines; a controlled ablation isolates multi-way splitting as the source of the gain. These gains come with an explicit trade-off: MBNDT realizes more leaves than the other single-tree baselines, making it best suited when accuracy under short, bounded decision paths is prioritized over minimal global tree size.

# 论文总结：Adaptive Multi-Branching for Shallow Decision Tree Induction

## 1. 核心问题与整体含义

- **研究背景**：决策树因其“根到叶路径由特征–阈值测试构成”的天然可解释性，在表格数据预测中广泛使用；路径长度常被作为局部检查成本的代理，叶节点数则反映全局模型大小。
- **问题定义**：在严格的最大深度预算（如 D≤4）下，传统二叉决策树表达力受限——每个内部节点仅能做一个阈值决策，最多形成 2^D 个叶节点，难以刻画复杂或不规则的类别边界。
- **核心矛盾**：浅层树的路径短、便于人工审计，但标准二叉树在浅层时准确率不足；贪心算法在根节点处可能做出局部次优选择，且难以在有限深度内修正。
- **研究目标**：在保持“根到叶路径较短、单一路径推理”的前提下，通过提升局部划分能力而非加深树来提升浅层树的预测准确率。
- **整体含义**：本文提出一种**可微多路分支决策树**，为浅层可解释模型中“深度受限与表达能力”的折中提供了新思路，并系统量化了其与全局树大小之间的权衡。

## 2. 方法论

- **模型名称**：MBNDT（Multi-Branch Neural Decision Tree with Adaptive Pruning，带自适应剪枝的多分支神经决策树）。
- **核心思想**：把每个内部节点从“单阈值二分”扩展为“同一特征上的多阈值有序区间划分（多路分裂）”，并通过端到端梯度优化联合学习分裂特征、阈值和叶节点输出。
- **关键技术细节**：
  - **特征选择**：节点使用特征 logits 经 entmax1.5 得到稀疏概率，前向用 one-hot（argmax）保证轴对齐，反向用 straight-through estimator 传递梯度。
  - **有序阈值参数化**：为满足阈值严格递增，将 B−1 个阈值表示为基阈值 t0 与 softplus 正间隙的累积和，从而免去排序操作且保持可微。
  - **软路由与硬路由**：用累积逻辑分布计算 B 个区间概率（πj = 相邻累积概率差），训练时前向采用 one-hot 硬路由、反向直通梯度；推理时恢复为纯单路径决策。
  - **自适应分支掩码**：每个内部节点学习 sigmoid 化的分支掩码 m，对路由概率做乘法偏置并重新归一化；掩码可全局抑制弱分支，等效改变节点的实际分支数（arity），避免所有节点都使用满 B 叉。
  - **叶预算正则**：以反 Simpson 指数定义节点有效分支数 Neff，结合软可达概率构建可微的“软叶计数” Lsoft，采用增广拉格朗日式惩罚 μ[Lsoft−K]+ + ρ/2 [Lsoft−K]²₊ 控制叶数。
  - **训练后剪枝**：基于训练集硬路由路径，只保留实际出现过的分支；被剪分支的输入重定向到最近存活分支，叶 logits 不变，得到最终确定性剪枝树。
- **损失函数**：平衡二分类交叉熵 + 叶预算正则项，Adam 优化，并采用随机重启和早停等训练细节。

## 3. 实验设计

- **基准数据集**：21 个 OpenML 二分类数据集合，按规模分层：
  - 小规模（n<10³）：hepatitis、colic、vote、breast-w、blood-transfusion 等；
  - 中规模（10³≤n<10⁴）：credit-g、qsar-biodeg、banknote、mushroom 等；
  - 大规模（10⁴≤n≤10⁵）：MagicTelescope、bank-marketing、electricity、adult；
  - 海量规模：creditcard（约 28 万）、SEA(50000)（100 万实例）。
- **对比方法**（单树基线）：
  - **CART**：贪心二叉决策树；
  - **SPLIT**：基于有界 lookahead 的近似最优浅层树（作为最优/近最优树求解器的可扩展代理）；
  - **GradTree**：梯度训练的二值轴对齐树；
  - **XGBoost**：仅作黑盒参考，不视为单树可比较模型。
- **统一评估协议**：
  - 所有单树方法最大深度 D≤4；MBNDT 对 B∈{3,4} 调优；
  - 5 次 80/20 外部分层划分，内部 Optuna 做 5 折 HPO，每方法每次外部分裂最多 1 小时墙钟预算；
  - 使用平衡准确率作为主要指标，并报告路径长度、实际叶数和拟合时间；
  - 统计检验：Friedman 检验、配对 Wilcoxon 符号秩检验（Holm 校正）。
- **消融实验**：
  - 分支因子：B=2 vs B=3 vs B=4（固定 D=4、K=16）；
  - 分支掩码 × 后验剪枝：2×2 受控消融（关闭叶预算以分离归因）；
  - 叶预算扫描：K=4、16、64、无预算、HPO 选择。

## 6. 主要结论与发现

- **性能**：在深度受限的单树方法中，MBNDT 平均排名最高（1.48）、赢得 15/21 个数据集、平均平衡准确率最高（0.832），优于 CART（0.822）、SPLIT（0.790）和 GradTree（0.762）。
- **统计显著性**：Friedman 检验拒绝四种方法性能相同（p≈2.37×10⁻⁶）；配对 Wilcoxon 检验显示 MBNDT 对每个基线均有显著提升（最优对 GradTree，最小但对 CART 仍显著）。
- **多路分支是关键**：在固定深度和叶预算下，B=3 相比 B=2 将准确率从 0.820 提高到 0.833，且平均路径更短，说明增益来自于局部划分能力而非路径变长。
- **分支掩码与剪枝各司其职**：后验剪枝提供大部分叶数压缩；分支掩码在训练中塑造路由，带来微小但稳定（且剪枝后仍存在）的准确率增益；二者结合获得最优的准确率–规模平衡。
- **叶预算可作为精度–规模调节旋钮**：K 越大精度越高但叶数越多，且 K=16 时已接近饱和；相对基线，MBNDT 始终处于“更高精度但更多叶”的工作点。
- **明确权衡**：MBNDT 平均实现 20.6 个叶，明显多于 CART（10.3）、GradTree（11.5）和 SPLIT（6.1），因此最适合“短、有界决策路径下优先准确性”的应用，而非追求全局最小树的场景。

## 7. 优点

- **方法创新性**：将多路数值分裂、梯度端到端训练与可学习自适应分支数统一在一个单一轴对齐树中，且推理时转化为确定性单路径树。
- **技术设计细致**：softplus 累积和保证阈值有序；entmax + straight-through 实现硬特征选择与硬路由可微；分支掩码为全局稀疏化提供简洁机制。
- **实验严谨**：21 个数据集、分层规模、统一深度约束和 HPO 预算、嵌套交叉验证与多重统计检验，结论可信度较高。
- **透明呈现权衡**：不仅报告准确率，还明确报告路径长度、叶数、训练时间和叶预算影响，方便实际应用判断。
- **可复现性**：提供 GitHub 实现链接。

## 8. 不足与局限

- **任务范围**：仅验证二分类；多分类和回归扩展尚未实现。
- **可解释性论证较弱**：仅以路径长度和叶数作为复杂度代理，未引入“路径中不同特征数”“条件冗余度”等更细粒度可解释性指标，也未开展人类评估。

- **基线选择限制**：未与精确最优树求解器直接对比（以 SPLIT 替代），也未包含软路由/集成树作为参考（后者因非单路径被排除，但可能与可解释性讨论相关）。
