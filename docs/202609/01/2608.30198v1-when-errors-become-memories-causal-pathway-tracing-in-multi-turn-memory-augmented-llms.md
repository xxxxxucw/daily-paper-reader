## 摘要
长期记忆使大语言模型（LLMs）能够在交互中保留和复用信息，但也可能将局部错误转化为持续风险。现有工作主要评估记忆系统是否正确存储和检索信息，对错误如何在响应、记忆状态和未来交互之间传播的理解仍然有限。我们提出一个基于结构因果模型（SCM）的框架，用于分析记忆增强LLM中的跨轮错误传播。我们将用户问题、模型响应和记忆状态建模为动态因果过程，并识别两条进入路径：内部记忆更新和外部问题反馈。通过干预这些路径，我们构建了四个反事实轨迹，并量化其下游效应和交互作用。错误影响在四个层面进行评估：记忆保留、自然响应、目标诊断探针和概率级错误偏好。实验表明，错误影响通常随交互距离衰减，而记忆更新路径比问题反馈产生更持久的影响；即使从自然响应中消失，潜在错误仍可能保留。传播模式也因记忆类别和记忆机制而异。路径引导的恢复进一步验证了这种分解：问题修复将残余错误减少27.5%，记忆修复减少70.2%，联合修复减少98.3%，几乎消除了残余传播。

## Abstract
Long-term memory enables large language models (LLMs) to preserve and reuse information across interactions, but it can also turn localized errors into persistent risks. Existing work mainly evaluates whether memory systems store and retrieve information correctly, leaving limited understanding of how errors propagate across responses, memory states, and future interactions. We propose a structural causal model (SCM)-based framework for cross-turn error propagation in memory-augmented LLMs. We model user questions, model responses, and memory states as a dynamic causal process, and identify two entry pathways: internal memory updating and external question feedback. By intervening on these pathways, we construct four counterfactual trajectories and quantify their downstream effects and interaction. Error influence is evaluated at four levels: memory retention, natural responses, targeted diagnostic probing, and probability-level error preference. Experiments show that error influence generally decays with interaction distance, while the memory-update pathway contributes more persistent effects than question feedback; latent errors may remain even after disappearing from natural responses. Propagation patterns also vary across memory categories and memory mechanisms. Pathway-guided restoration further validates this decomposition: Question Repair reduces residual error by 27.5%, Memory Repair by 70.2%, and Joint Repair by 98.3%, nearly eliminating residual propagation.

## 1. 核心问题与整体含义

- **研究动机**：长期记忆使大语言模型（LLMs）能够在多轮交互中持续保留和复用信息，但这也带来一个关键风险——局部的模型错误一旦被写入长期记忆，就可能在后续交互中被反复检索和复用，从而演变为持续性的系统风险。在健康管理、财务规划、任务执行等高风险场景中，这种持久错误可能影响用户决策或智能体行为，造成严重后果。
- **现有研究不足**：已有工作（如 LongMemEval、MemBench、MemoryAgent-Bench）主要评估记忆系统是否能正确存储和检索信息，关注的是"记住与否"的正确性问题，而**缺乏对错误如何在响应、记忆状态和未来交互之间动态传播的因果理解**。此外，现有因果分析研究（如因果追踪、激活修补）大多限于单次生成轨迹内的内部机制分析，未扩展至跨轮系统级动态。
- **核心科学问题**：当一个错误响应产生后，它如何通过哪些因果路径影响后续的对话历史、用户提问、记忆状态和模型生成？两条主要路径（内部记忆更新和外部问题反馈）各自的贡献有多大？它们之间是否存在交互效应？

## 2. 方法论

### 2.1 动态结构因果模型（SCM）

- 将多轮交互抽象为一个按交互轮次索引的结构因果模型，变量包括：用户问题 Q_r、模型响应 A_r、第 r 轮生成响应前可用的记忆状态 M_r。
- 采用**一阶马尔可夫假设**：第 r 轮的变量仅依赖第 r-1 轮和当前轮的变量，更早信息通过中间状态传递。
- 因果图中包含四类关系：
  - **记忆持久化**（M_{r-1} → M_r）：长期记忆的跨轮保留
  - **记忆更新**（Q_{r-1} → M_r 和 A_{r-1} → M_r）：用户问题与模型响应都被写入记忆
  - **问题延续**（A_{r-1} → Q_r）：前一轮响应塑造用户下一轮提问方向
  - **响应生成**（Q_r → A_r 和 M_r → A_r）：当前响应由当前问题与记忆共同决定

### 2.2 两条错误进入路径

- **记忆更新路径**（A_{r-1} → M_r → A_r）：错误响应中的信息被提取并存储到长期记忆，后续生成被污染的记忆状态所偏置。
- **问题反馈路径**（A_{r-1} → Q_r → A_r）：错误响应误导用户基于错误前提继续提问，使对话沿着错误轨迹演进。

### 2.3 四个反事实轨迹设计

- 在错误注入轮 t，为同一问题构造匹配的正确响应 A_t^c 和错误响应 A_t^e（仅目标命题不同，其余内容与措辞尽可能一致）。
- 将两种响应分别送入记忆更新器和下一问题生成器，构造 2×2 联合干预设计：

| 轨迹 | 记忆状态输入 | 问题生成输入 | 含义 |
|------|-------------|-------------|------|
| T_cc | 正确 | 正确 | 完全干净 |
| T_ec | 错误 | 正确 | 仅记忆更新路径 |
| T_ce | 正确 | 错误 | 仅问题反馈路径 |
| T_ee | 错误 | 错误 | 两条路径均进入 |

- 干预后四个轨迹独立自然演化，差异即归因于不同的错误进入机制。

### 2.4 四层错误传播结果度量

- **记忆保留**（Y_M(k)）：目标错误是否仍存在于交互距离 k 的记忆状态中
- **自然响应**（Y_A(k)）：自然生成的响应（不经过探针）是否包含目标错误
- **受控诊断探针**（Y_C(k)）：面对直接询问目标事实的诊断问题 q_k，响应是否包含错误
- **概率级错误偏好**（Y_P(k)）：通过长度归一化的对数似然差，衡量生成分布中错误答案相对正确答案的偏好偏移（以比特为单位）

### 2.5 因果效应估计量

- **总传播效应**（TPE）：T_ee 与 T_cc 的期望差
- **记忆更新路径效应**（PE_M）：T_ec 与 T_cc 的期望差
- **问题反馈路径效应**（PE_Q）：T_ce 与 T_cc 的期望差
- **路径交互效应**（PIE）：TPE − PE_M − PE_Q，衡量两条路径的加性偏离（正为超加性，负为次加性）

## 3. 实验设计

### 3.1 数据集

- 现有开源多轮对话数据集不支持所需的路径特异干预，因此**自建 144 个多轮交互样本**。
- 覆盖六类记忆类别：**约束（Constraint）、决策（Decision）、计划（Plan）、偏好（Preference）、资料（Profile）、日常（Routine）**，每类 24 个实例。
- 每次交互包含 15 轮，在第 3 轮注入目标错误，追踪后续 12 轮（k ∈ {1, ..., 12}）。

### 3.2 模型配置

- **答案模型**：Qwen2.5-7B-Instruct 和 OLMo3-7B-Instruct（两个架构不同的 7B 模型，用于跨模型验证）
- **辅助模型**：Qwen2.5-32B-Instruct（用于问题模拟、反事实构造和命题级评估）
- **记忆机制**：
  - 主设定：MemoryBank 风格（持续更新的动态记忆状态）
  - 变体：情节检索（独立记忆条目 + Top-3 检索，基于长度归一化的词法重叠得分）

### 3.3 有效实例筛选

- 仅保留"正确响应产生干净记忆状态且错误响应成功写入目标错误"的实例：Qwen 得到 125 个有效实例，OLMo 得到 120 个。
- 每个有效实例在四个反事实轨迹下分别执行。
- 效应值为实例平均，置信区间为 5,000 次自举重采样的 95% 百分位区间。

### 3.4 评估器鲁棒性检验

- 使用 GLM-5.2 对全部 35,280 个命题级结果重新评估，用 GPT-5.5 对 900 个分层抽样结果评估。
- Qwen 评估器与两个外部评估器的一致率分别为 91.9%（GLM，κ=0.709）和 89.3%（GPT，κ=0.591）。

## 6. 主要结论与发现

1. **错误影响总体随交互距离衰减**，但衰减速度因度量层级而异：自然响应中的错误效应衰减最快（k=1 时约 0.58~0.64，k=12 时降至约 0.04~0.07），而记忆状态和受控探针的效应持续时间显著更长（k=1 时记忆状态效应接近 1.0）。
2. **概率级错误偏好**是更敏感的探测器：k=1 时总效应达 2.726（Qwen）和 1.646（OLMo）比特，表明即使自然响应不包含错误，生成分布中仍存在显著的错误偏好偏移。
3. **记忆更新路径比问题反馈路径贡献更强、更持久**，这在不同结果度量和两个模型中都保持一致。交互效应多为负或接近零，可能是因为两条路径下游影响存在重叠，一条路径已诱发错误时另一条的边际贡献变小。
4. **记忆类别影响传播模式**：偏好类错误主要通过记忆保留持续；计划类错误通过记忆保留和问题改变共同维持；日常类错误两条路径均有贡献；约束、决策、资料类错误衰减较快或波动较大。跨模型差异说明传播模式还取决于模型的记忆存储同利用方式。
5. **记忆机制影响错误持久性**：MemoryBank 持续更新导致效应稳步衰减，而情节检索使错误条目长期保留在记忆中，效应持续居高不下。但两种机制下记忆更新路径都主导了记忆状态的错误效应。
6. **路径引导修复有效**：Memory Repair 将残留错误减少 70.2%，Question Repair 仅减少 27.5%，Joint Repair 减少 98.3%，几乎完全消除残余传播。在独立验证实例上，问题反馈路径效应的大小与 Question Repair 的收益正相关（ρ=0.335），进一步验证了因果分解的实用价值。

## 7. 方法优点

- **因果框架创新性强**：首次将 SCM 框架应用于记忆增强 LLM 的跨轮错误传播分析，将多轮对话中的"问题—响应—记忆"动态统一建模，填补了单轮因果分析与系统级传播之间的空白。
- **反事实轨迹设计精巧**：两条通路 × 两种输入的 2×2 联合干预设计，可以干净地分离记忆更新与问题反馈的独立贡献及交互效应。正确/错误响应仅目标命题不同，最大限度控制了混淆因素。
- **多层次结果度量**：从记忆状态（内部表征）到自然响应（显式行为）到受控探针（可揭示性）到概率级偏好（潜在分布），四个层级互补，能发现"从自然响应中消失但仍有潜在影响"的隐藏错误。
- **跨维度验证充分**：两个不同模型、六类记忆类别、两种记忆机制、三个评估器，多维度交叉验证了结论的稳健性。
- **方法兼具诊断与修复价值**：路径引导修复实验连接了因果分析与实际干预，证明分解结果可直接指导错误修复策略的优先级选择。

## 8. 不足与局限

- **数据规模与覆盖有限**：仅 144 个自建样本、六类记忆类别，样本量不大；部分类别（如资料、日常）在远距离上的效应信号较弱。数据集为合成构造，缺少真实长对话数据的验证。
- **模型规模与泛化性**：答案模型仅有两个 7B 模型，未验证更大模型（如 70B 以上）或多语言、多领域场景下的结论是否成立。
- **对话模拟偏差**：后续问题由 Qwen2.5-32B 生成，模拟用户行为，可能与真实用户基于错误响应的自然反应有差异（真实用户可能质疑、纠正或改变话题）。问题反馈路径的效应可能被低估或高估。
- **评估器依赖**：命题级评估依赖 LLM 判定，虽验证了跨评估器一致性，但评估器的内部偏差仍可能影响绝对效应值。且评估器自身的信念偏置可能影响对"错误"的判定，尤其在模糊或有争议的命题上。
- **交互效应解释有限**：论文报告 PIE 多为负或接近零，但对"重叠下游影响/结果饱和"的机制解释缺乏进一步的实验证据。
- **记忆机制覆盖不够全面**：仅比较了 MemoryBank 和情节检索两种变体，未覆盖 MemGPT 式的分层内存管理、LongMem 式的解耦架构、基于图结构的记忆等更丰富的记忆机制。
- **修复实验范围有限**：修复实验仅使用 Qwen2.5-7B、MemoryBank 机制、单一修复轮次（k=3）和受控探针度量，未测试不同修复时机、不同记忆机制下的修复效果，也缺少对自然响应度量的修复评估。
