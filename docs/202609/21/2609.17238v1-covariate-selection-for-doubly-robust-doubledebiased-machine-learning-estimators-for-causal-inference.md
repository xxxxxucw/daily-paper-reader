## 摘要
高维数据给因果效应估计带来挑战，因为识别正确模型设定所需的协变量变得越来越困难。双重/去偏机器学习（DML）通过减轻正则化和过拟合偏差，促进了机器学习（ML）在因果推断中的应用，但相对于某些 DML 估计量所具有的双稳健（DR）性质，协变量选择受到的关注相对较少。特别是，基于 ML 的协变量选择可能导致差异化协变量选择，或导致两个模型均设定错误，从而限制了 DR 性质的实际效用。为解决这些问题，我们提出使用倾向得分（PS）模型和结果 ML 模型所选协变量的并集来重新估计这两个模型。模拟结果表明，与使用分别选择的协变量集相比，使用并集能一致地减少更多混杂偏差。结果还表明，即使在对 Lasso 有利的条件下，基于 ML 的估计也并非一致优于传统 DR 估计，并且 post-Lasso 比标准 Lasso 减少更多混杂偏差。这些发现表明，成功地将 ML 用于因果推断不仅取决于 ML 算法，还取决于如何将通过协变量选择获得的信息纳入因果效应估计。

## Abstract
High-dimensional data create challenges for causal effect estimation because identifying the covariates needed for correct model specification becomes increasingly difficult. Double/debiased machine learning (DML) facilitates the use of machine learning (ML) for causal inference by mitigating regularization and overfitting bias, but comparatively less attention has been given to covariate selection in relation to the double robustness (DR) property possessed by some DML estimators. In particular, ML-based covariate selection may result in differential covariate selection or in misspecification of both models, thereby limiting the practical utility of the DR property. To address these issues, we propose using the union of the covariates selected by the propensity score (PS) and outcome ML models to re-estimate both models. Simulation results show that using the union consistently reduces more confounding bias than using separate selected covariate sets. The results also show that ML-based estimation does not uniformly outperform conventional DR estimation, even under conditions favorable to the Lasso, and that post-Lasso reduces more confounding bias than standard Lasso. These findings demonstrate that successful use of ML for causal inference depends not only on the ML algorithm but also on how the information obtained through covariate selection is incorporated into causal effect estimation.

## 1. 核心问题与整体含义

- **研究背景**：高维数据下，因果效应估计需要从大量候选协变量中选出能够满足无混杂假设的协变量集，同时正确设定倾向得分（PS）模型与结果模型。传统方法高度依赖领域知识，难以应对高维情形。
- **DML 的作用**：双重/去偏机器学习（DML）通过 Neyman 正交性和样本分割/交叉拟合，缓解正则化偏差与过拟合偏差，使估计量在较弱的收敛条件下仍可达到 \(\sqrt{n}\)-一致性。
- **被忽视的问题**：DML 文献更多强调 Neyman 正交性带来的收敛率性质，而对部分 DML 估计量所具有的**双稳健（DR）性质**与协变量选择之间的关系关注不足。
- **两个关键挑战**：
  - **差异化协变量选择**：PS 模型与结果模型通过 ML 分别选出的协变量集不同，导致即使某一模型本身正确设定，DR 性质也可能不成立，因为该模型无法校正另一模型因纳入额外变量而产生的偏倚放大或碰撞偏倚。
  - **两个模型同时误设**：各自选出的协变量集都可能遗漏正确设定所需的变量，此时 DR 性质不再提供保护，混杂偏倚无法被完全消除。
- **整体含义**：论文主张，在高维因果推断中，协变量选择不应被视为独立预处理步骤，而应作为 DR-DML 估计的有机组成部分；ML 算法本身并不能保证因果估计更优，关键在于如何将协变量选择信息纳入最终估计。

## 2. 方法论

### 核心思想

- 提出使用 **PS 模型与结果模型各自选出的协变量集的并集**，重新估计 PS 模型和结果模型，再代入 DR-DML 估计量。
- 并集策略同时针对两个问题：
  - 消除差异化协变量选择：两个模型最终使用同一协变量集。
  - 提高至少一个模型正确设定的可能性：并集保留任一模型认为重要的协变量，增加 DR 性质成立的机会。

### 关键技术细节

- **基本设定**：考虑异质性处理效应下的 ATE 估计：
  \[
  Y = g(Z,X)+U,\quad E[U|X,Z]=0
  \]
  \[
  Z = m(X)+V,\quad E[V|X]=0
  \]
  其中 \(Z\) 为二值处理，\(X\) 为满足无混杂的协变量，\(m(X)=P(Z=1|X)\)，\(g(Z,X)=E[Y|Z,X]\)。
- **目标参数**：
  \[
  \theta = E[g(1,X)-g(0,X)]
  \]
- **DR-DML 估计量**采用 AIPW 形式：
  \[
  \hat\theta_{DR-DML}=E_n\left[
  \hat g(1,X)-\hat g(0,X)
  +\frac{Z(Y-\hat g(1,X))}{\hat m(X)}
  -\frac{(1-Z)(Y-\hat g(0,X))}{1-\hat m(X)}
  \right]
  \]
- **正则化偏差与 DR-DML 的缓解机制**：正则化使 \(\hat g\) 和 \(\hat m\) 产生一阶偏差，但 DR-DML 的偏差取决于两个估计误差的乘积，例如：
  \[
  E[\hat\theta_{DR-DML}]-\theta
  =
  E\left[
  \frac{\delta_g(1,X)\delta_m(X)}{m(X)+\delta_m(X)}
  +
  \frac{\delta_g(0,X)\delta_m(X)}{1-m(X)-\delta_m(X)}
  \right]
  \]
  因而当两个误差乘积足够快趋于零时，估计量仍可 \(\sqrt{n}\)-一致。
- **DR 性质**：
  \[
  \hat\theta_{DR-DML}\xrightarrow{p}\theta
  \quad\text{若}\quad
  \hat g(z,R_g)\xrightarrow{p}g(z,X)
  \quad\text{或}\quad
  \hat m(R_m)\xrightarrow{p}m(X)
  \]
  其中 \(R_g\)、\(R_m\) 分别为结果模型和 PS 模型使用的协变量集。
- **强调区分**：Neyman 正交性不等于 DR 性质；并非所有 DML 估计量都具有 DR 性质，例如常数处理效应 DGP 下的某些 DML 得分函数只满足 Neyman 正交性，不具备 DR。

### 算法流程

- **Box 1：双 post-Lasso（分别选择协变量）**
  1. 对 PS 模型拟合 logistic Lasso，选出 \(X_{PS}\subset X\)。
  2. 对结果模型拟合 Lasso，选出 \(X_{Y_z}\subset X\)。
  3. 分别用 \(X_{PS}\) 和 \(X_{Y_z}\) 重新拟合 logistic 回归与 OLS。
  4. 将预测的 PS 与结果代入 DR-DML 公式估计 ATE。
- **Box 2：双 post-Lasso 使用并集**
  1. 与 Box 1 相同，分别用 Lasso 选出 \(X_{PS}\)、\(X_{Y_0}\)、\(X_{Y_1}\)。
  2. 构造并集：
     \[
     X_{Union}=X_{PS}\cup X_{Y_0}\cup X_{Y_1}
     \]
  3. 用同一并集重新估计 PS 模型和结果模型。
  4. 将基于并集的预测值代入 DR-DML 公式估计 ATE。
- **与 double selection 的区别**：Belloni 等（2014）的双选择方法主要在常数处理效应 DGP 下将并集用于最终结果模型；本文则在异质性处理效应下，将并集用于同时重新估计 PS 与结果模型，以直接维护 DR 性质。

## 3. 实验设计

- **数据来源**：完全基于模拟研究，未使用真实数据集。
- **数据生成过程**：
  - 两个独立的 p 维混杂变量集 \(A=(A_k)_{k=1}^p\) 和 \(B=(B_k)_{k=1}^p\)，均从 \([-1,1]\) 均匀分布生成。
  - 处理分配：
    \[
    p=P(Z=1|A,B)=\frac{1}{1+\exp\{-\beta_Z'(A+B)\}}
    \]
  - 结果模型：
    \[
    Y=Z+\beta_Y'(A+B)+\beta_{YZ}'Z(A+B)+\varepsilon,\quad \varepsilon\sim N(0,\sigma^2)
    \]
  - 包含处理与混杂变量交互，允许异质性处理效应。
- **实验条件**：
  - 样本量：\(n=500, 2000, 10000\)。
  - 协变量维度：\(p=50,150\)，对应总协变量数 \(2p=100,300\)。
  - 系数衰减率：\(r=0.51\) 和 \(r=1\)，分别代表勉强满足和较强满足近似稀疏性。
  - 每个条件生成 **2000 个数据集**。
- **模型设定场景**：
  - **Scenario 1**：PS 与结果模型初始集均为 \(S=\{A,B\}\)，两者均正确设定。
  - **Scenario 2**：PS 初始集为 \(S\)，正确设定；结果模型初始集为 \(B\)，误设。
  - **Scenario 3**：PS 初始集为 \(A\)，误设；结果模型初始集为 \(S\)，正确设定。
  - **Scenario 4**：PS 初始集为 \(A\)，结果模型初始集为 \(B\)，两者均误设。
- **对比方法**：
  - **DR**：传统双稳健估计，不使用 Lasso；PS 用 logistic 回归，结果用 OLS。
  - **DR-DL**：双稳健 double Lasso，直接使用 Lasso 收缩后的系数预测 PS 和结果。
  - **DR-DPL**：双稳健 double post-Lasso，分别用各自 Lasso 选出的协变量重新估计两个模型。
  - **DR-DPL(U)**：本文提出的双稳健 double post-Lasso 并使用并集重新估计两个模型。
- **Benchmark**：以传统 DR 估计和不同 Lasso 变体作为比较基准；主要评价指标为**剩余混杂偏差比例**，即各估计量偏差除以原始混杂偏差。
- **调参方式**：Lasso 惩罚参数使用 Belloni 等（2012）提出的理论 plug-in 值，而非交叉验证，以减少额外样本分割与调参需求。

## 6. 主要结论与发现

- **并集策略一致更优**：在所有 Lasso 类方法中，DR-DPL(U) 通常剩余混杂偏差最小，且在很多条件下接近传统 DR 估计。
- **并集优势在模型误设时更明显**：Scenario 4 中，两个模型分别误设，不使用并集的方法保留不可忽略的混杂偏差；DR-DPL(U) 通过让每个模型纳入另一模型选出的协变量，显著降低剩余偏差，部分条件下甚至略优于传统 DR。
- **post-Lasso 优于标准 Lasso**：DR-DPL 通常比 DR-DL 剩余偏差更小，说明直接使用 Lasso 收缩系数会损害因果估计，重新无惩罚估计有助于减少混杂偏差。
- **ML 并非自动优于传统 DR**：
  - 当传统方法可稳定使用合适协变量集时，传统 DR 表现很好。
  - 当样本量小、协变量多、系数衰减慢时，Lasso 类方法可能保留更多偏差，甚至不如传统 DR。
  - 即使在对 Lasso 有利的模拟条件下，ML 估计也未全面超越传统 DR。
- **近似稀疏性很关键**：衰减率越慢，预测信号越分散，Lasso 越难保留正确设定所需变量，偏差越大；样本量和衰减率改善后，Lasso 类方法逐渐接近传统 DR。
- **理论兼容性**：并集策略不改变 DR-DML 的 Neyman 正交得分函数，只改变 nuisance 模型的协变量集构造，因此不牺牲 DML 的渐近 \(\sqrt{n}\)-一致性动机。

## 7. 优点

- **问题定位清晰**：明确区分 Neyman 正交性与 DR 性质，指出 DR 性质在协变量选择不当情况下可能失效，弥补了 DML 文献中的空白。
- **方法简洁且针对性强**：并集策略直接对应 DR 性质成立条件，既消除差异化协变量选择，又提高至少一个模型正确设定的机会。
- **超越 double selection 的既有用法**：将并集从常数处理效应下的结果模型设定，扩展到异质性处理效应下同时重新估计 PS 与结果模型。
- **模拟设计系统**：系统变化样本量、协变量维度、稀疏性和模型设定场景，使用 2000 次重复，结果具有较好的稳定性。
- **对 Lasso 有利的 DGP 设置**：作者刻意设计有利于 Lasso 的条件，仍发现 ML 并非普遍优于传统 DR，增强了“不应盲目使用 ML”的说服力。
- **强调实践启示**：明确区分 Lasso 与 post-Lasso，提醒应用研究者二者不可互换；并指出 ML 方法效果依赖其底层假设是否成立。
