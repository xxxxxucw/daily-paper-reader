## 摘要
在分布偏移下提供有用的推荐对于平衡分布外（OOD）推荐中的效用与风险至关重要。然而，现有的大多数OOD方法改进排序或构建反事实候选时，并未对服务集合的代理标签错误发现率（FDR）进行控制。在本工作中，我们将OOD服务形式化为$\alpha$-有效反事实推荐（$\alpha$-VCR）问题，以在控制代理标签FDR的同时保留从反事实监督中学到的候选支持，并提出GenCAR，该方法将偏好基础的反事实监督与校准的集合选择相结合。具体而言，GenCAR在干预环境因素的同时固定稳定偏好表示，通过偏好锚点和信任半径过滤为离线大型语言模型提案提供基础，并使用符合p值进行Benjamini--Hochberg选择。我们在理论上限定了条件反事实近似误差，并证明在可交换性和正向回归依赖下代理标签FDR的有限样本、分布无关控制，同时在任意依赖下提供Benjamini--Yekutieli保证。大量实验审查了实际代理虚假发现比例，并证明GenCAR在不同基准上持续增强OOD候选恢复能力。

## Abstract
Serving useful recommendations under distribution shift is crucial for balancing utility and risk in out-of-distribution (OOD) recommendation. However, most existing OOD methods improve ranking or construct counterfactual candidates without controlling the proxy-label false discovery rate (FDR) of the served set. In this work, we formulate OOD serving as the $α$-Valid Counterfactual Recommendation ($α$-VCR) problem to retain candidate support learned from counterfactual supervision while controlling proxy-label FDR, and propose GenCAR, which couples preference-grounded counterfactual supervision with calibrated set selection. In particular, GenCAR fixes the stable-preference representation while intervening on the environmental factor, grounds offline large language model proposals through preference anchors and trust-radius filtering, and uses conformal $p$-values for Benjamini--Hochberg selection. We theoretically bound conditional counterfactual approximation error and prove finite-sample, distribution-free control of proxy-label FDR under exchangeability and positive regression dependence, with a Benjamini--Yekutieli guarantee under arbitrary dependence. Extensive experiments audit realized proxy false discovery proportions and demonstrate that GenCAR consistently enhances OOD candidate recovery across diverse benchmarks.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心场景**：分布外（OOD）推荐，即训练环境与在线服务环境的交互分布不同（时间、曝光、流行度等发生变化）。
- **既有问题**：
  - 多数 OOD 推荐方法只改进排序或构造反事实候选，未在“服务集合”层面控制推荐项的错误发现率（FDR），导致服务结果中可能混入大量与用户稳定偏好不一致的低质量候选。
  - 生成式反事实方法能扩充候选，但其优化目标（重构或个性化排序）缺乏对稳定偏好的显式约束，生成结果可能保留环境特有模式。
  - 传统可控推荐方法假设候选族固定且标签已知，无法同时处理“新生成的反事实候选”和“服务阶段风险控制”。
- **目标**：提出一个两阶段框架，在保留反事实候选支持的同时，控制服务集合中“代理标签”层面的 FDR，从而显式平衡 OOD 推荐中的效用与风险。
- **整体含义**：将 OOD 推荐的服务问题形式化为 `α-有效反事实推荐（α-VCR）`问题，并把生成式反事实构造与共形推断/选择相结合，使 OOD 推荐“在统计上有保证地”控制风险。

## 2. 论文提出的方法论

### 2.1 整体框架：GenCAR
- 两阶段、三模块：
  1. **偏好锚定反事实构造（离线）**
  2. **代理标签风险校准（离线）**
  3. **风险受控服务（在线，无 LLM 调用）**

### 2.2 核心思想
- 在潜在结构因果模型（SCM）中，将交互建模分解为：
  - 稳定用户偏好 \(z_c\)、环境因子 \(z_e\)、个体噪声 \(\eta\)。
- 反事实干预固定 \(z_c\)，仅改变环境因子 \(z_e\) 为 \( \tilde{z}_e \)，以生成符合目标环境且保留稳定偏好的候选。
- 离线阶段利用 LLM 生成候选，但通过“偏好锚点 + 信任半径过滤”约束其与稳定偏好一致；在线阶段不调用 LLM，仅由学好的编码器、排序器和校准产物完成服务。

### 2.3 关键技术细节
- **偏好–环境分解**：CausalVAE 式骨干网络，采用 ELBO + BPR + 解耦损失训练；
- **偏好锚点（anchor projection）**：将用户偏好向量映射为 Top-K 物品 ID 及描述，供 LLM 理解用户偏好；
- **信任半径过滤**：LLM 生成的候选须在物品嵌入空间中与用户偏好表示的余弦距离 ≤ δ（默认 0.7），否则丢弃；
- **反事实微调**：仅更新物品嵌入，用反事实 BPR 损失优化，保持编码器固定；
- **代理对齐预测器**：以 LLM 对齐分数（阈值 τ=0.85）构造二值代理标签，训练 \( \hat{h}(u,j) \) 预测代理对齐概率；
- **共形 p 值**：对代理无效（proxy-null）的校准样本，计算非一致性分数 \(V=1-\hat{h}\)，用弱秩 p 值；
- **FDR 控制选择**：BH 过程或 BY 过程（任意依赖）选出满足条件的最大嵌套集合；空集表示弃权。

### 2.4 核心公式与流程
- 反事实集合：\( \mathcal{C}^\text{cf}_u = \{ \tilde{j} \in \hat{\mathcal{I}}_u \cap \mathcal{I} : d_0(\tilde{j}, z_c^{(u)}) \le \delta \} \)
- 反事实微调损失：\( \mathcal{L}_\text{CF}(E) = - \sum_{u} \mathbb{E}_{(j^+,j^-)}\left[ \log \sigma(\langle z_c^{(u)}, e_{j^+}\rangle - \langle z_c^{(u)}, e_{j^-}\rangle) \right] \)
- 共形 p 值：\( p(u,j) = \frac{1 + \sum_{\text{cal}} \mathbf{1}[V_i \le V(u,j)]}{1 + n_0} \)
- BH 阈值：\( \hat{k}_\alpha = \max\{ k : p_{(k)} \le \alpha k / N \} \)
- 服务集合：\( \mathcal{S}_\alpha(\mathcal{M}) = \{(u,j) \in \mathcal{M}: p(u,j) \le \alpha \hat{k}_\alpha / N \} \)

## 6. 论文的主要结论与发现

- GenCAR 在五个候选池上均使经验代理 FDR 低于设定的 α（0.30），说明风险控制有效；
- 相比共享 CausalVAE backbone，Recall@10 在 ML-100K 提升 11.0%，Coat 提升 19.1%，Amazon-Book 提升 43.5%，且在所有 9 个“数据集×种子”组合上均正向；
- 在不使用在线 LLM 的方法中，GenCAR 在三个主基准上取得最高平均 Recall@10，甚至在某些数据集上优于在线 LLM 的 TallRec；
- 消融表明：增益来自于偏好锚定的反事实内容，不只是额外训练配对数量；候选新颖性与排序增益可分离；信任半径存在稳定工作区间；KL-clamp 因稳定偏好因子化同时提升新颖性与恢复；
- GenCAR 保持亚毫秒在线时延和与 backbone 相同的参数量，LLM 仅在离线阶段使用；
- 在部分离线覆盖（38%）下，GenCAR 仍能保持骨干水平，若使用显式保留反事实项的 rerank 变体则还能提升 Recall@10 9.2%。

## 7. 优点

- **问题定义清晰**：将 OOD 服务定义为 α-VCR，同时优化候选支持和 FDR 约束；
- **方法设计创新**：将生成式 LLM 反事实候选限制在由稳定偏好表示定义的“信任半径”内，再把 LLM 的产物转化为离线监督，保证在线无 LLM；
- **理论保证较完善**：对反事实构造的误差传播、候选集选择的最大性、共形 p 值的有效性，以及 BH/BY 的 FDR 控制，都给出了有限样本、分布无关的证明；并有向因果错配转移的误差界定；
- **实验体系较完整**：验证了风险控制有效性、候选恢复增益，并通过匹配增强、不同 LLM、trust radius 扫描、逐种子检验等消融隔离了各种解释；
- **实用导向强**：报告参数量、训练时间、在线时延、部分覆盖场景，并区分离线 LLM 与在线 LLM，设计动机贴近落地；
- **可复现考虑**：数据集均为公开资源，并计划发布代码与产物（GitHub 仓库）。

## 8. 不足与局限

- **代理标签可靠性**：FDR 保证只针对代理标签，真实因果错配风险依赖代理的覆盖质量（论文用 Δ_proxy 量化，但无法彻底消除代理误差）；LLM 对齐分数的误差会直接传播到选择结果；
- **实验多样性有限**：主基准只有三个中小规模数据集（Amazon-Book 较大但稀疏严重），未包含真实工业推荐日志；缺少对超大型、多域、高动态环境的验证；
- **部分实验仅在单一 α 下报告风险值**（如 α=0.30），对 α 变化带来的敏感性分析较少；
- **资源信息不完整**：未报告 GPU 数量、总训练时长、能耗等，部分实现细节（LLM 调用缓存机制、DeepSeek-Chat 推理成本）未量化；
- **离线 LLM 依赖**：虽然在线无 LLM，但离线构造仍依赖 LLM 输出质量和预算，在长尾/冷启动物品描述缺失时可能生成不稳定；
- **统计假设限制**：Theorem 1 需要目标环境内校准分数与测试分数的可交换性及 PRDS 条件，某些真实推荐环境难以保证；BY 变体虽处理任意依赖，但可能因修正使服务集偏保守（保留更少候选）；
- **用户级保证不提供**：FDR 是对批次池化的，不保证单个用户的错误率，论文承认这一点；
