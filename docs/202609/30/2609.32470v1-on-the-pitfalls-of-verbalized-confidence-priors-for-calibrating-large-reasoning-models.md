## 摘要
大型推理模型（LRMs）在表达其不确定性时常表现出过度自信。置信度感知的强化学习（RL）为优化校准提供了一种有前景的方法。然而，它依赖于同策略 rollout，因而受限于模型在 RL 前的置信分布，我们将其称为置信先验。在这项工作中，我们揭示现成的 LRMs 表现出一种高度集中于少数高值的置信先验，并且这种集中现象贯穿 RL 始终。理论上，我们证明这种集中会抑制对罕见采样置信值的策略梯度更新，并抬高期望 Brier 风险的下界。为克服这一探索瓶颈，我们提出 CalibSFT，这是一种即插即用的监督微调阶段，可在 RL 之前塑造具有广泛支撑的校准置信先验。对于每个问题，CalibSFT 构建结合其成功率与响应级正确性的置信目标，该目标可证明保持适当评分最优性，然后跨置信谱平衡训练响应，以在 RL 期间实现多样化的置信探索。为了从不正确响应中学习而不模仿其推理，CalibSFT 引入正确性条件监督，在所有响应上引导置信度，同时仅对正确响应监督推理。在 16 个数学与通用推理基准上，融入 CalibSFT 在五种代表性 RL 算法中降低了校准误差并提升了区分度，同时保持相当的准确率。此外，CalibSFT 为下游选择性预测和模型路由带来实际收益。我们的代码可在 https://github.com/ml-stat-Sustech/verbalized-confidence-training 获取。

## Abstract
Large reasoning models (LRMs) often suffer from overconfidence when expressing their uncertainty. Confidence-aware reinforcement learning (RL) offers a promising way to optimize calibration. However, it relies on on-policy rollouts and is thus constrained by the model's pre-RL confidence distribution, which we term confidence prior. In this work, we reveal that off-the-shelf LRMs exhibit a confidence prior heavily concentrated on a few high values, which persists throughout RL. Theoretically, we prove that this concentration suppresses policy gradient updates for rarely sampled confidence values and inflates the lower bound on expected Brier risk. To overcome this exploration bottleneck, we propose CalibSFT, a plug-and-play supervised fine-tuning stage that shapes a calibrated confidence prior with broad support before RL. For each question, CalibSFT constructs confidence targets combining its success rate with response-level correctness, which provably preserves proper-scoring optimality, and then balances training responses across the confidence spectrum to enable diverse confidence exploration during RL. To learn from incorrect responses without imitating their reasoning, CalibSFT introduces correctness-conditional supervision, guiding confidence across all responses while supervising reasoning only on correct ones. Across 16 mathematical and general reasoning benchmarks, incorporating CalibSFT reduces calibration errors and improves discrimination across five representative RL algorithms while preserving comparable accuracy. Furthermore, CalibSFT delivers practical benefits for downstream selective prediction and model routing. Our code is available at https://github.com/ml-stat-Sustech/verbalized-confidence-training.

# 论文总结：论言语化置信先验在大型推理模型校准中的陷阱

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型推理模型（LRMs）在数学、编程等复杂任务上准确率显著提升，但准确率提升并不等于置信度可靠。模型在给出错误答案时往往仍表达很高的置信度（过度自信）。
- **可靠置信度的价值**：良好校准的置信度（与正确概率匹配）可支撑选择性预测（selective prediction）与模型路由（model routing）等下游决策。
- **言语化置信度（verbalized confidence）的优势与问题**：
  - 优势：只需一次黑盒生成即可获得置信度，无需访问 token 概率、内部表示或多次采样。
  - 问题：现成 LRMs 输出的置信度高度集中于少数高值，且无论正确与否都如此。
- **现有校准路径**：基于构造目标的监督微调（SFT）与基于校准奖励的强化学习（RL）。其中置信度感知 RL 因泛化能力更强而更具前景。
- **核心瓶颈（论文的关键洞察）**：置信度感知 RL 依赖 on-policy rollout，因此优化本质上受限于 RL 之前的置信分布，作者将其称为**置信先验（confidence prior）**。该先验高度集中于少数高值，即使校准奖励明确惩罚误校准，这种集中也会在 RL 全程持续。
- **研究意义**：揭示该探索瓶颈不仅限制训练，还导致 RL 后置信度无法反映任务难度——例如 MinervaMath 上 Pass@1 比 Math500 低 39.1%，而平均置信度仅低 9.7%。

## 2. 方法论：核心思想、技术细节与理论支撑

### 2.1 核心思想
- 提出 **CalibSFT**：一个**即插即用**的监督微调阶段，在置信度感知 RL **之前**塑造一个“支撑广泛且校准”的置信先验，从而打破 on-policy 探索瓶颈。
- 不改动任何 RL 目标函数，仅改变初始化，因此可无缝集成到任意置信度感知 RL 框架。

### 2.2 关键技术细节

**(a) 构造保持 proper scoring 最优性的置信目标**

- 对每个问题 $x$ 采样 $n$ 个响应，得到正确性 $z_i \in \{0,1\}$ 与成功率 $q_x = \frac{1}{n}\sum_i z_i$。
- 构造混合目标：$c^*_i = \lambda q_x + (1-\lambda) z_i$，兼顾问题级难度校准与响应级区分度。
- **命题 3（混合目标的 proper-scoring 最优性）**：对任意严格 proper scoring 损失 $\ell$，有 $\mathbb{E}[C^*_i \mid x] = p_x$，且 $\mathbb{E}[\ell(\hat{c}, C^*_i)\mid x] = \mathbb{E}[\ell(\hat{c}, Z_i)\mid x]$，故 $p_x$ 仍是唯一最小化点。即混合目标在 rollout 分布下保持问题级最优置信度。
- 方差分析：相比二值标签，混合目标将方差从 $v_x$ 降至约 $0.265\,v_x$（降幅超 73%）；默认取 $n=50$、$\lambda=0.5$，组内正确/错误响应目标间距为 $1-\lambda=0.5$。

**(b) 目标平衡采样（target-balanced sampling）**

- 由于大量问题被全部解出或全部失败，61% 的原始目标恰为 0 或 1，直接训练会使 SFT 先验再次集中到两端。
- 做法：按目标值分组，每组均匀抽取等量响应（以最小组的数量为准），最终得到每个目标值 349 个样本、共 34,900 个样本（覆盖 11,539 个问题）。

**(c) 正确性条件监督（correctness-conditional supervision）**

- 目标：从错误响应中学习“低置信度”，但不模仿其错误推理。
- 损失函数：$\mathcal{L}_{\text{CalibSFT}} = (1-\beta)\,\mathbb{E}_{\text{correct}}[\text{推理/答案 token 的 NLL}] + \beta\,\mathbb{E}_{\text{all}}[\text{置信度 token 的 NLL}]$，默认 $\beta=0.5$。
- 即：推理与答案 token 仅在正确响应上监督，置信度 token 在所有响应上监督；分段平均以避免长推理序列主导损失。

### 2.3 理论分析（支撑动机）

- **命题 1（集中先验下的策略梯度抑制）**：softmax 策略下 $\frac{\partial J_h}{\partial \eta_i} = \pi_i(u_i(h)-J_h)$，且 $|\partial J_h/\partial\eta_i| \le \pi_i \Delta_h$。若某主导动作 $\pi_k = 1-\varepsilon$，则 $\|\nabla_\eta J_h\|_1 \le 2\varepsilon\Delta_h \le 2\varepsilon$。说明罕见采样的置信值梯度被压制，RL 难以逃离次优初始化。
- **命题 2（先验错位下的 Brier 风险下界）**：在 $C \perp Z \mid h$ 下，$\mathbb{E}[(C-Z)^2\mid h] \ge p_h(1-p_h) + \delta^2(1-m_\delta(h))$。当策略很少采样接近 $p_h$ 的值时，多余误差趋近 $\delta^2$；若支撑集远离 $p_h$，则有 $\ge p_h(1-p_h)+\text{dist}(p_h,S_h)^2$。还扩展到 best-of-G 采样：$\mathbb{E}[\min_{i\le G}(C_i-p_h)^2] \ge \delta^2(1-m_\delta(h))^G$。

## 4. 资源与算力

- **硬件**：单节点、8 张 NVIDIA B20Z GPU（SFT 与 RL 均在此配置下）。

## 6. 主要结论与发现

- **发现 1**：现成 LRMs 的置信先验高度集中于少数高值（如 Qwen3-8B 的 Top-3 质量占 93.94%，置信度 <0.5 的比例仅 0.61%），且该集中现象在 RL 全程持续。
- **发现 2**：置信度感知 RL 虽能降低 ECE，但 AUROC 不升反降（校准–区分度权衡）；置信 token 熵长期偏低，每题采样的不同置信值数量很少，限制了探索。
- **发现 3**：CalibSFT 初始化在全部 5 种 RL 方法上同时降低 Brier 与 ECE、提升 AUROC，且不损失平均精度（ID Pass@1 平均 +1.20，OOD 平均 +1.49）。
- **发现 4**：CalibSFT 缓解 RL 后的置信度集中（如 DCPO 在 MinervaMath 上 ECE 从 29.05% 降至 8.83%），并使置信度与任务准确率的相关性显著增强（如 DCPO Spearman 从 0.619 升至 0.976）。
- **发现 5**：增益在不同推理 token 预算、置信度格式、模型架构、其他置信度估计器上均稳健。
- **发现 6**：下游收益显著——选择性风险控制中在固定风险预算下大幅提升 certified coverage（OOD 20% 风险预算下，基线均为 0%，CalibSFT 达 16.8%–22.8%）；模型路由中在 $\varepsilon=2\%$ 容差下平均降低 27.7 个百分点的延迟率（如 DCPO 从 82.9% 降至 33.3%，token 节省从 5.6% 升至 43.5%）。
- **核心结论**：校准 RL 的瓶颈在于置信先验探索不足；在 RL 前塑造校准且支撑广泛的先验，可有效提升校准与区分度，并带来实际部署价值。

- **问题洞察新颖且深刻**：首次明确提出“置信先验”概念，指出 on-policy RL 的探索瓶颈源于先验集中，并用理论（命题 1、2）严格刻画梯度抑制与 Brier 风险下界。
- **理论与方法紧密耦合**：命题 3 证明混合目标在任意严格 proper scoring 规则下保持最优性，方法设计有理论

支撑；命题 1、2 则直接解释“为什么必须先验干预”，形成“诊断—理论—干预—验证”的闭环。
- **干预方式轻量且即插即用**：不修改任何 RL 目标、奖励或信用分配机制，仅替换初始化；CalibSFT 的额外算力仅约占 RL 的 6.9%，且 rollout 池可离线采集并跨方法复用，工程落地成本低。
- **实验证据链完整**：从机制层面（置信 token 熵、distinct values、支撑集大小）到指标层面（Brier、ECE、AUROC、PCE、RCE）再到应用层面（选择性风险控制、模型路由）逐层验证，避免了“只报单一指标好看”的常见问题。
- **统计与公平性处理到位**：下游应用给出有限样本保证（Clopper–Pearson 上界 + union bound）；RL 基线保留原奖励设计；多种子验证方差；消融使用共享响应池，控制了混杂因素。
- **结论具有反直觉价值**：明确指出“降低 ECE ≠ 提升区分度”，并展示置信度感知 RL 可能在 AUROC 上倒退，这一发现对后续校准研究具有纠偏意义。

## 8. 局限性与潜在问题

- **置信先验的可迁移性边界未充分刻画**：CalibSFT 的 rollout 池固定于 DeepScaleR-Preview 与特定 prompt 格式，论文虽声称可复用，但未系统检验当目标任务的难度分布、推理长度分布或领域（如代码、多模态）显著偏移时，先验塑造是否仍然有效。
- **依赖可验证正确性的场景假设**：混合目标 $c^*_i=\lambda q_x+(1-\lambda)z_i$ 需要自动判定响应正确性（如数学答案匹配），对开放式生成、主观任务或无法可靠判分的长程任务，$q_x$ 的估计本身不可得，方法的适用范围受限。
- **组内目标间距固定为 $1-\lambda=0.5$ 可能过于刚性**：论文默认 $\lambda=0.5$，但组内正确与错误响应被赋予同一问题级偏移下的固定间隔，未必匹配真实的条件正确概率结构；虽然做了 $\lambda$ 扫描，但未探索响应级难度自适应间距。
- **理论命题的假设较强**：命题 2 依赖 $C \perp Z \mid h$ 的条件独立性假设，而在同一 prompt 下模型正确性与所报置信度往往存在相关性（例如“难题上错误响应也偏低置信”），此时下界的形式与紧致性可能需要重新审视；命题 1 的梯度上界是最坏情形 $L_1$ 范数界，与实际训练中 Adam 等自适应优化器的动态之间缺少桥接分析。
- **评测置信度均为单次采样**：主实验以温度 0.6 采样一次读取言语化置信度，虽然补充了自一致性与 token 概率估计器，但对多采样聚合、温度敏感性、prompt 措辞敏感性等方差来源的刻画仍不完整。
- **模型规模与架构覆盖有限**：仅验证 Qwen3-8B 与 Gemma4-E2B-Instruct 两个骨干，缺少对更大规模（如 70B 级）或非指令微调基座的检验，CalibSFT 是否在更强先验集中（大模型往往更过度自信）下仍有效尚不明确。
- **“校准–区分度权衡”的机理解释仍偏现象学**：论文观察到 RL 后 AUROC 下降并归因于先验探索受限，但未给出形式化的因果论证（例如区分度下降是否必然由熵降低导致，抑或与奖励塑形引入的表示漂移有关）。
- **选择性风险控制中 OOD 基线为 0% 的解读**：certified coverage 从 0% 提升到 16.8%–22.8% 虽显著，但绝对水平仍偏低，论文对该结果在实际部署中的可用性讨论较简略。

## 9. 总体评价

本文的核心贡献在于把“置信度校准”从**目标函数设计问题**重新表述为**初始化/探索问题**：作者指出，置信度感知 RL 无论奖励如何精心设计，都受制于 RL 前的置信先验集中，因而难以在训练中被纠正。围绕这一洞察，论文给出三个层次的工作——理论刻画（命题 1、2 说明梯度抑制与 Brier 风险下界）、方法设计（CalibSFT 的混合 proper-scoring 目标、目标平衡采样、正确性条件监督）、以及跨 16 个 benchmark、5 种 RL 方法、多模型与多格式的系统验证——形成较完整的证据闭环。

方法层面的关键巧妙之处在于：混合目标 $c^*_i$ 在保持问题级最优置信度 $p_x$ 的同时，把响应级标签方差降低逾 73%，再配合目标平衡采样避免先验重新坍缩到 0/1 两端，从而使 RL 从一个“支撑广泛且已校准”的先验出发，既提升了 Brier/ECE，也恢复了 AUROC，并最终转化为选择性预测与模型路由上的实际收益。相较于直接改动 RL 奖励的做法，这种“只动初始化”的策略具有低耦合、低开销、可复用的工程优势。

总体而言，论文问题选得准、理论支撑扎实、实验规模充分、结论具有实践指导意义，是置信度校准方向一篇兼具洞察力与工程价值的系统性工作。其主要待完善之处在于跨领域/跨任务的先验可迁移性验证、对无法自动判分场景的适配，以及理论假设与真实训练动态之间的进一步桥接。
