## 摘要
随着大型语言模型越来越多地通过外部工具行动，决定何时调用工具已成为与决定如何使用工具并列的核心问题。不必要的工具调用会引入延迟、成本、检索噪声和错误传播，而遗漏调用则会损害需要最新证据的知识密集型查询或问题。现有方法通常从绝对查询或生成信号（如难度、置信度或最终任务奖励）触发工具，因此缺乏对工具使用的实例级边际收益的显式估计。我们提出CoBRA，一种用于工具增强型语言模型的反事实边界学习框架。CoBRA首先从同一基础模型构建内部和外部专家，收集配对轨迹，并估计有工具与无工具回答之间的奖励边际。该边际将数据划分为内部偏好、外部偏好和模糊情况。然后，CoBRA使用清晰边际样本进行边界感知冷启动SFT，随后进行带有参考分割轨迹和反事实边际优势的MARS-RL，以优化边界决策。以检索作为主要工具在Qwen3-4B上的实验表明，CoBRA提高了工具使用效率和边界敏感的答案准确性，同时在依赖工具的分布外问题上保持了强劲性能。

## Abstract
As large language models increasingly act through external tools, deciding when to call a tool has become a central problem alongside deciding how to use it. Unnecessary tool calls introduce latency, cost, retrieval noise, and error propagation, while missed calls hurt knowledge-intensive queries or questions requiring up-to-date evidence. Existing methods typically trigger tools from absolute query or generation signals, such as difficulty, confidence, or final task reward, and therefore lack an explicit estimate of the instance-level marginal benefit of tool use. We propose CoBRA, a counterfactual boundary-learning framework for tool-augmented language models. CoBRA first constructs internal and external experts from the same base model, collects paired trajectories, and estimates the reward margin between answering with and without tools. This margin partitions data into internal-favored, external-favored, and ambiguous cases. CoBRA then uses clear-margin samples for Boundary-Aware Cold-Start SFT, followed by MARS-RL with reference-split rollouts and counterfactual marginal advantages to optimize boundary decisions. Experiments with retrieval as the main tool on Qwen3-4B show that CoBRA improves tool-use efficiency and boundary-sensitive answer accuracy while maintaining strong performance on tool-dependent out-of-distribution questions.

## 1. 核心问题与研究动机

- **问题背景**：大语言模型（LLM）越来越多地通过外部工具（检索器、搜索 API 等）完成任务。此时"**是否调用工具**"与"**如何调用工具**"同等重要。工具调用并非总是有益的：过度调用会引入延迟、API/Token 成本、检索噪声，甚至因无关证据覆盖模型正确内部知识而造成错误传播；反之，漏调又会损害知识密集型、时效性强的查询。
- **现有方法局限**：已有自适应检索/工具触发方法多基于**绝对信号**——如查询难度（Adaptive-RAG）、模型置信度（Self-RAG）、复杂度预测或最终任务奖励。作者指出这些信号均不完备：难题不一定需要工具，高置信度也可能因知识过时/长尾而出错；最终答案奖励也无法将"工具对答案的贡献"从整体决策中剥离。
- **核心论点**：工具路由应被建模为**实例级别的反事实决策**——"与仅靠内部知识作答相比，对该查询调用工具能否提升期望效用？"作者用数据表明，不同基准中内部偏好/外部偏好/模糊样本的占比差异极大（如 TriviaQA 偏外部、2WikiMultiHop 偏内部），因此不能用粗粒度的数据集身份或难度实现路由。

## 2. 方法论：CoBRA 框架

CoBRA 是一个两模块、四阶段训练框架，核心在于利用**成对反事实奖励差**驱动路由决策。

### 2.1 总览与效用函数
- 每个轨迹 τ 的标量效用定义为：
  **R(τ) = S(τ) − λ·C(τ)**（公式 1）
  - S(τ)：统一评分器给出的任务正确性；
  - C(τ)：工具使用成本（默认按调用次数计）；
  - λ：精度–成本权衡系数。

### 2.2 反事实边界发现（Counterfactual Boundary Discovery）

- **双专才构建（Dual-Expert Construction）**：从同一基础模型 M₀ 出发，通过拒绝采样微调构造两个策略不同但共享相同来源的专家：
  - **内部专家 Mint**：在无工具条件下用推理正确作答；
  - **外部专家 Mext**：必须调用检索工具并整合返回证据后正确作答。
- **反事实边际估计**：对查询 q，分别获得内部与外部轨迹，估算边际：
  **Δ̂(q) = R(τ_ext|q) − R(τ_int|q)**（公式 2）
  实际实现中采用大规模查询集 + 每分支单次确定性 rollout（以样本量降方差），而非小样本重复采样。
- **三分数据划分**（阈值 ε）：
  - **D_int**（内部偏好）：Δ̂ < −ε 且内部正确；
  - **D_ext**（外部偏好）：Δ̂ > ε 且外部正确；
  - **D_amb**（模糊）：其余，包含近并列与"两分支均失败"样本。
- 关键设计：双双失败样本归入 D_amb，防止因外部分支承担工具成本而误判为"内部更优"。

### 2.3 边界感知策略优化（Boundary-Aware Policy Optimization）

**阶段一：边界感知冷启动 SFT**
- 仅使用 D_int ∪ D_ext 中清晰偏好样本；
- 统一系统提示词与工具 schema，模型学习自主决定调用工具，而非依赖提示词强制分支；
- 排除 D_amb，防止在模糊样本上注入噪声硬标签；输出为具备路由能力的 M_warm。

**阶段二：MARS-RL（Marginal Advantage from Reference-Split Rollouts）**

- **参考分裂 Rollout（RS）**：对每个模糊查询分别从两条分支采样，内部分支抑制首选工具输出，外部分支从工具调用前缀开始；保证组间可比，使奖励差真实反映工具价值。
- **分支内归一化优势（PBN）**：在各自分支内计算组归一化优势，避免高质量内部轨迹因外部总体高分而被误压。
- **分支边际项（BM）**：
  **Δ_B(q) = mean(R, G_ext) − mean(R, G_int)**（公式 4）
  归一化后以正负号按分支注入：
  **A_MARS_i = A_within_i + β·sign(T_i)·Δ̃_B(q)**（公式 6）
- **优化目标**：PPO 式裁剪目标（公式 7–8），KL 系数 β_KL 约束到参考策略 π_ref（即 M_warm）。

## 6. 主要结论与发现

1. **一致性阶段递进**：强制外部专家 M_ext 相对 M_int 在 ID/OOD 上提升 jEM 约 19.15 pp / 27.88 pp，证明检索在"用得正确"时高度有效。
2. **冷启动 SFT 提升精度–成本平衡**：M_warm 相较 M_ext 减少 ID 上 47.0% 工具调用，同时将 ID 效用从 0.3544 提升至 0.4148。
3. **MARS-RL 进一步优化路由而非盲目加调工具**：CoBRA 相对 M_warm，ID jEM 提升 9.15 pp、OOD 提升 9.04 pp，OOD 平均工具调用次数反而从 1.034 略降至 0.997。
4. **主结果**：5 个数据集上 CoBRA 在 4 个取得最佳 jEM；相比 Search-R1-3B，效用 ID +0.0759 / OOD +0.0866 且工具调用分别减少 20.1% / 22.2%；在 D_amb 模糊边界子集取得最高 jEM 0.9658，且比 Search-R1-3B 用更少工具调用。
5. **消融验证**：RS、PBN、BM 三组件缺一不可；Vanilla GRPO 和仅 RS 变体在最终答案奖励下塌缩为不动用工具的退化策略；warm-init 对 MARS 类变体提升约 9.5–16.5 pp，说明冷启动 SFT 为后续反事实 RL 提供了必需的路由先验。
6. **垂域泛化**：在音乐垂域智能体中，混合奖励从 2.428 升至 2.680 的同时，工具调用率由 39.3% 降至 25.1%，离线 Hit@5 / 相关性 / 事实性指标均超越内部模型、盲用工具基线及无 RL 的冷启动变体。

## 7. 方法/实验亮点

- **显式反事实边际信号**：将工具路由从"建模查询难度"转为"建模工具边际效用"，提供了直接可优化的训练信号。
- **双专家源自同一基础模型**：同源约束保证内部/外部策略可比，排除了因基座不同带来的混淆。
- **数据分区差异化使用**：清晰样本用于监督冷启动，模糊样本交给 RL 探索，与学习理论中的"困难样本渐进式学习"思路一致，避免噪声硬标签。
- **MARS-RL 的优势估计结构**：分支内归一化（PBN，等价于分支内 GRPO/RLOO）与分支间信号（BM）解耦，修正了标准组相对优势估计对"路由结构潜在变量"的盲区；同时对分支存在系统性奖励偏移（如外部承担 λC 成本）具有鲁棒性。
- **单一模型零额外推理开销**：不引入"先想再说"或额外评判器 token，最终路由由模型一次生成决策完成，有利于工业部署。
- **指标设计严谨**：jEM 主指标兼顾严格匹配与语义等价并附置信度量；同屏报告工具调用与效用（牺牲精度换成本/效用分离）。
- **垂域与通用域双验证**：显著提升了结论可推广性。

## 8. 不足与局限

- **验证范围有限**：仅以 Qwen3-4B + 检索工具为主，未覆盖其他模型家族、其他工具类型（计算器/API/搜索+检索同现）与多工具协同场景。
- **边际依赖 rollout 质量与超参**：反事实边际质量受双专家 SFT 轨迹、检索器质量、评分器可靠性影响；λ 与 ε 的取值需要人工设定，且对数据划分有显著影响。
- **工具成本建模较粗**：主要用"调用次数"近似成本，未考虑延迟差异、API 价格、隐私/安全约束等真实部署中的多元效用。
