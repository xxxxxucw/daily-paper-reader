## 摘要
许多序贯分布漂移检测器会用新到的观测更新一个不断增长的参考集。一旦发生漂移，这种更新会使得参考集混入漂移后的观测，从而削弱后续的证据。保持校准样本固定可以缓解这种污染，但重复使用会导致固定参考秩之间产生相依性，因此基于独立保形p值的论证不再适用。我们推导了给定前序秩时下一个秩的精确条件零分布，并据此构造了预测秩鞅(PRM)。对PRM设定阈值，即可实现分布无关、有限样本、任意时点有效的边际第一类错误控制。为了针对特定的偏离，我们对每个秩应用一个预设的特征，在预测零分布下对相应的收益进行中心化，并使用在线牛顿步(ONS)来适应性地设定赌注。有序特征和离散特征分别针对方向性变化和中心与尾部之间的变化。对于任意在备择假设下非零诱导对比度的Lipschitz特征，我们建立了有限窗口的检测保证，并证明随着初始校准样本量的增大，检验是一致的。然而，在固定的校准样本量下，我们为任何分布无关的检测方法导出了一个功效上限。在合成数据和真实数据上，我们的PRM方法在检测性能上优于条件保形检验鞅(CCTM)。

## Abstract
Many sequential distribution shift detectors update a growing reference set with incoming observations. After a change, this update contaminates the reference set with post-change observations and can weaken subsequent evidence. Keeping the calibration sample fixed mitigates this contamination, but repeated reuse induces dependence among fixed-reference ranks, so arguments based on independent conformal \(p\)-values do not apply. We derive the exact conditional null distribution of the next rank given the preceding ranks and use it to construct a predictive rank martingale (PRM). Thresholding a PRM gives distribution-free, finite-sample anytime marginal type I error control. To target specific departures, we apply a pre-specified feature to each rank, center the resulting payoff under the predictive null law, and use Online Newton Step (ONS) to adapt the bet. Order and dispersion features target directional and center-versus-tail changes, respectively. For any Lipschitz feature with nonzero induced contrast under the alternative, we establish a finite-window detection guarantee and show that the test is consistent as the initial calibration size increases. At a fixed calibration size, however, we derive a power ceiling for every distribution-free detection procedure. Across synthetic and real data, our PRM methods achieve better detection performance than conditional conformal test martingale (CCTM).

### 二、论文提出的方法论

- **核心思想**：
  - 用一个固定的初始校准样本（D0）来计算新观测 X_t 的秩 R_t，但这些秩并不独立。
  - 关键观察：在零假设且分布连续时，X_1, …, X_n 的校准样本所对应的经验分布函数的分位数（gap），其分布为对称的 Dirichlet 分布，秩变量在该分位数向量下为条件独立分类变量。
  - 基于共轭性，可推导出精确的**预测秩定律**：给定过去观测到的秩，下一次观测落入各秩槽的概率满足：
    \[
    \pi_{t,j} = \frac{1 + N_{t-1,j}}{n+t}
    \]
    其中 N 为历史中出现过该秩的计数。
  - 利用该“预测规律”作为对赌的参考分布，构建非负鞅（称为预测秩鞅，PRM）：M_t = ∏ q_{t,R_t} / π_{t,R_t}。

- **关键技术与步骤**：
  1. **预测秩定律（Predictive Rank Law）**：该定律将固定参考样本导致的秩依赖通过 Pólya urn 结构表示，并用于构造精确的零分布。
  2. **特征的引入**：
     - 为了利用检验法则定位特定漂移，对每个秩施加一个**预设的特征函数 h**（对均匀分布均值为零且值域宽度 ≤1）。
     - **Order PRM**：h(u) = u - 0.5（Mann–Whitney / CCTM 线性得分）针对方向性/位置漂移。
     - **Dispersion PRM**：h(u) = |2u-1| - 0.5（Ansari-Bradley 风格得分）在均值不变、方差改变等中心与尾部对称的场景中有效。
  3. **特征收益与中心化 (Predictively Centered Feature Betting)**：
     - 根据预测分布对 h（(Rt-1)/n）的所有可能取值进行中心化，得到零条件均值收益 Z_t。
     - Z_t 在备份下的漂移通过特征对比度 Δh(P,Q) 联系起来。
  4. **ONS（在线牛顿法）自适应投注**：
     - 为了让检验在未知的方向和大小的漂移下都能生效，使用 ONS 根据历史收益动态调整下注的方向与强度，将累计对数边际财富最大化。其使用了可投影区间以保证对数收益足够远离零。
  5. **PRM 投资组合**：
     - 线性组合多个不同特征的 PRM（如等权合并 Order PRM 与 Dispersion PRM），形成一个新的非负鞅，同时保留多种漂移检测的能力且受边际类型 I 错误控制。
  6. **理论保障线**：
     - 阈值化 PRM：当财富 M_t ≥ 1/α 时，拒绝零假设（可随时打停）。
     - **有限窗功率保证**：对每个 Lipschitz 特征给出（一旦主要特征的非零对比度被激活），数量有限的 online 观测即可完成检测的保证。并证明了当校准样本 n →∞ 时的普通一致性。
     - **无自由 lunch 定理**：规定当校准样本固定时，对任何分布无关检测器都存在“功效上限”，并证明了在此之上进行校准条件的控制将剥夺非平凡功效。
