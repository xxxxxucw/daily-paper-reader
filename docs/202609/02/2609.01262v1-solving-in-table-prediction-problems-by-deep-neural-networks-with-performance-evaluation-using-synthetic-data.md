## 摘要
表格深度学习利用神经网络从表格数据中提取模式。传统的表格深度学习方法遵循监督学习范式，其中明确给定目标特征。然而，在本工作中，我们探索了一种不同的方法，即使用深度神经网络学习给定表格中各列之间的关系。我们研究神经网络能否基于剩余已知列预测给定表中任意选定列的值。我们将此问题称为表内预测，它与表格插补方法和表格深度学习的预训练任务略有不同。我们确定了三种潜在的使用场景，据我们所知，这些场景在文献中尚未得到广泛研究。我们采用自监督学习方法来解决此问题，通过随机选择要掩蔽并用作学习目标的列。本工作聚焦于仅包含连续特征的表格数据集。为了处理连续特征中的缺失值，提出了一种新颖的神经网络层，用于同时嵌入数值和空值。基于预定义的列关系生成合成数据，并使用两种不同的机制插入空值。此外，采用自适应的掩蔽策略来创建测试数据。使用生成的合成数据评估了三种神经网络架构（即MLP、ResNet和Transformer）的性能。我们得出结论：当训练样本数量足够大且选择相对较大的嵌入长度时，基于注意力的结构优于其他两种网络。我们强调，这些发现是在可控的合成条件下、列数较少的情况下获得的，因此应视为初步的、范围有限的研究，而非对真实世界表格数据上表内预测问题的普遍性描述。

## Abstract
Tabular deep learning (TDL) leverages neural networks (NN) to extract patterns from tabular data. Traditional TDL methods follow a supervised learning paradigm, where a target feature is explicitly given. In this work, however, we explore a different approach by employing deep NNs to learn relationships among individual columns within a given table. We investigate whether NNs can predict the values of arbitrarily selected columns in a given table based on the remaining known columns. We call this problem In-Table Prediction (ITB), which is slightly different from table imputation methods and the pretraining task of TDL. Three potential usage scenarios are identified, which, to our best knowledge, have not been extensively studied in the literature. A self-supervised learning approach is applied to address this problem by randomly selecting columns to be masked out and used as learning targets. This work focuses on tabular datasets containing only continuous features. To handle missing values in continuous features, a novel neural layer is proposed to embed both numerical and empty values. Synthetic data is generated based on predefined column relationships, with empty values inserted using two distinct mechanisms. Additionally, an adapted masking strategy is employed to create test data. Performances of three NN architectures, namely MLP, Resnet and Transformer, are evaluated using the generated synthetic data. We conclude that, the attention-based structure outperforms the other two networks, when a sufficiently large number of training examples is available and a relatively large embedding length is chosen. We stress that these findings are obtained under controlled, synthetic conditions with a small number of columns and it should therefore be regarded as an initial, narrowly-scoped investigation rather than a general characterization of ITP on real-world tabular data.

## 1. 论文核心问题与研究意义

- **研究背景**：表格数据（tabular data）的结构化、异构性使其长期被视为深度学习较难攻克的领域。传统方法或依赖 GBDT 等树模型，或采用监督学习设定——预先指定某一列作为目标特征，利用其余列进行预测；预训练/自监督方法也多作为面向下游任务的中间步骤。
- **本文要解决的问题**：提出了一个在文献中较少被关注的“表内预测”（In-Table Prediction，正文中简称 ITP）问题，即给定一张表的其他列，预测该表中**任意被选中的列**的取值。预测目标列不事先固定，可以是任意列。
- **与相关任务的区别**：
  - 与缺失值插补的区别：缺失值插补针对表中的 `NaN`，目的是让完整表可被下游流程使用；而 ITP 针对的是用户指定的掩蔽位置，且 `NaN` 本身是特殊状态，模型需要“恢复”该位置原本是数值还是 `NaN`。
  - 与表格深度学习中自监督/预训练任务的区别：本文不将学习结果用于监督下游任务，而是独立、直接地解决表内任意列的预测。
- **三个可能应用场景**：(1) 新行创建时向用户实时提供列值建议；(2) 因技术原因丢失/损坏的部分列内容恢复；(3) 通过人为掩蔽并预测，验证表中某些位置是否符合整体数据一致性。
- **研究范围**：仅处理**连续特征的表格**；不涉及类别特征。实验基于合成数据，作者明确说明这是**受控、窄范围的首轮探索**，而非对真实表上 ITP 的普遍性结论。

## 2. 方法论

- **总体思想**：采用基于掩蔽的自监督训练策略。对每个训练样本，随机选择若干列的位置插入掩码（mask），并将这些位置作为学习目标；模型依据剩余未掩蔽列推测被掩蔽位置的标签或数值。
- **输入与掩蔽预处理**：
  - 每个位置的状态可能为：实数值、`NaN`（空值）、掩码 ζ。
  - 训练阶段使用“按最大掩蔽数 MBMN”策略：随机插入 0 到 nmax 个掩码；nmask ≤ K−1，K 为列数，从而支持“用任一已知量预测其余所有量”的场景。
  - 测试阶段则使用“确定性关系掩蔽 MFDR”策略：先删除无法由其余列唯一确定掩码位置的样本，确保掩蔽位置的取值能够在理论上由未掩蔽列推出。
- **嵌入层（核心创新点）**：提出一个同时建模数值、空值与掩码的可学习嵌入层：
  - 数值 x：为每个列维护一个可学习表向量 ei,1，乘以该数值得到嵌入 x·ei,1；
  - `NaN`：直接用该列的第二个可学习向量 ei,2 表示；
  - 掩码 ζ：用该列的第三个可学习向量 ei,3 表示。

  f_embedding(xi)= { xi·ei,1, if xi∈R; ei,2, if xi=NaN; ei,3, if xi=ζ }

- **三种骨干网络**：复用成熟结构，不引入列顺序位置编码（因表列天然无序），并替换自定义嵌入层与输出头：
  1. MLP：线性层、ReLU、Dropout；
  2. ResNet：多层带 BatchNorm、Dropout、残差连接；
  3. Transformer：只使用编码器部分，含多头注意力与 LayerNorm。
- **输出与损失函数**：
  - 每个列的输出是 3 维向量：前两维表示“该位置是空值” vs “是数值”的分类概率；第三维是回归的数值（仅在真实为数值时得到监督）；
  - 损失只在被**掩蔽的位置**上计算：分类用交叉熵判空/数值，数值用 MSE 回归；`NaN` 不参与回归项（见原文式 2）。
- **训练细节**：Adam、learning rate=0.0001、batch size=256、早停 patience=20；网络深度和宽度全部固定，未做超参数搜索。

## 3. 实验设计

- **合成数据**（关键设计）：
  - 数据集 A——线性关系：x2 = x0 + x1 + τd，其中 x0, x1 ∈ [−π/2, π/2]，d~N(0,1)；
  - 数据集 B——指数关系：x2 = e^(−1/16·(cos x0 + cos x1)) + τd，x0, x1 ∈ [0, π]；
  - 这样列间关系**先验已知**，便于判断是否真的学到了依赖关系；噪声强度 τ 可调，实验中固定在 τ=0.01。
- **空值插入机制**：
  - MAR：某特征的缺失概率由其他特征的状态决定（本文实现为“其他列之和 ≥ 0.5 时该列置为空”）；
  - MNAR：某特征缺失概率由自身值决定（本文实现为“自身值 ≥ 0 时置空”）；
  - NoNaN：不插入空值（对照组）。
  - 作者提到 MCAR 未评价，因为 MCAR 无可学习规律。
- **对照基准与变量设置**：
  - 模型：MLP vs ResNet vs 注意力网络（Transformer）；
  - 掩蔽最大数：nmax=1 或 nmax=2；
  - 训练规模：100、1000、10000、50000；
  - 嵌入长度：D=32、128、256、512；
  - 数据生成函数 × 遮蔽机制 × 模型类型 × 掩码数 × 训练大小 × D 构成全网格搜索。
- **评估指标**：
  - NRMSE：预测数值与真实值的归一化均方根误差；
  - accuracy：仅针对掩蔽位置，判断“是否为空值”的二分类正确率。

## 6. 主要结论与发现

- **模型结构**：当训练样本量大（N ≥ 10000）时，注意力/Transformer 在大多数测试情境下优于 MLP 与 ResNet；指数数据集上准确率表现出明显优势。
- **数据规模效应**：性能随 N 增大而提升；线性数据在 N=10000 左右趋于饱和，而指数数据没有趋势放缓的说法，更多数据可能有更多增益。
- **掩码数量效应**：大训练集下，测试时以“掩蔽 ≤ 1”训练通常优于“掩蔽 ≤ 2”，仅在指数数据、MAR、N=10000 的个别情况例外。
- **缺失机制影响**：
  - 线性数据在 N=50000 时三种缺失机制差异不大；
  - 指数数据中，NoNaN 情境下 MLP 与 ResNet 明显败给注意力网络，注意力网络在 NoNaN 下仍可保持与 MAR/MNAR 相近表现；
  - MNAR 的准确率整体低于 MAR，MNAR 被认为是更困难的学习引入机制（可能推理模式更依赖先推断真实值再推缺失）。
- **嵌入长度影响**：嵌入长度 D 对 MLP/ResNet 的 NRMSE 影响不大，但显著影响注意力网络：线性数据上 D≥128 后趋于饱和，指数数据需 D≥256（MAR/NoNaN）；MNAR 下 D 最大到 512 也未明显饱和。

## 7. 优点

- **问题定义新颖**：明确区分 ITP、MVI 与既有表深度学习自监督的差异；将“空值”作为合法状态而不是待删除的噪声，预测范围同时覆盖数值与空值。
- **方法论自然**：嵌入层设计简洁，用三个可学习向量同时表达“数值加权/NaN/掩码”三个状态，融入现有 MLP/ResNet/Transformer 结构后改动小、通用性好。
- **损失函数自洽**：仅对掩蔽位置计算分类+回归混合损失，回归只在真实值为数字时激活，契合任务目标的设置。
- **实验设计严谨而克制**：用已知数学关系的合成数据（线性/指数）能精确检验模型是否“真的学到列关系”；MBMN 与 MFDR 分开处理“训练任务构造”与“测试可否预测”，后续在指标选择（NRMSE + 准确率）上也匹配了分类与回归的双重损失。
- **对局限坦诚**：强调所有结论仅在可控合成条件下成立，不夸大为真实表上的普遍效用。
