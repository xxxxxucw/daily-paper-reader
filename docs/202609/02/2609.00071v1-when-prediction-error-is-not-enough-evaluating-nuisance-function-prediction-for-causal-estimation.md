## 摘要
预测误差被广泛用于评估因果推断中的干扰函数估计器，但其与因果估计器性能的关系可能因性能指标的不同而有所差异。我们在部分线性模型中通过蒙特卡洛模拟研究了这一问题。我们比较了普通最小二乘法（OLS）、广义加性模型（GAMs）、XGBoost以及使用XGBoost的双机器学习（DML-XGBoost），评估了干扰函数预测误差、偏差、均方根误差（RMSE）和95%置信区间覆盖率。我们还考察了一种基于暴露和结局干扰函数估计误差的绝对交叉乘积的简单联合误差度量。在模拟设置中，XGBoost在非神谕方法中具有最低的RMSE，而DML-XGBoost通常提供更好的置信区间覆盖率。预测误差在不同方法和设置中并未始终与因果偏差保持一致，并且点估计性能最佳的方法不一定具有最佳的置信区间覆盖率。联合误差度量与因果偏差仅弱相关，不能作为因果性能的有用独立度量。这些结果表明，预测误差有助于评估干扰函数估计，但不应将其视为所得因果估计器质量的直接度量。

## Abstract
Prediction error is widely used to evaluate nuisance-function estimators in causal inference, but its relationship with causal estimator performance may differ across performance measures. We studied this question in a partially linear model using Monte Carlo simulations. We compared ordinary least squares (OLS), generalized additive models (GAMs), XGBoost, and Double Machine Learning with XGBoost (DML-XGBoost), evaluating nuisance-function prediction error, bias, RMSE, and 95\% confidence interval coverage. We also examined a simple joint-error measure based on the absolute cross-product of estimation errors from the exposure and outcome nuisance functions. Across the simulated settings, XGBoost had the lowest RMSE among the non-oracle methods, while DML-XGBoost generally provided better confidence interval coverage. Prediction error did not consistently track causal bias across methods and settings, and the method with the best point-estimation performance did not necessarily have the best confidence interval coverage. The joint-error measure was only weakly associated with causal bias and did not provide a useful standalone measure of causal performance. These results suggest that prediction error is useful for assessing nuisance-function estimation, but it should not be treated as a direct measure of the quality of the resulting causal estimator.

## 1. 论文的核心问题与整体含义

- **研究动机**：在因果推断中，估计因果效应（如处理效应 τ）通常需要先估计干扰函数（nuisance functions），例如暴露回归函数和结局回归函数。实际研究中常使用预测误差（如交叉验证误差、MSE）来评估这些干扰函数模型的好坏。
- **核心问题**：本文提出一个关键问题——**干扰函数的预测误差，是否能够反映最终因果估计器的性能？** 即“预测得好”是否意味着“因果估计得好”。
- **整体含义**：如果预测误差不能可靠地表征因果估计的质量，那么仅靠预测指标选择模型或调参可能会误导因果推断。因此需要实证检验预测误差与因果偏差、RMSE、置信区间覆盖率之间的关系。

## 2. 方法论

- **基础模型**：使用部分线性模型：
  - \(X_i = m_0(C_i) + \epsilon_{Xi}\)
  - \(Y_i = \tau X_i + g_0(C_i) + \epsilon_{Yi}\)
  - 其中 \(m_0(C)=\mathbb{E}(X|C)\) 和 \(h_0(C)=\mathbb{E}(Y|C)=\tau m_0(C)+g_0(C)\) 是需要估计的两个关键干扰函数。
- **预测误差定义**：
  - 对拟合函数 \(\hat m(C)\)、\(\hat h(C)\)，定义误差 \(\delta_m = \hat m - m_0\)、\(\delta_h = \hat h - h_0\)；
  - 边际预测误差为 \(E_m = \mathbb{E}[\delta_m^2]\)、\(E_h = \mathbb{E}[\delta_h^2]\)，在独立评估样本上计算。
- **联合误差度量**：
  - 定义 \(D_{\text{joint}} = |\mathbb{E}\{\delta_m(C)\delta_h(C)\}|\)，捕捉两个干扰函数误差的平均对齐程度；但作者强调它只是描述性诊断，并非完整的正交分数余项度量。
- **因果估计方法**：
  - 对暴露和结局分别拟合干扰函数，得到残差 \(\tilde X_i = X_i - \hat m(C_i)\)、\(\tilde Y_i = Y_i - \hat h(C_i)\)；
  - 通过简单的残差回归 \(\hat\tau = \frac{\sum_i \tilde X_i \tilde Y_i}{\sum_i \tilde X_i^2}\) 估计常数处理效应。
- **不同估计流程**：
  - OLS、GAM、XGBoost：使用同一残差化估计器，但用不同学习器拟合干扰函数；
  - DML-XGBoost：在 XGBoost 基础上结合交叉拟合（cross-fitting）和 Neyman 正交化；
  - 在聚类场景中，交叉拟合按“簇”分割，保证同一簇的所有观测在同一折内。
- **推断**：基于影响函数（influence function）估计标准误，构建 Wald 型 95% 置信区间；聚类场景使用簇级分数贡献进行方差估计。

## 6. 主要结论与发现

- **点估计与推断表现分离**：在非 Oracle 方法中，XGBoost 的 RMSE 最低（如 Scenario 1 RMSE=0.0143），但置信区间覆盖率较差（0.856）；DML-XGBoost 的 RMSE 较大（0.0372），而覆盖率更好（0.928）。
- **预测误差不能一致预测因果偏差**：预测误差最好的方法不一定是推断校准最好的方法；XGBoost 的干扰函数预测误差低于 DML-XGBoost，但其 CI 覆盖率却更差。
- **联合误差度量价值有限**：\(D_{\text{joint}}\) 与绝对因果偏差之间的相关性很弱（相关系数约在 \(-0.11\) 到 \(0.11\) 之间），不适合作为独立筛选因果估计器的指标。
- **实践建议**：预测误差对于“干扰函数是否被合理估计”仍是有用指标，但**不应作为因果估计质量的直接代理**；需要结合点估计偏差、RMSE、覆盖率等最终因果指标进行综合判断。
